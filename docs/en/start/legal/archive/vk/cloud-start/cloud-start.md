The "Cloud Start" Program (hereinafter — the **"Program"**) has been developed by VK Limited Liability Company (OGRN: 1027739850962) (hereinafter — the **"Organizer"**) and is intended to attract and retain on the "VK Cloud" Platform companies (legal entities or individual entrepreneurs) developing digital products and services.

## 1. Terms and Definitions

**Program** — the "Cloud Start" program, providing special terms of use of the VK Cloud, VK WorkSpace, and VK ID platforms (jointly — the **Platforms**) for Participants of the Program.

**Rules** — this document, which is a public offer, posted on the Internet at: [https://cloud.vk.ru/promopage/сloud-start](https://cloud.vk.ru/promopage/сloud-start).

**Program Term** — the term of the Program during which applications for participation in the Program may be submitted.

**VK Cloud Platform / VK Cloud** — a computer program accessible to the User via the website [https://cloud.vk.ru/](https://cloud.vk.ru/) and operated by the Organizer, which allows the User, in accordance with the terms of the Agreement, to create and delete Projects, to create and delete within such Projects Accounts for Users of the Projects, as well as to grant and restrict access of such Users to selected Services.

**VK WorkSpace Platform / VK WorkSpace** — a computer program accessible to the user via the website [https://biz.mail.ru/](https://biz.mail.ru/), which allows the user, in accordance with the terms of the agreement for the VK WorkSpace Platform, to create and delete projects, to create and delete within such projects accounts for end users of the projects, as well as to grant and restrict access of such end users to selected VK WorkSpace services.

**Agreement** — the agreement on the provision of access services to the VK Cloud Platform, concluded between the Organizer and the User, which includes the Terms of Use of the VK Cloud Platform, Agreements on the Use of individual Platform Services, the Organizer's Privacy Policy, posted on the website [https://cloud.vk.ru/docs/ru/start/legal/archive/vk](https://cloud.vk.ru/docs/ru/start/legal/archive/vk).

**User** — a person possessing the necessary legal capacity to conclude the Agreement, who has created an Account on the VK Cloud Platform. A User who has been granted the status of a Program Participant by the Organizer in accordance with the conditions listed in section 3 of the Rules is also referred to as a "Program Participant".

**Account** — information provided by the User (the presence of which is a necessary condition) for registration and subsequent authorization of the User on the VK Cloud Platform in the process of the Organizer providing services to them, which consists of a name (login), a password for accessing the Personal Account (password), as well as other information. Access to the Account is carried out through the Personal Account.

**User's Personal Account** — a closed area of the VK Cloud Platform that allows the User to manage settings, edit the User's Account, access statistical data, as well as perform other actions necessary for the implementation of the functionality of the VK Cloud Platform and individual Services.

**Price List** — the Internet page [https://cloud.vk.ru/pricelist](https://cloud.vk.ru/pricelist) indicating the cost of the Services of the VK Cloud Platform.

**Service** — a software module of the VK Cloud Platform that makes it possible to implement individual functional capabilities within the VK Cloud Platform, which are provided by the Organizer or the Organizer's partners. Granting the User the right to use any Service does not depend on the provision of access to other Services.

**Customer's Bonus Balance (account)** — a set of records reflecting the accrual/write-off by the Organizer of points to the User when paying the User compensation in connection with the Organizer's violation of the agreed level of services. The Bonus Balance is reduced by the amount of services connected by the User on the VK Cloud Platform (including when applying the special terms of use of VK Cloud established by section 5.1 of these Rules). If funds are available on both the Bonus Balance and the Personal Balance, write-offs are made first from the Bonus Balance, then from the Personal Balance.

**Customer's Personal Balance (account)** — a set of records reflecting the financial relationship between the User and the Organizer regarding the services provided. The User's Balance is increased by the amount of funds transferred by the User to the Organizer and credited by the Organizer to the User's Balance as prepayment for services, and is decreased by the cost of services connected by the User.

If the Rules use terms for which definitions are not given in this section of the Rules, the definitions of these terms from the Agreement and (or) the agreements on the use of the VK WorkSpace and VK ID Platforms, accepted by the User on the websites of the respective Platforms, shall apply.

## 2. Program Term

2.1. The Program is valid from November 1, 2024 to March 1, 2025 inclusive.

The special terms of use of the Platforms provided for by section 5 of the Rules are valid for 3 (three) months from the date the User is granted the status of Program Participant.

## 3. Conditions of Participation in the Program

3.1. You may participate in the Program if you simultaneously:

* Are a new User of VK Cloud services, which means: (1) if the User joined the Program (submitted an application to participate in the Program) in 2024: the User has not previously had an Account on VK Cloud, registered an Account on the VK Cloud Platform no earlier than "01" January 2023 and no later than "01" January 2024, and did not pay for Access Services to the Services in 2024. In this case, the Program Participant's account on the VK Cloud Platform must be registered as a legal entity or individual entrepreneur.
* Submitted an application to participate in the Program and received confirmation of participation from the Program Organizer.

3.2. To apply the special terms of use of VK WorkSpace services listed in clauses 5.2, 5.3 of the Rules, the Program Participant must be a new user of VK WorkSpace services; you are a new user if: (1) in case of joining the Program in 2024: you registered an account/management console on these Platforms no earlier than "01" January 2024 and did not pay for the services in 2024; the Program Participant's account on the VK WorkSpace Platform must be registered as a legal entity or individual entrepreneur.

3.3. **Restrictions**. The special program terms do not combine with other promotions and discounts. The Program does not apply to new projects under an existing contract.

3.4. Requirements for the Participant: The minimum monthly payment to participate in the program is 3,000 (three) thousand rubles.

## 4. Application to Participate in the Program

4.1. To participate in the Program, you must submit an application on the Website [https://cloud.vk.ru/promopage/сloud-start](https://cloud.vk.ru/promopage/сloud-start). Applications may be submitted until December 20, 2024 inclusive.

4.2. **By submitting an application to participate in the Program and clicking the "Submit Application" button, the User, acting of their own free will and in their own interest, expresses their full and unconditional consent to the Organizer with the Program Rules.**

4.3. The application is reviewed by the Organizer within 5 (five) business days. Based on the results of reviewing the application and assessing the User's compliance with the Program criteria specified in section 3 of these Rules, the Organizer decides whether to grant the User the status of Program Participant or to refuse to grant such status. The User unconditionally agrees that the Organizer reserves the right to refuse to grant the User the status of Program Participant at its own discretion without explanation.

Information about the decision made is sent to the phone number, as well as to the email address of the User specified when submitting the application.

4.4. If you have a personal VK Cloud manager and you are already in communication regarding the terms of commercial use of the platform, participation in the Program is confirmed by the personal manager.

## 5. Special Terms of Use of the Platforms for Program Participants

5.1. **The Program Participant is provided with the following special terms of use of the VK Cloud Platform:**

5.1.1. For 3 (three) months from the date of approval of the Application to participate in the Program, the Program Participant gains access to the Services specified in clause 5.1.2 on the VK Cloud Platform under special terms:

* 3 (three) months of using the Services at a 50% discount from the prices specified in the Price List

    The reporting period for the use of Services for the purposes of acceptance and payment is 1 (one) calendar month. If the Participant joins the Program during a calendar month, the first partial reporting period (from the date of granting the Participant status and the start of using the Services until the end of the current calendar month) and the last partial reporting period (from the beginning of the calendar month until the expiration of the 3-month validity period of the special terms) are, for the purposes of applying the special terms, considered one full month.

**Restrictions on the application of special terms:**

* The special terms apply to the following VK Cloud Services: Cloud Servers, VK Object Storage, Managed Containers, Cloud Databases (MySQL, PostgreSQL, MongoDB, Redis, ClickHouse, Tarantool), Cloud Spark, Cloud Kafka, Cloud Flink, Cloud ML Platform, Vision, Voice, Cloud Backup.
    
    Payment for the use of other Services is made by the User on general terms based on the prices specified in the Price List.
    
    The special terms do not apply to Licensed products, Marketplace products, and CDN.
    
* The maximum amount of benefits used by the Participant, including the amount of the 50% discount and the amount of Bonus Points accrued to the Participant within the test period, for the entire period of the Participant's participation in the Program is **no more than 2,000,000 (two million rubles), VAT included**. If this amount is exceeded, payment for the use of other Services is made by the User on general terms based on the prices specified in the Price List.

5.1.2. Consultation on the use of cloud services for hosting the User's product on the VK Cloud Platform (one consultation from a VK Cloud expert).

5.1.3. Free basic technical support in accordance with the terms posted on the website [https://cloud.vk.ru/](https://cloud.vk.ru/).

5.1.4. If the monthly consumption within the Program amounts to 50,000 (fifty thousand) rubles or more, a one-time bonus of 10,000 (ten thousand) bonus rubles will be credited, which can be spent on VK Cloud products.

5.2. VK Workspace Platform

For 1 (one) year from the date of approval of the Application to participate in the Program, the Program Participant is granted the right to use VK WorkSpace services at a 30% discount from the base cost of the "Beneficial" (Vygodny) plan (the plan description is available at the link [https://biz.mail.ru/tariffs/](https://biz.mail.ru/tariffs/)). The subscription includes the following set of VK WorkSpace tools: business email, calendar, messenger with video calls, drive, and document editor. Upon the expiration of 1 (one) month from the date of granting the Participant status, the User selects a plan for using VK Workspace services available on the website [https://biz.mail.ru/tariffs/](https://biz.mail.ru/tariffs/) and pays for it in full on standard terms.

## 6. Exclusion from the Program

A User may be deprived of the status of Program Participant in the event of any of the following circumstances:

* The User has not started using the special terms on VK Cloud before January 1, 2025. In this case, the Organizer notifies the User of the termination of the Participant status by sending a notification to the Participant's email address specified when submitting the application, 14 (fourteen) calendar days before the date of exclusion from the Program.
* Suspicious activity has been detected in the User's Project, or the Project does not comply with the Conditions of Participation in the Program. In this case, the Organizer notifies the User of the termination of the Participant status by sending a notification to the Participant's email address specified when submitting the application, 7 (seven) calendar days before the date of exclusion from the Program.

From the moment of the User's exclusion from the Program, the special terms of use of VK Cloud and VK WorkSpace provided for by section 5 of these Rules cease to be valid. Starting from the day following the day of the User's exclusion from the Program, payment for services on the VK Cloud and VK Workspace Platforms is made on the basis of the tariffs published on the websites of the Platforms.
