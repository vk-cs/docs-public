## 4. Selection Criteria for the Program

4.1. **Scientific Significance**. The project must have clear research objectives, a research program with timelines and expected results at each stage. The results of the program implementation must contribute to solving a scientific problem or a socially significant issue.

4.2. **Technology Focus**. The implementation of the project must involve the use of computing capacity in the VK Cloud and cloud services.

4.3. **Scientific Openness**. The project team must be ready to publicly share the results of the project implementation, the experience of applying cloud technologies for solving the task, and to mention VK Cloud as a technological partner of the project.

4.4. **Scalability**. The possibility of expanding the project or replicating it in other areas.
