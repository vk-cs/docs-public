- Terms of Use of the "VK Cloud" Platform;
- Agreements on the use of individual Services of the Platform;
- Contractor's Privacy Policy.

1.4. **"VK Cloud" Platform (Platform)** — a computer program available to the Customer through the Website and operated by the Contractor, which provides the Customer with access to selected services, the list of which is available on the Website.

1.5. **Website** — an Internet website located at: [https://cloud.vk.ru/](https://cloud.vk.ru/), providing access to the Platform and the Contractor's Services, where the Contractor, among other things, posts information mandatory for the Customer, including all its subdomains and pages containing the Promo Code and the conditions for granting a Discount and (or) other extended capabilities of the Service based on such Promo Code. 1.6. **Promo Code Activation Period** — the time period established by the Company and specified on the Website, during which the Customer can activate the Discount and start using other extended capabilities of the Service.
Currently, the Promo Code activation period is set at 7 (seven) calendar days from the moment of Notification.

1.7. **Discount** — a reduction in the standard Tariff amount provided that the Customer fulfills the conditions for activating the Promo Code and the conditions for granting the Discount specified on the Website.

1.8. **Promo Code Validity Period** — the period of time after the activation of the Promo Code during which the Customer is given the opportunity to use the Service with a Discount or use other extended capabilities of the Service.
The Promo Code grants the right to receive a Discount only if the Promo Code is activated within the period specified in the Notification.

1.9. **Promo Code Nominal Value** — the minimum promo code size is 3,000 bonus points. The maximum promo code size is 50,000 bonus points.
The crediting of the promo code Nominal Value is carried out in the format of bonus points in the user's Personal Account.

1.10. **Promo Code Activation** — entering the Promo Code into a specially designated field in the Client web interface or another action provided for by the terms of use of the Promo Code.

1.11. **Bonus Points Validity Period** — 30 (thirty) calendar days from the moment of accrual. After the specified period, bonus points expire.
Terms not specified in these Rules are used in the meaning given to them in the Applicable Rules.

These Rules are posted at: [https://cloud.vk.ru/docs/ru/start/legal/loyalty-programs/policy-promocode](/en/start/legal/loyalty-programs/policy-promocode) and are an integral part of the Applicable Rules.
