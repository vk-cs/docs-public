## {heading(Service readiness stages)[id=support-info-stages]}

[cols="1,3", options="header"]
|===
| Stage
| Description

| Beta
| Preliminary versions of services at the testing stage. Suitable for developers willing to use services whose stability is not guaranteed: failures or incorrect operation of some functions are possible.

Beta versions of services are not billed; their use is free of charge. If a beta version of a service uses any billable {var(cloud)} service during operation, that service is charged according to the [price list](https://cloud.vk.ru/pricelist).

Technical support for beta versions is limited: providing a response and fixing even critical errors is not guaranteed, the {linkto(../sla#support-sla)[text=service level agreement (SLA)]} does not apply, and the response waiting time is not limited.

Documentation for beta versions may be incomplete or missing.

| General Availability
| Stable versions of services available to all users for purchase. They can be fully used to solve tasks.

Billing terms apply to these services, and technical support is provided in full in accordance with the {linkto(../sla#support-sla)[text=service level agreement (SLA)]}.

|===

## {heading(Support competencies)[id=support-info-competence]}

Technical support:

- Provides architecture consultations regarding the use of {var(cloud)} services.
- Performs diagnostics of resource issues on a project.
- Handles questions of restoring access to a {linkto(../../../tools-for-using-services/account/faq#tools-account-faq)[text=account]}.
- Provides information on billing.
- Consults on resolving issues in the platform.
- Assists with configuring {var(cloud)} services.

{note:warn}
The {var(cloud)} technical support team does not administer or support operating systems and other services created using the Platform, unless this is agreed upon in a separate agreement.
{/note}

## {heading(Notifications from technical support)[id=support-info-notifications]}

The support team informs customers about failures that occurred with a service or resource in the customer's account, and also provides recommendations on eliminating potential issues in the customer's project.

Notifications also include informing project owners about security threats or other cases that may result in data loss or interruptions in access to {var(cloud)} services.

## {heading(Individual support)[id=support-info-individual]}

The list of {var(cloud)} platform services includes the option of providing priority support (Professional Services).

This service includes extended support on all issues of implementation, maintenance, and troubleshooting in customer projects:

- System administration 24/7:

  - outsourcing of IT infrastructure and cloud services;
  - technical support;
  - monitoring and availability support;
  - incident response;
  - recovery after failures.

- Audit and consulting:

  - architecture consulting;
  - infrastructure audit;
  - performance audit.

- Configuration and implementation:

  - monitoring setup;
  - backup, high availability (HA), and disaster recovery systems setup;
  - updating PaaS service software;
  - migration of data and information systems.

[Learn more](https://cloud.vk.ru/professional-services/) about the service and submit a request for a cost estimate.
