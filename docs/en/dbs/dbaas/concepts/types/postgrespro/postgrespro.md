# {heading(Postgres Pro)[id=dbaas-postgrespro]}

{include(/en/_includes/_translated_by_ai_en.md)}

Postgres Pro is an object-relational DBMS developed by Postgres Professional based on the open-source PostgreSQL DBMS. Postgres Pro is included in the [Russian software registry](https://reestr.digital.gov.ru/reestr/301574/?sphrase_id=3439534).

Postgres Pro differs from PostgreSQL in improved performance under load, optimized memory consumption, and greater fault tolerance. Releases of this DBMS follow PostgreSQL releases, but several versions of Postgres Pro may be released based on a single PostgreSQL version.

The following are available in {var(cloud)}:

- [Postgres Pro Standard](https://postgrespro.ru/docs/postgrespro/14/);
- [Postgres Pro Enterprise](https://postgrespro.ru/docs/enterprise/14/).

For more information about the features of various versions of Postgres Pro Standard and Enterprise, see the [official documentation](https://postgrespro.ru/docs/). The supported additional modules are described in Appendix F.

The list of supported versions is available when {linkto(../../../instructions#dbaas-instructions)[text=creating]} a Postgres Pro Standard or Postgres Pro Enterprise instance.
