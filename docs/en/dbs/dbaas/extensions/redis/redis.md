## {heading(Redis Metrics Exporter)[id=dbaas-extensions-redis-exporter]}

Module name in the management console: `redis_exporter`.

Redis Metrics Exporter allows collecting metrics for a Redis DB (for more details, see the [official documentation](https://github.com/oliver006/redis_exporter) on GitHub).

An example of configuring monitoring based on Prometheus+Grafana+Redis Exporter is provided in the [official documentation](https://mcs.mail.ru/docs/ru/additionals/cases/cases-monitoring/case-redis-exporter) of {var(cloud)}.
