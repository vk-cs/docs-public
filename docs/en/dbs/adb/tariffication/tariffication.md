## {heading(What is billed)[id=adb-tariffication-list]}

- CPU (vCPU) — for each core. 1 vCPU corresponds to 1 physical core of the virtualization server.
- RAM — for each 1 GB of RAM.
- Arenadata DB Enterprise Full and Arenadata DB Enterprise Test licenses — for each TB of the total storage size.
- Disks — for each 1 GB of disk space, the price depends on the disk type (SSD, High-IOPS).
- {linkto(../../../networks/balancing/concepts/about#balancing-load-balancer-types)[text=service load balancers]}.

## {heading(What is not billed)[id=adb-tariffication-not-list]}

- Incoming and outgoing traffic.
- Monitoring.
