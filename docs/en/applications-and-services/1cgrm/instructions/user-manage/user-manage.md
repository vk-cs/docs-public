## {heading(Adding users)[id=1cgrm-user-manage-add]}

If you have a user information base, contact {linkto(../../../../applications-and-services/1cgrm/concepts/about#1cgrm-support)[text=technical support]} to upload it to the 1С application.

If you do not have an information base, add users manually.

{tabs}

{tab(Personal dashboard)}

1. [Go to](https://msk.cloud.vk.ru/app/) the {var(cloud)} personal dashboard.
1. Go to the **1С:Ready workplace** → **Applications** section.

{include(/en/_includes/_1c_app.md)[tags=1c_app_transition]}

1. Authenticate in the 1С application. To do this, use the login and password of the 1С application administrator account created when {linkto(../../../../applications-and-services/1cgrm/connect#1cgrm-connect-settings-1c)[text=connecting the service]}.
1. Add users in the 1С application.

   {note:warn}
   
   To protect data, set passwords for all users who will work with the 1С application.
   
   {/note}

1. Provide the users who will work with the 1С application with:

   - the login and password of their account.
   - a link to the application.

{/tab}

{/tabs}

## {heading(Changing the number of licenses)[id=1cgrm-user-manage-editing-licenses]}

{tabs}

{tab(Personal dashboard)}

1. [Go to](https://msk.cloud.vk.ru/app/) the {var(cloud)} personal dashboard.
1. Go to the **1С:Ready workplace** → **Applications** section.
1. Click ![ ](../../../../assets/more-icon.svg "inline") for the desired application and select **Edit**.
1. Change the number of licenses depending on the {linkto(../../../../applications-and-services/1cgrm/concepts/about#1cgrm-modes)[text=operation mode]} of the 1С application:

   - file mode: from 1 to 5 licenses;
   - client-server mode: from 6 to 50 licenses.

1. Click **Save changes**.

{/tab}

{/tabs}
