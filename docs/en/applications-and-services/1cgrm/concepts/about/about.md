# {heading(About the service)[id=1cgrm-about]}

{include(/en/_includes/_translated_by_ai_en.md)}

{var(cloud)} together with Firm 1C offers a ready-made infrastructure solution for your business — the 1C:Ready Workplace service (1C:GRM).

The service provides a convenient interface for launching infrastructure for 1C products deployed in the {var(cloud)} cloud infrastructure. This allows you to use only the 1C:GRM applications you need, without having to deploy, update, and maintain 1C:GRM yourself. {var(cloud)} ensures fault tolerance, stable operation, and secure data storage.

You can work with 1C:GRM applications in {var(cloud)} through a browser from any device with internet access. A free {linkto(../../../1cgrm/tariffication#1cgrm-tariffication-demo-period)[text=trial period]} of 30 days is provided for testing application functionality, after which payment is made monthly only for the resources actually used. The number of licenses can be increased as needed.

1C:GRM in {var(cloud)} is backed by qualified {linkto(#1cgrm-support)[text=technical support]}.

## {heading(Modes of working with applications)[id=1cgrm-modes]}

Depending on the number of licenses needed, an application can be created in two modes:

- **File mode**, from 1 to 5 licenses. This mode is recommended for infobases where simultaneous operation of up to 5 users is expected. A file infobase is provided with up to 30 GB of total data volume, including 5 GB for the working infobase and 25 GB for all of its backup copies.
- **Client-server mode**, from 6 to 50 licenses. This mode is recommended for "heavy" infobases, as well as for those where simultaneous operation of 6 to 50 users is expected. A client-server base is provided with no more than 60 GB of total data volume, including 10 GB for the working infobase and 50 GB for its backup copies.

  {note:info}
  If you have exceeded the total data volume, send a request to increase the volume to [support.1c.grm@mcs.mail.ru](mailto:support.1c.grm@mcs.mail.ru). The volume increase is billed separately, and prices are set by Firm 1C. For current rates for additional storage space, check with {linkto(#1cgrm-support)[text=technical support]}.
  {/note}

The number of licenses corresponds to the number of active sessions that can be launched simultaneously in 1C applications. Licenses are assigned automatically when a user authorizes in the application.

You can both increase and decrease the number of licenses, but only within the selected mode. If you want to use more than 5 licenses in file mode, send the corresponding request to [support.1c.grm@mcs.mail.ru](mailto:support.1c.grm@mcs.mail.ru), but in this case the quality of the service cannot be guaranteed.

## {heading(Limitations)[id=1cgrm-limitations]}

For 1C:GRM applications, the total physical volume of all database tables must not exceed 12 GB, and a single table cannot be larger than 4 GB. If this volume is exceeded, the reliability and fault tolerance of the service operation are not guaranteed.

## {heading(Backup)[id=1cgrm-backup]}

In 1C:GRM, backup copies of the application and its data are created regularly. This process is launched automatically at night on weekdays. Additionally, you can create a backup copy manually; to do this, write to [support.1c.grm@mcs.mail.ru](mailto:support.1c.grm@mcs.mail.ru).

A maximum of 7 backup copies of databases can be stored.

The 1C:GRM service is supported by technical experts of Firm 1C — the [IT Cloud](https://itcloud.pro) partner.

Issues for which you can get help and consultation:

{/note}
