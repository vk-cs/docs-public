Cloud PostgreSQL is an object-relational DBMS used for storing and managing data. The service is built on PostgreSQL. For more information about PostgreSQL, see the [official documentation](https://www.postgresql.org/docs/).

Cloud PostgreSQL is suitable for storing large volumes of data. The DBMS supports multiple data types and allows you to create custom types.

Key advantages of Cloud PostgreSQL:

- data integrity preservation close to the ANSI-SQL:2008 standard;
- the ability to create complex queries: views, rules, subqueries;
- concurrency control via multiversioning (MVCC).
