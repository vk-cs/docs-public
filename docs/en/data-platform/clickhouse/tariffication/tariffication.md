## What is charged

- CPU — per each core.
- RAM — per each 1 GB of RAM.
- Disks — per each 1 GB of disk space, the price depends on the disk type (SSD or High-IOPS SSD).
- IP addresses and load balancers, for more details see [Virtual networks](/en/networks/vnet/tariffication).
- System disks.

## What is not charged

- Outbound and inbound traffic.
- Using DP Console.
