{includetag(monitoring_info)}

{var(data-p)} in the Standalone version collects metrics and displays them as charts on the **Monitoring** tab for each deployed service instance.

## {heading(Viewing charts)[id=monitoring_standalone_view]}

1. Go to the **Data Platform** → **Service instances** section.
1. Click the name of the required service instance.
1. Go to the **Monitoring** tab.
1. Review the charts.
1. (Optional) Refresh the charts or enable auto-refresh every 5 minutes.
1. (Optional) Change the order of the displayed charts. To do this, drag the upper-right corner of the desired chart in the required direction.
1. Use the **Multi-hint** option so that when hovering over one chart, data tooltips appear on all charts simultaneously.

## {heading(Filtering)[id=monitoring_standalone_filtering]}

1. Go to the **Data Platform** → **Service instances** section.
1. Click the name of the required service instance.
1. Go to the **Monitoring** tab.
1. Click the **Filters** button and select filtering parameters:

   - A fixed time period for which to display metrics.
   - A custom time period for which to display metrics. Set the period manually, using the calendar or the time scale.

   To reset filtering settings, click the **Reset filters** button.
