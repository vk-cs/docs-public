## What is billed

- CPU — for each core.
- RAM — for each 1 GB of RAM.
- Disks — for each 1 GB of disk space; the price depends on the disk type (SSD or High-IOPS SSD).
- IP addresses and load balancers, see the [Virtual networks](/en/networks/vnet/tariffication) section for details.
- System disks.

## What is not billed

- Outbound and inbound traffic.
- Use of the DP Console.
