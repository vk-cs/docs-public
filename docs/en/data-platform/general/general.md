## {heading(General information)[id=dp_index_inform]}

Full name of the system: {var(data-p)}.

{var(data-p)} is a platform for working with data processing projects in the customer's data center. It provides convenient access to data storage, processing, and management services.

## {heading({var(data-p)} capabilities)[id=dp_main_functionalities]}

- Search and display of data processing projects.
- Centralized project management, including:

   - Creating, deleting, and modifying projects.
   - Allocating the necessary resources and tools to a project in the related {var(data-p)} subsystems, including those based on configuration templates.

- Displaying and navigating all tools connected to a project.
- Displaying the environments available to projects.
- Creating and deleting infrastructure for project environments.
- Creating and deleting special compute nodes for running data processing and analysis pipelines.
- Displaying statistics on tools and resources used in the subsystems.
