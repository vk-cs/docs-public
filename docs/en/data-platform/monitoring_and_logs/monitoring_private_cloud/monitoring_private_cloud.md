# {heading(Data Platform monitoring as part of Private Cloud)[id=monitoring-private_cloud]}

{include(/en/_includes/_translated_by_ai_en.md)}

Some services of {var(data-p)} deployed as part of Private Cloud are integrated with the Cloud Monitoring system. Monitoring of collected metrics allows you to monitor the state of {var(data-p)} services, detect issues and failures in a timely manner. For more information about how Cloud Monitoring works, see the **Administrator Guide** of VK Private Cloud, in the **Components** section → [Cloud Monitoring](https://cloud.vk.ru/docs/on-premises/private-cloud/ru/4_3/admin-guide/components/cloud_monitoring).

List of services integrated with Cloud Monitoring:

- Cloud Kafka;
- Cloud Airflow;
- Cloud Trino;
- Redis.
