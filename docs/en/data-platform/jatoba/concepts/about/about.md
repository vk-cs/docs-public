Jatoba is a secure DBMS based on a modernized open source PostgreSQL DBMS core. It can be used by both small organizations and large companies. For more information about Jatoba, see the [official documentation](https://jatoba.ru/).

Service features:

- an automatic fault-tolerant and high-performance cluster with a geographically distributed DBMS architecture;
- advanced administration functions with a convenient graphical interface, as well as management of "vanilla" PostgreSQL;
- a developed monitoring system with dashboards;
- protection of databases and tables from unauthorized reading in case of leaks, SQL Firewall, and advanced cybersecurity features.
