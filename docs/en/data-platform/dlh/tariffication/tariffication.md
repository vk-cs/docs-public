# {heading(Tariffication)[id=dlh-tariffication]}

{include(/en/_includes/_translated_by_ai_en.md)}

There is no general tariffication for the entire Data Lakehouse service. Instead, each individual service included in Data Lakehouse is billed according to its own rules. For accurate information about the cost of a specific service used within Data Lakehouse, see the **Tariffication** section of the corresponding service.
