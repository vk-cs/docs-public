{include(/en/_includes/_translated_by_ai_en.md)}

OpenSearch is a software suite for building search engines and analytical solutions. The service includes the OpenSearch search platform and the OpenSearch Dashboards web interface for data visualization and analysis. For more information, see the [official documentation](https://docs.opensearch.org/docs/latest/).

Use cases for the service:

- search engines;
- log analytics;
- application monitoring;
- user behavior analysis;
- building business intelligence solutions.

An OpenSearch instance can only be {linkto(../../instructions/create#opensearch_create)[text=created]} in the **Cluster** configuration (consisting of multiple nodes). This solution is suitable for processing large volumes of data and provides high performance and fault tolerance: a failure of one node will not cause the instance to stop working.
