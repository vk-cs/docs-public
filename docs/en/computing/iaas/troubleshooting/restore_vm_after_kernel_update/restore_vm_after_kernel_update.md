# {heading(VM fails to boot after kernel update)[id=iaas-restore-vm-after-kernel-update]}

{include(/en/_includes/_translated_by_ai_en.md)}

After a new OS kernel was installed, the virtual machine stopped booting.

The problem can be caused by various reasons: incompatibility, configuration errors, missing required modules, or errors in the new kernel version.

### {heading(Solution)[id=iaas-restore-vm-after-kernel-update-decision]}

When booting the system, select the previous kernel version. If you cannot do this, contact [technical support](/en/contacts).
