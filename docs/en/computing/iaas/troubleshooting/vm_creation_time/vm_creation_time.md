# {heading(Delays in VM creation)[id=iaas-vm-creation-time]}

{include(/en/_includes/_translated_by_ai_en.md)}

VMs are created slower than usual.

The problem may be caused by various reasons.

### {heading(Solution)[id=iaas-vm-creation-time-decision]}

1. {linkto(../../../../tools-for-using-services/account/how-to-guides/systemstate#tools-account-how-to-systemstate)[text=Verify]} that the {var(cloud)} services are running stably.
1. {linkto(../../../../computing/iaas/instructions/vm/vm-create#iaas-vm-create)[text=Try]} to create a VM in another availability zone.
1. If the issue is not resolved, contact [technical support](/en/contacts) and provide the exact time interval of VM creation and the project identifier.
