# {heading(Lost private key)[id=iaas-vm-ssh-key]}

{include(/en/_includes/_translated_by_ai_en.md)}

The private key used for SSH access to the VM has been lost.

### {heading(Solution)[id=iaas-vm-ssh-key-decision]}

Create a new key pair and manually add the public key to the VM. To do this, use the {linkto(../../../../computing/iaas/instructions/vm/vm-manage#iaas-vm-manage-recovery-access-key)[text=instructions for restoring VM access]}.
