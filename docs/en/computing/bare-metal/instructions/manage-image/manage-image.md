# {heading(Working with ISO images)[id=bare-metal-manage-image]}

{include(/en/_includes/_translated_by_ai_en.md)}

Uploading ISO images to Bare Metal allows you to:

- install your desired OS on your own;
- use utilities that run in the boot environment.

## {heading(Uploading an ISO image)[id=bare-metal-image-upload]}

{tabs}

{tab(Personal account)}

1. [Go to](https://msk.cloud.vk.ru/app/) the management console of {var(cloud)}.
1. Navigate to the **Cloud Computing** → **Images** section.
1. Click **Create**.
1. Select **File** for the **Source** parameter.
1. In the **Select file** field, click the row; a file selection window will open.
1. Select the ISO image file.
1. Enter the image name.
1. Click **Create image**.
1. Wait for the image to finish uploading.

   To avoid an error, do not close the window until the upload is complete.
