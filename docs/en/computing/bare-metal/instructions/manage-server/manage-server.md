## {heading(Getting server information)[id=bare-metal-server-get-info]}

1. [Go to](https://msk.cloud.vk.ru/app/) the {var(cloud)} management console.
1. Go to the **Cloud Computing** → **Bare Metal** section.
1. In the list of Bare Metal servers, click the name of the desired server.
1. Select the tab with the information you need:

   - **General information**: name, specifications, identifier, current status, availability zone, IP address, OS.
   - **Network**: which network the server is connected to and the connection parameters.
   - **Connection**: information for remotely connecting to the server.
