# {heading(Description of output parameters)[id=tf_manifest_output]}

{include(/en/_includes/_translated_by_ai_en.md)}

Describe the output parameters so that they can be sent to the user by email after the manifest is executed and the service is deployed.

If an output parameter contains sensitive data, set the `sensitive` attribute. In this case, the output parameter data will be passed to the user, but will not be saved to Terraform logs.

The following can be passed to the user in the output parameters:

* The IP address of the created service instance VM.

   {caption(Example of an output parameter for the VM IP address)[align=left;position=above]}
   ```hcl

   # Output the VM IP address
   output "address" {
     description = "The host IP-address"
     value = vkcs_compute_instance.compute.access_ip_v4
   }
   ```
   {/caption}
* Passwords for the initial setup of the service instance, generated by a script.

   {caption(Example of an output parameter for script results)[align=left;position=above]}
   ```hcl

   # Script execution
   resource "ivkcs_agent_exec" "start" {
     hosts = [local.hosts_name]
     name  = "start"
     uuid  = var.instance_uuid
     step {
       index   = 1
       type    = "bash"
       content = pwgen 25 1
       options {
         timeout                = "10m"
         attempts               = 1
       }
     }

     depends_on = [
       vkcs_compute_instance.compute,
       vkcs_compute_volume_attach.attached,
     ]
   }

   # Requesting script results
   data "ivkcs_agent_script_result" "password" {
     uuid  = var.instance_uuid
     host  = local.hosts_names[0]
     group = ivkcs_agent_exec.start.name
     index = 1

     depends_on = [
       ivkcs_agent_exec.start
     ]
   }

   # Output of script results
   output "password" {
     description = "password"
     value = data.ivkcs_agent_script_result.password.result
     sensitive = true
   }
   ```
   {/caption}
* Passwords for the initial setup of the service instance, generated using the `random_password` resource.

   {caption(Example of an output parameter for a password generated using the `random_password` resource)[align=left;position=above]}
   ```hcl
   output "default_password" {
     value     = random_password.user.result
     sensitive = true
   }
   ```
   {/caption}
* A private SSH key for accessing the service instance VM.

   {caption(Example of an output parameter for a private SSH key)[align=left;position=above]}
   ```hcl
   output "private_key" {
     value     = ivkcs_ssh_keypair.key.private_key
     sensitive = true
   }
   ```
   {/caption}

   {note:err}

   Outputting a private SSH key in `output` without the `sensitive` attribute is prohibited.

   {/note}
