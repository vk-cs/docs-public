{include(/en/_includes/_translated_by_ai_en.md)}

To add a SaaS application to the store:

1. [Develop](../saas_broker) a broker for the service.
1. [Describe](../saas_configure) the service configuration (tariff plans, options).
1. [Upload](../saas_broker_add_configuration) the service configuration to the broker.
1. [Upload and publish](../saas_upload) the service in the store.
