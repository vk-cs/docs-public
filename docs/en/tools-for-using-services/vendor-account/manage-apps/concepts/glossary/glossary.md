|

|Volume
|
A network block device that provides data storage for a VM

|Private key
|
A set of secret data that defines the algorithm and cryptographic material for decryption. Available only to the owner of the encrypted data

|Instance
|
A virtual machine that is launched and runs on the cloud platform

|Service instance
|
An instance of a service deployed at the user's side

|My account
|
Personal account

|OS
|

|
A namespace that provides consumers with access to published revisions of services hosted in the marketplace

|Public key
|
A set of secret data that defines the algorithm and cryptographic material for encryption

|Software
|
Software

|Service/plan revision
|
A version of a service/plan for the marketplace specified in its configuration

|Service binding
|
An entity that represents a request to use a service instance

|Service package ({var(cloud)} product package)
|
A structured set of files that describes in a certain way an image-based application and the process of its deployment on a VM in a cloud project

|Deployment system
|
A system that provides deployment of an image-based application on VMs in the cloud platform. It manages the infrastructure and software of the service

|Test marketplace namespace
|
A namespace intended for testing the service configuration before publication. Available to providers, not available to consumers

|Flavor
|
An instance configuration that defines the characteristics of its resources. The flavor determines the number and type of CPUs and the amount of RAM

|Node
|
A separate VM where the software is deployed and executed
