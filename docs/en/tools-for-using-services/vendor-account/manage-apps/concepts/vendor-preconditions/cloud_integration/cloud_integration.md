# {heading(How the service works in the cloud platform)[id=cloud_integration]}

{include(/en/_includes/_translated_by_ai_en.md)}

To check how the service will function in the cloud platform, it is recommended to test the service before publishing it in the store. For this purpose, bonuses are issued and credited to the bonus account of the cloud platform project.

During testing, the main operations with the service instance and the service user scenarios are verified.

Detailed information about testing the service in the cloud platform and about publishing the service in the store is provided in the sections [Uploading an image-based application to the store](../../../ibservice_add/ibservice_upload) and [Uploading a SaaS application to the store](../../../saas_add/saas_upload).
