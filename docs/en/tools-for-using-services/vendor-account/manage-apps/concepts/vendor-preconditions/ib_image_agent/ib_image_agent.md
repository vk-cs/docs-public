# {heading(Agent)[id=ib_image_agent]}

{include(/en/_includes/_translated_by_ai_en.md)}

The Agent is a software installed on a VM during service deployment. Main functions:

* Executes scripts.
* Monitors script execution.
* Allows using script execution results when deploying a service instance.
* Allows sending script execution results to the user.
* Allows configuring monitoring of a service instance.

{note:warn}

The Agent must be present in the service image that is deployed in a cluster.

{/note}

In a service image that is deployed on a single VM, the Agent may be absent. In this case, the service will not have the following capabilities:

* Script execution monitoring.
* Sending script execution results to the user.
* Monitoring.

For example, without the Agent there will be no way to pass a one-time password for the initial configuration of a service instance generated by a script.

Using the Agent is provided by the iVK CS provider (for more details, see the section {linkto(../../../ibservice_add/tf_manifest/tf_manifest_settings/#tf_manifest_settings)[text=%text]}). Viewing the logs and results of the Agent's operation is described in the section {linkto(../../../ibservice_add/ibservice_upload/ibservice_upload_deploysystemtest/#deploysystemtest_log)[text=%text]}.
