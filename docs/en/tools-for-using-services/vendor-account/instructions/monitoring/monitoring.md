The vendor account provides statistical data about the services you have published on the {var(cloud)} platform.

{note:info}
The statistics section is available only to users with the appropriate [role](../../concepts/about#xaas_vendor_roles).
{/note}

## How to view service statistics

1. [Go to](https://msk.cloud.vk.ru/app/) the {var(cloud)} management console.
1. In the **Application Marketplace** section, click the **Go to vendor account** button.
1. Go to the **Dashboard** tab.
1. (Optional) Set parameters for filtering statistical data:

    * **Service**: specify the service for which you want to view statistics. All services are selected by default.
    * **Period**: specify the period. Statistics are displayed for the current month by default.

## Available metrics

- **Services** — the number of services you have published on the {var(cloud)} platform.
- **Instances** — the number of instances (user installations) for all services you have published on the {var(cloud)} platform.
