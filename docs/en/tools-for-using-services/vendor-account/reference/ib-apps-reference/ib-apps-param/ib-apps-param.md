The `service.yaml` configuration file contains the following information:

- [General application parameters](#app_parameters).
- The [plans array](#ib-apps-param-service-plans) with tariff plan names. These names are used only to describe the service package and are not displayed in the Marketplace interface.
- The [preview section](#service_options_for_matrix) with tariff option names. These names are used only to describe the service package and are not displayed in the Marketplace interface.
