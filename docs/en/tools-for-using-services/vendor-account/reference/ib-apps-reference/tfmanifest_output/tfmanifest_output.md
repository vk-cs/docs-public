Output parameters are data generated during the execution of the Terraform manifest and service deployment that the user needs to work with your application. Output parameters can be sent to the user by email.

{note:warn}
If an output parameter contains sensitive data, its description must include the `sensitive` attribute. In this case, the output parameter data will be passed to the user but will not be saved in the Terraform logs.
{/note}

Output parameters can be used to pass the following to the user:

* The IP address of the created service instance VM.

   {cut(Example of an output parameter)}
   ```hcl

   # Output the VM IP address
   output "address" {
     description = "The host IP-address"
     value = vkcs_compute_instance.compute.access_ip_v4
   }
   ```
   {/cut}

* Passwords for the initial setup of the service instance, generated by a script.

   {cut(Example of an output parameter)}
   ```hcl

   # Script execution
   resource "ivkcs_agent_exec" "start" {
     hosts = [local.hosts_name]
     name  = "start"
     uuid  = var.instance_uuid
     step {
       index   = 1
       type    = "bash"
       content = pwgen 25 1
       options {
         timeout                = "10m"
         attempts               = 1
       }
     }

     depends_on = [
       vkcs_compute_instance.compute,
       vkcs_compute_volume_attach.attached,
     ]
   }

   # Requesting script results
   data "ivkcs_agent_script_result" "password" {
     uuid  = var.instance_uuid
     host  = local.hosts_names[0]
     group = ivkcs_agent_exec.start.name
     index = 1

     depends_on = [
       ivkcs_agent_exec.start
     ]
   }

   # Outputting script results
   output "password" {
     description = "password"
     value = data.ivkcs_agent_script_result.password.result
     sensitive = true
   }
   ```
   {/cut}

* Passwords for the initial setup of the service instance, generated using the `random_password` resource.

   {cut(Example of an output parameter)}
   ```hcl
   output "default_password" {
     value     = random_password.user.result
     sensitive = true
   }
   ```
   {/cut}

* A private SSH key for accessing the service instance VM.

   {cut(Example of an output parameter)}
   ```hcl
   output "private_key" {
     value     = ivkcs_ssh_keypair.key.private_key
     sensitive = true
   }
   ```
   {/cut}

   {note:err}

   Outputting a private SSH key in `output` without the `sensitive` attribute is prohibited.

   {/note}
