# {heading(Tariffication)[id=tools-vk-cloud-account-tariffication]}

{include(/en/_includes/_translated_by_ai_en.md)}

Usage of a {var(cloud)} account is not charged.

Service prices are listed in the [price list](https://cloud.vk.ru/pricelist) and in the [project settings](https://msk.cloud.vk.ru/app/project/prices). To calculate the cost of the selected service configuration, use the [calculator](https://cloud.vk.ru/pricing/). For information on how to pay for {var(cloud)} services, see the {ifdef(public,private,private-pg)}[Billing](../../../intro/billing){/ifdef}{ifdef(private-pdf,private-pg-pdf)}{linkto(../../../intro/billing#billing)[text=Billing]}{/ifdef} section.
