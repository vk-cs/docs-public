# {heading(Viewing applications)[id=pp-applications]}

{include(/en/_includes/_translated_by_ai_en.md)}

1. [Go to](https://partners.tech.vk.ru) the VK Tech partner management console.
1. On the main page, click the **Partner Account** button in the {var(cloud)} card.
1. Go to the **Deal Registration** section.
1. Go to the **Open Applications** tab. The list of applications will open.
1. (Optional) Configure the list:

   1. Filter the list by application status:

      - `All applications`: applications with any statuses. Applied by default.
      - `Registered`: successfully registered applications, based on the results of which deals will be concluded.
      - `Confirmation`: applications that are at the final stage of review.
      - `In Progress`: applications that are being processed by VK Tech.
      - `Rejected`: applications for which a rejection has been received. Ask the partner account manager about the reasons for rejection.
      - `Awaiting Review`: applications that are in the processing queue at VK Tech.
      - `New`: successfully created new applications.

   1. Use the text search by company name or TIN (INN) so that the list displays only applications for a deal with a specific company.
   1. Select the number of deals displayed on the page from the drop-down list at the bottom of the page.
   1. Sort the list by application number, status, or submission date.

   The list of applications displays:

   - Application number.
   - Name of the company for which the application was created.
   - Company TIN (INN).
   - Application status. Hover your mouse over the status icon to see additional information.
   - Application submission date.

1. Click the desired application to view detailed information about it.
