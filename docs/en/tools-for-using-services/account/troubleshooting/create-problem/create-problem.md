An error when creating a project can occur if too many projects have been created in the account. Under the [basic quotas](/en/tools-for-using-services/account/concepts/quotasandlimits#quotasandlimits-general), one user can create no more than 5 projects.

### Solution

1. [Go](https://cloud.vk.ru/app/) to the VK Cloud management console.
1. Check the list of all projects.
1. If the limit is reached, [delete](/en/tools-for-using-services/account/instructions/project-settings/manage#project-delete) the project.

If the limit is not exceeded, [contact technical support](/en/contacts) with a screenshot of the error.
