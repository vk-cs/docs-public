If bonuses are available, funds are first debited from the bonus account, then from the main one.

Billing is based on the "pay as you go" principle: you are charged only for the resources you consume. Funds are debited every minute from running virtualization objects. If virtualization objects are stopped, charges continue only for the rented disk space and the storage of existing backups.

{note:warn}
The final cost is rounded to **two decimal places**.
{/note}
