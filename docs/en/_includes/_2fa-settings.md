{includetag(manage-2fa-intro)}
To strengthen the security of your [account](/en/tools-for-using-services/vk-cloud-account), enable two-factor authentication (2FA). After that, every time you sign in to your VK Cloud account, you will need to enter a one-time six-digit code from a one-time code generation app.
{/includetag}

{includetag(manage-2fa-on)}
1. Install any one-time code generation app. For example, FreeOTP or Yandex Key.
1. [Go to](https://cloud.vk.ru/account) your VK Cloud account.
1. Go to the **Security** section.
1. In the **Two-factor authentication** block, click the ![pencil-icon](../../../../assets/pencil-icon.svg "inline") icon. A page with a QR code will open.
1. Scan the code using the selected one-time code generation app.

   {note:info}
   If the QR code cannot be scanned by the app, use the manual entry code displayed below. In the app, select manual account addition, fill in the account details, and enter the resulting code.
   {/note}

1. Enter the code generated by the app in the **Code from the 2FA app** field.
1. Enter your account password in the **Account password** field.
1. Click **Enable**.

   Two-factor authentication will be enabled for your account. A list of backup codes will be displayed, which can be used to sign in to your VK Cloud account if the authentication app is unavailable.

1. Save the backup codes in case you lose access to the app. For example, you can download them in TXT format by clicking **Download .txt file with codes**.
1. Click **Finish connection**.
   {/includetag}

   {includetag(manage-2fa-project)}
1. [Go to](https://msk.cloud.vk.ru/app/) the VK Cloud management console.
1. Click the username in the page header, then select **Access management** from the drop-down list.
1. (Optional) On the access management page, enable the **Mandatory two-factor authentication** option.

{/includetag}
