{includetag(peripherals-intro)}
In the VK Workspace client settings, you can select peripheral devices that will be available from the virtual machine during an active session.

By default, only the keyboard and mouse are connected. To work with other devices, they must be selected manually.
{/includetag}

{includetag(peripherals-list)}
|Device
|Description

|Printer
|Routes print jobs from the session to the local printer.

|USB port
|Provides access to USB devices from the virtual machine.

|Clipboard
|Exchanging data between the virtual machine and the local computer.

|Disk
|Provides access to local disks from the virtual machine.

|Folder
|Provides access to a selected local folder from the virtual machine.

|Audio device
|Routes audio from the virtual machine to local speakers or headphones.

|Camera
|Routes the video stream from the local webcam to the virtual machine.

|===

{/includetag}
