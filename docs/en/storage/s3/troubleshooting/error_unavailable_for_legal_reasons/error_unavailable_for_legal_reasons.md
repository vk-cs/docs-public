# {heading(Error 451 when uploading data to S3)[id=s3-error-unavailable_for-legal-reasons]}

{include(/en/_includes/_translated_by_ai_en.md)}

When accessing object storage, the error `451 Unavailable For Legal Reasons` occurs.

This error means that access is blocked for legal reasons.

### {heading(Solution)[id=s3-error-unavailable_for-legal-reasons-resolve]}

If you are sure that the blocking is erroneous, [contact technical support](/en/contacts).
