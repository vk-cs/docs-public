## {heading(Brief description of features)[id=s3-index-description-of-features]}

{var(s3)} is an S3 protocol-compatible service for organizing secure, reliable, and scalable object data storage, installed on hardware resources provided in the Customer's own data center (hereinafter referred to as DC) (on-premises).

{var(s3)} solves the problem of scattered storage of various types of objects, and also addresses the task of maintaining a stable delivery speed for any type of object regardless of the number of concurrent requests. Objects may include: multimedia, website content, transaction logs, electronic documents, big data, backups, and archives.

## {heading(User qualification requirements)[id=s3-index-user-qualifications]}

When working with {var(s3)}, users perform the following actions:

- Creating and deleting buckets and objects.
- Uploading and downloading objects from buckets.

The following requirements apply to users of {var(s3)}:

- Completion of training from {var(vendor)} on the use of components developed by the vendor.
- PC skills, including the ability to independently perform:

  - Installation and launch of an S3-compatible file manager.
  - Installation and launch of the AWS command line interface (AWS CLI).
  - Performing file operations using the OS (creating, copying, renaming, deleting, moving, etc.).
