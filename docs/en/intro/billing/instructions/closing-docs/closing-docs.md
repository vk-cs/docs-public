# {heading(Downloading closing documents)[id=billing-closing-docs]}

{include(/en/_includes/_translated_by_ai_en.md)}

If you work on a {linkto(/en/intro/billing/concepts/physical-corporate#billing-physical-corporate-postpay)[text=post-payment]} basis, you can download closing documents — invoices and universal transfer documents (UTD) — in the {var(cloud)} management console.

1. [Go to](https://msk.cloud.vk.ru/app/) the {var(cloud)} management console.

{include(/en/_includes/_balance_page.md)}

1. Go to the **Closing documents** tab.
1. (Optional) Set filters for the displayed records.
1. Click the ![Download](assets/download_icon.svg "inline") icon for the desired document.

   If you want to download several documents at once, select them using the checkbox and click the ![Download](assets/download_icon.svg "inline") icon.

The documents will be downloaded to your computer.
