# {heading(Platform compliance with 152-FZ)[id=it-security-compliance-152fz]}

{include(/en/_includes/_translated_by_ai_en.md)}

{var(cloud)} can be used for processing personal data (PDn) in accordance with 152-FZ "On Personal Data Protection". {var(cloud)} holds an FSTEC of Russia certificate confirming that the first protection level (UZ-1) of the processed personal data is ensured.

Personal data processing is provided through the [Cloud 152-FZ](https://cloud.vk.ru/solutions/152-fz/) service. This service places personal data in the cloud on secure and certified servers suitable for processing personal data of the following protection levels:

- UZ-3;
- UZ-2;
- UZ-1.

{note:warn}
All user personal data is stored within the territory of the Russian Federation.
{/note}

The principle of shared security responsibility between {var(cloud)} and the user is applied. In addition, responsibility for personal data storage is also shared.

You can find information about the shared responsibility on the [Cloud Security](https://cloud.vk.ru/cloud-security/) page.

{var(cloud)} notifies users in the [management console](https://msk.cloud.vk.ru/app/) of any legally binding requests for PDn disclosure from law enforcement agencies within 72 hours of receiving such a request.

All facts of PDn disclosure to third parties are recorded by {var(cloud)}, including information about which PDn were disclosed, to whom, and at what time.

{var(cloud)} informs the respective users in cases of:

- unauthorized access to their PDn;
- facts of unauthorized access to equipment or processing facilities resulting in loss, disclosure, or alteration of PDn.

{note:info}
For any questions related to PDn processing when providing cloud services, contact [technical support](/en/contacts).
{/note}
