# {heading(Жизненный цикл объектов в бакете)[id=s3-instructions-manage-lifecycle]}

Чтобы настроить правила {linkto(../../concepts/lifecycle#s3-concepts-lifecycle)[text=жизненного цикла]} (lifecycle):

{tabs}

{tab(Личный кабинет{ifdef(s3,s3-pdf)} IAM Only{/ifdef})}

{ifdef(public)}

1. [Перейдите](https://msk.cloud.vk.ru/app) в личный кабинет {var(cloud)}.

{/ifdef}

{ifdef(s3,s3-pdf)}

1. {linkto(../iamo/iamo-auth#s3-instructions-iamo-auth)[text=Войдите]} в личный кабинет IAM Only.

{/ifdef}

1. Выберите проект, в котором находится нужный бакет.
1. Перейдите в раздел **Object Storage** → **Бакеты**.
1. Перейдите в настройки бакета одним из способов:

   - Нажмите ![more-icon](../../assets/more-icon.svg "inline") для нужного бакета и выберите пункт **Настройки**.
   - Нажмите на имя нужного бакета, затем на странице бакета нажмите кнопку ![settings-icon](../../assets/settings-icon.svg "inline").

1. Перейдите на вкладку **Жизненный цикл**. Выполните необходимую операцию с правилами.

   {tabs}

   {tab(Добавить)}

   1. Откройте форму добавления правил одним из способов.

      - Если нет ни одного правила, нажмите кнопку ![plus-icon](../../assets/plus-icon.svg "inline") **Добавить**.
      - Если правила уже есть, нажмите сначала кнопку **Настроить правила**, затем ![plus-icon](../../assets/plus-icon.svg "inline") **Добавить правило**.

   1. Задайте статус правила:

      - `Включено` — если правило нужно включить после добавления.
      - `Выключено` — если в настоящее время правило не нужно применять к объектам.

   1. Задайте имя правила. Допустимы только цифры, латинские буквы и символы `-`, `_`, `.`. Имя должно быть уникальным в рамках бакета.
   1. (Опционально) Задайте префикс: правило будет применяться только для объектов с указанными префиксными ключами. Фильтр может содержать только один ключ. Примеры префиксных ключей: `image/`, `pre/`, `image/photo`.
   1. (Опционально) В блоке **Теги** нажмите ![plus-icon](../../assets/plus-icon.svg "inline") **Добавить тег**, укажите **Ключ** и **Значение** тега. При необходимости повторите операцию.
      
      Чтобы удалить тег, нажмите на значок ![trash-icon](../../assets/trash-icon.svg "inline") рядом с ним.

   1. В блоке **Тип срабатывания** включите опцию **Expiration**, чтобы включить удаление объектов из бакета согласно выбранному условию срабатывания:

      - `По дням`: задается количество дней, по истечении которых правило сработает.
      - `Удалять маркеры удаления` (только для бакетов с версионированием): правило будет удалять маркеры удаления объектов, если других версий объекта не осталось.

   1. (Только для бакетов с версионированием) В блоке **Тип срабатывания** включите опцию **NoncurrentVersionExpiration**, чтобы задать условия удаления неактуальных версий объектов из бакета:

      - **Срок срабатывания**: количество дней, в течение которых хранится версия объекта, после чего она удаляется.
      - **Версии**: количество хранимых неактуальных версий объекта, при превышении которого более старые версии будут удаляться. Максимальное значение — `100`.

      Если заданы оба параметра, неактуальная версия удаляется только при достижении обоих условий.

   1. Чтобы добавить в форму еще одно правило, нажмите кнопку ![plus-icon](../../assets/plus-icon.svg "inline") **Добавить правило** и задайте его параметры так же, как описано выше.
   1. Нажмите кнопку **Сохранить**.

   {/tab}

   {tab(Редактировать)}

   1. Откройте форму редактирования правила одним из способов:

      - Нажмите ![more-icon](../../assets/more-icon.svg "inline") рядом с правилом, которое нужно отредактировать и выберите пункт ![pencil-icon](../../assets/pencil-icon.svg "inline") **Редактировать**.
      - Нажмите кнопку **Настроить правила**, и раскройте блок c нужным правилом, нажав на его заголовок `Правило <НОМЕР_ПРАВИЛА>`.

   1. Задайте статус правила:

      - `Включено` — если правило нужно включить после редактирования.
      - `Выключено` — если в настоящее время правило не нужно применять к объектам.

   1. Нажмите кнопку **Сохранить**.

   {/tab}

   {tab(Включить или выключить)}

   Выберите с помощью флажка нужные правила, нажмите на кнопку **Выключить** или **Включить** и подтвердите действие.

   {/tab}

   {tab(Удалить)}

   - Для множественного удаления выберите с помощью флажка нужные правила, нажмите кнопку **Удалить** и подтвердите действие.
   - Для удаления одного правила нажмите ![more-icon](../../assets/more-icon.svg "inline") рядом с правилом, которое нужно удалить, выберите пункт ![trash-icon](../../assets/trash-icon.svg "inline") **Удалить** и подтвердите действие.

   {/tab}

   {/tabs}

{/tab}

{tab(AWS CLI)}

{note:warn}
Загрузка конфигурации правил с помощью `put-bucket-lifecycle-configuration` удаляет текущую конфигурацию, в том числе правила, заданные в личном кабинете.
{/note}

1. Установите и настройте {linkto(../../connect/s3-cli#s3-connect-cli)[text=AWS CLI]}, если он еще не установлен.
1. Выполните необходимую операцию с конфигурацией правил жизненного цикла.

   {tabs}

   {tab(Запросить)}

   Чтобы узнать текущую конфигурацию, выполните команду:

   ```console
   aws s3api get-bucket-lifecycle-configuration --bucket <ИМЯ_БАКЕТА> --endpoint-url <ENDPOINT_URL>
   ```

   Здесь:

   - `<ИМЯ_БАКЕТА>` — имя бакета, конфигурацию правил которого нужно получить.
     {ifdef(public)}
   - `<ENDPOINT_URL>` — должен соответствовать {linkto(../../../../tools-for-using-services/account/concepts/regions#tools-account-concepts-regions)[text=региону]} аккаунта:

   - `https://hb.vkcloud-storage.ru` или `https://hb.ru-msk.vkcloud-storage.ru` — для региона Москва;
   - `https://hb.kz-ast.vkcloud-storage.ru` — для региона Казахстан.
     {/ifdef}
     {ifdef(s3,s3-pdf)}
   - `<ENDPOINT_URL>` — ссылка с доменным именем, которое используется в вашей инсталляции {var(s3)}. Формат имени может отличаться. Чтобы узнать точный формат ссылки, обратитесь к вашему администратору.
     {/ifdef}

   {/tab}

   {tab(Создать)}

   1. Подготовьте новый JSON-файл с {linkto(../../concepts/lifecycle#s3-concepts-lifecycle-config)[text=конфигурацией правил жизненного цикла]} одним из способов.

   1. Загрузите конфигурацию жизненного цикла:

      ```console
      aws s3api put-bucket-lifecycle-configuration --bucket <ИМЯ_БАКЕТА> --lifecycle-configuration file://<ИМЯ_ФАЙЛА>.json --endpoint-url <ENDPOINT_URL>
      ```

      Здесь:

      - `<ИМЯ_БАКЕТА>` — имя бакета, которому нужно добавить конфигурацию правил.
      - `<ИМЯ_ФАЙЛА>` — имя файла с конфигурацией правил жизненного цикла.
        {ifdef(public)}
      - `<ENDPOINT_URL>` — должен соответствовать {linkto(../../../../tools-for-using-services/account/concepts/regions#tools-account-concepts-regions)[text=региону]} аккаунта:

         - `https://hb.vkcloud-storage.ru` или `https://hb.ru-msk.vkcloud-storage.ru` — для региона Москва;
         - `https://hb.kz-ast.vkcloud-storage.ru` — для региона Казахстан.
        {/ifdef}
        {ifdef(s3,s3-pdf)}
      - `<ENDPOINT_URL>` — ссылка с доменным именем, которое используется в вашей инсталляции {var(s3)}. Формат имени может отличаться. Чтобы узнать точный формат ссылки, обратитесь к вашему администратору.
        {/ifdef}

   {/tab}

   {tab(Редактировать)}

   1. Сохраните текущую конфигурацию в файл:

      ```console
      aws s3api get-bucket-lifecycle-configuration --bucket <ИМЯ_БАКЕТА> --endpoint-url <ENDPOINT_URL> --output json > <ИМЯ_ФАЙЛА>.json
      ```

      Здесь:

      - `<ИМЯ_БАКЕТА>` — имя бакета, конфигурацию правил которого нужно получить.
        {ifdef(public)}
      - `<ENDPOINT_URL>` — должен соответствовать {linkto(../../../../tools-for-using-services/account/concepts/regions#tools-account-concepts-regions)[text=региону]} аккаунта:

         - `https://hb.vkcloud-storage.ru` или `https://hb.ru-msk.vkcloud-storage.ru` — для региона Москва;
         - `https://hb.kz-ast.vkcloud-storage.ru` — для региона Казахстан.
        {/ifdef}
        {ifdef(s3,s3-pdf)}
      - `<ENDPOINT_URL>` — ссылка с доменным именем, которое используется в вашей инсталляции {var(s3)}. Формат имени может отличаться. Чтобы узнать точный формат ссылки, обратитесь к вашему администратору.
        {/ifdef}
      - `<ИМЯ_ФАЙЛА>` — имя файла в который будет записана текущая конфигурация правил жизненного цикла.

   1. Внесите необходимые изменения в {linkto(../../concepts/lifecycle#s3-concepts-lifecycle-config)[text=конфигурацию правил жизненного цикла]}.
   1. Загрузите конфигурацию жизненного цикла:

      ```console
      aws s3api put-bucket-lifecycle-configuration --bucket <ИМЯ_БАКЕТА> --lifecycle-configuration file://<ИМЯ_ФАЙЛА>.json --endpoint-url <ENDPOINT_URL>
      ```

      Здесь:

      - `<ИМЯ_БАКЕТА>` — имя бакета, которому нужно добавить конфигурацию правил.
      - `<ИМЯ_ФАЙЛА>` — имя файла с конфигурацией правил жизненного цикла.
        {ifdef(public)}
      - `<ENDPOINT_URL>` — должен соответствовать {linkto(../../../../tools-for-using-services/account/concepts/regions#tools-account-concepts-regions)[text=региону]} аккаунта:

         - `https://hb.vkcloud-storage.ru` или `https://hb.ru-msk.vkcloud-storage.ru` — для региона Москва;
         - `https://hb.kz-ast.vkcloud-storage.ru` — для региона Казахстан.
        {/ifdef}
        {ifdef(s3,s3-pdf)}
      - `<ENDPOINT_URL>` — ссылка с доменным именем, которое используется в вашей инсталляции {var(s3)}. Формат имени может отличаться. Чтобы узнать точный формат ссылки, обратитесь к вашему администратору.
        {/ifdef}

   {/tab}

   {tab(Удалить)}

   Чтобы полностью удалить все правила жизненного цикла, выполните команду:

   ```console
   aws s3api delete-bucket-lifecycle --bucket <ИМЯ_БАКЕТА> --endpoint-url <ENDPOINT_URL>
   ```
   
   Здесь:

   - `<ИМЯ_БАКЕТА>` — имя бакета, конфигурацию правил которого нужно удалить.
     {ifdef(public)}
