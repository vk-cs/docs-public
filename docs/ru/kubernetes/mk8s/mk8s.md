# {heading(Managed Containers для второго поколения кластеров)[id=mk8s-k8s]}

Сервис Managed Containers имеет сертификацию CNCF и совместим со стандартным Kubernetes API. Благодаря автоматическому масштабированию (autoscaling), приложения на Managed Containers моментально получают дополнительные мощности в момент пиковых нагрузок и снижают потребление при ее падении. Автомасштабирование позволяет экономить до 60% на вычислениях.

Кластеры [второго поколения](/ru/kubernetes/mk8s/concepts/cluster-generations) (или управляемые кластеры) обслуживаются и управляются платформой {var(cloud)}, что минимизирует рутинное ручное управление со стороны пользователей.

{note:warn}
Функциональность кластеров может отличаться в зависимости от их поколения. В этом разделе описаны возможности только второго поколения кластеров. Документация для первого поколения доступна в разделе [Managed Containers для кластеров первого поколения](/ru/kubernetes/k8s).
{/note}
