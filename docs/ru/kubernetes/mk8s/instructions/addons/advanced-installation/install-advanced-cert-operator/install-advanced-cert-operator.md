## {heading(Установка аддона)[id=mk8s-install-advanced-cert-operator-install]}

Аддон {linkto(../../../../concepts/addons-and-settings/addons#mk8s-addons-cert-operator)[text=cert-operator]} запускает по одному поду на каждом worker-узле кластера и синхронизирует на них CA-сертификаты. Доступны {linkto(../../../../concepts/addons-and-settings/addons#mk8s-addons-install-features)[text=стандартная и быстрая установка]}.

{tabs}

{tab(Стандартная установка)}

1. Установите аддон:

   {tabs}

   {tab(Личный кабинет)}

    1. [Перейдите](https://msk.cloud.vk.ru/app/) в личный кабинет {var(cloud)}.
    1. Выберите проект, где находится нужный кластер.
    1. Перейдите в раздел **Кластеры Kubernetes → Кластеры Kubernetes**.
    1. Нажмите на имя нужного кластера.
    1. Перейдите на вкладку **Аддоны**.
    1. Нажмите кнопку **Установить** на карточке аддона `cert-operator` и нажмите кнопку **Установить аддон**.
    1. (Опционально) Отредактируйте:

        - выбранную версию;
        - название приложения;
        - название пространства имен, куда будет установлен аддон (по умолчанию `cert-operator`);
        - {linkto(#mk8s-install-advanced-cert-operator-edit-code)[text=код настройки аддона]}.

          {note:warn}
          Некорректно заданный код настройки может привести к ошибкам при установке или неработоспособности аддона.
          {/note}

    1. Нажмите кнопку **Установить аддон**.

       Начнется установка аддона в кластер. Этот процесс может занять длительное время.

   {/tab}

   {/tabs}

1. (Опционально) {linkto(../../../../how-to-guides/cert-operator#mk8s-cert-operator)[text=Познакомьтесь с практическим руководством по работе с cert-operator]}.

{/tab}

    1. Нажмите кнопку **Установить** на карточке аддона `cert-operator` и нажмите кнопку **Установить аддон**.

## {heading(Редактирование кода настройки аддона при установке)[id=mk8s-install-advanced-cert-operator-edit-code]}

Редактирование кода аддона применимо только для стандартной установки.

В коде можно изменить параметр `reconcileInterval` — интервал, с которым аддон синхронизирует CA-сертификаты на worker-узлах кластера. По умолчанию его значение `30s`.

Остальные параметры подов аддона (`tolerations`, `nodeSelector`, `affinity`, `priorityClassName` и другие) задаются стандартным образом, как для других ресурсов Kubernetes. С помощью `nodeSelector`, `affinity` или `tolerations` можно ограничить список узлов, на которых аддон синхронизирует CA-сертификаты.

После редактирования кода продолжите установку аддона.
