Сервис Managed Containers имеет сертификацию CNCF и совместим со стандартным Kubernetes API. Благодаря автоматическому масштабированию (autoscaling), приложения на Managed Containers моментально получают дополнительные мощности в момент пиковых нагрузок и снижают потребление при ее падении. Автомасштабирование позволяет экономить до 60% на вычислениях.

Для развертывания и автомасштабирования кластеров [первого поколения](/ru/kubernetes/k8s/concepts/cluster-generations) используется [Magnum](https://docs.openstack.org/magnum/latest/user/index.html), инструмент OpenStack для оркестрации контейнеров.

{note:warn}
Функциональность кластеров может отличаться в зависимости от их поколения. В этом разделе описаны возможности только первого поколения кластеров. Документация для второго поколения доступна в разделе [Managed Containers для кластеров второго поколения](/ru/kubernetes/mk8s).

Создание кластеров первого поколения из личного кабинета отключено для новых пользователей и доступно только по запросу через [техническую поддержку](/ru/contacts).
{/note}
{/ifdef}
