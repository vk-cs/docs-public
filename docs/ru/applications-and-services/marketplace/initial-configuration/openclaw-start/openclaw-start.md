# {heading(Установка и настройка сервиса OpenClaw)[id=marketplace-openclaw-quick-start]}

[OpenClaw](https://msk.cloud.vk.ru/app/services/marketplace/v2/apps/service/546d0a61-00dd-4ce9-b662-d7eeb4be3149/v0.12/info) — это инструмент с открытым исходным кодом для создания AI-агентов и приложений на базе LLM. Он также позволяет эффективно управлять такими агентами и приложениями. OpenClaw предоставляет интерфейс для настройки агентов, интеграции внешних инструментов и автоматизации задач.

Возможности OpenClaw:

- AI-агенты: создание умных помощников для анализа данных и взаимодействия с пользователями и внешними сервисами.
- Управление LLM: подключение и контроль моделей для генерации текста, анализа информации и автоматизации процессов.
- Интеграции с внешними сервисами: использование API для расширения функций агентов.
- Автоматизация задач: настройка сценариев, при помощи которых агенты будут самостоятельно выполнять задачи.
- Мониторинг: контроль конфигурации и отслеживание работы агентов.
- Кастомизация: расширение платформы собственными инструментами и плагинами.

Используя сервис OpenClaw, вы соглашаетесь с лицензионными соглашениями [Marketplace VK Cloud](/ru/start/legal/archive/digital-cloud/marketplace) и [OpenClaw](https://github.com/openclaw/openclaw/blob/main/LICENSE).

## {heading(Подготовительные шаги)[id=marketplace-openclaw-prep]}

Чтобы развернуть сервис OpenClaw на ВМ в вашем проекте {var(cloud)}:

1. {linkto(../../../../intro/onboarding/account/create-account#onboarding-create-account)[text=Зарегистрируйтесь]} в {var(cloud)} и [перейдите](https://msk.cloud.vk.com/app) в личный кабинет.

1. Определите, какой доступ должен быть у сервиса:

   - Внешний — к сервису OpenClaw, развернутому на ВМ, будет доступ из интернета. Может потребоваться настройка сети, если это еще не сделано.
   - Внутренний — сервис OpenClaw будет доступен только из сети проекта {var(cloud)} по внутреннему IP-адресу. В таком случае настройка внешней сети не потребуется.
   
1. Если вы хотите иметь доступ к сервису из интернета, дополнительно настройте сеть:
 
   1. {linkto(../../../../networks/vnet/instructions/net#vnet-net-add)[text=Создайте]} сеть с доступом в интернет, если это еще не сделано.
   1. В {linkto(../../../../networks/vnet/instructions/net#vnet-net-subnet-edit)[text=настройках подсети]}, где будет размещена ВМ, отключите опцию **Приватный DNS**.

## {heading({counter(openclaw)}. Подключите сервис)[id=marketplace-openclaw-enable]}

1. В [личном кабинете](https://msk.cloud.vk.com/app/) {var(cloud)} перейдите в раздел **Магазин приложений**.
1. На карточке сервиса **OpenClaw** нажмите кнопку **Подробнее**.
1. На странице с описанием сервиса нажмите кнопку **Подключить**.
1. На странице **Параметры сервера** укажите настройки подключения к сервису OpenClaw.

   1. Укажите параметры OpenClaw:

      - **Как будет размещен openclaw**: выберите тип размещения сервиса.

         - `external` — с внешним IP-адресом и доменным именем, предоставленным {var(cloud)}. Так ВМ с развернутым сервисом OpenClaw будет доступна из интернета.
         - `internal` — с доступом только из сети проекта {var(cloud)} по внутреннему IP-адресу.

      - **Включить резервное копирование на S3**: включите опцию, чтобы ежедневно создавать резервные копии данных OpenClaw в {linkto(../../../../storage/s3/concepts/about#s3-concepts-about)[text=объектном хранилище]} {var(cloud)}. Хранилище создается автоматически. Сохраняются последние 7 копий.

      - **Включить мониторинг**: включите опцию, чтобы автоматически отправлять в сервис {linkto(../../../../monitoring-services/monitoring#monitoring)[text=Cloud Monitoring]} метрики виртуальной машины, на которой развернут OpenClaw. Эти метрики будут доступны в разделе **Мониторинг** личного кабинета.

   1. Укажите параметры виртуальной машины, на которой будет развернут инстанс сервиса:

      - **Сеть**: выберите сеть, где будет размещена ВМ с развернутым сервисом. Если вы указали тип размещения `external`, выберите ранее настроенную сеть с доступом в интернет и подсеть, для которой отключена опция **Приватный DNS**.
      - **Зона доступности**: выберите {linkto(../../../../start/concepts/architecture#architecture-az)[text=зону доступности]}, где будет запущена ВМ.
      - **Тип виртуальной машины**: выберите {linkto(../../../../computing/iaas/concepts/vm/flavor#iaas-flavor)[text=предустановленную конфигурацию ВМ]} в соответствии с вашей нагрузкой. Для пилотных сценариев достаточно минимальной конфигурации.

   1. Укажите параметры системного диска и диска с данными:

      - **Размер диска**: укажите нужный размер диска ВМ в гигабайтах.
      - **Тип диска**: выберите {linkto(../../../../computing/iaas/concepts/data-storage/disk-types#iaas-disk-types-list)[text=один из типов диска]} — `HDD`, `SSD` или `High-IOPS SSD`.

1. Нажмите кнопку **Следующий шаг**.

1. Ознакомьтесь со стоимостью инфраструктуры для развертывания сервиса и нажмите кнопку **Подключить тариф**.

   Начнется развертывание облачной инфраструктуры, и откроется страница свойств сервиса. Статус процесса будет отображаться также в разделе **Магазин приложений → Мои сервисы**.

   После успешного развертывания на почту, привязанную к вашему аккаунту в {var(cloud)}, придут сообщения:

   - уведомление со ссылкой на инстанс сервиса в личном кабинете {var(cloud)};
   - письмо с одноразовой ссылкой на данные для доступа к сервису.

1. Перейдите по одноразовой ссылке из письма и сохраните данные для доступа к сервису:

   - `openclaw_url` — адрес веб-интерфейса OpenClaw;
   - `openclaw_login_url` — адрес веб-интерфейса с токеном доступа, который можно сразу открыть в браузере;
   - `openclaw_gateway_token` — токен доступа к OpenClaw;
   - `os_user` — имя системного пользователя для входа по SSH;
   - `keypair` — приватный ключ для подключения по SSH к виртуальной машине, где развернут сервис.
   
   {note:info}
   Если данные для доступа утрачены, {linkto(../../../../applications-and-services/marketplace/instructions/pr-instance-manage#marketplace-pr-instance-manage-update-access)[text=сгенерируйте]} новые.
   {/note}

## {heading({counter(openclaw)}. Проверьте работоспособность сервиса)[id=marketplace-openclaw-check]}

1. Перейдите в веб-интерфейс сервиса OpenClaw одним из способов:

   - По адресу, указанному в `openclaw_login_url`.
   - По адресу, указанному в `openclaw_url`. В этом случае на открывшейся странице в поле **Gateway Token** ведите значение параметра `openclaw_gateway_token` и нажмите кнопку **Connect**.

1. Создайте любой агент или проект в интерфейсе OpenClaw. Подробнее в [официальной документации OpenClaw](https://docs.openclaw.ai/).

1. Укажите учетные данные вашего LLM-провайдера и настройте нужные [инструменты](https://docs.openclaw.ai/channels) для интеграции с внешними сервисами.

1. Запустите тестовую задачу, чтобы убедиться, что агент корректно выполняет сценарий.

## {heading({counter(openclaw)}. Добавьте модель через веб-интерфейс)[id=marketplace-openclaw-check]}

1. В веб-интерфейсе сервиса OpenClaw перейдите в раздел **Config**.
1. Переключитесь в режим **Raw** и добавьте настройки нужной модели в JSON-конфигурацию, не удаляя существующие параметры.

   ```json
   {
     "gateway": {
       "mode": "local",
       "bind": "lan",
       "controlUi": {
         "dangerouslyDisableDeviceAuth": true,
         "allowedOrigins": [
           "http://127.0.0.1:18789",
           "http://openclaw-XXXXXXXX.xaas.msk.bizmrg.com"
         ]
       }
     },
     "agents": {
       "defaults": {
         "model": {
           "primary": "my-provider/my-model"
         }
       }
     },
     "models": {
       "mode": "merge",
       "providers": {
         "my-provider": {
           "baseUrl": "https://api.example.com/v1",
           "apiKey": "${<API_KEY>}",
           "api": "openai-completions",
           "models": [
             { "id": "my-model", "name": "My Model" }
           ]
         }
       }
     }
   }
   ```

   Здесь:

   - `allowedOrigins` — задает список URL, по которым разрешено подключение. Помимо стандартного `http://127.0.0.1:18789` добавьте также значение из `openclaw_url`.
   - `primary` — LLM-модель из блока `providers`, которая будет использоваться по умолчанию. Указывается в формате `<НАЗВАНИЕ_ПРОВАЙДЕРА>/<ID_МОДЕЛИ>` или просто `<ID_МОДЕЛИ>`.
   - `my-provider` — блок с произвольным названием, который описывает параметры вашего провайдера и доступные модели:
      - `baseUrl` — URL-адрес эндпоинта вашего AI-провайдера. Например, `https://api.openai.com/v1`.
      - `apiKey` — API-ключ вашего провайдера для доступа к LLM-модели (если используется).
      - `api` — протокол, по которому OpenClaw обращается к API провайдера. В большинстве случаев используется `openai-completions` или `openai-chat-completions`, поддерживаемые множеством провайдеров.
      - `models` — массив объектов со значениями:
         - `id` — идентификатор модели, должен в точности соответствовать значению у AI-провайдера.
         - `name` — произвольное имя для модели.

   Больше информации в [официальной документации OpenClaw](https://docs.openclaw.ai/).

1. Нажмите кнопку **Apply**, чтобы сохранить и применить конфигурацию.
