# {heading(Расширения)[id=clickhouse_extensions_info]}

Расширения Cloud ClickHouse дополняют базовую функциональность СУБД без изменения конфигурации экземпляра. Их можно в любой момент {linkto(../../instructions/manage#clickhouse_extensions)[text=включить или отключить]}.

## {heading(Справочник с данными о странах)[id=clickhouse_extension_countries]}

Расширение **Справочник с данными о странах** позволяет:

- Валидировать коды стран в данных: проверять, существует ли указанный код в справочнике, чтобы находить некорректные значения до их попадания в аналитику.
- Обогащать данные атрибутами стран: по коду страны получать ее название, столицу, континент, телефонный код, код валюты и языки, если в исходных данных хранится только код, а для отчета нужны полные данные о стране.
- Группировать и агрегировать данные по странам или континентам: строить отчеты с разбивкой по регионам, например об объеме продаж или распределении пользователей.

Для каждой страны хранятся:

- `alpha_2_code` — двухбуквенный код страны;
- `alpha_3_code` — трехбуквенный код страны;
- `numeric_code` — числовой код страны;
- `name_en`, `name_ru` — название страны на английском и русском языках;
- `continent_en`, `continent_ru` — название континента на английском и русском языках;
- `capital_en`, `capital_ru` — название столицы на английском и русском языках;
- `phone_prefix` — телефонный код страны;
- `currency_code` — код валюты;
- `languages` — языки страны.
