# {heading(Вывод экземпляра из режима только для чтения)[id=clickhouse_read_only]}

{note:warn}
Только для Standalone и Standalone в составе {var(cloud)}.
{/note}

Когда на диске узла Cloud ClickHouse остается менее 10 МБ свободного места, {var(data-p)} автоматически переводит экземпляр в режим только для чтения (read-only). Это предотвращает переполнение диска и потерю работоспособности базы данных. При попытке записи возникнет ошибка.

В режиме только для чтения недоступны операции записи `INSERT`, `ALTER`, `CREATE` и др.

Режим применяется ко всему экземпляру, даже если место закончилось только на одном узле.

## {heading(Отображение режима только для чтения)[id=clickhouse_read_only_view]}

Когда экземпляр переходит в режим только для чтения, в разделе **Data Platform** → **Экземпляры сервисов** в столбце **Состояние сервиса** отображается статус `Только для чтения`.

Чтобы узнать, на каком узле закончилось свободное место, перейдите на вкладку **Архитектура** экземпляра.

## {heading(Вывод экземпляра из режима только для чтения)[id=clickhouse_read_only_exit]}

Экземпляр в режиме только для чтения автоматически возвращается в обычный режим при увеличении диска. Рекомендуется увеличивать размер диска не менее чем на 20% от текущего размера во избежание скорого повторного заполнения.

Чтобы вывести экземпляр из режима только для чтения:

После расширения диска экземпляр автоматически вернется в обычный режим.
