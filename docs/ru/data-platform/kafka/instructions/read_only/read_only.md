# {heading(Вывод экземпляра из режима только для чтения)[id=kafka_read_only]}

{ifdef(public)}
{include(/ru/_includes/_dp-unavailable.md)}
{/ifdef}

Если на диске хотя бы одного {linkto(../../concepts/entities#kafka_entities_broker)[text=брокера]} Cloud Kafka свободно меньше 1% места, экземпляр сервиса автоматически переходит в режим только для чтения (read-only). Это предотвращает переполнение диска и помогает сохранить работоспособность кластера. Публикация приостанавливается: брокер не подтверждает запись, и приложение-поставщик получает ошибку по таймауту. В интерфейсе платформы режим отдельным статусом не отображается.

В режиме только для чтения:

- Запись сообщений в топики недоступна;
- Чтение сообщений доступно.

Режим применяется ко всему экземпляру, даже если место закончилось только на одном брокере.

Узнать, на диске какого из брокеров закончилось свободное место, можно в разделе **Data Platform** → **Экземпляры сервисов** на вкладке **Архитектура**.
