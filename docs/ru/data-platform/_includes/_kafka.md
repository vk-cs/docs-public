<!-- Роли для Kafka -->

{includetag(roles)}
- `Стандартный пользователь`: может создавать, изменять и удалять топики, в том числе менять их настройки; управлять группами потребителей; создавать и изменять схемы и коннекторы; читать и писать сообщения. Не может удалять схемы и коннекторы, запускать анализ и управлять другими конфигурациями. В Kafka UI этой роли доступен только просмотр.
- `Наблюдатель`: может только просматривать топики, схемы, группы, коннекторы и читать сообщения. Не может создавать, изменять или удалять объекты.
- `Аудитор безопасности`: может просматривать конфигурации приложений, кластеров, ACL, а также описания топиков, групп, транзакций и пользователей. Не имеет доступа к сообщениям и операциям с объектами.
{/includetag}

{includetag(connection-preparation)}

{ifdef(public)}
1. [Перейдите](https://msk.cloud.vk.ru/app/) в личный кабинет {var(cloud)}.
{/ifdef}

1. Перейдите в раздел **Data Platform** → **Экземпляры сервисов**.
1. Нажмите на название экземпляра Cloud Kafka.
1. Скопируйте на вкладке **Общая информация** строку подключения для нужного варианта:

   - **Строка подключения Bootstrap с TLS** — для подключения по TLS;
   - **Строка подключения Bootstrap** — для подключения без TLS.

1. Загрузите цепочку сертификатов для подключения по TLS: на вкладке **Общая информация** в карточке сертификата нажмите ![значок](/ru/data-platform/assets/more-icon.svg "inline") → **Скачать цепочку сертификатов**.

1. Подготовьте логин и пароль учетной записи Cloud Kafka. Учетную запись можно {linkto(/ru/data-platform/kafka/instructions/management#kafka_user-add)[text=добавить на странице экземпляра сервиса]}.

{/includetag}

{includetag(connection-values)}

Здесь:

- `<АДРЕС_И_ПОРТ_BOOTSTRAP_СЕРВЕРА>`: строка подключения, скопированная при подготовке.
- `<ЛОГИН>` и `<ПАРОЛЬ>`: учетные данные пользователя Cloud Kafka.
- `<ПУТЬ_К_ЦЕПОЧКЕ_СЕРТИФИКАТОВ>`: путь к файлу цепочки сертификатов, скачанному на вкладке **Общая информация** при подготовке к подключению. Используется только для подключения по TLS.

{/includetag}
