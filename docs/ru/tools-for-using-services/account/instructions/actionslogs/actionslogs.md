# {heading(Работа с журналом событий)[id=tools-account-actionslogs]}

Журнал событий позволяет:

- {linkto(#event-log-view)[text=просматривать]} в личном кабинете информацию событиях, поступающих от ваших облачных сервисов и виртуальных машин;
- {linkto(#event-log-filter)[text=использовать]} фильтры и поисковые запросы для поиска нужных событий в журнале;
- {linkto(#event-log-export)[text=экспортировать]} отфильтрованный список событий.
