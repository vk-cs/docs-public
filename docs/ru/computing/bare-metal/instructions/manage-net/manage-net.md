# {heading(Настройка сетевой конфигурации)[id=bare-metal-network-config]}

Вы можете назначать VLAN на сетевые интерфейсы сервера Bare Metal и объединять интерфейсы в агрегированный интерфейс (LAG-интерфейс).

   {note:warn}
   Настройка сетевой конфигурации в личном кабинете применяется только на стороне сервиса Bare Metal. После сохранения настроек обновите конфигурацию сети в ОС.
   {/note}

## {heading(Настройка конфигурации сетевого интерфейса или LAG-интерфейса)[id=bare-metal-network-config-nic-or-bond]}

{tabs}

{tab(Личный кабинет)}

1. [Перейдите](https://msk.cloud.vk.ru/app/) в личный кабинет {var(cloud)}.
1. {linkto(../manage-server#bare-metal-server-get-info)[text=Узнайте]} количество сетевых интерфейсов вашего сервера.
1. Определите желаемую конфигурацию сети. При необходимости {linkto(#bare-metal-network-config-aggregate)[text=объедините]} сетевые интерфейсы в LAG-интерфейс.
1. Вычислите количество комбинаций сетевого интерфейса и VLAN, которые необходимы для желаемой конфигурации сети. Например, сервер имеет два сетевых интерфейса `nic0` и `nic1`.

   {cut(Примеры конфигураций с указанием количества комбинаций)}

   - `nic0` и `nic1` работают как два независимых сетевых интерфейса и оба используют только Native VLAN: `nic0 + Native VLAN` и `nic1 + Native VLAN`. Количество комбинаций: `2`.
   - `nic0` и `nic1` {linkto(#bare-metal-network-config-aggregate)[text=объединены]} в LAG-интерфейс `bond0`, который использует только Native VLAN: `bond0 + Native VLAN`. Количество комбинаций: `1`.
   - `nic0` и `nic1` работают как два независимых сетевых интерфейса, оба используют Native VLAN, `nic0` использует дополнительный VLAN: `nic0 + Native VLAN`, `nic0 + Дополнительный VLAN`, `nic1 + Native VLAN`. Количество комбинаций: `3`.

   {/cut}

1. Определите, какие VLAN будут использоваться для каждой комбинации сетевого интерфейса и VLAN. Для каждого интерфейса должен быть свой VLAN. При необходимости, {linkto(../manage-vlan#bare-metal-vlan-add)[text=создайте]} недостающие.
1. Перейдите в раздел **Bare Metal** → **Серверы**.
1. Откройте окно настройки сетевой конфигурации одним из способов:

   - Из списка серверов:

     1. В списке серверов Bare Metal нажмите ![ ](../../../../assets/more-icon.svg "inline") для нужного сервера.
     1. Выберите пункт **Настроить сетевую конфигурацию**.

   - На странице сервера:

     1. В списке серверов Bare Metal нажмите на имя нужного сервера.
     1. На странице сервера нажмите ![ ](../../../../assets/more-icon.svg "inline").
     1. Выберите пункт **Настроить сетевую конфигурацию**.

1. Каждый интерфейс (`nic`) в списке соответствует отдельной физической сетевой карте сервера. При необходимости, {linkto(#bare-metal-network-config-aggregate)[text=настройте]} объединение интерфейсов в LAG-интерфейс.

   Сетевые интерфейсы, включенные в LAG-интерфейс, не могут быть настроены отдельно.

1. Подготовьте желаемую конфигурацию для сетевых интерфейсов, а также LAG-интерфейсов, если они используются.

   1. Выберите **Native VLAN** из выпадающего списка.

      Трафик Native VLAN передается без тега (untagged) по стандарту 802.1Q.

   1. (Опционально) Добавьте дополнительные VLAN. Для этого нажмите **Добавить VLAN** и выберите нужный VLAN в выпадающем списке.

      В отличие от Native VLAN, трафик в дополнительных VLAN идет с тегом VLAN ID по стандарту 802.1Q.

      Чтобы убрать дополнительный VLAN из конфигурации, нажмите на значок ![trash-icon](../../../../assets/trash-icon.svg "inline") рядом с ним.

1. Нажмите **Сохранить** и обновите настройки сетевого интерфейса. Это можно делать автоматически или вручную.

   {tabs}

   {tab(Автоматически)}

   Автоматическое обновление конфигурации поддерживается в ОС, установленных из образов {var(cloud)} или [облачных образов популярных дистрибутивов](https://docs.openstack.org/image-guide/obtain-images.html), а также при самостоятельной установке [cloud-init](https://cloud-init.io/) в ОС. 

   Автоматическая конфигурация недоступна для сетевых интерфейсов, использующих VLAN с типом `L2Only`.

   Чтобы выполнить инициализацию `cloud-init`:

   1. Перезагрузите сервер, дождитесь загрузки ОС и проверьте доступность сервера по сети.
   1. Если связность не восстановилась, {linkto(../../connect/console#bare-metal-connect-console)[text=подключитесь]} к серверу через VNC-консоль и запустите инициализацию вручную с помощью команды:

      ```console
      cloudinit init
      ```

   1. Повторно проверьте доступность сервера.

      Если сервер по-прежнему недоступен, выполните настройку сетевых интерфейсов вручную.

   {/tab}

   {tab(Вручную)}

   Если сетевой интерфейс используется с VLAN типа `L2Only`, определите желаемую L2-адресацию самостоятельно и выполните настройку с помощью конфигуратора сетей вашей ОС (`netplan`, `ifupdown`, `network-scripts`, `wicked` и другие). В такой сети можно использовать любую адресацию из приватного пула адресов ([RFC 1918](https://www.rfc-editor.org/info/rfc1918/)). Для автоматического назначения IP-адресов в такой сети потребуется собственный DHCP-сервер.
   
   При использовании VLAN типа `Sprut` для изменения настроек сети, а также для подключения сервера к интернету воспользуйтесь практическим руководством {linkto(../../how-to-guides/configure-public-access#bare-metal-configure-public-access)[text=%text]}.

   Если сетевые интерфейсы объединены в LAG-интерфейс, в ОС необходимо создать объединенный интерфейс (`bond`) с поддержкой LACP (Link Aggregation Control Protocol).

   Если во время настройки сети в ОС связь с сервером пропала, {linkto(../../connect/console#bare-metal-connect-console)[text=подключитесь]} к серверу через VNC-консоль.

   {/tab}

   {/tabs}

{/tab}

## {heading(Объединение сетевых интерфейсов в LAG-интерфейс)[id=bare-metal-network-config-aggregate]}

Несколько сетевых интерфейсов сервера (`nic`) можно объединить в агрегированный интерфейс (LAG-интерфейс). Каждый сетевой интерфейс, участвующий в LAG-интерфейсе, подключается к двум разным коммутаторам, что обеспечивает резервирование сети на уровне L2-канала.

После объединения настроить сетевую конфигурацию на отдельных интерфейсах нельзя — вместо этого настраивается конфигурация LAG-интерфейса.

{tabs}

{tab(Личный кабинет)}

1. [Перейдите](https://msk.cloud.vk.ru/app/) в личный кабинет {var(cloud)}.
1. Перейдите в раздел **Bare Metal** → **Серверы**.
1. В списке серверов Bare Metal нажмите ![ ](../../../../assets/more-icon.svg "inline") для нужного сервера.
1. Выберите пункт **Настроить сетевую конфигурацию**.
1. Создайте LAG-интерфейс одним из способов.

   - В блоке **Сетевые интерфейсы** нажмите **Добавить в агрегат** у нужного интерфейса.

     Если в конфигурации сервера еще нет ни одного LAG-интерфейса, будет сразу создан LAG-интерфейс `bond0`, в который добавится этот интерфейс.
     Если хотя бы один LAG-интерфейс уже есть, откроется окно выбора, в котором можно добавить интерфейс в уже существующий LAG-интерфейс или же создать новый.

   - В блоке **Агрегация** нажмите **Добавить агрегат** и добавьте в него нужные сетевые интерфейсы, нажав **Добавить в агрегат** у нужных интерфейсов в блоке **Сетевые интерфейсы**, как описано выше.

   Для создания LAG-интерфейса в него необходимо добавить минимум два сетевых интерфейса.

1. Нажмите **Сохранить**.

{/tab}
