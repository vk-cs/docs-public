# {heading(Управление сервером)[id=bare-metal-manage-server]}

## {heading(Получение информации о сервере)[id=bare-metal-server-get-info]}

1. [Перейдите](https://msk.cloud.vk.ru/app/) в личный кабинет {var(cloud)}.
1. Перейдите в раздел **Облачные вычисления** → **Bare Metal**.
1. В списке серверов Bare Metal нажмите на имя нужного сервера.
1. Выберите вкладку с нужной информацией:

   - **Общая информация**: название, характеристики, идентификатор, текущий статус, зона доступности, IP-адрес, ОС.
   - **Сеть**: к какой сети подключен сервер и параметры подключения.
   - **Подключение**: информация для удаленного подключения к серверу.

## {heading(Создание тега для сервера)[id=bare-metal-server-tag-create]}

1. [Перейдите](https://msk.cloud.vk.ru/app/) в личный кабинет {var(cloud)}.
1. Перейдите в раздел **Облачные вычисления** → **Bare Metal**.
1. Откройте меню сервера одним из способов:

   - В списке серверов Bare Metal нажмите ![ ](../../../../assets/more-icon.svg "inline") для нужного сервера.
   - На странице сервера: 
   
      1. В списке серверов Bare Metal нажмите на имя нужного сервера. 
      1. На странице сервера нажмите ![ ](../../../../assets/more-icon.svg "inline").

1. Выберите пункт **Создать тег**.
1. В окне **Добавление нового тега** задайте имя и цвет тега.
1. Нажмите кнопку **Добавить тег**.
