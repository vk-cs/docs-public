# {heading(Ошибка 403 при удалении образа)[id=iaas-error-image-deleting]}

При попытке удалить образ возникает ошибка `403 Forbidden`.

Возможные причины:

- Образ используется. От него зависят диски или виртуальные машины, созданные из этого образа.
- Образ является общим (`shared`) и принадлежит другому проекту. Удалить его может только проект-владелец.

### {heading(Решение)[id=iaas-error-image-deleting-solution]}

1. Убедитесь, что вы удаляете образ в том проекте, где он был создан. 

   1. Посмотрите список образов проекта:

      ```console
      openstack image list
      ```

   1. Посмотрите детальную информацию об образе:

      ```console
      openstack image show <ID_ОБРАЗА>
      ```

      Если поле `visibility` в выводе имеет значение `shared`, образ принадлежит другому проекту, и удалить его из вашего проекта нельзя. Удалите образ в проекте-владельце либо отвяжите его от вашего проекта (команда выполняется в проекте-владельце образа):

      ```console
      openstack image remove project <ID_ОБРАЗА> <ID_ПРОЕКТА>
      ```

1. Проверьте, нет ли ресурсов, созданных на основе этого образа:

   1. Найдите диски, созданные из образа. Исходный образ указан в поле `volume_image_metadata`:

      ```console
      openstack volume list
      openstack volume show <ID_ДИСКА>
      ```

   1. Найдите виртуальные машины, созданные из образа:

      ```console
      openstack server list --long
      openstack server show <ID_ВМ>
      ```

   1. Если найдены зависимые диски или ВМ, сначала удалите их или дождитесь их удаления, затем повторите попытку:

      ```console
      openstack image delete <ID_ОБРАЗА>
      ```

1. Если образ не используется и принадлежит вашему проекту, а ошибка сохраняется, обратитесь в [техническую поддержку](/ru/contacts) и укажите ID образа.
