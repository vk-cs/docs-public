# {heading(Поколения процессоров)[id=iaas-cpu-generation]}

Производительность виртуальной машины зависит от ресурсов хоста, на котором она размещена. {var(cloud)} предоставляет серверное оборудование, которое позволяет сконфигурировать ВМ разных уровней производительности.

В {var(cloud)} для размещения ВМ используются процессоры:

[cols="3,3,1", options="header"]
|===
|Процессор
|Тип и поколение процессора
|Доступность

|Intel(R) Xeon(R) Gold 6230 CPU @ 2.10GHz <br> Intel(R) Xeon(R) Gold 6238R CPU @ 2.20GHz
|Intel Cascade Lake (Intel Xeon Gen 2)
|По умолчанию

|Intel Xeon Gold 6338 @ 2.0GHz <br> Intel Xeon Platinum 8380 CPU @ 2.3GHz
|Intel Ice Lake (Intel Xeon Gen 3)
|По умолчанию

|Intel(R) Xeon(R) Gold 6230 CPU @ 2.10GHz <br> (3.40GHz в Turbo Boost) <br> Intel(R) Xeon(R) Gold 6238R CPU @ 2.20GHz <br> (3.70GHz в Turbo Boost) <br> Intel(R) Xeon(R) Platinum 8380 CPU @ 2.30GHz <br> (3.40GHz в Turbo Boost)
|Высокопроизводительные процессоры
|По запросу

|AMD EPYC 7662
|Только для некоторых виртуальных машин с GPU
|По запросу
|===

Конфигурации, доступные по умолчанию, позволяют создавать ВМ на серверах со стандартными процессорами.

Для получения доступа к высокопроизводительным процессорам обратитесь в [техническую поддержку](/ru/contacts). Стоимость виртуальной машины с высокопроизводительным процессором рассчитывается индивидуально для каждого запроса.

Поколение процессора, на котором размещается ВМ, определяется {linkto(../../vm/flavor#iaas-flavor)[text=шаблоном конфигурации]} (flavor) виртуальной машины. Шаблоны с высокопроизводительными CPU доступны по запросу и выбираются при создании или изменении конфигурации ВМ.
