# {heading(Теги)[id=iaas-tags]}

Тег — строка, с помощью которой можно классифицировать виртуальные машины в {var(cloud)}. Теги позволяют группировать ВМ, например по окружению, команде или назначению, и быстрее находить нужные при {ifndef(private-cert)}{linkto(../../../../../computing/iaas/instructions/vm/vm-filter#iaas-vm-filter)[text=фильтрации]}{/ifndef}{ifdef(private-cert)}фильтрации{/ifdef}.

Вы можете {linkto(../../../../../computing/iaas/instructions/vm/vm-manage#iaas-vm-manage-tags)[text=присвоить]} тег виртуальной машине, указав его имя и цвет. В OpenStack CLI тег имеет формат `<ИМЯ>^<ЦВЕТ>`, например `env:prod^positive`. Цвет задается одним из следующих значений:

- `validation` — фиолетовый;
- `negative` — красный;
- `positive` — зеленый;
- `neutral` — серый;
- `info` — синий;
- `light` — белый;
- `warning` — оранжевый.

К тегам применяются ограничения:

- тег не может быть пустым;
- максимальная длина одного тега — 60 символов, включая обозначение цвета;
- запрещены символы `/` и `,`;
- у одной ВМ может быть не более 50 тегов;
- теги чувствительны к регистру: например, `Prod` и `prod` — разные теги.
