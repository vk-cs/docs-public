# {heading(Триггеры)[id=alerting-triggers]}

## {heading(Создание триггера)[id=alerting-triggers-add]}

1. {ifdef(public)}[Перейдите](https://msk.cloud.vk.ru/app/){/ifdef}{ifndef(public)}{linkto(../../../../tools-for-using-services/account/instructions/lk-entry#tools-account-lk-entry)[text=Перейдите]}{/ifndef} в личный кабинет {var(cloud)}.
1. Добавьте триггер одним из способов:

    - Через вкладку **Триггеры**:
        1. Перейдите в раздел **Мониторинг → Алертинг**.
        1. Перейдите на вкладку **Триггеры** и нажмите кнопку **Добавить**.
    - Со страницы мониторинга:
        1. Перейдите в раздел **Мониторинг**.
        1. В блоке **Алертинг** нажмите кнопку **Создать триггеры**.
1. Выберите источник данных:

   - `Мониторинг` — по метрикам сервиса {linkto(../../../monitoring/concepts/architecture#monitoring-architecture)[text=Cloud Monitoring]};
   - `Логирование` — по записям сервиса {linkto(../../../logging/concepts/about#event-log-about)[text=Cloud Logging]};
   - `Журнал событий` — по событиям сервиса {linkto(../../../event-log/concepts/about#logging-about)[text=Cloud Audit]}.

1. Укажите название триггера.
1. (Опционально) Нажмите кнопку ![plus-icon](../../../../assets/plus-icon.svg "inline") **Добавить описание** и добавьте описание триггера.
1. Укажите параметры триггера:

   {tabs}
   {tab(Мониторинг)}
   - **Тип ресурса**: выберите из списка тип ресурса {var(cloud)}, с которого собираются данные мониторинга.
   - **Источник**: выберите из списка источник (название ВМ, БД, контейнера и т.п.).
   - **Название метрики**: выберите из списка нужную метрику. Если список пуст, значит, для инстанса не включен мониторинг. {linkto(../../../monitoring/instructions/mon-setup-current#monitoring-mon-setup-current)[text=Установите]} агент мониторинга на нужную ВМ.
   - (Опционально) ![plus-icon](../../../../assets/plus-icon.svg "inline") **Добавить метку**: нажмите на кнопку и выберите из списков название и значение {linkto(../../../monitoring/concepts/architecture#monitoring-label)[text=метки]}.
   - **Условие срабатывания триггера**: выберите из списка операцию сравнения и укажите пороговое значение.
   - **Интервал сравнения**: выберите из списка интервал, в течение которого должно выполняться условие, чтобы триггер сработал.
   {/tab}
   {tab(Логирование)}
   - **Продукт**: выберите из списка один из сервисов {var(cloud)}.
   - **Введите запрос для создания триггера**: чтобы найти нужную запись в логах, введите запрос на {linkto(../../../logging/concepts/search-tools#logging-search-tools)[text=языке поисковых запросов]} и нажмите кнопку **Проверить запрос**.

     Если запрос составлен корректно, в правой части экрана отобразится предварительный график срабатываний триггера на основе найденных записей.
   {/tab}
   {tab(Журнал событий)}
   - **Слой**: выберите из списка слой, из которого будут собираться события:
     - `Управляющий слой` — {linkto(../../../event-log/concepts/logged-events#event-log-logged-events)[text=события]} внутренних компонентов, отвечающих за работу сервисов {var(cloud)};
     - `Слой данных` — события обработки и передачи данных в развернутых пользователем компонентах сервиса.
   - **Продукт**: выберите из списка один из сервисов {var(cloud)}.
   - **Введите запрос для создания триггера**: чтобы найти нужное событие, введите запрос на {linkto(../../../logging/concepts/search-tools#logging-search-tools)[text=языке поисковых запросов]} и нажмите кнопку **Проверить запрос**.

     Если запрос составлен корректно, в правой части экрана отобразится предварительный график срабатываний триггера на основе найденных записей.
   {/tab}
   {/tabs}

1. Выберите из списка существующий канал уведомлений или опцию `Создать новый канал`. Если вы создаете новый канал уведомлений, укажите его параметры:

   - **Имя канала**: введите название для канала.
   {ifdef(public)}
   - **Тип уведомлений**: выберите опцию `Email` или `SMS`.
   {/ifdef}
   - **Получатель**: введите электронный адрес или телефон получателя уведомлений.

1. (Опционально) Нажмите ![plus-icon](../../../../assets/plus-icon.svg "inline") **Добавить канал**, чтобы добавить еще один канал уведомлений и укажите его параметры.
1. Нажмите кнопку **Создать триггер**.

## {heading(Редактирование триггера)[id=alerting-triggers-edit]}

1. {ifdef(public)}[Перейдите](https://msk.cloud.vk.ru/app/){/ifdef}{ifndef(public)}{linkto(../../../../tools-for-using-services/account/instructions/lk-entry#tools-account-lk-entry)[text=Перейдите]}{/ifndef} в личный кабинет {var(cloud)}.
1. Перейдите в раздел **Мониторинг → Алертинг**.
1. Нажмите ![more-icon](../../../../assets/more-icon.svg "inline") для нужного триггера и выберите пункт **Изменить**.
1. Введите необходимые изменения.
1. Нажмите кнопку **Сохранить**.

## {heading(Запуск триггера)[id=alerting-triggers-start]}

Если триггер сработал более 100 раз в течение 24 часов, он автоматически отключается. Вы получите электронное письмо с рекомендациями.

Наиболее распространенная причина частого срабатывания триггера — его неправильная настройка. Перед запуском триггера {linkto(#alerting-triggers-add)[text=проверьте]}, что он настроен правильно.

Чтобы запустить триггер:

1. {ifdef(public)}[Перейдите](https://msk.cloud.vk.ru/app/){/ifdef}{ifndef(public)}{linkto(../../../../tools-for-using-services/account/instructions/lk-entry#tools-account-lk-entry)[text=Перейдите]}{/ifndef} в личный кабинет {var(cloud)}.
1. Перейдите в раздел **Мониторинг → Алертинг**.
1. Нажмите ![more-icon](../../../../assets/more-icon.svg "inline") для нужного триггера, выберите пункт **Включить** и подтвердите действие.
