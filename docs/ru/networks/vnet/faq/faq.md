## {heading(Сети, подсети и порты)[id=vnet-faq-nets-ports]}

{cut(Для чего используются подсети в моем облаке и к каким зонам доступности они относятся?)}

Для анализа подсетей обратитесь в [техническую поддержку](/ru/contacts).
В обращении сообщите:

- {linkto(../../../tools-for-using-services/account/instructions/project-settings/manage#project-pid-view)[text=PID проекта]};
- {linkto(../../../networks/vnet/instructions/net#vnet-net-view)[text=ID подсетей]}.

{/cut}

{cut(Будет ли IP-адрес шлюза доступен из другого проекта?)}

Будет, если вы используете {linkto(../../../networks/vnet/concepts/net-types#vnet-net-types-shared-net)[text=общие сети]}. Для организации сетевой связности в целевом проекте {linkto(../../../networks/vnet/instructions/shared-nets#vnet-shared-nets)[text=предоставьте доступ к нужной сети]}, а затем {linkto(../../../networks/vnet/instructions/router#vnet-router-static-routs-manage)[text=настройте маршрутизацию]} в обоих проектах.

{/cut}

{cut(Как перенести порт с одной ВМ на другую?)}

1. {linkto(../../../networks/vnet/instructions/ports#vnet-ports-off)[text=Отключите]} порт от первой виртуальной машины.
1. {linkto(../../../networks/vnet/instructions/ports#vnet-ports-on)[text=Подключите]} порт ко второй виртуальной машине.

{/cut}

{cut(Можно ли управлять продвинутым маршрутизатором через OpenStack CLI?)}

Нет, управление {linkto(../concepts/router#vnet-router-advanced)[text=продвинутым маршрутизатором]} через команды OpenStack CLI не поддерживается, так как это специализированный сервис {var(cloud)}. Для управления продвинутым маршрутизатором используйте {linkto(../instructions/advanced-router#vnet-advanced-router)[text=личный кабинет]} или {linkto(../../../tools-for-using-services/api/api-spec/network-api/neutron-sprut-api#api-spec-neutron-sprut)[text=API]}.

{/cut}

## {heading(IP-адреса и доступ в интернет)[id=vnet-faq-ip]}

{cut(Как управлять PTR-записями для IP-адреса?)}

Чтобы настроить обратный DNS-запрос с помощью PTR-записи, обратитесь в [техническую поддержку](/ru/contacts).
В обращении сообщите IP-адрес и соответствующее ему доменное имя.

{/cut}

{cut(Как сменить Floating IP-адрес ВМ?)}

1. {linkto(../../../networks/vnet/instructions/ip/floating-ip#vnet-floating-ip-disassociate)[text=Отвяжите]} текущий Floating IP-адрес от порта.
1. {linkto(../../../networks/vnet/instructions/ip/floating-ip#vnet-floating-ip-add)[text=Получите]} новый Floating IP-адрес.

{/cut}

{cut(Можно ли выбрать конкретный диапазон IP-адресов, если нет возможности разрешать сразу несколько IP-зон?)}

Выбор конкретного диапазона или подсети для публичного IP (Floating IP) не предусмотрен. Адрес назначается случайным образом из доступного пула. Для реализации белых списков на вашей стороне рекомендуется использовать VPN-туннель или выделенное подключение, чтобы взаимодействовать через стабильный внутренний IP.

{/cut}

{cut(Как получить квоту на внешний IP-адрес?)}

По умолчанию в проекте нет доступных квот на внешние IP-адреса и их нельзя увеличить через [техническую поддержку](/ru/contacts).

Чтобы снять ограничение, обратитесь к менеджеру по почте [sales-team@mcs.mail.ru](mailto:sales-team@mcs.mail.ru). После согласования деталей менеджер создаст запрос на увеличение квоты внешних IP-адресов. В дальнейшем вы сможете {linkto(../../../tools-for-using-services/account/instructions/project-settings/manage#project-increase-quota)[увеличивать]} квоты самостоятельно.

{/cut}

{cut(Как получить IP-адрес из утвержденного списка Минцифры?)}

{var(cloud)} не предоставляет IP-адреса из утвержденного списка Минцифры и не добавляет в него новые IP-адреса.

Если вам необходимо обеспечить доступность веб-сервиса для пользователей, рассмотрите альтернативный вариант — запуск сервиса в виде мини-приложения в MAX. Для размещения мини-приложений можно использовать инфраструктуру {var(cloud)}.

Подробнее о создании и подключении мини-приложений — в [документации MAX](https://dev.max.ru/docs/webapps/introduction).

{/cut}

{cut(Есть ли ограничения на доступ к публичным ресурсам с IP-адресов {var(cloud)}?)}

{var(cloud)} предоставляет стандартный доступ в интернет без блокировки публичных ресурсов.

Вы можете проверить это, {linkto(../../../networks/vnet/quick-start#vnet-quick-start)[text=создав]} ВМ с доступом в интернет.

{/cut}

{cut(Что делать, если внешний ресурс недоступен из сети {var(cloud)}?)}

{var(cloud)} не ограничивает доступ к публичным ресурсам. Однако для IP-адресов с территории Российской Федерации некоторые сервисы могут ограничивать доступ, например, к API или зеркалам. В таком случае получение внешнего IP-адреса недостаточно.

Для некоторых сценариев {var(cloud)} может предложить альтернативные варианты организации сетевого взаимодействия. Возможность их использования зависит от архитектуры вашего решения и необходимых ресурсов.

Чтобы подобрать подходящий вариант для вашего сценария, обратитесь к менеджеру по почте [sales-team@mcs.mail.ru](mailto:sales-team@mcs.mail.ru).

{/cut}

{cut(Ограничивается ли трафик до внешних SMTP-серверов?)}

Для защиты от спама на новых проектах исходящий трафик через порты SMTP (25, 465, 587) по умолчанию ограничен.

Если вы не можете отправить почту, обратитесь в [техническую поддержку](/ru/contacts), чтобы снять ограничение.

{/cut}

{cut(На ВМ в одной зоне доступности сервис работает стабильно, а на ВМ в другой зоне периодически растет число ошибок 5XX. Что делать?)}

[Обратитесь в техническую поддержку](/ru/contacts) для диагностики сетевых проблем. Обязательно приложите результаты трассировки (MTR) в момент возникновения проблемы (минимум 1000 пакетов) и точные временные метки инцидентов.

{/cut}

## {heading(VPN)[id=vnet-faq-vpn]}

{cut(Какие есть особенности настройки VPN на Windows Server?)}

Для работы VPN (IPsec/IKEv2) на Windows Server настройте разрешающие правила:

1. В группах безопасности {var(cloud)}.
   
   {linkto(../../../networks/vnet/instructions/secgroups#vnet-secgroups-add-rule)[text=Добавьте]} правило для входящего трафика по протоколу UDP на порты 500 и 4500. В качестве источника укажите IP-адрес или диапазон адресов VPN-клиентов.

1. В Брандмауэре Windows на виртуальной машине.
   
   Создайте правила, разрешающие входящие подключения по UDP к портам 500 и 4500.

{/cut}
