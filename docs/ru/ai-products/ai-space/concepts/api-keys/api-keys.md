# {heading(API-ключи)[id=ai-space-concepts-api-keys]}

API-ключ нужен, чтобы отправлять запросы к {linkto(../models#ai-space-concepts-models)[text=моделям]} из кода, скриптов, IDE и внешних систем. Ключ передается в каждом запросе. API совместим с API OpenAI.

Запрос к модели по ключу выполняется с правами владельца ключа — {linkto(../organization#ai-space-concepts-organization-users)[text=пользователя или виртуального пользователя]}. Расход по ключу учитывается в {linkto(../billing#ai-space-concepts-balance-control)[text=лимитах расходов]} владельца, а также в лимитах проекта и организации.

В VK AI Space есть два вида ключей: личные ключи и ключи виртуального пользователя. Они различаются тем, от чьего имени выполняется запрос, где действует ключ и когда он перестает работать.

[cols="1,2,2", options="header"]
|===
|Параметр
|Личный ключ
|Ключ виртуального пользователя

|От чьего имени выполняется запрос
|От имени пользователя, который создал ключ, с его правами
|От имени виртуального пользователя проекта, с его правами

|Где действует
|Во всех проектах организации, в которых состоит пользователь
|В проекте виртуального пользователя

|В каком лимите учитывается расход
|В лимите пользователя
|В лимите виртуального пользователя. Лимит ограничивает суммарный расход по всем его ключам

|Кто создает
|Любой пользователь — для себя
|Владелец и администраторы проекта, а также администраторы организации

|Когда перестает работать
|Когда пользователя исключают из организации, его ключи удаляются
|Когда виртуального пользователя отключают или удаляют. Уход сотрудников на ключ не влияет
|===

Сервис хранит не само значение ключа, а только его хеш, и показывает его значение один раз при создании или перевыпуске.

Для каждого ключа сервис хранит дату последнего использования.
