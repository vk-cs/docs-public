# {heading(Модели)[id=ai-space-concepts-models]}

Модель в VK AI Space — алгоритм машинного обучения, доступный в проекте для обработки запросов. Модели могут вести диалог, обрабатывать документы, искать ответы в базе знаний и работать с изображениями.

Модели работают на стороне VK AI Space. Пользователи тестируют модели в интерфейсе сервиса и подключают их к своим приложениям через API.

Набор моделей один для всей {linkto(../organization#ai-space-concepts-organization)[text=организации]}. Во всех проектах доступны одни и те же модели по одинаковой цене.

## {heading(Типы моделей)[id=ai-space-concepts-models-types]}

Тип модели определяет, для каких задач она подходит. В VK AI Space доступны:

- Текстовые модели — генерируют и анализируют текст: ведут диалог, отвечают на вопросы и выполняют инструкции.
- Мультимодальные модели — анализируют не только текст, но и изображения и видео: распознают текст на сканах, описывают фотографии и отвечают на вопросы по скриншотам. Мультимодальная модель возвращает результат анализа в виде текста.

## {heading(Дополнительные возможности моделей)[id=ai-space-concepts-models-capabilities]}

Модели одного типа могут поддерживать разные дополнительные возможности. В отличие от {linkto(#ai-space-concepts-models-card)[text=характеристик]}, возможность нельзя измерить. Модель либо поддерживает ее, либо нет.

В VK AI Space есть модели со следующими возможностями:

- Вызов функций (function calling) — модель формирует вызов внешней функции по заданной схеме. Это позволяет подключать к модели собственные инструменты и API.
- Структурированный вывод (structured output) — модель возвращает ответ строго по заданной JSON-схеме. Это удобно для интеграций и автоматической обработки ответов.
- Рассуждение (reasoning) — модель анализирует задачу перед ответом и выделяет промежуточные шаги. Такие модели лучше справляются с расчетами и сложными вопросами, но обычно отвечают дольше и расходуют больше токенов.

## {heading(Характеристики модели)[id=ai-space-concepts-models-card]}

Чтобы выбрать модель под задачу, сравните ее характеристики:

- Размер контекста — количество токенов, которое модель способна удерживать за один запрос. *Токен* — единица текста для модели: слово, часть слова или знак. По ним рассчитывается стоимость и в них измеряется длина запроса и ответа.

  В контекст входят системный промпт, история диалога, переданные документы и ответ модели. Запрос, который не помещается в контекст, модель не обрабатывает. В этом случае сократите историю диалога или объем документов.

- Максимальное количество выходных токенов — количество токенов, которое модель может сгенерировать в одном ответе.

- Квантизация — формат хранения весов модели. Примеры: FP8, BF16 или INT4. Чем меньше разрядность, тем быстрее и дешевле модель, но тем ниже может быть и качество ответов.

- Бенчмарки — результаты выполнения открытых тестов моделью. Бенчмарки позволяют оценить модели по следующим показателям:

  - Интеллект — способности модели к рассуждениям. Для оценки используется средний результат в тестах GPQA Diamond (научные вопросы) и AIME (олимпиадная математика).
  - Код — способности модели к написанию кода и работе с инструментами в реальных проектах. Для оценки используется средний результат в тестах LiveCodeBench и SWE-bench Verified.
  - Знания — знания модели в разных областях и умение решать задачи на русском языке. Для оценки используется средний результат в тестах MMLU-Pro и MERA.

  Бенчмарки помогают сравнить модели между собой, но не заменяют проверку на ваших данных. Перед подключением модели к приложению {linkto(../../instructions/models/comparison#ai-space-instructions-models-comparison)[text=сравните]} несколько моделей на типовых запросах.

- Цена — стоимость 1 млн входных, выходных и кешированных токенов.

## {heading(Параметры генерации)[id=ai-space-concepts-models-parameters]}

Параметры генерации влияют на то, каким будет ответ модели:

- Температура (`temperature`) — степень случайности ответов. Низкие значения дают точные и предсказуемые ответы, а высокие — творческие и разнообразные.
- Выходные токены (`max_completion_tokens`) — максимальное количество токенов в ответе. Значение не может превышать максимальное количество выходных токенов модели.
- Top-p (`top_p`) — отбор следующих слов по суммарной вероятности. Чем ниже значение, тем точнее и предсказуемее ответ.
- Top-k (`top_k`) — ограничение выбора следующего слова наиболее вероятными вариантами. Чем меньше значение, тем предсказуемее текст.

Модели могут не поддерживать некоторые из этих параметров.

Определите задачу и правила поведения для модели с помощью системного промпта — инструкции, которая передается вместе с каждым запросом.

## {heading(Запрос к модели)[id=ai-space-concepts-models-request]}

API VK AI Space совместим с API OpenAI. Для запросов подходят SDK OpenAI и HTTP-клиенты. Базовый URL один для всех моделей. Чтобы выбрать модель, укажите ее в параметре `model`.

Запрос выполняется с {linkto(../api-keys#ai-space-concepts-api-keys)[text=API-ключом]}:

- Личный ключ действует от имени создателя и с его правами во всех проектах, в которых он состоит.
- Ключ {linkto(../organization#ai-space-concepts-organization-users)[text=виртуального пользователя]} действует с правами и лимитами расходов виртуального пользователя в рамках его проекта.

В API-запросе тип ответа задается параметром `stream`. Ответ модели может быть:

- обычным (`stream: false`) — целиком одним сообщением;
- потоковым (`stream: true`) — передается клиенту частями по мере генерации.

Если исчерпан любой из применимых {linkto(../billing#ai-space-concepts-balance-control)[text=лимитов расходов]}, запрос будет отклонен.

## {heading(Стоимость)[id=ai-space-concepts-models-cost]}

У каждой модели своя цена. Цена указывается за 1 млн токенов и различается для следующих видов токенов:

- Входные токены — токены запроса: системный промпт, история диалога, документы и вопрос.
- Выходные токены — токены ответа модели.
- Кешированные токены — токены запроса, которые модель уже обработала раньше. Например, кешированными могут быть токены повторного системного промпта или истории диалога. Если модель не поддерживает кеширование, такие токены не тарифицируются отдельно.

Некоторые модели предоставляются бесплатно.

Стоимость запроса рассчитывается по цене модели и фактическому числу токенов и списывается с {linkto(../billing#ai-space-concepts-billing)[text=лицевого счета организации]}. Запрос, на который модель вернула ошибку, не тарифицируется. Если потоковый ответ прерван, списывается стоимость фактически полученной части ответа.
