# {heading(Отправка запроса к модели через API)[id=ai-space-instructions-api]}

В VK AI Space вы можете подключить модель к приложению, боту или внутреннему сервису: API совместим с OpenAI, поэтому подходят SDK OpenAI и HTTP-клиенты. Базовый URL один для всех моделей. Параметры подключения можно взять со страницы модели.

## {heading(Предварительные шаги)[id=ai-space-instructions-api-prep]}

1. Войдите в VK AI Space:

   {include(../../../_includes/_ai-login.md)[tags=ai-go]}

1. При предоплате убедитесь, что {linkto(../../billing/balance#ai-space-instructions-billing-balance-topup)[text=баланс лицевого счета]} положительный.

   Если для запроса не хватает средств или исчерпан лимит расходов, сервис отклоняет запрос.

## {heading(1. Выберите модель)[id=ai-space-instructions-api-choose]}

1. Нажмите на название проекта в шапке страницы и в списке **Проекты** выберите нужный проект.
1. В разделе **Модели** перейдите на вкладку **Парк моделей**.
1. Найдите модель и нажмите на ее название. Чтобы быстрее найти модель, введите ее название в поле **Поиск** или нажмите кнопку **Фильтры** и задайте условия.

## {heading(2. Выберите или создайте API-ключ)[id=ai-space-instructions-api-key]}

1. На странице модели перейдите на вкладку **API**.
1. В блоке **API-ключ AI Space** выберите API-ключ.

   Если нужного ключа нет или нужно создать новый, нажмите кнопку **Создать ключ**:

   1. Выберите вид ключа: личный ключ или ключ виртуального пользователя. Выбор доступен владельцу проекта, администратору проекта и администратору организации. Участник проекта может создать только личный ключ.

      Для ключа виртуального пользователя выберите существующего виртуального пользователя или создайте нового. Для нового укажите название, роль — `Администратор` или `Участник` — и, при необходимости, описание.

   1. Задайте параметры ключа:

   {include(../../../_includes/_api-keys.md)[tags=create-form]}

## {heading(3. Скопируйте запрос к модели)[id=ai-space-instructions-api-sample]}

1. В области **Запрос к модели** выберите язык запроса: Python, JavaScript или cURL.
1. Скопируйте запрос и подставьте свой ключ.

   Пример на Python:

   ```python
   from openai import OpenAI
   client = OpenAI(
       base_url="<БАЗОВЫЙ_URL>",
       api_key="<API_КЛЮЧ>",
   )

   completion = client.chat.completions.create(
       model="<МОДЕЛЬ>",
       messages=[
           {
               "role": "user",
               "content": "What is the capital of Russia?"
           }
       ],
   )

   print(completion.choices[0].message)
   ```

   Здесь:

   - `<БАЗОВЫЙ_URL>` — базовый URL сервиса, единый для всех моделей. Заполняется автоматически.
   - `<API_КЛЮЧ>` — значение личного ключа или ключа виртуального пользователя. Заполняется вручную.
   - `<МОДЕЛЬ>` — название модели. Заполняется автоматически.

   В приложениях не указывайте значение ключа прямо в коде: передавайте его через переменную окружения или хранилище секретов.

Модель проанализирует запрос и вернет ответ.

После успешного запроса {linkto(../../billing/statistics#ai-space-instructions-billing-statistics-personal)[text=посмотрите личную статистику]}: в ней видно, сколько токенов израсходовал запрос и сколько он стоил.
