# {heading(Справочник ролей)[id=iam-roles-reference]}

Роли доступа — это предустановленные наборы прав, которые позволяют выполнять определенные операции в {var(cloud)}.

Роли бывают следующих типов:

- {linkto(#iam-roles-reference-basic)[text=Базовые роли]} — встроенные роли сервиса с заранее заданными наборами прав, необходимых для администрирования, просмотра и аудита.
- {linkto(#iam-roles-reference-special)[text=Специализированные роли]} — содержат наборы прав для управления определенным сервисом или какой-либо частью настроек [проекта](/ru/tools-for-using-services/account/concepts/projects).
