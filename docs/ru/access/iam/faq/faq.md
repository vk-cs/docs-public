# {heading(Вопросы и ответы)[id=iam-faq]}

{cut(Как выйти из проекта?)}

В {var(cloud)} вы не можете самостоятельно выйти из проекта. Чтобы покинуть проект, обратитесь к владельцу или администратору проекта с просьбой удалить вашу учетную запись из списка участников.

Если вы не можете связаться с владельцем проекта или он отказывается удалить вас, обратитесь в [техническую поддержку](/ru/contacts).

{/cut}

{cut(Как владельцу или администратору удалить пользователя из проекта?)}

Чтобы удалить пользователя из проекта воспользуйтесь {linkto(../instructions/access-manage#iam-access-manage-delete-user)[text=инструкцией]}.

{/cut}

{cut(Можно ли работать под одной учетной записью в разных локациях?)}

Нет. Невозможно зарегистрировать учетные записи с одной и той же почтой в разных регионах.

{/cut}

{cut(Можно ли подтвердить номер телефона тем же номером, что у прошлого владельца проекта?)}

Нет. Один номер можно привязать только к одной учетной записи.

{/cut}
