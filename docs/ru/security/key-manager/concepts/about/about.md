# {heading(О сервисе)[id=km-about]}

Менеджер ключей — сервис для централизованного управления {linkto(#km-about-keys)[text=ключами]} шифрования в безопасной и изолированной среде {var(cloud)}.

Сервис обеспечивает криптографическую защиту чувствительных данных как в собственных приложениях и сервисах, так и в {linkto(../../../secret-manager/concepts/about#sm-about)[text=менеджере секретов]} от {var(cloud)}.

## {heading(Ключи)[id=km-about-keys]}

_Ключ_ — набор криптографических параметров для шифрования и дешифрования данных.

- _Идентификатор ключа_ — указанная пользователем уникальная последовательность символов. Содержит только цифры, латинские буквы и символы `-`, `_` и `.`, должен быть уникальным среди всех ключей в проекте {var(cloud)}.
- _Алгоритм шифрования_ — выбираемый пользователем один из доступных алгоритмов для шифрования и дешифрования.

    - AES-128 (aes128-gcm96),
    - AES-256 (aes256-gcm96),
    - ChaCha20-Poly1305 (chacha20-poly1305),
    - XChaCha20-Poly1305 (xchacha20-poly1305).

    {note:info}
    В бета-версии менеджер ключей от {var(cloud)} поддерживает только алгоритмы с симметричным шифрованием.
    {/note}

- _Ключевой материал_ — данные, которые используются для шифрования и дешифрования на основе выбранного алгоритма. Менеджер ключей {var(cloud)} самостоятельно генерирует ключевой материал в изолированной среде, пользователь не участвует в его подготовке.

Ключами и их версиями можно {linkto(../../security/key-manager/instructions#km-instructions)[text=управлять]} через личный кабинет {var(cloud)} или с помощью {linkto(../../../../tools-for-using-services/api/api-spec/key-manager-api#api-spec-km)[text=API]}.

## {heading(Версии и ротация)[id=km-about-versions]}

Менеджер ключей {var(cloud)} позволяет хранить несколько версий одного и того же ключа. Новая версия создается с помощью ротации — новый ключевой материал генерируется вручную по запросу или автоматически через заданный временной интервал.

После запуска ротации обновление ключевого материала происходит асинхронно, он обновляется не сразу. Новый ключевой материал привязывается к новой версии ключа и, эта версия становится текущей. Прежние версии также доступны, чтобы выполнять дешифрование данных, зашифрованных ранее.
