{includetag(configure)}

1. При необходимости отредактируйте:

   - выбранную версию;
   - название приложения;
   - название пространства имен, куда будет установлен аддон.
       
1. Настройте код аддона, чтобы хранить создаваемые резервные копии в {var(s3)}. Для этого добавьте следующие параметры:

   [cols="2", options="header"]
   |===
   |Параметр
   |Значение

   |`bucket`, блок `configuration` 
   |Имя созданного бакета

   |`aws_access_key_id`, блок `credentials`
   |Идентификатор ключа (`Access Key ID`) аккаунта {var(s3)} 

   |`aws_secret_access_key`, блок `credentials`
   |Секретный ключ (`Secret Key`) аккаунта {var(s3)}
   |===
   
1. При необходимости {linkto(#k8s-install-advanced-velero-edit-code)[text=внесите]} дополнительные изменения в код настройки аддона.

   {note:warn}
   Некорректно заданный код настройки может привести к ошибкам при установке или неработоспособности аддона.
   {/note}

{/includetag}

{includetag(optional)}

1. Убедитесь, что аддон установлен с корректными настройками хранилища {var(s3)}:

   1. {linkto(../../../../connect/kubectl#k8s-kubectl)[text=Подключитесь]} к кластеру с помощью `kubectl`.
   1. Убедитесь, что под, на котором расположен Velero, запущен, с помощью команды:
      
      ```console
      kubectl -n velero get pods 
      ```
   
      В выводе команды статус пода должен быть `Running`.
   
   1. Убедитесь, что указанное хранилище {var(s3)} доступно для Velero, с помощью команды:
      
      ```console
      kubectl -n velero get backupstoragelocations 
      ```
      
      В выводе команды состояние конфигурации, которое отображается в столбце `PHASE`, должно быть `Available`.

1. (Опционально) [Познакомьтесь с официальной документацией Velero](https://velero.io/docs/main/).
