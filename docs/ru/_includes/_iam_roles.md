{includetag(mcs_owner)}
Название в личном кабинете: `Владелец проекта`.

Роль с максимальным набором прав на проекте. Роль автоматически назначается пользователю, который сам создал проект, либо для которого проект был автоматически создан при регистрации аккаунта.

В проекте может быть только один владелец. Эту роль нельзя назначить вручную или пригласить на нее.
{/includetag}

{includetag(mcs_co_owner)}
Название в личном кабинете: `Суперадминистратор`.

Роль, которая предоставляет разрешения на управление всеми ресурсами проекта. Эта роль может быть назначена пользователю только владельцем проекта.
{/includetag}

{includetag(mcs_admin)}
Название в личном кабинете: `Администратор проекта`.

Роль, которая предоставляет разрешения на управление всеми ресурсами проекта, кроме групп пользователей и баланса.
{/includetag}

{includetag(mcs_admin_security)}
Название в личном кабинете: `Администратор пользователей (IAM)`.

Роль, предназначенная для управления участниками проекта на странице управления доступами. Администратор пользователей может приглашать участников в проект и удалять их из него, редактировать назначенные участникам роли. Сервисы и информация о балансе проекта для этой роли недоступны.

В сервисе Cloud Logging роль позволяет просматривать логи.

В сервисе Cloud Monitoring роль позволяет просматривать дашборды.

В сервисе Cloud Audit роль позволяет просматривать события сервиса IAM и собственные действия пользователя.
{/includetag}

Название в личном кабинете: `Наблюдатель`.  

Роль, которая предоставляет разрешения на просмотр большей части информации о проекте и ресурсах, но не имеет разрешений для их создания и изменения.

В сервисе Cloud Logging роль позволяет просматривать логи.

{/includetag}

{includetag(k8s-admin-magnum)}
Название в личном кабинете: `Администратор Kubernetes`.

Роль с максимально широким набором разрешений для работы с сервисом Managed Containers. Некоторые действия доступны только в определенном состоянии кластера. Например, установка и удаление аддонов возможны, только если кластер запущен.

Пользователь с этой ролью может: 

- создавать и удалять кластеры;
- запускать и останавливать кластеры;
- отображать информацию о кластере и группах узлов;
- получать файл `kubeconfig`;
- получать секрет для доступа в Kubernetes Dashboard;
- обновлять версию кластера;
- изменять тип виртуальной машины;
- изменять размер диска Prometheus;
- добавлять или удалять группу узлов;
- изменять настройки масштабирования групп узлов;
- изменять метки (labels) и ограничения (taints);
- устанавливать или удалять аддоны.

В сервисе Cloud Logging роль позволяет просматривать логи и генерировать учетные данные.

В сервисе Cloud Monitoring роль позволяет просматривать, создавать и редактировать дашборды, а также делать запись в систему мониторинга.

В сервисе Cloud Audit роль позволяет просматривать события сервиса Managed Containers и собственные действия пользователя, а также выгружать эти данные.

{/includetag}
