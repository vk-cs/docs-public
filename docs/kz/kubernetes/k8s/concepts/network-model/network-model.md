# {heading(Kubernetes желілік моделі)[id=k8s-network-model]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Kubernetes қолданбалар арасында машиналарды бірлесіп пайдалануға арналған. Әдетте, компьютерлерді бірлесіп пайдалану үшін екі қолданбаның бірдей порттарды пайдалануға әрекеттеспеуі талап етіледі.

Әр под өз IP-мекенжайын алады. Бұл порттарды бөлудің, атау беру әдісінің, қызметтерді анықтау әдісінің, жүктемені теңгерудің, қолданбаларды конфигурациялаудың және миграцияның тұрғысынан подтармен ВМ немесе физикалық хосттармен жұмыс істегендей жұмыс істеуге мүмкіндік беретін таза, кері үйлесімді модельді құрайды.

Kubernetes кез келген желілік іске асыруға мынадай іргелі талаптар қояды (желдің әдейі сегменттелуіне бағытталған кез келген саясатты тоқтата отырып):

* Түйіндегі (node) модульдер NAT пайдаланбай барлық түйіндегі барлық модульдермен байланыса алады.
* Түйіндегі агенттер, мысалы жүйелік демондер, осы түйіндегі барлық модульдермен байланыса алады.
* Хост желісінде подтармен жұмыс істеуді қолдайтын платформалар үшін, мысалы Linux, түйіннің хост-желісіндегі модульдер NAT пайдаланбай барлық түйіндегі барлық модульдермен байланыса алады.

Kubernetes IP-мекенжайлары под ауқымында өмір сүреді — контейнерлер подтардың желілік атаулар кеңістіктеріне ортақ қолжетімділік шеңберінде, оның ішінде олардың IP-мекенжайлары да бар. Под ішіндегі барлық контейнерлер бір-бірінің порттарына `localhost` арқылы қол жеткізе алады. Под ішіндегі контейнерлер портты пайдалануды үйлестіруі тиіс.
