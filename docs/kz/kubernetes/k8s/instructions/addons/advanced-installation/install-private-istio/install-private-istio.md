# {heading(Istio)[id=k8s-install-advanced-istio]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Istio — бұл қызметтер желісінің (service mesh) тұжырымдамасын жүзеге асыратын фреймворк, онда қолданба қызметтерінің өзара әрекеттесуі үшін бөлек қабат бөлінеді. Istio пайдалану қызметтерге өз кодтарын өзгертпей-ақ трафикті басқару мүмкіндігін береді (sidecar-контейнерлер пайдаланылады).

## {heading(Аддонды орнату)[id=k8s-install-advanced-istio-install]}

1. {var(cloud)} жеке кабинетіне {linkto(../../../../../../tools-for-using-services/account/instructions/lk-entry#tools-account-lk-entry)[text=өтіңіз]}.
1. Қажетті кластер орналасқан жобаны таңдаңыз.
1. **Кластеры Kubernetes** → **Кластеры Kubernetes** бөліміне өтіңіз.
1. Қажетті кластердің атауын басыңыз.
1. **Аддоны** қойындысына өтіңіз.
1. `istio` аддонының карточкасындағы **Установить** түймесін басып, **Установить аддон** түймесін басыңыз.
1. (Қалауыңыз бойынша) Өзгертіңіз:

    - қолданбаның атауын;
    - аддон орнатылатын атаулар кеңістігінің атауын;
    - аддонды баптау кодын.

      {note:warn}
      Дұрыс берілмеген баптау коды орнату кезінде қателерге немесе аддонның жұмыс істемеуіне әкелуі мүмкін.
      {/note}

      Код параметрлерінің толық сипаттамасы [Istio репозиторийінде](https://github.com/istio/istio/blob/1.19.3/manifests/charts/istio-control/istio-discovery/values.yaml) қолжетімді.

1. **Установить аддон** түймесін басыңыз.

   Аддонды кластерге орнату басталады. Бұл процесс ұзақ уақыт алуы мүмкін.

1. Қолданбасы бар атаулар кеңістігі үшін Istio аддонын белсендіру үшін команданы орындаңыз:

   ```console
   kubectl label namespace <АТАУЛАР_КЕҢІСТІГІ> istio-injection=enabled --overwrite
   ```
   Мұнда `<АТАУЛАР_КЕҢІСТІГІ>` — атаулар кеңістігінің атауы.
