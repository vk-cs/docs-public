# {heading(Istio-ingressgateway)[id=k8s-install-istio-ingressgateway]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Istio Ingress Gateway қосымшалар деңгейіндегі L7 жүктеме теңгерушісі ретінде пайдаланылады.
Күрделі микросервистік қосымшалардағы кіріс трафигін басқаруды жеңілдетеді.

Мүмкіндіктері:

* Жүктемені теңгеру, сүзгілеу және маршруттау.
* Кеңейтілген мониторинг.
*(circuit breaker) арқылы каскадтық істен шығулардан қорғауды қолдау.
* Қосымшаға бір уақыттағы қосылыстардың максималды санын шектеу.

## {heading(Аддонды орнату)[id=k8s-install-istio-ingressgateway-install]}

1. {var(cloud)} жеке кабинетіне {linkto(../../../../../../tools-for-using-services/account/instructions/lk-entry#tools-account-lk-entry)[text=өтіңіз]}.
1. Қажетті кластер орналасқан жобаны таңдаңыз.
1. **Кластеры Kubernetes** → **Кластеры Kubernetes** бөліміне өтіңіз.
1. Қажетті кластердің атауын басыңыз.
1. **Аддоны** қойындысына өтіңіз.
1. `istio-ingressgateway` аддонының карточкасындағы **Установить** түймесін басып, **Установить аддон** түймесін басыңыз.
1. (Қалауыңыз бойынша) Өзгертіңіз:

   - қосымшаның атауын;
   - аддон орнатылатын атаулар кеңістігінің атауын;
   - аддонды баптау кодын.

     Kubernetes кластері сыртқы желіде орнатылған болса, аддон кодында теңгерушінің IP-адресінің алдына аннотацияны қосыңыз:

     ```console
     annotations:
       service.beta.kubernetes.io/openstack-internal-load-balancer: "true"
     ```

1. **Установить аддон** түймесін басыңыз.

   Аддонның кластерге орнатылуы басталады. Бұл процесс ұзақ уақыт алуы мүмкін.

1. Орнату аяқталғаннан кейін теңгерушінің IP-адресін алуын күтіңіз.

1. Теңгерушінің IP-адресін алыңыз:

   ```console
   kubectl get svc -n <АТАУЛАР_КЕҢІСТІГІ>
   ```

   Мұнда `<АТАУЛАР_КЕҢІСТІГІ>` — атаулар кеңістігінің атауы.
