# {heading(Кластерлерді қолжетімділік аймақтары арасында миграциялау)[id=mk8s-az-migration]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Кластерді қолжетімділік аймақтары арасында миграциялау үш қадамда жүреді:

1. Миграция сіздің кластерлеріңіздің жұмыс жүктемесіне ([workload](https://kubernetes.io/docs/concepts/workloads/)) әсер ететінін анықтаңыз. Ол үшін қолжетімділік аймағы көрсетілген-көрсетілмегенін тексеріңіз:

   {include(/kz/_includes/_az-migration-magnum.md)[tags=check]}

1. Егер кластердің жұмыс жүктемесі қолжетімділік аймағына тәуелді болса, оны өз бетіңізше немесе {var(cloud)} тарапынан кластер ресурстарын миграциялау жұмыстары {linkto(../../how-to-guides/workload-migration/pre-migration#mk8s-pre-migration)[text=басталмай тұрып]}, немесе {linkto(../../how-to-guides/workload-migration/post-migration#mk8s-post-migration)[text=кейін]} көшіріңіз.

   Өз бетіңізше көшіру кезінде жұмыс жүктемесін тоқтатуға тура келеді.

1. {var(cloud)} қызметкерлері кластер ресурстарын көшіргенше күтіңіз:

   - master-түйіндер,
   - worker-түйіндер топтары,
   - ВМ,
   - дискілер,
   - жүктеме балансирлеушілері.

   Кластер жұмыстар кезінде қолжетімді болады, миграция live migration форматасында жүреді. {var(cloud)} қызметкерлері жұмыстардың басталуы мен мерзімі туралы сізге пошта арқылы хабарлайды.
