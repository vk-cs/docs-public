## {heading(Орнату кезінде аддонды баптау кодын өңдеу)[id=mk8s-install-advanced-cert-operator-edit-code]}

Аддон кодын өңдеу тек стандартты орнатуға қолданылады.

Кодта `reconcileInterval` параметрін өзгертуге болады. Бұл — аддон кластердің worker-түйіндеріндегі CA-сертификаттарды синхрондайтын аралық. Оның әдепкі мәні — `30s`.

Аддон подтарының қалған параметрлері (`tolerations`, `nodeSelector`, `affinity`, `priorityClassName` және басқалары) басқа Kubernetes ресурстары сияқты стандартты тәсілмен беріледі. Аддонның CA-сертификаттарды синхрондайтын түйіндер тізімін шектеу үшін `nodeSelector`, `affinity` немесе `tolerations` пайдаланыңыз.

Кодты өңдегеннен кейін аддонды орнатуды жалғастырыңыз.
