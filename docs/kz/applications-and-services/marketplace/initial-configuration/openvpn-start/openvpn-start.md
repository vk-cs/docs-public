# {heading(OpenVPN орнату)[id=marketplace-openvpn-start]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Бұлт ресурстарына қолжетімділікті [OpenVPN](https://msk.cloud.vk.ru/app/mcs3723876490/services/marketplace/v2/apps/service/11bd457f-5006-4a5e-9aa3-e07586a487c2/v1_test/info) сервисі арқылы басқаруға болады. Бұл нұсқаулық {var(cloud)} құрамындағы ВМ-де OpenVPN сервисін орнатуға, сервис консоліне кіруге және жаңа пайдаланушы жасауға көмектеседі.

OpenVPN сервисін пайдалана отырып, сіз [Marketplace](../../../../start/legal/offer/private-special-conditions/policy-marketplace) және [OpenVPN](https://openvpn.net/legal) сервистерінің лицензиялық келісімдерімен келісесіз.

OpenVPN сервисін жобада орнату үшін:

1. {var(cloud)} қызметінде {linkto(../../../../intro/onboarding/account/create-account#onboarding-create-account)[text=тіркеліңіз]}.
1. Бұрын жасалмаса, интернетке қолжетімділігі бар желіні {linkto(../../../../networks/vnet/instructions/net#vnet-net-add)[text=жасаңыз]}.
1. Сервис орнатылатын ВМ орналасатын {linkto(../../../../networks/vnet/instructions/net#vnet-net-subnet-edit)[text=субжелінің баптауларында]} **Приватный DNS** опциясын өшіріңіз.
1. OpenVPN сервисін {linkto(../../../../applications-and-services/marketplace/instructions/pr-instance-add#marketplace-pr-instance-add)[text=орнатыңыз]}:

   1. **Кластер баптаулары** қадамында ВМ баптауларын көрсетіңіз:

     - **Желі**: бұрын жасалған интернетке қолжетімділігі бар желі мен субжеліні таңдаңыз. Сыртқы IP-адрес автоматты түрде тағайындалады.
     - ВМ-нің қалған параметрлерін өз қалауыңыз бойынша таңдаңыз.

   1. **Келесі қадам** түймесін басыңыз.
   1. **OpenVPN баптаулары** қадамында желілік қолжетімділік баптауларын көрсетіңіз:

     - **Клиенттік адресаттар субжелісі**: сервис пайдаланушы құрылғыларына адресаттар тағайындайтын субжелінің адресін көрсетіңіз. Бұл адрес кеңістігі қолжетімділік бапталатын адрес кеңістігімен қиылыспауын тексеріңіз.
     - **DNS адресі**: OpenVPN домен атауларын IP-адрестермен сәйкестендіру үшін пайдаланатын DNS-сервердің адресі. Субжеліден қолжетімді болса, жергілікті де, сыртқы сервер де пайдаланылуы мүмкін.
     - **Full-tunneling қосу**: опция қосылғанда, пайдаланушылардың бүкіл трафигі VPN арқылы бағытталады. Бұл үлкен деректер ағындары берілу кезінде серверге жүктемені арттырады. Егер VPN арқылы тек субжеліге қолжетімділік үшін пайдаланушылар трафигін бағыттау қажет болса, опцияны өшіріңіз.
     - **Субжелі адресаттары**: қолжетімділік беру қажет субжелілердің адресаттарын үтір арқылы көрсетіңіз. Мысалы: `10.0.0.0/24,10.0.10.0/24`. Бұл субжелілерге сервис орнатылған субжеліден қолжетімділік болады. Орналастыру субжелісі сервисте әдепкі бойынша көрсетіледі, сондықтан оны осында қосудың қажеті жоқ. **Full-tunneling қосу** опциясы қосылғанда параметр еленбейді.

       {note:warn}
       Қолжетімділік жасалатын субжелілердегі маршрутизаторлар баптауларын тексеріңіз: **Субжелі адресаттары** өрісінде көрсетілген субжелілер арасында желілік байланыс бапталған болуы тиіс.
       {/note}

   1. **Келесі қадам** түймесін басыңыз.
   1. **Растау** қадамында есептелген сервис құнымен танысып, **Тарифті қосу** түймесін басыңыз.

   Орнату аяқталғаннан кейін поштаға мыналарды қамтитын беттің бір реттік сілтемесі келеді:

   - бірінші пайдаланушыға арналған конфигурация;
   - ВМ-ге кіру кілті;
   - ВМ-нің сыртқы және ішкі IP-адрестері.

1. Сервис ВМ-іне SSH арқылы қосылыңыз. Ол үшін терминалда команданы орындаңыз:

   ```console
   ssh -i <КЛЮЧ_ДОСТУПА> ubuntu@<IP-АДРЕС_ВМ>
   ```

   Мұнда:

   - `<КЛЮЧ_ДОСТУПА>` — бір реттік сілтеме арқылы алынған кіру кілті;
   - `<IP-АДРЕС_ВМ>` — бір реттік сілтеме арқылы алынған ВМ-нің сыртқы IP-адресі.

1. Root-пайдаланушы құқықтарын алыңыз (`sudo bash` командасы).
1. Жаңа пайдаланушы жасаңыз. Команданы орындаңыз:

   ```console
   /home/ubuntu/create_client.sh <ИМЯ_ПОЛЬЗОВАТЕЛЯ>
   ```

   Скрипт сәтті аяқталғаннан кейін `/etc/openvpn/server` жолында жаңа пайдаланушының конфигурация файлы пайда болады.

1. (Қалауыңыз бойынша) Пайдаланушыны блоктаңыз. Команданы орындаңыз:

   ```console
   /home/ubuntu/revoke_client.sh <ИМЯ_ПОЛЬЗОВАТЕЛЯ>
   ```

   Скрипт сәтті аяқталғаннан кейін `crl.pem` сертификаты жаңартылады, ал OpenVPN сервисі қайта іске қосылады. `<ИМЯ_ПОЛЬЗОВАТЕЛЯ>` пайдаланушысына қолжетімділік алынып тасталады.

   Пайдаланушының конфигурация файлы `/etc/openvpn/server` каталогынан өшірілмейді. Ондай атпен пайдаланушы жасау әрекетінде скрипт орындалады, бірақ ештеңе болмайды, себебі мұндай пайдаланушы әлдеқашан бар. Пайдаланушыға қолжетімділікті қалпына келтіру үшін жаңа атаумен конфигурация файлын жасаңыз.

{note:info}
Сервисті кеңейтілген баптау үшін [OpenVPN ресми нұсқаулығын](https://openvpn.net/access-server-manual/introduction) пайдаланыңыз.
{/note}
