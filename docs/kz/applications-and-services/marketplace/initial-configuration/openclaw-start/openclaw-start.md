# {heading(OpenClaw сервісін орнату және баптау)[id=marketplace-openclaw-quick-start]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

[OpenClaw](https://msk.cloud.vk.ru/app/services/marketplace/v2/apps/service/546d0a61-00dd-4ce9-b662-d7eeb4be3149/v0.12/info) — бұл LLM негізінде AI-агенттер мен қолданбалар жасауға арналған ашық бастапқы кодты құрал. Ол сондай-ақ мұндай агенттер мен қолданбаларды тиімді басқаруға мүмкіндік береді. OpenClaw агенттерді баптауға, сыртқы құралдарды интеграциялауға және тапсырмаларды автоматтандыруға арналған интерфейс ұсынады.

OpenClaw мүмкіндіктері:

- AI-агенттер: деректерді талдауға, пайдаланушылармен және сыртқы сервистермен әрекеттесуге арналған ақылды көмекшілерді жасау.
- LLM басқару: мәтін генерациялау, ақпаратты талдау және процестерді автоматтандыру үшін модельдерді қосу және бақылау.
- Сыртқы сервистермен интеграция: агенттердің функцияларын кеңейту үшін API пайдалану.
- Тапсырмаларды автоматтандыру: агенттер тапсырмаларды дербес орындайтын сценарийлерді баптау.
- Мониторинг: конфигурацияны бақылау және агенттердің жұмысын қадағалау.
- Кастомизация: платформаны өз құралдары мен плагиндерімен кеңейту.

OpenClaw сервисін пайдалану арқылы сіз [Marketplace VK Cloud](/ru/start/legal/vk/marketplace) және [OpenClaw](https://github.com/openclaw/openclaw/blob/main/LICENSE) лицензиялық келісімдерімен келісесіз.

## {heading(Дайындық қадамдары)[id=marketplace-openclaw-prep]}

OpenClaw сервисін сіздің {var(cloud)} жобасыңыздағы ВМ орналастыру үшін:

1. {var(cloud)} платформасында {linkto(../../../../intro/onboarding/account/create-account#onboarding-create-account)[text=тіркеліңіз]} және жеке кабинетке [өтіңіз](https://msk.cloud.vk.com/app).

1. Сервиске қандай қол жетімділік болуы керектігін анықтаңыз:

   - Сыртқы — ВМ орналастырылған OpenClaw сервисіне интернеттен қол жеткізуге болады. Егер бұл әлі жасалмаған болса, желіні баптау қажет болуы мүмкін.
   - Ішкі — OpenClaw сервисіне {var(cloud)} жоба желісінен ішкі IP-мекенжай бойынша ғана қол жеткізуге болады. Мұндай жағдайда сыртқы желіні баптау қажет болмайды.
   
1. Егер сервиске интернеттен қол жеткізгіңіз келсе, қосымша желіні баптаңыз:
 
   1. Егер әлі жасалмаған болса, интернетке қол жетімділігі бар желіні {linkto(../../../../networks/vnet/instructions/net#vnet-net-add)[text=жасаңыз]}.
   1. ВМ орналасатын {linkto(../../../../networks/vnet/instructions/net#vnet-net-subnet-edit)[text=ішкі желі баптауларында]} **Жеке DNS** опциясын өшіріңіз.

## {heading({counter(openclaw)}. Сервісті қосыңыз)[id=marketplace-openclaw-enable]}

1. {var(cloud)} [жеке кабинетінде](https://msk.cloud.vk.com/app/) **Қолданбалар дүкені** бөліміне өтіңіз.
1. **OpenClaw** сервис картасында **Толығырақ** түймесін басыңыз.
1. Сервис сипаттамасы бар бетте **Қосылу** түймесін басыңыз.
1. **Сервер параметрлері** бетінде OpenClaw сервисіне қосылу баптауларын көрсетіңіз.

   1. OpenClaw параметрлерін көрсетіңіз:

      - **openclaw қалай орналастырылады**: сервис орналастыру түрін таңдаңыз.

         - `external` — {var(cloud)} ұсынған сыртқы IP-мекенжаймен және домен атауымен. Сонымен OpenClaw сервисі орналастырылған ВМ интернеттен қол жетімді болады.
         - `internal` — {var(cloud)} жоба желісінен ішкі IP-мекенжай бойынша ғана қол жетімділікпен.

      - **S3 резервтік көшіруге қосуды қосыңыз**: OpenClaw деректерінің резервтік көшірмелерін күн сайын {var(cloud)} {linkto(../../../../storage/s3/concepts/about#s3-concepts-about)[text=объектілік сақтауішінде]} жасау үшін опцияны қосыңыз. Сақтауыш автоматты түрде жасалады. Соңғы 7 көшірме сақталады.

      - **Мониторингті қосуды қосыңыз**: OpenClaw орналастырылған виртуалды машинаның метрикаларын автоматты түрде {linkto(../../../../monitoring-services/monitoring#monitoring)[text=Cloud Monitoring]} сервисіне жіберу үшін опцияны қосыңыз. Бұл метрикалар жеке кабинеттің **Мониторинг** бөлімінде қолжетімді болады.

   1. Сервис инстансы орналастырылатын виртуалды машинаның параметрлерін көрсетіңіз:

      - **Желі**: сервис орналастырылған ВМ орналасатын желіні таңдаңыз. Егер сіз `external` орналастыру түрін көрсетсеңіз, интернетке қол жетімділігі бар бұрын бапталған желіні және **Жеке DNS** опциясы өшірілген ішкі желіні таңдаңыз.
      - **Қолжетімділік аймағы**: ВМ іске қосылатын {linkto(../../../../start/concepts/architecture#architecture-az)[text=қолжетімділік аймағын]} таңдаңыз.
      - **Виртуалды машина түрі**: сіздің жүктемеңізге сәйкес [алдын ала орнатылған ВМ конфигурациясын](/kz/computing/iaas/concepts/vm/flavor#iaas-flavor-vm-categories) таңдаңыз. Пилоттық сценарийлер үшін ең аз конфигурация жеткілікті.

   1. Жүйелік дискі мен деректер дискісінің параметрлерін көрсетіңіз:

      - **Диск өлшемі**: ВМ дискісінің қажетті өлшемін гигабайтпен көрсетіңіз.
      - **Диск түрі**: `HDD`, `SSD` немесе `High-IOPS SSD` {linkto(../../../../computing/iaas/concepts/data-storage/disk-types#iaas-disk-types-list)[text=диск түрлерінің біреуін]} таңдаңыз.

1. **Келесі қадам** түймесін басыңыз.

1. Сервисті орналастыру үшін инфрақұрылым құнымен танысыңыз және **Тарифті қосыңыз** түймесін басыңыз.

   Бұлтты инфрақұрылымды орналастыру басталады және сервис қасиеттерінің беті ашылады. Процесс күйі сондай-ақ **Қолданбалар дүкені → Менің сервистерім** бөлімінде көрсетіледі.

   Сәтті орналастырудан кейін {var(cloud)} аккаунтыңызға байланған поштаға келесі хабарламалар келеді:

   - {var(cloud)} жеке кабинетіндегі сервис инстансына сілтеме бар хабарлама;
   - сервиске қол жеткізуге арналған деректерге бір реттік сілтемесі бар хат.

1. Хаттағы бір реттік сілтеме бойынша өтіп, сервиске қол жеткізуге арналған деректерді сақтаңыз:

   - `openclaw_url` — OpenClaw веб-интерфейсінің мекенжайы;
   - `openclaw_login_url` — браузерде бірден ашылуы мүмкін қол жеткізу токені бар веб-интерфейс мекенжайы;
   - `openclaw_gateway_token` — OpenClaw-ға қол жеткізу токені;
   - `os_user` — SSH арқылы кіру үшін жүйелік пайдаланушы аты;
   - `keypair` — сервис орналастырылған виртуалды машинаға SSH арқылы қосылу үшін жеке кілт.
   
   {note:info}
   Егер қол жеткізу деректері жоғалса, жаңаларды [генерациялаңыз](/kz/applications-and-services/marketplace/instructions/pr-instance-manage#pr-instance-manage-recreate).
   {/note}

## {heading({counter(openclaw)}. Сервистің жұмыс қабілеттілігін тексеріңіз)[id=marketplace-openclaw-check]}

1. OpenClaw сервисінің веб-интерфейсіне келесі әдістердің бірімен өтіңіз:

   - `openclaw_login_url` ішінде көрсетілген мекенжай бойынша.
   - `openclaw_url` ішінде көрсетілген мекенжай бойынша. Бұл жағдайда ашылған беттегі **Gateway Token** өрісіне `openclaw_gateway_token` параметрінің мәнін енгізіңіз және **Connect** түймесін басыңыз.

1. OpenClaw интерфейсінде кез келген агент немесе жоба жасаңыз. Толығырақ [OpenClaw ресми құжаттамасында](https://docs.openclaw.ai/).

1. LLM-провайдеріңіздің тіркелгі деректерін көрсетіп, сыртқы сервистермен интеграция үшін қажетті [құралдарды](https://docs.openclaw.ai/channels) баптаңыз.

1. Агенттің сценарийді дұрыс орындайтынына көз жеткізу үшін тесттік тапсырманы іске қосыңыз.

## {heading({counter(openclaw)}. Модельді веб-интерфейс арқылы қосыңыз)[id=marketplace-openclaw-check]}

1. OpenClaw сервисінің веб-интерфейсінде **Config** бөліміне өтіңіз.
1. **Raw** режиміне ауысып, бар параметрлерді өшірместен, қажетті модель баптауларын JSON-конфигурацияға қосыңыз.

   ```json
   {
     "gateway": {
       "mode": "local",
       "bind": "lan",
       "controlUi": {
         "dangerouslyDisableDeviceAuth": true,
         "allowedOrigins": [
           "http://127.0.0.1:18789",
           "http://openclaw-XXXXXXXX.xaas.msk.bizmrg.com"
         ]
       }
     },
     "agents": {
       "defaults": {
         "model": {
           "primary": "my-provider/my-model"
         }
       }
     },
     "models": {
       "mode": "merge",
       "providers": {
         "my-provider": {
           "baseUrl": "https://api.example.com/v1",
           "apiKey": "${<API_KEY>}",
           "api": "openai-completions",
           "models": [
             { "id": "my-model", "name": "My Model" }
           ]
         }
       }
     }
   }
   ```

   Мұнда:

   - `allowedOrigins` — қосылуға рұқсат етілген URL тізімін орнатады. Стандартты `http://127.0.0.1:18789`-ден басқа, `openclaw_url` ішінен мәнді де қосыңыз.
   - `primary` — `providers` блогынан алынған, әдепкі бойынша пайдаланылатын LLM моделі. `<ПРОВАЙДЕР_АТАУЫ>/<МОДЕЛЬ_ID>` немесе жай ғана `<МОДЕЛЬ_ID>` пішімінде көрсетіледі.
   - `my-provider` — провайдеріңіздің параметрлерін және қолжетімді модельдерді сипаттайтын кез келген атаулы блок:
      - `baseUrl` — AI-провайдеріңіздің эндпоинт URL мекенжайы. Мысалы, `https://api.openai.com/v1`.
      - `apiKey` — LLM моделіне қол жеткізу үшін провайдеріңіздің API-кілтi (егер қолданылса).
      - `api` — OpenClaw провайдер API-сына өтінетін протокол. Көп жағдайда көптеген провайдерлер қолдайтын `openai-completions` немесе `openai-chat-completions` пайдаланылады.
      - `models` — мәндері бар нысандар жиымы:
         - `id` — модель идентификаторы, AI-провайдердегі мәнге дәл сәйкес келуі тиіс.
         - `name` — модель үшін кез келген атау.

   Көбірек ақпарат [OpenClaw ресми құжаттамасында](https://docs.openclaw.ai/).

1. Конфигурацияны сақтау және қолдану үшін **Apply** түймесін басыңыз.
