# {heading(VK Security Gate орнату)[id=secgate-start]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

VK Security Gate — бұл VK Cloud жобасындағы бөлек виртуалды машинаға орнатылатын қауіпсіздікті талдау платформасы, ол код сапасын автоматтандырылған бақылау мүмкіндіктерін ұсынады:

* кодты статикалық талдау (SAST),
* тәуелділіктерді талдау (SCA),
* құпиясөздерді іздеу,
* SBOM құру.

Сервис мүмкіндіктерін LLM-моделдерімен немесе CodeQL, Jira сияқты сіздің ішкі құралдарыңызбен интеграция арқылы кеңейтуге болады. Сервис туралы толығырақ [VK Security Gate ресми құжаттамасында](https://cloud.vk.com/docs/on-premises/security-gate).

Сервисті пайдалана отырып, сіз [Marketplace](../../../../start/legal/offer/private-special-conditions/policy-marketplace) сервисінің лицензиялық келісімі мен [VK Security Gate](https://vkcloud-cms-prod.s3.prodcloud.vk.team/EULA_Security_Gate_fin_1_2bec12401b.pdf) сервисінің лицензиялық келісімін қабылдайсыз.

VK Security Gate сервистін VK Cloud жобасында орнату үшін:

1. {linkto(../../../../intro/onboarding/account/create-account#onboarding-create-account)[text=Тіркеліңіз]} және {var(cloud)} жеке кабинетіне [өтіңіз](https://msk.cloud.vk.ru/app).
1. Интернеттен сервиске қолжетімділік болу үшін желіні баптаңыз:

   1. Бұрыннан жасалмаған болса, интернетке қолжетімділігі бар {linkto(../../../../networks/vnet/instructions/net#vnet-net-add)[text=желі жасаңыз]}.
   1. Сервис орнатылатын ВМ орналасатын {linkto(../../../../networks/vnet/instructions/net#vnet-net-subnet-edit)[text=ішкі желі баптауларында]} **Приватный DNS** опциясын өшіріңіз.

1. **Қосымшалар дүкені** бөліміне өтіп, бөлім бетінде **Барлық шешімдер** түймесін басыңыз.
1. **VK Security Gate** сервис карточкасында **Толығырақ** түймесін басыңыз.
1. Сервис сипаттамасы бар бетте **Қосу** түймесін басыңыз.
1. **Тарифтік жоспарлар** қойындысынан тізімнен сервис нұсқасын таңдаңыз.
1. Қолайлы тарифті таңдаңыз:

   - **VK Security Gate 10** — 10 репозиторийге дейін және 1 000 000 жол кодқа дейін.
   - **VK Security Gate 50** — 50 репозиторийге дейін және 5 000 000 жол кодқа дейін.
   - **VK Security Gate 200** — 200 репозиторийге дейін және 20 000 000 жол кодқа дейін.
   - **VK Security Gate 500** — 500 репозиторийге дейін және 50 000 000 жол кодқа дейін.

1. **Параметры сервера** бетінде деректерді енгізіңіз.

   1. Сервис орнатылатын виртуалды машинаның параметрлерін көрсетіңіз:

      - **Зона доступности**: ВМ іске қосылатын {linkto(../../../../start/concepts/architecture#architecture-az)[text=қолжетімділік аймағын]} таңдаңыз.
      - **Тип виртуальной машины**: {linkto(../../../../computing/iaas/concepts/vm/flavor#iaas-flavor)[text=алдын ала орнатылған ВМ конфигурациясын]} таңдаңыз. **VK Security Gate 200** және **VK Security Gate 500** жоспарлары үшін `STD3-16-64` қалдырыңыз: бұл жоспарларға кемінде 16 ядро және 64 ГБ жад қажет.
      - **Сеть**: бұрыннан жасалған интернетке қолжетімділігі бар желіні және **Приватный DNS** опциясы өшірілген ішкі желіні таңдаңыз.

   1. Жүйелік диск пен деректері бар дисктің параметрлерін көрсетіңіз.

      - **Размер диска**: ВМ дискісінің қажетті өлшемін гигабайтпен көрсетіңіз. Дискіде осалдықтар базасы, Kafka, MinIO және сканерлеудің жұмыс каталогтары сақталады, сондықтан өлшемі 100 ГБ-дан кем болмауы керек.
      - **Тип диска**: {linkto(../../../../computing/iaas/concepts/data-storage/disk-types#iaas-disk-types-list)[text=диск түрлерінің бірін]} таңдаңыз — `HDD`, `SSD` немесе `High-IOPS SSD`. Қарқынды жүктеме үшін `High-IOPS SSD` таңдаңыз.

1. **Следующий шаг** түймесін басыңыз.
1. **Параметры продукта** қадамында параметрлерді көрсетіңіз:

   - **E-mail администратора**: жұмыс адресін көрсетіңіз. Ол администратордың логині болады.
   - **Домен, сертификат и публичный адрес**: өнімге интернеттен қол жеткізілсе, опцияны қосулы қалдырыңыз. Опцияны өшірген жағдайда өнім ішкі желідегі өзі қол қойған сертификаты бар ВМ-нің IP-адресі арқылы ғана қолжетімді болады.
   - **Сеть мониторинга**: сервиске тек таңдалған ішкі желіден қолжетімділік ашу үшін `subnet` мәнін көрсетіңіз немесе қосымшалар жұмыс істейтін `10.20.0.0/16` түріндегі желі ауқымын қойыңыз. {linkto(../../../../computing/iaas/concepts/data-storage/disk-types#iaas-disk-types-list)[text=Ішкі желі адресін]} жеке кабинеттен көруге болады. Метрикалар құпиясөзсіз беріледі, сондықтан ауқымды тарылту жақсы.

1. (Қалауыңыз бойынша) **Интеграции** қадамында қажетті интеграцияларды қосыңыз:

   - **Отправка почты**: шақыру хаттарын және құпиясөзді қалпына келтіру хаттарын алу қажет болса, қосыңыз. Пошта болмаса, шақыру — администратор пайдаланушыға өзі жеткізетін сілтеме. Пошта жіберу параметрлерін қойыңыз:

      - **SMTP-сервер**: SMTP-серверіңіздің атын немесе IP-адресін көрсетіңіз, мысалы `smtp.example.com`.
      - **Порт SMTP**: `465` мәнін қалдырыңыз. Тек логин мен құпиясөзі бар SSL (жасырын TLS) қолдау көрсетіледі.
      - **Логин SMTP**: SMTP-серверіне кіру үшін қолданылатын тіркелгіңізді көрсетіңіз.
      - **Пароль SMTP**: тіркелгіңіздің басқару таңбаларысыз құпиясөзін көрсетіңіз. Кері қиғаш сызық құпиясөздің соңында немесе жалқы тырнақшаның алдында тұра алмайды.
      - **Адрес отправителя**: хаттар жіберілетін адресін көрсетіңіз, мысалы `secgate@example.com`.

    - **CodeQL**: GitHub-тың CodeQL анализаторы қажет болса, опцияны қосыңыз. Ол жеткізілімге кірмейді, оған лицензияны сіз өзіңіз аласыз.

      - **Ссылка на архив CodeQL**: Linux үшін `tar.gz` форматындағы CodeQL архивініе тікелей https сілтемесін көрсетіңіз: GitHub релизі, сіздің серверіңіз немесе Object Storage-тағы нысанға уақытша сілтеме. Серверге бұл адреске қолжетімділік қажет. Сервер архивті өзі жүктеп алады.

    - **AI-триаж находок**: табылдықтарды тіл моделі арқылы талдағыңыз келсе, опцияны қосыңыз. OpenAI-мен үйлесімді API-і бар кез келген модель жарамды. Табылған құпиясөздерді модель автоматты түрде талдайды, қалған табылдықтар — табылдық карточкасындағы түйме арқылы. Модель табылдықтардан код фрагменттерін алады, сондықтан оны код қайда бағытталатынын ескере отырып таңдаңыз.

      - **Адрес модели**: `/v1` сіз базовый адресін көрсетіңіз, мысалы `https://llm.example.com`.
      - **Имя модели**: атауын API қабылдайтын түрде көрсетіңіз, мысалы `gpt-4o-mini`.
      - **Ключ API модели**: модельге кіру кілтін көрсетіңіз. Егер модельге кілт қажет болмаса, әдепкі мәнді қалдырыңыз.
      - **Разбирать все SAST-находки автоматически**: опцияны өшірулі қалдырыңыз. Модельдің әрбір жаңа SAST табылдығын талдауы үшін оны қосыңыз: модельге жасалатын сұраныстар шығыны табылдықтар санына байланысты өседе.

    - **Jira**: табылдықтар бойынша тапсырмалар жасағыңыз келсе, опцияны қосыңыз. Тек Jira Data Center және Jira Server қолдау көрсетіледі, Jira Cloud жарамайды.

      - **Адрес Jira**: `/rest` әдетегі адресін көрсетіңіз, мысалы `https://jira.example.com`.
      - **Персональный токен доступа**: Jira-да **Profile** → **Personal Access Tokens** бөлімінде токен жасаңыз. Оны тек қажетті жобаларға қолжетімділігі бар бөлек тіркелгіден шығарған дұрыс: осылайша өнім қажеттіліктен артық құқық алмайды.

1. **Следующий шаг** түймесін басыңыз.
1. Сервисті орнатуға арналған инфрақұрылымның құнымен танысып, **Подключить тариф** түймесін басыңыз.

   Бұлттық инфрақұрылымды орнату басталады және сервис қасиеттерінің беті ашылады. Процесс статусы **Қосымшалар дүкені** → **Мои сервисы** бөлімінде де көрсетіледі.

   Сәтті орнатудан кейін {var(cloud)} байланыстырылған поштаңызға хабарламалар келеді:

   - {var(cloud)} жеке кабинетіндегі сервис инстансына сілтемесі бар хабарлама;
   - сервиске кіру деректеріне бір реттік сілтемесі бар хат.

1. Хаттағы бір реттік сілтеме арқылы өтіп, сервиске кіру деректерін сақтаңыз:

   - `productURL` — сервис веб-интерфейсінің адресі;
   - `adminEmail` және `adminPassword` — администратордың логині мен құпиясөзі;
   - `statusURL` — интеграциялар күйі бетінің адресі.

   {note:info}
   Кіру деректері жоғалған жағдайда жаңаларын {linkto(../../../../applications-and-services/marketplace/instructions/pr-instance-manage#marketplace-pr-instance-manage-update-access)[text=жасаңыз]}.
   {/note}

1. Хаттағы `adminEmail` логині және `adminPassword` құпиясөзі арқылы `productURL` адресі бойынша VK Security Gate сервисінің веб-интерфейсіне өтіңіз.
1. (Қалауыңыз бойынша) қосылған интеграциялардың күйін тексеріңіз:

   1. Браузерде `statusURL` адресін ашыңыз, тіркелгі деректерін енгізудің қажеті жоқ.
   1. Бетте көрсетілген JSON файлының мазмұнын қарап шығыңыз. `mail`, `codeql`, `ai` және `jira` параметрлері үшін мына мәндердің бірі көрсетілуі керек:

      - `ok` — интеграция қосылған,
      - `disabled` — интеграция өшірілген,
      - `downloading` — сервер CodeQL архивін жүктеп алады,
      - `error` — қосу немесе қойылған параметрлерде қате. Сервис баптауларындағы қосу параметрлерінің мәндерін {linkto(../../../../applications-and-services/marketplace/instructions/pr-instance-manage#marketplace-pr-instance-manage-edit)[text=түзетіңіз]}.

    Қосылған интеграциялар өнімде көрінеді:

    - Jira: веб-интерфейсте **Администрирование** → **Менеджеры задач** → **Jira** ашыңыз, конфигурация жасап, оны жобамен байланыстырыңыз;
    - CodeQL: жаңа сканерлеулерде бірнеше минуттан кейін `codeql-<ЯЗЫК>` тапсырмалары пайда болады. Аяқталған сканерлеулер қайта есептелмейді.
