# {heading(SIEM-қосылымдары)[id=event-log-siem-connections]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

SIEM-қосылым — бұл Cloud Audit сервисінен сыртқы SIEM-жүйеге қауіпсіздік оқиғалары туралы ақпарат беру арнасы, ол {var(cloud)} бұлттық сервистерінің {linkto(../logged-events#event-log-logged-events)[text=тіркелген оқиғаларын]} қамтиды.

Cloud Audit-те бір немесе бірнеше SIEM-жүйелерден бірнеше SIEM-қосылымды қосуға болады. Сонымен қатар, кез келген уақытта осы қосылымдардың тек біреуі ғана белсенді болуы мүмкін.

Әрбір қосылым мыналарды анықтайды:

- SIEM-жүйе тарапындағы деректерді қабылдау нүктесін: IP-мекенжайы мен порт.
- Деректерді беру хаттамасын: TCP, UDP немесе TLS арқылы TCP.
- Жіберілетін хабарламалардың пішімін: Syslog ([RFC5424](https://datatracker.ietf.org/doc/html/rfc5424)) немесе CEF (Common Event Format). Оқиға өрістері мен хабарлама өрістерін салыстыру — {linkto(../siem-export-format#event-log-siem-export-format)[text=%text]} бөлімінде.
- (Қалау бойынша) жіберілуі қажет оқиғалардың сүзгісін.

Қосылымды іске қосар алдында Cloud Audit SIEM-жүйенің берілген параметрлер бойынша қолжетімділігін тексереді. Тексеру және кейінгі деректерді табысты беру үшін SIEM-жүйе тарапында келесі IP-мекенжайлардан келетін кіріс трафигіне рұқсат етілуі керек:

- `89.208.217.12/30`,
- `89.208.217.40/30`,
- `89.208.219.248/30`,
- `89.208.219.252/30`,
- `90.156.148.16/28`.

SIEM-қосылымдарын баптау туралы толығырақ {linkto(../../instructions/siem-integration#event-log-siem-connection)[text=%text]} бөлімінде.
