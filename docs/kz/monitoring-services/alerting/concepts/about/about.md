# {heading(Сервис туралы)[id=alerting-about]}

{include(/kz/_includes/_translated_by_ai.md)}

Cloud Alerting — {var(cloud)} бақылау сервистеріндегі назар аударуды қажет ететін оқиғалар туралы хабарландыруларды баптауға мүмкіндік беретін сервис. Хабарландырулар бұлттық ресурстар күйінің өзгеруіне уақтылы әрекет етуге және қолданбаларыңыздың жұмысындағы іркілістердің алдын алуға көмектеседі.

Мысалы, процессор жүктемесінің артуы туралы хабарландыру ВМ-ның тапсырмалармен шамадан тыс жүктелгенін анықтауға көмектеседі, ал белгісіз пайдаланушыға әкімші рөлінің тағайындалуы туралы хабарландыру инфрақұрылымыңызға қажетсіз қолжетімділікті дер кезінде анықтап, тоқтатуға көмектеседі.

Cloud Alerting оқиғаның орын алуын _триггерлер_ көмегімен тіркейді, содан кейін SMS немесе электрондық пошта арқылы хабарландыру жібереді.

Триггердің іске қосылуын {linkto(../../instructions/triggers#alerting-triggers)[text=баптауға]} келесі дереккөздер бойынша болады:

- {linkto(../../../monitoring/concepts/architecture#monitoring-architecture)[text=Cloud Monitoring]} сервисінің метрика мәндері бойынша. Метрикалар нақты бір ресурстан (мысалы, ВМ немесе БД) жиналады. Метрика мәндерін PromQL тілінде бақылау {linkto(../../../../tools-for-using-services/api/api-spec/monitoring2-api#api-spec-monitoring2)[text=API]}-іне сұрау арқылы алуға болады.
- {linkto(../../../logging/concepts/about#logging-about)[text=Cloud Logging]} сервисінің жазбалары бойынша. Жазбалар {var(cloud)} ішіндегі нақты бір сервис аясындағы ресурстардан жиналады және триггер үшін дереккөз ретінде осы сервис қызмет етеді. Триггер шарты {linkto(../../../logging/concepts/search-tools#logging-search-tools)[text=іздеу сұраулары тілінде]} беріледі.
- {linkto(../../../event-log/concepts/about#event-log-about)[text=Cloud Audit]} сервисінің оқиғалары бойынша. Оқиғалар {var(cloud)} сервисінің `Басқару қабаты` немесе `Деректер қабаты` деңгейінен жиналады. Триггер шарты {linkto(../../../logging/concepts/search-tools#logging-search-tools)[text=іздеу сұраулары тілінде]} беріледі.

Метрика мәндері бойынша триггерлер ресурс көрсеткіштерінің сандық мәндеріндегі өзгерістерді бақылауға мүмкіндік береді, мысалы, ВМ өнімділігінің төмендеуі немесе БД-ға қолжеткізу жылдамдығының азаюы. Жазбалар мен оқиғалар бойынша триггерлер логтарда немесе аудит журналында тіркелген нақты оқиға туралы хабарландыру алып, инциденттерге жылдам әрекет етуге мүмкіндік береді. Мұндай триггерлер инфрақұрылым әкімшілеріне және қауіпсіздік мамандарына логтарды қолмен талдамай-ақ аномалиялар мен инциденттерді жылдам анықтау үшін пайдалы.
