# {heading(Сервис туралы)[id=alerting-about]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Cloud Alerting — бұл {var(cloud)} мониторинг сервистеріндегі назар аударуды қажет ететін оқиғалар туралы хабарландыруларды конфигурациялауға мүмкіндік беретін сервис. Хабарландырулар бұлт ресурстарының күйінің өзгеруіне уақтылы реакция жасауға және қосымшаларыңыздың жұмысындағы ақаулардың алдын алуға көмектеседі.

Мысалы, процессор жүктемесінің өсуі туралы хабарландыру ВМ-нің тапсырмалармен шамадан тыс жүктелгенін анықтауға көмектеседі, ал белгісіз пайдаланушыға әкімші рөлін тағайындау туралы хабарландыру инфраструктураңызға жасалған жүйксіз қол жетімділікті уақтылы анықтауға және тоқтатуға көмектеседі.

Cloud Alerting оқиғаның басталғанын триггерлер арқылы тіркейді, содан кейін SMS немесе электрондық пошта арқылы хабарландыру жібереді.

Триггердің іске қосылуын келесі деректер көздері бойынша {linkto(../../instructions/triggers#alerting-triggers)[text=конфигурациялауға болады]}:

- {linkto(../../../monitoring/concepts/architecture#monitoring-architecture)[text=Cloud Monitoring]} сервисінің метрика мәндері бойынша. Метрикалар нақты бір ресурстан (мысалы, ВМ немесе БД) жиналады. Метрика мәндерін PromQL тілінде бақылау {linkto({@root}/tools-for-using-services/api/api-spec/monitoring-api#api-spec-monitoring2)[text=API]}-іне сұрау арқылы алуға болады.
- {linkto(../../../logging/concepts/about#logging-about)[text=Cloud Logging]} сервисінің жазбалары бойынша. Жазбалар {var(cloud)} ішіндегі нақты бір сервис аясындағы ресурстардан жиналады және триггер үшін дереккөз ретінде осы сервис қызмет етеді. Триггер шарты {linkto(../../../logging/concepts/search-tools#logging-search-tools)[text=іздеу сұраулары тілінде]} беріледі.
- {linkto(../../../event-log/concepts/about#event-log-about)[text=Cloud Audit]} сервисінің оқиғалары бойынша. Оқиғалар {var(cloud)} сервисінің `Басқару қабаты` немесе `Деректер қабаты` деңгейінен жиналады. Триггер шарты {linkto(../../../logging/concepts/search-tools#logging-search-tools)[text=іздеу сұраулары тілінде]} беріледі.

Метрикалардың мәндері бойынша триггерлер ресурстың сандық көрсеткіштерінің өзгерістерін, мысалы, ВМ өнімділігінің немесе БД-ге қол жеткізу жылдамдығының төмендеуін бақылауға мүмкіндік береді. Жазбалар мен оқиғалар бойынша триггерлер логтарда немесе аудит журналында тіркелген нақты бір оқиға туралы хабарландыру алып, инциденттерге жылдам реакция жасауға мүмкіндік береді. Мұндай триггерлер инфраструктура әкімшілері мен қауіпсіздік мамандарына логтарды қолмен талдаусыз ауытқулар мен инциденттерді жедел анықтауға көмектеседі.
