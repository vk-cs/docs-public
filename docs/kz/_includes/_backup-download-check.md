1. Әрбір көшірменің папкасында барлық бес файлдың (`content`, `object_segments`, `volume_segments`, `sha_list` және `volume_metadata`) бар екеніне көз жеткізіңіз. Ол үшін мына пәрменді орындаңыз:

   ```console
   ls -l ./<ПАПКА_КОПИИ>/
   ```

   Мұндағы `<ПАПКА_КОПИИ>` — көшірме файлдары орналасқан папка.

1. Егер `content` файлы бөліктермен (`content1`, `content2` және т.б.) жүктелсе, оларды табиғи сұрыптаумен біріктіріңіз:

   ```console
   cat $(ls ./<ПАПКА_КОПИИ>/content[0-9]* | sort -V) > ./<ПАПКА_КОПИИ>/content
   ```

   Мұндағы `<ПАПКА_КОПИИ>` — көшірме файлдары орналасқан папка.

   {note:warn}
   `-V` параметрінсіз әдеттегі `sort` сұрыптауын пайдаланбаңыз: ол файл бөліктерінің ретін бұзады және диск деректерін зақымдайды.
   {/note}

1. `content` файлының толық жүктелгеніне көз жеткізіңіз. Ол үшін `object_segments` файлындағы соңғы элементті алып, `object_offset` және `object_length` қосындысын `content` файлының өлшемімен салыстырыңыз:

   ```console
   python3 -I - <<'EOF'
   import json, os
   d = "./<ПАПКА_КОПИИ>"
   seg = json.load(open(os.path.join(d, "object_segments")))
   last = seg[-1]
   print("карта бойынша:", last["object_offset"] + last["object_length"],
         "файл:", os.path.getsize(os.path.join(d, "content")))
   EOF
   ```

   Мұндағы `<ПАПКА_КОПИИ>` — көшірме файлдары орналасқан папка.

   Егер сандар сәйкес келмесе, файл толық жүктелмеген — көшірмені қайта жүктеп алыңыз.
