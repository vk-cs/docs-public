Жеке кабинеттегі атауы: `ВМ операторы`.

Рөл тек бұрын жасалған Cloud Servers виртуалды машиналарымен және Cloud Networks желілерімен жұмыс істеу үшін қолданылады:

- ВМ-ді іске қосу немесе тоқтату;
- ВМ-мен VNC-консоль арқылы жұмыс істеу;
- ВМ-ге SSH немесе RDP арқылы қосылу;
- ВМ параметрлерін және желі баптауларын қарау.

Cloud Logging сервисінде рөл журналдарды қарауға мүмкіндік береді.

Cloud Monitoring сервисінде рөл дашбордтарды қарауға және мониторинг жүйесіне жазба жасауға мүмкіндік береді.

Рөл Cloud Audit сервисіне қолжетімділік бермейді.
