{note:warn}

`id` және `revision` параметрлерінің тіркесімі Marketplace шеңберінде бірегей болуы тиіс. Егер осындай идентификатор мен ревизиясы бар қосымша Marketplace-те бұрыннан бар болса, қызметтік пакет жаңартылмайды.

{/note}

`plans` және `preview` массивтерінде көрсетілген тарифтік жоспарлар мен опциялар негізінде [тарифтік жоспарлар матрицасы](/kz/tools-for-using-services/vendor-account/manage-apps/concepts/about#xaas_tariff_matrix) құрылады.
{/includetag}

{includetag(service.yaml-plans)}
`plans` массивінде `name` кілттерінің көмегімен Marketplace пайдаланушысына қолжетімді болатын тарифтік жоспарлардың атаулары (`<ЖОСПАР_АТЫ>`) тізіледі.

`plans` массивінің мысалы:

```yaml
plans:
    - name: free
    - name: basic
```

Бұл мысалда `free` және `basic` тарифтік жоспарлары тізілген. Олардың конфигурациялары `plans/free` және `plans/basic` директорияларында сипатталуы тиіс. Тарифтік жоспарлар матрицасында бұл жоспарлар `plans/free/plan.yaml` және `plans/basic/plan.yaml` файлдарының `description` параметрінде көрсетілген атаулармен беріледі.

{note:warn}

`plans` массивінде көрсетілмеген тарифтік жоспарлар Marketplace-тегі [тарифтік жоспарлар матрицасында](/kz/tools-for-using-services/vendor-account/manage-apps/concepts/about#xaas_tariff_matrix) көрсетілмейді.

{/note}
{/includetag}

{includetag(service.yaml-preview)}
`preview` секциясы `parameters` массивін қамтиды. Бұл массивте `name` кілттерінің көмегімен Marketplace пайдаланушысына қолжетімді болатын тарифтік опциялардың атаулары (`<ОПЦИЯ_АТЫ>`) тізіледі. Массив бос болуы мүмкін.

`preview` секциясының мысалы:

```yaml
preview:
  parameters:
  - name: groups
  - name: products
```

Бұл мысалда `groups` және `products` тарифтік опциялары тізілген. Олар `parameters` директориясында сәйкесінше `groups.yaml` және `products.yaml` файлдарында сипатталуы тиіс. Тарифтік жоспарлар матрицасында опциялар көрсетілген YAML-файлдардың `description` параметрінде берілген атаулармен көрсетіледі.

{note:warn}

`preview` секциясында көрсетілмеген тарифтік опциялар Marketplace-тегі [тарифтік жоспарлар матрицасында](/kz/tools-for-using-services/vendor-account/manage-apps/concepts/about#xaas_tariff_matrix) көрсетілмейді.

{/note}
{/includetag}

{includetag(full_description-ib-tariff)}
Тарифтеу ережелері еркін түрде сипатталады. Мыналарды орындау ұсынылады:

* [Тарифтеу түрін](/kz/tools-for-using-services/vendor-account/manage-apps/concepts/about#xaas_billing) көрсету.
* Егер бірнеше тарифтік жоспар болса, олармен қайдан танысуға болатынын көрсету. Мысалы: «Тарифтеу ережелерімен қызмет бетіндегі тарифтік жоспарлар матрицасынан танысуға болады».
* Ақылы тарифтік опциялар болса, олардың тарифтік жоспардың құнына қосымша тарифтелетінін айту.
* Келісімшарттық бағасы бар тарифтік жоспарлар болса, оларды сипаттау.
* Бұлттық платформа инфрақұрылымының құны бөлек тарифтелетінін түсіндіру.

{note:warn}

{includetag(plan.yaml-parameters_patch)}
Секцияда тарифтік жоспар үшін тарифтік опциялардың параметрлері — жекелеген параметрлер немесе тарифтік опция сипаттамасының бүкіл секциялары — таңдамалы түрде қайта анықталады.

{tabs}
{tab(Тарифтік опциялардың жекелеген параметрлерін қайта анықтау)}

Қайта анықталатын әрбір параметр үшін оның атауы түбірлік секцияға дейінгі жолмен бірге көрсетіледі. Параметр атауы мен оның ата-секцияларының атаулары нүктемен бөлінеді.

Тарифтік опциялардың параметрлерін қайта анықтау мысалы:

```yaml
parameters_patch:
  users:
    schema.const: 5000
  volume_data_size:
    schema.default: 550
    schema.minimum: 550
```

Бұл мысалда жаңа мәндерді мыналар алады:

- `users` тарифтік опциясының `schema` секциясындағы `cost` параметрі;
- `volume_data_size` тарифтік опциясының `schema` секциясындағы `default` және `minimum` параметрлері.

Тарифтік опция түріне байланысты мүмкін параметрлер [Тарифтік опцияның YAML-файлы](/kz/tools-for-using-services/vendor-account/reference/ib-apps-reference/tariff-options) бөлімінде келтірілген.

{/tab}
{tab(Тарифтік опция секциясын толығымен қайта анықтау)}

Қайта анықталатын тарифтік опция секциясы тарифтік опцияның YAML-файлындағыдай форматта көрсетіледі.

Тарифтік опцияның `billing` секциясын қайта анықтау мысалы:

```yaml
parameters_patch:
  assemblies_size:
    billing:
      base: 25
      cost: 0
      unit:
        size: 100
```

Бұл мысалда `assemblies_size` тарифтік опциясының `billing` секциясы толығымен жаңасына ауыстырылады.

{/tab}
{/tabs}

{note:warn}
Секцияны толығымен және осы секциядағы жекелеген параметрді бір мезгілде қайта анықтауға тыйым салынады.
{/note}

`parameters_patch` секциясында көрсетілген параметр мәндері тарифтік опциялардың YAML-файлдарындағы мәндерден басым болады.

Тарифтік жоспарларда бір-бірінен айтарлықтай ерекшеленетін опциялар қолданылса:

- Әрбір опцияны `parameters` директориясында жеке YAML-файлмен сипаттау ұсынылады.
- Барлық тарифтік жоспарлар үшін бір тарифтік опцияны сипаттап, оның параметрлерінің көпшілігін әртүрлі тарифтік жоспарларда қайта анықтау ұсынылмайды.

{/includetag}

Массив тарифтік жоспар шеңберінде тарифтелетін VK Cloud инфрақұрылымының элементтерін сипаттайды.

{note:warn}

[Terraform манифесттері](/kz/tools-for-using-services/vendor-account/reference/ib-apps-reference/tf-manifest) `entities` массивіндегі инфрақұрылым элементтерінің сипаттамасын қамтуы тиіс.

{/note}

Әдепкі бойынша тарифтік жоспарды конфигурациялау шеберінде `entities` массивінде сипатталған инфрақұрылымның барлық элементтерінің құны көрсетіледі. Шарттарға байланысты инфрақұрылым құнын көрсету немесе жасыру үшін [when құрылымы](#when_construction) пайдаланылады.

`entities` массивінің жалпы параметрлері:

[cols="2,5,2,2", options="header"]
|===
|Атауы
|Сипаттамасы
|Форматы
|Міндетті

|`entity`
|Инфрақұрылым элементінің түрі:

* `vm` — ВМ.
* `load_balancing` — жүктеме балансирлеуші.
* `floating_ip` — сыртқы IP-мекенжай.
|`string`
|![](/kz/assets/check.svg "inline")

|`description`
|Инфрақұрылым элементінің сипаттамасы
|`string`
|![](/kz/assets/no.svg "inline")
|===

**Сервисті баптау** бетін тарифтік жоспарды конфигурациялау шеберінде сипаттау мысалы:

```yaml
pages:
- name: Сервисті баптау # Бет атауы
  groups:
  - name: Сервер # Тарифтік опциялар тобының атауы
    parameters:
    - name: network # Тарифтік опция атауы
    - name: vm
    - name: az

  - name: Жүйелік диск
    parameters:
    - name: volume_size
    - name: volume_type
```

{/includetag}

```yaml
entities:

    description: Виртуалды машина
    count:
      const: 1

          param: root_type
        size:
          param: root_size
      - type:
          param: data_type
        size:
          param: data_size
```

{includetag(display.yaml-when-common)}

`when` құрылымы тарифтік жоспар шеберін көрсету кезіндегі шартты тармақталуды басқарады. Ол мыналарды қамтиды:

* Шарт түрі:

  * `when.in` — `key` және `values` параметрлерінде берілген мәндердің теңдігін тексеру. `key` мәні `values` мәндерінің кем дегенде біреуіне тең болса, шарт орындалады.
  * `when.not_in` — `key` және `values` параметрлерінде берілген мәндердің тең еместігін тексеру. `key` мәні `values` мәндерінің ешқайсысына тең болмаса, шарт орындалады.

* Өлшемшарттар. `key` және `values` параметрлерінің бірімен беріледі:

  * `param` параметрі арқылы — нақты тарифтік опцияның мәнін пайдалану үшін.
  * `const` параметрі арқылы — тіркелген мәнді пайдалану үшін.

  `key` ішінде бір мән, `values` ішінде бір немесе бірнеше мән көрсетуге болады.

YAML форматындағы `when` құрылымы:

```yaml
when:
  in: # немесе not_in
    key:
      param: <ОПЦИЯ_АТЫ> # немесе const: <МӘН>
    values:
      - const: <МӘН>
      - param: <ОПЦИЯ_АТЫ>
      ...
```
Мұндағы:

* `<ОПЦИЯ_АТЫ>` — осы опцияның YAML-файлының атауымен сәйкес келетін тарифтік опцияның атауы.
* `<МӘН>` — тіркелген мән.

{note:warn}

[Terraform манифестеріндегі](/kz/tools-for-using-services/vendor-account/reference/ib-apps-reference/tf-manifest) ресурстар `when` құрылымдарында берілген шарттарды ескере отырып сипатталуы тиіс.

{/note}

{/includetag}

{includetag(display.yaml-when-pages)}

`pages` массивінде `when` құрылымы тарифтік жоспарды конфигурациялау шеберінде тарифтік опциялар тобын көрсету қажет пе екенін анықтайтын шартты беру үшін пайдаланылады.

{note:warn}

Топтарды көрсету шарттарында иерархияның тек бірінші деңгейіне қолдау көрсетіледі. Егер топта `when` құрылымы көрсетілсе, `parameters` массивінде тізілген осы топтың тарифтік опцияларын басқа топтардағы `when` құрылымында пайдалануға болмайды.

{/note}

Бір тарифтік опция әртүрлі топтардағы `when` құрылымдарында пайдаланылуы мүмкін. Тарифтік опцияның мәніне байланысты конфигурациялау шеберінде сол немесе басқа топтар көрсетіледі.

`when` құрылымы пайдаланылғанда, мына шарттар бір мезгілде орындалса, тарифтік опциялар топтары бар бет жасырылады:

* Бір бет шеңберінде барлық топтарда `when` құрылымы бар.
* Тарифтік жоспарды конфигурациялау шеберінде осы беттегі барлық топтардың шарттары орындалмайтындай тарифтік опция мәндері берілген.

`pages` массивінде `when` құрылымын пайдалану мысалы:

```yaml
pages:
- name: Бекап баптаулары # Бет атауы
  groups:
  - name: High-frequency бекап # Тарифтік опциялар тобының атауы
    parameters:
    - name: frequency_per_day # Тарифтік опция атауы
    when:
      in:
        key:
          param: backup_method # Тарифтік опция атауы
        values:
          - const: high-frequency
```

Бұл мысалда пайдаланушы конфигурациялау шеберінде `backup_method` тарифтік опциясы үшін `high-frequency` мәнін таңдаса, `frequency_per_day` тарифтік опциясы бар `High-frequency бекап` тобы көрсетіледі. Содан кейін пайдаланушы бекап жасау жиілігін таңдай алады.

`backup_method` тарифтік опциясы:

* басқа топтардағы `when` құрылымында пайдаланылуы мүмкін;
* басқа топтың `parameters` массивінде көрсетілуі тиіс.

`frequency_per_day` тарифтік опциясы басқа топтарда пайдаланылмауы мүмкін:

* `when` құрылымында — себебі шарттар иерархиясының тек бір деңгейіне қолдау көрсетіледі;
* `parameters` ішінде — себебі бір тарифтік опция тек бір топта ғана көрсетілуі мүмкін.

{/includetag}

{includetag(display.yaml-when-entities)}

`entities` массивінде `when` құрылымы `entities` массивінде сипатталған инфрақұрылым элементінің құнын тарифтік жоспарды конфигурациялау шеберінде көрсету қажет пе екенін анықтайтын шартты беру үшін пайдаланылады.

`entities` массивінде `when` құрылымын пайдалану мысалы:

```yaml
entities:
  - entity: vm
    description: alkair_software
    when:
      in:
        key:
          param: need_install_alkair_software # Тарифтік опция атауы
        values:
          - const: true
    flavor:
      const: 6a7a0690-943a-4921-936e-2849970ccfba # ВМ түрі (CPU, RAM). Бұл мысалда 2 CPU және 3 ГБ RAM бар ВМ
    count:
      const: 1
    disks:
      - type:
          const: high-iops # Диск түрі
        size:
          const: 500 # Диск өлшемі
```

Бұл мысалда Алькаир БҚ үшін ВМ құнын көрсету баптамасы берілген. Егер пайдаланушы `need_install_alkair_software` тарифтік опциясы үшін `true` мәнін таңдаса, тарифтік жоспарды конфигурациялау шеберінде `entities.entity` элементінде сипатталған ВМ құны көрсетіледі.

{/includetag}
