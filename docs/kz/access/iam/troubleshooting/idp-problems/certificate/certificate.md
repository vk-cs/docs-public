Функцияларды растау арқылы кіру талабы жасалғанда келесі хабарлама көрсетіледі:

```plaintext
Forbidden: received invalid saml response: cannot validate signature on Assertion: Could not verify certificate against trusted certs
```

Қате — растау провайдері (IdP) тарапында сертификат өзгергенде пайда болады. Мысалы, сертификат автоматты түрде жаңартылғанда.

## Шешім

Федерация үшін IdP метадеректерін қайта жүктеңіз:

1. VK Cloud аккаунтына [өтіңіз](https://cloud.vk.ru/account).
1. **Функцияаралық растау** бөлімінің **Федерациялар** қойыншасына өтіңіз.
1. **IdP метадеректерін жүктеу** түймесін басып, растау провайдерінің метадеректері бар XML файлын қосыңыз.
1. **Жүктеу** түймесін басыңыз.
1. Егер мәселе сақталса немесе VK Cloud аккаунты арқылы метадеректерді жүктей алмасаңыз, растау провайдерінің метадеректері бар XML файлын тіркеп, [техникалық қолдау көрсету](/kz/contacts) қызметіне жүгініңіз.
