# {heading(Рөлдер анықтамалығы)[id=iam-roles-reference]}

Қолжетімділік рөлдері — {var(cloud)} ішінде белгілі бір операцияларды орындауға мүмкіндік беретін алдын ала орнатылған құқықтар жиынтығы.

Рөлдердің келесі түрлері бар:

- {linkto(#iam-roles-reference-basic)[text=Базалық рөлдер]} — әкімшілендіру, қарау және аудит үшін қажет алдын ала берілген құқықтар жиынтығы бар сервистің құрылымдық рөлдері.
- {linkto(#iam-roles-reference-special)[text=Мамандандырылған рөлдер]} — белгілі бір сервисті немесе [жобаның](/kz/tools-for-using-services/account/concepts/projects) баптауларының қандай да бір бөлігін басқаруға арналған құқықтар жиынтығын қамтиды.
