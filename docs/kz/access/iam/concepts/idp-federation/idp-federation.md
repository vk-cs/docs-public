# {heading(Жеке куәліктер федерациясы)[id=iam-idp-federation]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

*Жеке куәліктер федерациясы* — бұл тәуелсіз қауіпсіздік домендері арасындағы сенім қатынастар жүйесі, онда әр домен өзінің рұқсаттарды басқару жүйесін сақтайды, бірақ федерацияға кіретін басқа доменде орындалған аутентификация нәтижелерін қабылдайды. Федеративті кіру кезінде бір доменде аутентификациядан өткен пайдаланушы басқа доменнің ресурстарына қол жеткізеді. Мысалы, пайдаланушы VK Cloud жүйесіне логин мен құпиясөзді енгізбей-ақ, өзінің корпоративтік желісіне кіру деректерін пайдаланып кіре алады.

Федерация режимінде аутентификация мен кіру деректерін сақтауға жеке сервис жауап береді — *жеке куәліктер провайдері* (Identity Provider, IdP).

Сіз VK Cloud жүйесіне өзіңіздің жеке куәліктер провайдерін қоса аласыз. Жеке куәліктер федерациясын келесілер арқылы баптауға болады:

- [Active Directory](/kz/access/iam/how-to-guides/federations/add-fim-for-ad),
- [Keycloak](/kz/access/iam/how-to-guides/federations/keycloak-to-fim),
- [Microsoft Entra](/kz/access/iam/how-to-guides/federations/ms-entra-fim).

Жеке куәліктер провайдері SAML 2.0 стандартын қолдауы тиіс.
