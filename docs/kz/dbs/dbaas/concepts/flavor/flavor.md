# {heading(ДБ инстанстарының конфигурациясының шаблоны)[id=dbaas-flavor]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

ВМ конфигурациясының шаблоны (flavor) ВМ ресурстарының мөлшерін анықтайды: CPU саны мен RAM көлемін.

{var(cloud)} орнатқан кезде ДБ инстанстары үшін келесі сипаттамалары бар Standard ВМ конфигурациясының шаблондары жасалады:

* vCPU: 2-ден 16-ға дейін.
* RAM: 8 ГБ-тан 64 ГБ-қа дейін.

Қолжетімді ВМ конфигурациясының шаблондарының толық тізімін {linkto(../../instructions/create#dbaas-create)[text=деректер қорын жасау]} кезінде **Виртуалды машина түрі** тізімін ашып көруге болады.

{note:warn}
Еркін конфигурациялары бар жаңа пайдаланушылық ВМ конфигурациясының шаблондарын қосу мүмкін. ВМ конфигурациясының басқа шаблондарын жасау үшін {var(cloud)} әкімшісіне жүгініңіз.
{/note}
