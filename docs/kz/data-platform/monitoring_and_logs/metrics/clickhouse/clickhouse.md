# {heading(Cloud ClickHouse)[id=clickhouse_metrics]}

{include(/kz/_includes/_translated_by_ai.md)}

Cloud ClickHouse сервисінде метрикалар Prometheus форматында жиналады. Әр метрика үшін дашбордта көрсетуге болатын панель автоматты түрде жасалады.

## {heading(ClickHouse түйіндерінің метрикалары)[id=clickhouse_metrics_instance]}

ClickHouse түйіндерінің метрикалар тізімі {linkto(#tab_clickhouse_metrics_instance)[text=%number кестесінде]} көрсетілген.

{caption({counter(table)[id=numb_tab_clickhouse_metrics_instance]} кестесі — ClickHouse түйіндерінің метрикалары)[align=right;position=above;id=tab_clickhouse_metrics_instance;number={const(numb_tab_clickhouse_metrics_instance)}]}
[cols="1,2", options="header"]
|===
|Метрика атауы
|Сипаттамасы

|`CPU пайдалану`
|Таңдалған уақыт аралығында орнатылған шекке қатысты CPU пайдалану пайызы

|`RAM пайдалану`
|Таңдалған уақыт аралығында орнатылған шекке қатысты RAM пайдалану пайызы

|`Дискіден оқу`
|Таңдалған уақыт аралығында дискіден оқу операцияларының саны

|`Дискіге жазу`
|Таңдалған уақыт аралығында дискіге жазу операцияларының саны

|`Дискіден оқу жылдамдығы`
|Таңдалған уақыт аралығында дискіден деректерді оқу жылдамдығы, секундына мебибайт

|`Дискіге жазу жылдамдығы`
|Таңдалған уақыт аралығында дискіге деректерді жазу жылдамдығы, секундына мебибайт

|`Кіріс желілік трафигі`
|Таңдалған уақыт аралығында кіріс желілік трафигінің жылдамдығы, секундына мебибайт

|`Шығыс желілік трафигі`
|Таңдалған уақыт аралығында шығыс желілік трафигінің жылдамдығы, секундына мебибайт

|`Дискіні пайдалану`
|Таңдалған уақыт аралығында дискілік кеңістікті пайдалану пайызы

|`HTTP қосылымдары`
|Белсенді HTTP қосылымдарының ағымдағы саны

|`TCP қосылымдары`
|Белсенді TCP қосылымдарының ағымдағы саны

|`Орындалып жатқан сұраулар саны`
|Орындалып жатқан сұраулардың ағымдағы саны

|`S3 сұраулары`
|Белсенді S3 сұрауларының ағымдағы саны

|`Сұрауларды орындау уақыты`
|Таңдалған уақыт аралығында сұрауларға жұмсалған CPU микросекундтарының секундына орташа саны

|`SELECT сұрауларының жылдамдығы`
|Таңдалған уақыт аралығында секундына орындалған `SELECT` сұрауларының саны

|`INSERT сұрауларының жылдамдығы`
|Таңдалған уақыт аралығында секундына орындалған `INSERT` сұрауларының саны

|`Қате SELECT сұраулары`
|Таңдалған уақыт аралығында секундына орындалған қате `SELECT` сұрауларының саны

|`Қате INSERT сұраулары`
|Таңдалған уақыт аралығында секундына орындалған қате `INSERT` сұрауларының саны

|`Деректерді енгізу жылдамдығы`
|Таңдалған уақыт аралығында деректерді енгізу жылдамдығы, секундына байт

|===
