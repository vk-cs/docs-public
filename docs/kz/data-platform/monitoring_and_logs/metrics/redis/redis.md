Cloud Redis сервисінде метриктер Prometheus пішімінде жиналады. Әр метрик үшін дашбордта көрсетуге болатын панель автоматты түрде жасалады. Метриктер тізімі {linkto(#redis_tab_metrics)[text=%number кестеде]} келтірілген.

{caption({counter(table)[id=numb_redis_tab_metrics]} кесте — Redis метриктері)[align=right;position=above;id=redis_tab_metrics;number={const(numb_redis_tab_metrics)}]}
[cols="1,1", options="header"]
|===
|Метрик атауы
|Сипаттамасы

|`% CPU`
|Таңдалған уақыт аралығында орнатылған шекке қатысты CPU жүктелуі, пайызбен

|`% Memory`
|Таңдалған уақыт аралығында орнатылған шекке қатысты жад пайдаланылуы, пайызбен

|`Read IOPS`
|Таңдалған уақыт аралығында дискіден оқу операцияларының жалпы саны

|`Write IOPS`
|Таңдалған уақыт аралығында дискіге жазу операцияларының жалпы саны

|`Read MB`
|Таңдалған уақыт аралығында дискіден оқылған деректер көлемі, МБ

|`Write, Mbytes`
|Таңдалған уақыт аралығында дискіге жазылған деректер көлемі, МБ

|`Network received, Mbytes`
|Таңдалған уақыт аралығындағы кіріс желілік трафик көлемі, МБ

|`Network sent, Mbytes`
|Таңдалған уақыт аралығындағы шығыс желілік трафик көлемі, МБ

|`Connected clients`
|Қазіргі уақыттағы белсенді клиенттік қосылымдар саны

|`Total commands per second`
|Таңдалған уақыт аралығында секундына орындалған командалардың жалпы саны

|`Blocked clients`
|Қазіргі уақыттағы блокталған клиенттік қосылымдар саны

|`Memory fragmentation ratio`
|Жад фрагментациясы коэффициентінің ағымдағы мәні

|`Keyspace hits per second`
|Таңдалған уақыт аралығында деректерге жасалған сұраулардың кешке секундына түсу саны

|`Keyspace misses per second`
|Таңдалған уақыт аралығында деректерге жасалған сұраулардың кештен секундына өту саны

|`Hit ratio`
|Таңдалған уақыт аралығында деректерге жасалған сұраулардың кешке түсу үлесі

|`Expired keys (per sec)`
|Таңдалған уақыт аралығында мерзімі өткен кілттердің секундына саны

|`Evicted keys per sec`
|Таңдалған уақыт аралығында жад жетіспеуіне байланысты жойылған кілттердің секундына саны

|`Connected slaves`
|Қазіргі уақытта қосылған репликалар саны

|`Replication offsets for master`
|Мастер-түйіндегі репликация ауытқуының ағымдағы мәні, байтпен

|`Replication offsets for slave`
|Реплика түйініндегі репликация ауытқуының ағымдағы мәні, байтпен

|===
