# {heading(Сертификаттармен жұмыс)[id=certificates_manage]}

{include(/kz/_includes/_translated_by_ai.md)}

TLS сертификатын мына сервистер үшін ауыстыруға болады: Cloud Trino, Cloud Airflow, Cloud ClickHouse, Cloud PostgreSQL, Redis, OpenSearch.

## {heading(Сертификаттар тізімін көру)[id=certificates_view]}

1. **Data Platform** → **Сертификаттар** бөліміне өтіңіз.
1. Кестедегі сертификаттар тізімін көріңіз. Әр сертификат үшін атауы, ағымдағы күйі, сипаттамасы және жарамдылық мерзімі көрсетіледі.

## {heading(Сертификат жасау)[id=certificates_create]}

1. **Data Platform** → **Сертификаттар** бөліміне өтіңіз.
1. **Қосу** түймесін басыңыз.
1. Сертификат атауын көрсетіңіз.
1. (Қажет болса) Сертификат сипаттамасын көрсетіңіз.
1. Сертификат файлдарын жүктеңіз. Әр файл үшін қосу әдісін таңдаңыз:

   - **Сертификатты жүктеу** — файлды жүктеу аймағына сүйреп апарыңыз немесе құрылғыдан файлды таңдаңыз.
   - **Мәтін ретінде қою** — сертификат мазмұнын мәтін өрісіне қойыңыз.

   Қолжетімді файл түрлері:

   - **Сертификат** — PEM форматындағы ашық сервер сертификаты. TLS қосылымын орнатқанда сервер оны клиентке ұсынады.
   - **Сертификаттар тізбегі** — PEM форматындағы аралық сертификаттар. Олар сервер сертификатын сенімді түбірлік сертификаттау орталығымен байланыстырады. Тізбек болмаса, клиент сертификаттың түпнұсқалығын тексере алмайды.
   - **Жабық кілт** — сертификатқа сәйкес келетін PEM форматындағы жабық кілт. Сервер оны TLS қол алысуын аяқтау үшін пайдаланады.

   Жүктелген файлды ауыстыру немесе жою үшін файл жанындағы **•••** түймесін басып, қажетті әрекетті таңдаңыз.

1. **Жасау** түймесін басыңыз.

## {heading(Сертификат туралы ақпаратты көру)[id=certificates_info]}

1. **Data Platform** → **Сертификаттар** бөліміне өтіңіз.
1. Қажетті сертификаттың атауын басыңыз.
1. Ақпаратты көріңіз:

   - **Атауы** — сертификат атауы.
   - **Сипаттамасы** — сертификат сипаттамасы.
   - **Сертификат ID-і** — сертификаттың бірегей идентификаторы.
   - **Кім берген** — сертификатты берген сертификаттау орталығы.
   - **Күйі** — сертификаттың ағымдағы күйі.
   - **Жарамдылық мерзімі** — сертификат жарамды болатын кезең.
   - **Қосылған күні** — сертификат жасалған күн мен уақыт.
   - **Қосқан пайдаланушы** — сертификатты жасаған пайдаланушы.
   - **Қосылған даналар** — сертификат қосылған сервис даналары.

## {heading(Сертификатты жою)[id=certificates_delete]}

1. **Data Platform** → **Сертификаттар** бөліміне өтіңіз.
1. Қажетті сертификат үшін **•••** түймесін басып, **Жою** тармағын таңдаңыз.
1. Жоюды растаңыз.
