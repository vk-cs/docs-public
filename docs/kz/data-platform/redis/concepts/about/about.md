Redis — деректерді кілт/мән жұптары түрінде жедел жадта сақтайтын, ашық бастапқы кодты, жоғары тиімді және жоғары жылдамдықты NoSQL типті ДБЖ. Redis туралы толығырақ — [ресми құжаттамада](https://redis.io/).

Redis сұрауларды өңдеу кезінде микросекундтық кідіріс қамтамасыз етеді, секундына миллиондаған операцияны өңдей алады және жылдамдық басым болатын міндеттерге сай келеді: деректерді кэштеу, пайдаланушы сессияларын сақтау, чаттарды, кезектерді, хабарлама брокерлерін, нақты уақыттағы аналитиканы және басқаларын іске асыру.

Сервисті қолдану салалары:

- веб-қосымшалар;
- нақты уақыттағы жүйелер;
- геймификация;
- аналитикалық жүйелер;
- микросервистік архитектура;
- таратылған (distributed) қосымшалар.
