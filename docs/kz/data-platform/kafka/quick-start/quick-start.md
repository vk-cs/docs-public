Жылдам бастау сервиспен жұмысты бастауға және оның мүмкіндіктерімен танысуға көмектеседі.

Жылдам бастаудың барлық қадамдарынан өтсеңіз, сіз:

1. **Single** конфигурациясында Cloud Kafka данасын жасайсыз.
1. Топикке ([topic](https://kafka.apache.org/documentation/#intro_concepts_and_terms)) хабарлама жіберді және Cloud Kafka данасының топигінен хабарлама алуды үйренесіз.

{note:warn}
Cloud Kafka данасы [тарифтеленеді](../tariffication) және есептеу ресурстарын тұтынады. Жылдам бастаудан өткеннен кейін, егер ол сізге қажет болмаса, [сервис данасын жойыңыз](#kafka-quick-start-delete).
{/note}

## 1. Cloud Kafka сервис данасын жасаңыз

1. {var(cloud)} жеке кабинетіне [өтіңіз](https://msk.cloud.vk.ru/app/).
1. Сервис данасын жасау қажет жобаны таңдаңыз.
1. **Data Platform → Сервис даналары** бөліміне өтіңіз.
1. **Дананы жасау** түймесін басыңыз.
1. **Конфигурация** қадамында:

   1. **Cloud Kafka** сервис түрін таңдаңыз.
   1. **3.5.0** нұсқасын таңдаңыз.
   1. **Жеке түйін** конфигурациясын таңдаңыз.
   1. **Келесі қадам** түймесін басыңыз.

1. **Параметрлер** қадамында:

   1. Данаға атау мен сипаттаманы орнатыңыз: `vkcloud-demo-kafka` және `Первый экземпляр Cloud Kafka`.
   1. Брокер үшін түйін параметрлерін орнатыңыз:

      - **Виртуалды машина түрі:** `Standard-2-4`.
      - **Диск түрі:** `High-IOPS SSD`.
      - **Диск өлшемі:** `50 ГБ`.

   1. **Kubernetes кластері**: **Жаңа кластер жасау** түйінін таңдаңыз.
   1. **Желі**: **Жаңа желі жасау** түйінін таңдаңыз.
   1. SDN ретінде **Sprut** таңдаңыз.
   1. **Сабжелі адресі**: `10.0.1.0/24` көрсетіңіз.
   1. **Қолжетімділік аймағы**: `Москва (PA2)`.
   1. **Келесі қадам** түймесін басыңыз.

1. **Тіркелу деректері** қадамында:

   1. **Kafka-ға кіру үшін администратор логині**: мысалы, `kafkaadmin`.
   1. **Kafka-ға кіру үшін администратор құпиясөзі**: **Генерациялау** түймесін басыңыз және алынған құпиясөзді сақтаңыз.

      {note:err}
      Құпиясөзді қалпына келтіру мүмкін емес.
      {/note}

   1. **Жасау** түймесін басыңыз.

      Операцияның аяқталуын күтіңіз. Cloud Kafka данасын жасау ұзақ уақыт алуы мүмкін.

## 2. Cloud Kafka сервис данасымен жұмысқа дайындалыңыз

1. Сервис данасымен жұмыс жоспарланған хостта Kafka консольдік клиенттеріне қолжетімділік алыңыз:

   {tabs}

   {tab(Linux (bash) / macOS (zsh))}

   1. Хостта Java 11 немесе одан жоғары нұсқа орнатылғанына көз жеткізіңіз:

      ```console
      java --version
      ```

      Егер шығыста `Command 'java' not found` немесе нұсқа ескірген болса, Java Development Kit (JDK) орнатыңыз, мысалы, [OpenJDK](https://openjdk.org/install/). JDK-ны толығымен де, тек Java Runtime Environment (JRE) де орнатуға болады.

      Ubuntu 22.04 LTS үшін `apt` көмегімен OpenJDK 11 (тек JRE) орнату мысалы:

      ```console
      sudo apt update && sudo apt install openjdk-11-jre
      ```

   1. Kafka 3.5.0 нұсқасының дистрибутиві бар [архивті жүктеп алыңыз](https://archive.apache.org/dist/kafka/3.5.0/kafka_2.13-3.5.0.tgz). Сервис данасы мен хосттағы Kafka нұсқалары сәйкес болуы керек. cURL көмегімен дистрибутивті жүктеп алу командасының мысалы:

      ```console
      curl -O https://archive.apache.org/dist/kafka/3.5.0/kafka_2.13-3.5.0.tgz
      ```

   1. Архивті ашып, ашылған файлдар орналасқан директорияға өтіңіз:

      ```console
      tar -xzf kafka_2.13-3.5.0.tgz && cd kafka_2.13-3.5.0
      ```

   1. Өндіруші консольдік клиентінің (producer) және тұтынушы консольдік клиентінің (consumer) нұсқасын алыңыз:

      ```console
      bin/kafka-console-producer.sh --version
      bin/kafka-console-consumer.sh --version
      ```

      Нұсқаның сәтті шығуы клиенттердің дұрыс жұмыс істеп тұрғанын білдіреді.

   1. Мына мазмұнмен `client-sasl-ssl.properties` конфигурациялық файлын жасаңыз:

      ```ini
      security.protocol=SASL_SSL
      ```

      Бұл файл өндіруші клиенті мен тұтынушы клиентінің SASL_SSL протоколы арқылы сервис данасында аутентификациялануын талап ететін [баптауды](https://kafka.apache.org/documentation/#security_sasl_scram) қамтиды.

   {/tab}

   {/tabs}

1. Сервис данасына қосылу үшін bootstrap-сервердің адресін алыңыз:

   1. {var(cloud)} жеке кабинетіне [өтіңіз](https://msk.cloud.vk.ru/app/).
   1. Сервис данасы орналасқан жобаны таңдаңыз.
   1. **Data Platform → Сервис даналары** бөліміне өтіңіз.
   1. `vkcloud-demo-kafka` кластерінің атауын басып, оның бетін ашыңыз.
   1. **Жалпы ақпарат** қойындысына өтіңіз.
   1. **Bootstrap** параметрінен адресін жазыңыз.

   {note:info}
   Әрі қарай мысал ретінде `kafka-bootstrap.example.com:9093` адресі қолданылады.

   Төмендегі командаларда оны bootstrap-сервердің нақты адресімен ауыстырыңыз.
   {/note}

## 3. Топикке хабарлама жіберіңіз және оны алыңыз

{tabs}

{tab(Linux (bash) / macOS (zsh))}

1. Консольдік клиент жұмыс істейтін жеке терминал сессиясын жасаңыз.
1. Осы сессияда consumer клиентін іске қосып, `test` топигін дереккөз ретінде көрсетіңіз. Consumer клиенті бұрын алынған bootstrap-сервер мекенжайын және конфигурация файлын пайдаланып Cloud Kafka данасына қосылады да, топиктен хабарламаларды үздіксіз оқып, шығарып отырады. Жаңа топик оған бірінші рет жүгінген кезде автоматты түрде жасалады.

   Ол үшін мына пәрменді орындаңыз:

   ```console
   bin/kafka-console-consumer.sh      --bootstrap-server kafka-bootstrap.example.com:9093      --consumer.config client-sasl-ssl.properties      --topic test
   ```

1. Басқа консольдік клиент жұмыс істейтін тағы бір терминал сессиясын жасаңыз.
1. Осы сессияда producer клиентін іске қосып, `test` топигін қабылдағыш ретінде көрсетіңіз. Producer клиенті бұрын алынған bootstrap-сервер мекенжайын және конфигурация файлын пайдаланып Cloud Kafka данасына қосылады да, енгізілген хабарламаларды топикке жібереді.

   Ол үшін мына пәрменді орындаңыз:

   ```console
   bin/kafka-console-producer.sh      --broker-list kafka-bootstrap.example.com:9093      --producer.config client-sasl-ssl.properties
     --topic test
   ```

1. Producer клиенті бар терминал сессиясында сынақ хабарламасын енгізіп, содан кейін _Enter_ пернесін басыңыз:

   ```text
   This is the test message.
   ```

1. Consumer клиенті бар терминал сессиясында жіберілген сынақ хабарламасының көрсетіліп тұрғанын тексеріңіз:

   ```text
   This is the test message.
   ```

   Хабарламаның болуы Cloud Kafka данасының дұрыс жұмыс істеп тұрғанын білдіреді.

1. Екі терминал сессиясында да CTRL+C пернелер тіркесімін басып, клиенттердің жұмысын аяқтаңыз.

{/tab}

## {heading(Пайдаланылмайтын ресурстарды жойыңыз)[id=kafka-quick-start-delete]}

Cloud Kafka данасы [тарифтеледі](../tariffication) және есептеу ресурстарын тұтынады. Егер ол сізге енді қажет болмаса, оны жойыңыз.

Сондай-ақ `client-sasl-ssl.properties` конфигурациялық файлын және жүктелген Kafka дистрибутивін жоя аласыз.
