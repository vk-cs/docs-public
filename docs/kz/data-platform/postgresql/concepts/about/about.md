Cloud PostgreSQL — деректерді сақтау және басқару үшін қолданылатын объектілі-реляциялық СҚБД. Сервис PostgreSQL негізінде әзірленген. PostgreSQL туралы толығырақ [ресми құжаттамада](https://www.postgresql.org/docs/).

Cloud PostgreSQL көлемді деректерді сақтауға жарамды. СҚБД көптеген деректер түрлерін қолдайды және меншікті түрлерді жасау мүмкіндігін ұсынады.

Cloud PostgreSQL-дің негізгі артықшылықтары:

- ANSI-SQL:2008 стандартына жақын деңгейде деректер тұтастығын сақтау;
- күрделі таңдауларды жасау мүмкіндігі: көріністер, ережелер, ішкі сұраныстар;
- көпнұсқалық арқылы (MVCC) параллельді қолжетімділікті басқару.
