Cloud Flink архитектурасы таратылған ағынды есептеу тұжырымдамасына негізделген және бірнеше компоненттен тұрады:

- *Job Manager* — сервистегі деректерді өңдеудің барлық процестерін үйлестіретін master-түйін:

  - Тапсырмаларды жоспарлауға, ресурстарды бөлуге және Task Manager түйіндерінің жұмысын үйлестіруге жауап береді.
  - Тапсырмалардың орындалу күйін бақылайды және ақауға төзімділікті қамтамасыз етеді.
  - Сұраулардың орындалуын бақылайды және олардың барысын қадағалайды.

  Job Manager түйіні кластерде конфигурациясына қарамастан бірау болады.

- *Task Manager* — деректерді өңдеудің нақты тапсырмаларын (tasks) орындайтын worker-түйін:

  - Job Manager түйіннен алынған тапсырмаларды өңдейді.
  - Деректер ағынындағы операторларды орындауға және күйді (state) сақтауға жауап береді.
  - Тапсырмалар мен есептерді алу үшін Job Manager түйінімен деректер алмасады.

  Кластерде әр түрлі тапсырмаларды параллель өңдейтін 1-ден 10-ға дейінгі Task Manager түйіндері болуы мүмкін.

- *DataStream API/DataSet API* — сәйкесінше ағынды және пакеттік өңдеуді программалауға арналған API. Деректерді сүзгілеу, түрлендіру және агрегациялауға арналған операторлар жинағын ұсынады.

- *Деректер ағындары (Data Streams)* — операторлар тізбектері арқылы өңделетін және түрлендірілетін оқиғалардың реттелген тізбектері. Әр түрлі деректер түрлерін қолдайды.

- *Күй (State)* — белгілі бір уақыт мезетіндегі аралық нәтижелер мен деректердің көшірмесі.

- *Операторлар (Operators)* — деректер ағындарына түрлендірулер мен амалдар орындайтын элементтер: сүзгілер, агрегациялар, біріктірулер, сұрыптаулар және т.б. Task Manager түйіндерінде орындалуға оңтайландырылған.

- *Таратылған сақтау* — тапсырмаға байланысты Cloud Flink әр түрлі деректер қоймаларымен (мысалы, файлдық жүйелер, деректер қорлары) өзара әрекеттесуі мүмкін. Дисктерде немесе түйіндерде туындайтын мәселелерге төзімділікті қамтамасыз етеді.

- *Тапсырмаларды жоспарлаушы (Task Scheduler)* — ресурстарды оңтайлы пайдалану үшін тапсырмаларды (tasks) Task Manager түйіндері арасында бөлуге жауап береді.

Cloud Flink архитектурасы Job Manager түйіні Task Manager түйіндерінің жұмысын үйлестіретін таратылған жүйе болып табылады. Әрбір Task Manager түйіні операторларды пайдаланып деректер ағындарын өңдейді. Бұл масштабталу мүмкіндігі мен жоғары өнімділікті қамтамасыз етеді. Күйдің таратылған сақталуы Cloud Flink-ке жүйенің ішінара істен шығулары кезінде жұмысын жалғастыруға мүмкіндік береді.
