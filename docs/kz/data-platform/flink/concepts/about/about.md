Cloud Flink — кез келген көлемдегі деректерді дереккөздерден мақсатты жүйелерге ағынды өңдеу және жіберу сервисі. Сервис [Apache Flink](https://flink.apache.org/) және Kubernetes негізінде әзірленген.

Apache Flink сервисінің жұмыс принципі таратылған ағынды есептеу концепциясына негізделген: деректер параллель және таратылған түрде өңделетін үздіксіз ағын ретінде қарастырылады. Бұл тәсіл жоғары өнімділікке және масштабталуға қол жеткізуге мүмкіндік береді.

Cloud Flink сервисі автоматтандыратын процестер:

- оқиғаларды ағынды өңдеу;
- үлкен деректер жиындарын өңдеу;
- деректерді агрегациялау және талдау;
- деректерді әртүрлі жүйелерге жіберу (мысалы, деректерді Kafka-дан деректер базасына, деректер базасынан деректер қоймасына жіберу);
- ETL-тапсырмаларын өңдеу: деректерді шығару (Extract), түрлендіру (Transform) және жүктеу (Load) процестері.

Сервисді пайдаланудың мүмкін сценарийлері:

- Қаржылық талдау: транзакцияларды бақылау, алаяқтық әрекеттерді анықтау.
- Веб-сайттарды мониторингілеу: пайдаланушылардың белсенділігін нақты уақытта талдау.
- Приборлардан алынған деректерді талдау: әртүрлі датчиктер мен құрылғылардан алынған алғашқы деректерді өңдеу.
- Машиналық оқыту: машиналық оқыту модельдерін жаттығу және бағалау.
- Big Data талдауы: трендтерді, болжамдарды т.б. анықтау үшін үлкен деректерді өңдеу.
