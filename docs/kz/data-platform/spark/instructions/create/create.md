1. {var(cloud)} жеке кабинетіне [өтіңіз](https://msk.cloud.vk.ru/app/).
1. Сервис данасын құру қажет жобаны таңдаңыз.

1. **Data Platform** → **Сервис даналары** бөліміне өтіңіз.
1. **Дана құру** түймесін басыңыз.
1. **Конфигурация** қадамында:

   1. Сервис түрін таңдаңыз: `Spark`.
   1. Қажетті сервис нұсқасын таңдаңыз.

   1. **Келесі қадам** түймесін басыңыз.

1. **Параметрлер** қадамында:

   1. Дана параметрлерін орнатыңыз:

      - **Атауы**: сервис данасының атауын көрсетіңіз.
      - **Сипаттамасы**: қажет болса, сипаттама қосыңыз.
      {ifdef(public)}

      - **Сыртқы IP тағайындау**: Spark данасы интернет арқылы қолжетімді болуы үшін опцияны қосыңыз.
      {/ifdef}

      {ifndef(public)}

      - Тек {var(cloud)} құрамындағы {var(data-p)} үшін:

        - **Желі**: сервис данасы орналасатын ішкі желіні таңдаңыз.
        - (Міндетті емес) Қауіпсіздік тобын қосыңыз. Егер қажетті қауіпсіздік тобы тізімде болмаса, оны **{var(cloud)} әкімшісінің нұсқаулығы** → **Желілер** → [Firewall баптауы](https://cloud.vk.ru/docs/on-premises/private-cloud/ru/4_3/admin-guide/service_management/network/network_firewall_setup) нұсқаулығы бойынша жасаңыз.

      - (Міндетті емес) **IP автоматты тағайындау**: дананың IP-мекенжайын ішкі желіден қолмен орнату үшін опцияны өшіріңіз. Әдепкі бойынша мекенжай автоматты түрде тағайындалады.
      {/ifndef}
      {ifdef(public)}

      - **Kubernetes кластері**: ашылмалы тізімнен қажетті кластерді таңдаңыз немесе тізімнен `Жаңа кластер жасау` опциясын таңдап, жаңа кластер жасаңыз. Жаңа кластер жасағанда параметрлерді орнатыңыз:

        - **Желі**: кластер қолжетімді болатын ішкі желіні тізімнен таңдаңыз немесе тізімнен `Жаңа желі жасау` опциясын таңдап, жаңа желі жасаңыз. Жаңа ішкі желі жасағанда [SDN](/kz/networks/vnet/concepts/sdn) және ішкі желінің мекенжайын көрсетіңіз.
        - **Қолжетімділік аймағы**: тізімнен кластердің [қолжетімділік аймағын](/kz/start/concepts/architecture#architecture-az) таңдаңыз.
      {/ifdef}
   1. Spark Connect сервисінің параметрлерін көрсетіңіз: CPU саны мен RAM көлемі.

      Бұл сервис Spark кластеріне қашықтан қосылуға және Spark тапсырмаларымен интерактивті жұмыс істеуге мүмкіндік береді.

   1. Spark History Server серверінің параметрлерін көрсетіңіз: CPU саны, RAM көлемі, диск түрі мен өлшемі.

      Бұл сервер Spark тапсырмаларының орындалу логтарын сақтайды.

   1. Sparkjobs контейнерлерінің параметрлерін көрсетіңіз: CPU саны, RAM көлемі және Sparkjobs контейнерлерінің саны.

      Бұл контейнерлер Spark тапсырмаларын орындайды.
