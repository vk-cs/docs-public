# {heading(Интерактивті логтарды қарау)[id=spark_interactive_logs]}

Cloud Spark-та Spark-тапсырмалардың орындалуы туралы толық ақпаратты мәтін немесе JSON форматында көрсететін интерактивті логтарды қарау мүмкіндігі бар.

{note:warn}
Логтар тек аяқталған Spark-тапсырмалар үшін, соның ішінде қатесі бар тапсырмалар үшін де көрсетіледі, егер олардың кодында `job.delete` функциясы қолданылмаса.
{/note}

Интерактивті логтарды қарау үшін:

1. **Data Platform** → **Сервис инстанстары** бөліміне өтіңіз.
1. Cloud Spark сервис инстансының атауын басыңыз.
1. **Жалпы ақпарат** қойындысында **Spark Service** тармағынан URL-мекенжайын көшіріңіз.
1. Көшірілген URL-мекенжайы бойынша өтіңіз. Аяқталған Spark-тапсырмалардың оқиғаларын визуализациялауға арналған веб-интерфейс — History Server ашылады.
1. Қажетті тапсырманы `App Name` мәні бойынша тауып, оның App ID сілтемесін басыңыз.
1. **Executors** қойындысына өтіңіз.
1. Executors кестесінде оң жақтағы `logs` бағанында **log** түймесін басыңыз.

   Spark-тапсырмасының орындалуының интерактивті логтары бар бет ашылады — мәтін немесе JSON форматында (баптауларға байланысты).

   Егер логтар болмаса және `failed to get pod logs` хабарламасы көрсетілсе, Spark-тапсырмасының кодында `job.delete` функциясы қолданылмағанына көз жеткізіңіз. Егер функция болса, оны жойып, тапсырманы қайта іске қосыңыз.
