[Terraform командалық жолы](https://www.terraform.io/cli/commands) — бұл көптеген ішкі командаларды қабылдайтын `terraform` командасы.

Негізгі қолданылатын командалар:

- `terraform init` — Terraform жұмыс каталогын инициализациялайды.
- `terraform validate` — Terraform файлының синтаксисінің дұрыстығын растайды.
- `terraform plan` — өзгерістер файлын жасайды және іске қосу кезінде не өзгеретінін көрсетеді. Нәтижелердің ниетке сай болатынына көз жеткізу үшін `apply` командасын іске қоспас бұрын бұл команданы орындау ұсынылады.
- `terraform apply` — инфрақұрылымды құрады немесе өзгертеді. Команда орындау жоспарын көрсетеді және «иә» немесе «жоқ» жауабын талап етеді (`--auto-approve` жалаушасы қолданылмаса, бұл жалауша кезінде команда автоматты түрде орындалады).
- `terraform refresh` — жергілікті күй файлын нақты ресурстарға қатысты жаңартады. Бұл Terraform-ның ағымдағы ортада не бар екені туралы дәл білуін қамтамасыз етеді.
- `terraform destroy` — Terraform басқаратын инфрақұрылымды жояды. Бұл кластерден күй файлында жасалған және сақталған барлық нәрсені қайтарылмайтын түрде жоюға әкеледі.

Командаларды қолданар алдында `.tf` конфигурация файлдары орналасқан жұмыс каталогына өтіңіз.

Автоматтандыру скрипттерінде командаларды қолданған жағдайларда, ыңғайлылық үшін, команданы қолданар алдында жұмыс каталогын ауыстыру үшін `-chdir=` опциясы қолданылады:

```console
terraform -chdir=terraform/configuration apply
```
