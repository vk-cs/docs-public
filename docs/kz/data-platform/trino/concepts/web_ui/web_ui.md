Cloud Trino веб-интерфейсін ұсынады, оның көмегімен белсенді және аяқталған сұрауларды қарауға, олардың күйі мен прогресін бақылауға, өнімділікті талдауға болады. Толығырақ — [Trino ресми құжаттамасында](https://trino.io/docs/current/admin/web-interface.html).

## {heading(Интерфейске кіру)[id=trino-ui-access]}

Trino веб-интерфейсінің сілтемесі сервис данасының **Жалпы ақпарат** қойындысындағы **Trino Admin UI** өрісінде көрсетіледі. Аутентификация үшін Cloud Trino пайдаланушысының логині мен құпиясөзін пайдаланыңыз. Веб-интерфейс арқылы қосылу туралы толығырақ — {linkto(../../instructions/connect#trino_connect-ui)[text=Сервис данасына қосылу]} нұсқаулығында.

## {heading(Интерфейстің негізгі бөлімдері)[id=trino-ui-sections]}

### {heading(Басты бет)[id=trino-ui-overview]}

Веб-интерфейстің басты беті — **Cluster overview**. Бетте келесі ақпарат көрсетіледі:

- Trino нұсқасы, орта және координатордың жұмыс уақыты туралы мәліметтер.
- Кластердің негізгі метрикалары көрсетілетін мониторинг тақтасы:

   - **Running queries**: орындалып жатқан сұраулар саны.
   - **Queued queries**: кезекте тұрған сұраулар саны.
   - **Blocked queries**: блокталған сұраулар саны.
   - **Active workers**: белсенді Trino worker-түйіндерінің саны.
   - **Runnable drivers**: ағымдағы мезетте жұмыс істеп тұрған драйверлердің саны.
   - **Reserved memory**: орындалып жатқан сұраулар үшін резервтелген жад көлемі.
   - **Rows/sec**: ағымдағы мезетте секундына өңделетін кесте жолдарының саны.
   - **Bytes/sec**: деректерді өңдеу жылдамдығы (секундына жолдар, секундына байттар).
   - **Worker parallelism**: worker-түйіндерін пайдалану тиімділігі.

- Сұраулар тізімі. Белсенді сұраулар тізімнің басында, олардан кейін аяқталғандар орналасады. Әр сұрау үшін көрсетіледі: ID, SQL-сұрауының мәтіні, күй, орындалу пайызы, сұрауды іске қосқан пайдаланушы және сұрау көзі.

Сұраулар арасында навигация жасау үшін келесі құралдарды пайдаланыңыз:

- сұрау мәтіні, ID, пайдаланушы, көз бойынша іздеу;
- күй бойынша сүзгілеу:

   - **Running** — орындалып жатқандар;
   - **Queued** — кезектегілер;
   - **Finished** — аяқталғандар;
   - **Failed** — қатесі барлар.

- әр түрлі параметрлер бойынша сұрыптау;
- көрсету параметрлерін баптау: беттегі сұраулар саны, жаңарту жиілігі.

### {heading(Сұрау беті)[id=trino-ui-query-detail]}

Сұрау туралы егжей-тегжейлі ақпарат бар бетке өту үшін оның ID-н басыңыз. Бетте қойындылар бар:

- **Overview**: сұрау параметрлері бар мәліметтер жиынтығы, уақыт шкаласы, ресурстарды пайдалану статистикасы, SQL-сұрауының толық мәтіні, орындалу кезеңдерінің тізімі.
- **Live plan**: сұраудың кезеңдер бойынша орындалу схемасы. Схеманы үлкейтуге және жылжытуға болады. Кезеңді басқанда **Stage performance** қойындысы ашылады.
- **Stage performance**: таңдалған орындалу кезеңінің егжей-тегжейі: ресурстарды пайдалану, өңделген деректер.
- **Splits**: әр кезең үшін уақыт шкалаларының графигі.
- **JSON**: барлық статистикасы бар сұраудың толық JSON-көрінісі.
- **References**: сұрау сілтеме жасаған кестелер және шақырылған функциялар.
