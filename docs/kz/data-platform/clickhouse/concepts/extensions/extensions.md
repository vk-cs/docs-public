# {heading(Кеңейтілгендер)[id=clickhouse_extensions_info]}

{include(/kz/_includes/_translated_by_ai.md)}

Cloud ClickHouse кеңейтілгендері ДҚЖ-ның базалық функционалдылығын инстанс конфигурациясын өзгертпей толықтырады. Оларды кез келген уақытта {linkto(../../instructions/manage#clickhouse_extensions)[text=қосуға немесе өшіруге]} болады.

## {heading(Елдер туралы анықтамалық)[id=clickhouse_extension_countries]}

**Елдер туралы анықтамалық** кеңейтілуі мүмкіндік береді:

- Деректердегі ел кодтарын валидациялау: көрсетілген код анықтамалықта бар-жоғын тексеру, бұл аналитикаға түспес бұрын қате мәндерді табуға мүмкіндік береді.
- Деректерді ел атрибуттарымен байыту: ел коды бойынша оның атауын, астанасын, континентін, телефон кодын, валюта кодын және тілдерін алу, егер бастапқы деректерде тек код сақталса, ал есепке ел туралы толық деректер қажет болса.
- Деректерді елдер немесе континенттер бойынша топтау және агрегациялау: аймақтар бойынша есептер құру, мысалы, сатылым көлемі немесе пайдаланушылардың таралуы туралы.

Әр ел үшін сақталады:

- `alpha_2_code` — елдің екі әріпті коды;
- `alpha_3_code` — елдің үш әріпті коды;
- `numeric_code` — елдің сандық коды;
- `name_en`, `name_ru` — ел атауы ағылшын және орыс тілдерінде;
- `continent_en`, `continent_ru` — континент атауы ағылшын және орыс тілдерінде;
- `capital_en`, `capital_ru` — астана атауы ағылшын және орыс тілдерінде;
- `phone_prefix` — елдің телефон коды;
- `currency_code` — валюта коды;
- `languages` — ел тілдері.
