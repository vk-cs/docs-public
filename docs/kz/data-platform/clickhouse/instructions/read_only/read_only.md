# {heading(Экземплярді тек оқу режимінен шығару)[id=clickhouse_read_only]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Cloud ClickHouse түйінінің дискинде 10 МБ-тан аз бос орын қалғанда, {var(data-p)} экземплярды автоматты түрде тек оқу режиміне (read-only) ауыстырады. Бұл дискінің толып кетуіне және деректер базасының жұмыс істеуін тоқтатуына жол бермейді. Жазу әрекеті кезінде қате пайда болады.

Тек оқу режимінде `INSERT`, `ALTER`, `CREATE` және т.б. жазу операциялары қолжетімсіз.

Режим бүкіл экземплярға қолданылады, тіпті орын тек бір түйінде аяқталса да.

## {heading(Тек оқу режимін көрсету)[id=clickhouse_read_only_view]}

Экземпляр тек оқу режиміне өткенде, **Data Platform** → **Сервис экземплярлары** бөлімінде **Сервис күйі** бағанында `Тек оқу` күйі көрсетіледі.

Қай түйінде бос орын аяқталғанын білу үшін экземплярдың **Архитектура** қойындысына өтіңіз.

## {heading(Экземплярді тек оқу режимінен шығару)[id=clickhouse_read_only_exit]}

Тек оқу режиміндегі экземпляр диск ұлғайтылғанда автоматты түрде қалыпты режимге оралады. Жақын арада қайтадан толып қалмауы үшін диск өлшемін ағымдағы өлшемнен кемінде 20%-ға ұлғайту ұсынылады.
