Cloud Iceberg Metastore — Apache Iceberg форматындағы кестелерге арналған метадеректерді басқару жүйесінің құрамдас бөлігі.

Cloud Iceberg Metastore:

- Сұрауларды (`INSERT`, `UPDATE`, `MERGE`, `DELETE`) орындау кезінде ACID-талаптарының сақталуын қамтамасыз етеді:

    - Атомарлық (Atomicity). Транзакция толығымен орындалады немесе, қандай да бір бөлігі (операциясы) істен шыққан жағдайда, барлық өзгерістерімен бірге қайтарылады.
    - Тұтастық (Consistency). Транзакция деректер базасын бір жарамды күйден екінші жарамды күйге ауыстырады, орнатылған тұтастық шектеулерін сақтай отырып. Шектеулердің бұзылуы транзакцияның толық тоқтатылуына әкеледі.
    - Оқшаулау (Isolation). Әрбір транзакция басқаларынан оқшауланған күйде орындалады. Транзакцияның аралық нәтижелері аяқталғанға дейін басқа параллель орындалып жатқан процестерге көрінбейді. Бұл деректерге бір мезгілде қол жеткізу кезіндегі қақтығыстардың алдын алады.
    - Тұрақтылық (Durability). Транзакция жасаған өзгерістер сақталады және оның аяқталуынан кейін қолжетімді болады, тіпті жүйе істен шыққан немесе басқа ақау орын алған жағдайда да.

- Деректер схемаларының эволюциясын (schema evolution) қолдайды: кестедегі бағандардың типтерін деректерді толық қайта жазбай қосуға, жоюға немесе өзгертуге мүмкіндік береді. Өзгерістерді PostgreSQL каталогымен және S3 қоймасымен синхрондау жүргізеді.
- ETL-тапсырмаларды — деректерді шығарып алу (Extract), түрлендіру (Transform) және жүктеу (Load) процестерін өңдейді.

Сервисті қолданудың мүмкін сценарийлері:

1. Келесі типті деректер қоймаларын жасау кезінде құрамдас бөлік ретінде:

   - Деректер көлі {ifdef(public)} ([Data Lakehouse](/kz/data-platform/dlh/concepts/about)){/ifdef}{ifndef(public)} Data Lakehouse {/ifndef}. Сервис S3 қоймасындағы құрылымдық және құрылымдық емес деректердің үлкен көлемдерін ұйымдастыру және басқару үшін қолданылады.
   - Аналитикалық деректер қоймасы (Data Warehouse). Сервис құрылымдық деректерге компактирование (тығыздау) және партиционирование (partitioning) арқылы оңтайландырылған аналитикалық сұрауларды орындайды.
   - Бұлттық қойма. Сервис S3 қоймасымен және VK Data Platform сервистерімен интеграцияланады.

1. ETL-процестерді ұйымдастыру. Сервис schema evolution мен транзакциялықты қолдау арқылы процестерді жеделдетеді.
