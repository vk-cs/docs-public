[VK Object Storage](/kz/storage/s3/concepts/about) — бұл {var(cloud)} ұсынатын құрылымдалмаған деректерді сақтауға арналған үнемді объектілік хранилище. Ол DLH-тің негізгі құрамдас бөлігі болып табылады, өйткені деректерді сақтаудағы икемділікті, масштабталылатындық пен экономикалық тиімділікті қамтамасыз етеді.

Компонент келесі функцияларды орындайды:

- Әртүрлі форматтағы объектілерді таратылған түрде сақтау.
- Хранилище метадеректерін сущность деңгейінде басқару:

    - `Projects` — S3 файлдары жататын жобалар.
    - `Buckets` — жобалар ішіндегі S3-ке қосылған жергілікті дискілер.
    - `Objects` — S3 объектілерін (файлдарын) өңдеудің негізгі параметрлері.

- Файлдарды жүктеу, сақтау, өңдеу және жүктеп алу ережелерін анықтау.
- [Access Control List](/kz/storage/s3/concepts/access/s3-acl) (ACL) қолдауымен деректерге рөлдік қолжетімділік моделін басқару — кім файлға қолжетімділік ала алады және қандай операцияларды орындауға рұқсат етіледі.
- Деректерге қолжетімділік үшін стандартты Amazon S3 API-ді қолдау.
- Хранилищеге кіретін және шығатын контент беру ағындарын ұйымдастыру.
- Үлкен файлдарды бірнеше ағынмен (multipart) істен шықпай жүктеуді ұйымдастыру, соның ішінде:

    - қайталап көру саясаты (retry);
    - файлдарды бөлу логикасы.

- S3-те жүктеудің сәтті өтуін және бұзылған файлдардың болмауын бақылау.
- S3-тегі объектілерді жылдам іздеу.
- Сыртқы сервистердің сұраулары бойынша S3 деректерін ұсыну.
