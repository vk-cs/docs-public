{linkto(../../../../spark/concepts/about#spark_info)[text=Cloud Spark]} — деректерді нақты уақыт режимінде өңдеуге арналған, есептеу тапсырмаларын кластерлер біріктірілген бірнеше есептеу тораптары арасында бөлуге мүмкіндік беретін фреймворк. DLH архитектурасына деректерді өңдеудің көзлерден S3-қоймасы арқылы түпкі тұтынушыларға дейінгі күрделі, басынан соңына дейінгі көпкезеңді ETL-пайпландарын жүзеге асыру қажет болған жағдайда қосымша опция ретінде қосылады.

Cloud Spark үлкен деректерді өңдеуді жүзеге асырылған технологиялық шешімдердің арқасында жеделдатады:

- In-memory processing — деректерді оперативті жадыда сақтау және өңдеу.
- Lazy Evaluation — есептеулердің орындалуы олардың нәтижесі қажет болған сәтке дейін кейінге қалдырылатын деректерді өңдеу стратегиясы.
- Resilient Distributed Datasets (RDD) — деректерді объектілердің таратылған жиыны ретінде сақтау стратегиясы, бұл кезде бастапқы датасеттер мен есептеу нәтижелері кластердің бірнеше тораптарында репликацияланады, бұл сұрауларды өңдеуді жеделдетуге және жүйенің ақауға төзімділігін арттыруға мүмкіндік береді.
- Параллельді өңдеу және операцияларды біріктіру — нақты уақыт режимінде операцияларды параллельді орындау мүмкіндігі үшін кластер тораптары бойынша жүктемені теңгерімдеу.

Компонент мынадай функцияларды орындайды:

- Деректерді көздерден жүктеуге мүмкіндік беретін API ұсынады — интеграциялық сервистерді Python, Java және R тілдерінде жазуға болады, бұл DLH-ға кіру шегін айтарлықтай төмендетеді.
- Көздерден алынған деректерді DLH негізгі S3-қоймасына сақтағанға дейін трансформациялайды.
- Әртүрлі деректер түрлерін қолдаумен DLH негізгі S3-қоймасымен екіжақты деректер алмасуға арналған кітапханалар ұсынады:

    - Spark SQL — қатынастық СУБД-лерге тән операцияларды құрылымдалған деректермен орындау.
    - Spark Streaming — кіріс деректер ағынын нақты уақыт режимінде өңдеу.
    - GraphX — графтық аналитиканың типтік есептерін шешу үшін («Вершина - Ребро» байланысқан объектілердің ауқымды массивтері үшін) есептеулерді орындау (мысалы, subgraph, joinVerticles және aggregateMessages).
    - MLlib — ML-модельдерін оқытуға арналған датасеттер мен алгоритмдерді дайындау үшін деректерді классификациялау, регрессия, кластерлеу операцияларын орындау.

- DLH деректерін есептер, BI-аналитика, машиналық оқыту үшін қажетті форматқа түрлендіреді.
- DLH ақпаратының тұтынушыларымен тікелей немесе аналитикаға арналған арнайы СУБД-лер арқылы өзара әрекеттеседі, мысалы, {linkto(../clickhouse#dlh_clickhouse)[text=ClickHouse]} немесе [PostgreSQL](/kz/dbs/dbaas/how-to-guides/tls-connect).

Cloud Spark DLH архитектурасындағы {linkto(../trino#dlh_trino)[text=Сloud Trino]} құрамдастырушысын толықтырады: Сloud Trino интерактивтік аналитикалық сұраулар мен data science есептеріне сай келеді, ал Cloud Spark ETL- және ELT-өңдеуді, ағындық есептеулер мен машиналық оқытуды қамтамасыз етеді. Екі құрамдастырушыны қолдану әрбір құрал ең қолайлы есептерге қолданылатын теңдестірілген ортаны құруға мүмкіндік береді.
