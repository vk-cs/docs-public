{linkto(../../../../trino/concepts/about#trino_info)[text=Cloud Trino]} – бұл әртүрлі деректер көздерінен келген үлкен көлемдегі деректерді өңдеуге арналған массивті-параллельді аналитикалық SQL-қозғалтқыш. Ол мыналарды жасауға мүмкіндік береді:

- бірнеше көздер мен деректер қоймаларынан оқуға арналған SQL-сұрауларын параллельді орындау;
- DLH архитектурасында мамандандырылған қызметтерді пайдаланбай ETL- және ELT-пайпландарын ұйымдастыру.

Cloud Trino аналитикалық жүктемені қызмет көрсетуі қымбат және масштабтауы қиын {linkto(../../compare/dwh#dlh_dwh)[text=корпоративтік деректер қоймаларынан]} (мысалы, Greenplum негізінде) арзанырақ {linkto(../../compare/data-lake#dlh_data-lake)[text=деректер көлдеріне]} және {linkto(../../compare/dlh#dlh_dlh)[text=DLH]}-ке ауыстыруға мүмкіндік береді.

{linkto(../../architecture#dlh_architecture)[text=Data Lakehouse архитектурасында]} компонент мынадай функцияларды орындайды:

- Көздерден деректерді {linkto(../../architecture#dlh_data_processing_models)[text=PULL-моделі]}\ бойынша сұрау (қарапайым сценарийлер үшін).
- Apache Iceberg API арқылы объектілік S3-қоймасында деректерді оқу және жазу операцияларын орындау.
- Көздерден және DLH тұтынушыларынан келетін SQL-сұрауларының кіріс ағынын балансировкалау.
- Деректерді басқару және олардың шығу тегін қадағалау үшін DLH көздері мен деректер құрылымы туралы ақпаратты сыртқы метадеректер каталогында жариялау.
- Есептерді құру, BI-аналитика, машиналық оқыту үшін сыртқы қызметтердің сұраулары бойынша деректерді S3-қоймасынан тікелей ұсыну.
- Нақты уақыттағы аналитиканы орындау үшін мамандандырылған аналитикалық СУБД-пен (мысалы, ClickHouse, PostgreSQL) өзара іс-қимыл.
- Сұрау жоспарын көпфазалы оңтайландыру — SQL-сұрауын орындау кезіндегі әрекеттердің бекітілген тізбегін құру:

    - фильтрлерді қолдану;
    - `JOIN` көмегімен оңтайлы ретті таңдау;
    - сұрауда кестелерді көрініске (`VIEW`) ауыстыру;
    - деректерді түрлендіру операцияларын орындау.
