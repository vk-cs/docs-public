# {heading(Партнёр жеке кабинеті)[id=partner-platform-ui]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

{var(cloud)} платформасының партнёр жеке кабинеті — бұл {var(cloud)} платформасында клиенттеріңіздің жобаларын басқаруға мүмкіндік беретін интерфейс. Партнёр кабинеты VK Tech партнёрлік инфрақұрылымының бөлігі болып табылады.

Жеке кабинеттің құралдары мыналарды жасауға мүмкіндік береді:

- клиенттерді платформаға шақыру;
- клиенттердің тізімін, олардың жобаларын және олар бойынша ақпаратты көру;
- клиент жобасындағы баланстың ағымдағы жағдайын тексеру;
- клиент жобаларының балансы мен тұтынуының детализациясын алу және детализациясы бар есептерді жүктеп алу;
- барлық клиенттеріңіздің тұтынуы бойынша есептерді құру және жүктеп алу;
- клиент үшін ресурстарға рұқсатты блоктау.
