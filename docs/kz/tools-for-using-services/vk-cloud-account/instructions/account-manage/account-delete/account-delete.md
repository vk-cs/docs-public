# {heading(Тіркелгіні жою)[id=vk-cloud-account-delete]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Егер {var(cloud)} қызметтерін пайдалануды жалғастырмақ болмасаңыз, өз тіркелгіңізді жойыңыз. Онымен бірге сіз иесі болып табылатын барлық жобалар да жойылады.

{note:err}
Жойылғаннан кейін тіркелгіні қалпына келтіру мүмкін емес.
{/note}

Қызметтерді пайдаланғаны үшін ақшаны шегеруді тоқтату үшін тіркелгіні жою міндетті емес. Ресурстарды тұтынатын жобаларды {linkto(../../../../account/instructions/project-settings/manage#project-freeze)[text=консервациялау]} немесе {linkto(../../../../account/instructions/project-settings/manage#project-delete)[text=жою]} жеткілікті.

Тіркелгіні жою үшін:

1. Жобалардан және қызметтерден қажетті барлық деректерді тасымалдағаныңызға көз жеткізіңіз.

   Деректерді миграциялау бойынша көмек қажет болса, [техникалық қолдау қызметіне](/kz/contacts) жүгініңіз.

1. Жоба иесінің атынан тіркелгіні жою туралы өтінішпен [техникалық қолдау қызметіне](/kz/contacts) жүгініңіз.

   Растау үшін сізбен байланысқа шығады. Жою тек пайдаланушымен оның тіркелген поштасынан хат алмасу болғаннан кейін ғана мүмкін.

1. Қажет болса, {linkto(../../../../../intro/billing/instructions/refund#billing-refund)[text=ақшаны қайтаруды]} жүзеге асырыңыз.
