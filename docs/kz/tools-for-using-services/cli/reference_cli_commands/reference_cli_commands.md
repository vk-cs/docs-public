# {heading(OpenStack CLI нұсқаулығы)[id=reference_cli_commands]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

{var(cloud)} қызметін OpenStack CLI көмегімен басқару үшін {linkto(../openstack-cli#tools-cli-openstack)[text=%text]} бөлімінен дайындық операцияларын орындаңыз және төменде келтірілген командаларды орындаңыз.

## {heading(Командалар бойынша кірістірілген анықтама)[id=cli_help]}

```console
openstack help <КОМАНДА>
```

Мұнда `<КОМАНДА>` — анықтама алу қажет команда.

## {heading(ВМ үлгілерін (типтерін) басқару)[id=cli_flavor]}

### {heading(ВМ үлгілерінің тізімін алу)[id=cli_openstack_flavor_list]}

```console
openstack flavor list
      [--public | --private | --all]
      [--long]
```

Мұнда:

- `--public` — тек жалпыға қолжетімді ВМ үлгілерін көрсету.
- `--private` — тек жеке ВМ үлгілерін көрсету.
- `--all` — барлық ВМ үлгілерін көрсету: жалпыға қолжетімді және жеке (әдепкі бойынша).
- `--long` — қосымша өрістерді шығару.

### {heading(ВМ үлгісі туралы ақпаратты қарау)[id=cli_flavor_info]}

```console
openstack flavor show <ШАБЛОН_ВМ>
```

Мұнда `<ШАБЛОН_ВМ>` — ВМ үлгісінің атауы немесе идентификаторы.

## {heading(ВМ басқару)[id=cli_vm]}

### {heading(ВМ тізімін қарау)[id=cli_openstack_server_list]}

```console
openstack server list
      [--reservation-id <РЕЗЕРВИРОВАНИЕ>]
      [--ip <IP-АДРЕС>]
      [--name <ИМЯ>]
      [--instance-name <ИНСТАНС>]
      [--status <СТАТУС>]
      [--flavor <ШАБЛОН_ВМ>]
      [--image <ОБРАЗ>]
      [--host <УЗЕЛ>]
      [--all-projects]
      [--project <ПРОЕКТ>]
      [--project-domain <ДОМЕН_ПРОЕКТА>]
      [--user <ПОЛЬЗОВАТЕЛЬ>]
      [--user-domain <ДОМЕН_ПОЛЬЗОВАТЕЛЯ>]
      [--long]
      [--marker <МАРКЕР>]
      [--limit <ЛИМИТ>]
      [--deleted]
      [--changes-since <ВРЕМЯ>]
```

Мұнда:

- `--reservation-id <РЕЗЕРВИРОВАНИЕ>` — резервтеуге сәйкес келетін ВМ даналарын көрсетеді.
- `--ip <IP-АДРЕС>` — ВМ-ді тиісті мекенжайлар бойынша іріктеуге арналған тұрақты өрнек.
- `--name <ИМЯ>` — ВМ-ді атауы бойынша іріктеуге арналған тұрақты өрнек.
- `--instance-name <ИНСТАНС>` — ВМ-ді дана атауы бойынша іріктеуге арналған тұрақты өрнек.
- `--status <СТАТУС>` — ВМ-ді көрсетілген күй бойынша сүзгілеу.
- `--flavor <ШАБЛОН_ВМ>` — ВМ-ді көрсетілген ВМ үлгісі бойынша сүзгілеу (атауы немесе идентификаторы бойынша).
- `--image <ОБРАЗ>` — ВМ-ді көрсетілген бейне бойынша сүзгілеу (атауы немесе идентификаторы бойынша).
- `--host <УЗЕЛ>` — ВМ-ді орналастыру гипервизоры бойынша сүзгілеу.
- `--all-projects` — іріктеуге барлық жобаларды қосу.
- `--project <ПРОЕКТ>` — ВМ-ді көрсетілген жобада сүзгілеу (атауы немесе идентификаторы бойынша).
- `--project-domain <ДОМЕН_ПРОЕКТА>` — ВМ-ді жоба домені бойынша атауы немесе идентификаторы арқылы сүзгілеу. Опция жобалардың атаулары арасында қақтығыстар болған жағдайда қолданылады.
- `--user <ПОЛЬЗОВАТЕЛЬ>` — көрсетілген пайдаланушының ВМ-ін сүзгілеу (атауы немесе идентификаторы бойынша).
- `--user-domain <ДОМЕН_ПОЛЬЗОВАТЕЛЯ>` — ВМ-ді пайдаланушы домені бойынша (атауы немесе идентификаторы арқылы) сүзгілеу. Опция пайдаланушылардың атаулары арасында қақтығыстар болған жағдайда қолданылады.
- `--long` — қосымша өрістерді шығару.
- `--marker <МАРКЕР>` — алдыңғы беттегі соңғы ВМ. Өзге жағдай көрсетілмесе, `<МАРКЕР>`-ден кейінгі барлық ВМ тізімін шығарады. `--deleted` опциясымен бірге қолданылса, `<МАРКЕР>` маркері идентификатор (ID) болуы тиіс, әйтпесе ВМ атауын немесе ID-ін қолдануға болады.
- `--limit <ЛИМИТ>` — шығарылатын тізімдегі ВМ-дің максималды саны. `-1` мәні көрсетілсе — барлық ВМ шығарылады. Көрсетілген `<ЛИМИТ>` мәні `osapi_max_limit` конфигурациялық параметрінің мәнінен асып кетсе — `osapi_max_limit` ВМ шығарылады.
- `--deleted` — тек жойылған ВМ-дерді шығару.
- `--changes-since <ВРЕМЯ>` — көрсетілген уақыт сәтінен кейін өзгертілген ВМ тізімін шығарады. Көрсетілетін уақыт ISO 8061 форматында болуы тиіс. Мысал: `2016-03-05T06: 27: 59Z`.

### {heading(ВМ қосу)[id=cli_openstack_server_create]}

```console
openstack server create
    (--image <ОБРАЗ> | --volume <ДИСК>)
    --flavor <ШАБЛОН_ВМ>
    [--security-group <ГРУППА_БЕЗОПАСНОСТИ>]
    [--key-name <КЛЮЧЕВАЯ_ПАРА>]
    [--property <КЛЮЧ=ЗНАЧЕНИЕ>]
    [--file <ФАЙЛ_НАЗНАЧЕНИЯ=ИСХОДНЫЙ_ФАЙЛ>]
    [--user-data <ДАННЫЕ>]
    [--availability-zone <ЗОНА_ДОСТУПНОСТИ>]
    [--block-device-mapping <УСТРОЙСТВО=МАППИНГ>]
    [--nic <net-id=UUID_СЕТИ,v4-fixed-ip=IP_АДРЕС,v6-fixed-ip=IP_АДРЕС,port-id=UUID_ПОРТА,auto,none>]
    [--hint <КЛЮЧ=ЗНАЧЕНИЕ>]
    [--config-drive <КОНФИГУРАЦИОННЫЙ_ДИСК>]
    [--min <КОЛИЧЕСТВО>]
    [--max <КОЛИЧЕСТВО>]
    [--wait]
    <ВМ>
```

Мұнда:

- `--image <ОБРАЗ>` — бар бейнені (атауы немесе идентификаторы) пайдалана отырып ВМ жасау.
- `--volume <ДИСК>` — көрсетілген дискіні (атауы немесе идентификаторы) пайдалана отырып ВМ жасау. Флаг `0` жүктеу индексі бар блоктық құрылғының сәйкестендіруін (маппинг) автоматты түрде жасайды.
- `--flavor <ШАБЛОН_ВМ>` — көрсетілген ВМ конфигурациясының үлгісін (атауы немесе идентификаторы) пайдалана отырып ВМ жасау. Толық ақпарат {linkto(#cli_openstack_flavor_list)[text=%text]} бөлімінде келтірілген.
- `--security-group <ГРУППА_БЕЗОПАСНОСТИ>` — қауіпсіздік тобын тағайындай отырып ВМ жасау. Бірнеше қауіпсіздік тобын тағайындау үшін бірнеше рет қолдануға болады.
- `--key-name <КЛЮЧЕВАЯ_ПАРА>` — қолданылатын кілттік жұп. Міндетті емес флаг.
- `--property <КЛЮЧ=ЗНАЧЕНИЕ>` — қосымша қасиеттері бар ВМ жасау. Бірнеше қасиет орнату үшін бірнеше рет қолдануға болады.
- `file <ФАЙЛ_НАЗНАЧЕНИЯ=ИСХОДНЫЙ_ФАЙЛ>` — ОС бейнесіне қосылатын файл атауы. Мысал: SSH-кілттер.
- `--user-data <ДАННЫЕ>` — метадеректер сервері үшін пайдаланушы деректері.
- `--availability-zone <ЗОНА_ДОСТУПНОСТИ>` — ВМ-ді көрсетілген қолжетімділік аймағында жасау.
- `--block-device-mapping <УСТРОЙСТВО=МАППИНГ>` — блоктық құрылғылардың маппингі.
- `--nic <net-id=UUID_СЕТИ,v4-fixed-ip=IP_АДРЕС,v6-fixed-ip=IP_АДРЕС,port-id=UUID_ПОРТА,auto,none>` — желілік адаптер жасау. Бірнеше адаптер жасау үшін бірнеше рет қолдануға болады. Желі идентификаторын немесе порт идентификаторын көрсету қажет, бірақ екеуін бірд емес:

  - `net-id` — желілік адаптерді `<UUID_СЕТИ>` UUID-і бар желіге қосу.
  - `v4-fixed-ip` — желілік адаптердің тіркелген IPv4-мекенжайы. Міндетті емес флаг.

   <!--- // ** `v6-fixed-ip` — фиксированный IPv6-адрес сетевого адаптера. Необязательный флаг. -->

- `port-id` — желілік адаптерді `<UUID_ПОРТА>` UUID-і бар портына қосу.
- `none` — желі қосылмаған.
- `auto` — желіні автоматты түрде бөлу.

  - `--hint <КЛЮЧ=ЗНАЧЕНИЕ>` — жоспарлаушы (scheduler) үшін қосымша параметрлер.
  - `--config-drive <КОНФИГУРАЦИОННЫЙ_ДИСК>` — көрсетілген дискіні конфигурациялық диск ретінде пайдалану. Эфемерлік дискіні пайдалану үшін `True` мәнін орнатыңыз.
  - `--min <КОЛИЧЕСТВО>` — іске қосу үшін ВМ-нің минималды саны. Әдепкі мәні — `1`.
  - `--max <КОЛИЧЕСТВО>` — іске қосу үшін ВМ-нің максималды саны. Әдепкі мәні — `1`.
  - `--wait` — ВМ жасаудың аяқталуын күту.
  - `<ВМ>` — ВМ атауы.

### {heading(ВМ параметрлерін өзгерту)[id=cli_openstack_server_set]}

```console
openstack server set
      [--name <НАЗВАНИЕ>]
      [--root-password <ПАРОЛЬ>]
      [--property <КЛЮЧ=ЗНАЧЕНИЕ>]
      [--state <СТАТУС>]
      <ВМ>
```

Мұнда:

- `--name <НАЗВАНИЕ>` — ВМ-нің жаңа атауы.
- `--root-password` — әдепкі пайдаланушыға ВМ-ге кіру үшін құпиясөз орнату. Әр ВМ үлгісі үшін пайдаланушы атауы өз болуы мүмкін. Мысал: CentOS 7 ОС бар кірістірілген бейне үшін әдепкі пайдаланушы атауы — `centos`.
- `--property <КЛЮЧ=ЗНАЧЕНИЕ>` — ВМ-нің қосымша қасиеттері. Бірнеше қасиет орнату үшін бірнеше рет қолдануға болады.
- `--state <СТАТУС>` — ВМ үшін күй орнату.
- `<ВМ>` — ВМ-нің атауы немесе идентификаторы.

### {heading(ВМ миграциясы)[id=cli_openstack_server_migrate]}

```console
openstack server migrate
    [--live <УЗЕЛ>]
    [--shared-migration | --block-migration]
    [--disk-overcommit | --no-disk-overcommit]
    [--wait]
    <ВМ>
```

Мұнда:

- `--live` — ВМ-ді `<УЗЕЛ>` есептеу торабына live-миграция жасау.
- `--shared-migration` — ортақ live-миграция орындау (әдепкі бойынша).
- `--block-migration` — блоктық live-миграция орындау.
- `--disk-overcommit` — мақсатты торапта дискінің артық резерін (overcommit) рұқсат ету.
- `--no-disk-overcommit` — мақсатты торапта дискінің артық резервін орындамау (әдепкі бойынша).
- `--wait` — миграцияның аяқталуын күту.
- `<ВМ>` — миграцияланатын ВМ-нің атауы немесе идентификаторы.

### {heading(ВМ-ге қауіпсіздік тобын тағайындау)[id=cli_openstack_server_add_security_group]}

```console
openstack server add security group <ВМ> <ГРУППА_БЕЗОПАСНОСТИ>
```

### {heading(ВМ бейнесін қосу)[id=cli_openstack_image_create]}

```console
openstack image create
      [--disk-format <ФОРМАТ_ДИСКА>]
      [--container-format <ФОРМАТ_КОНТЕЙНЕРА>]
      [--file <ФАЙЛ>]
      [--volume <ДИСК>]
      [--protected | --unprotected]
      [--public | --private]
      [--property <КЛЮЧ=ЗНАЧЕНИЕ> [<КЛЮЧ_2=ЗНАЧЕНИЕ_2> ...] ]
      [--project <ПРОЕКТ>]
      [--project-domain <ДОМЕН_ПРОЕКТА>]
      <ОБРАЗ>
```

Мұнда:

- `--disk-format <ФОРМАТ_ДИСКА>` — бейне дискісінің форматы. Мүмкін мәндер: `ami`, `ari`, `aki`, `vhd`, `vmdk`, `raw`, `qcow2`, `vhdx`, `vdi`, `iso`, `ploop`. Әдепкі мәні — `raw`.
- `--container-format <ФОРМАТ_КОНТЕЙНЕРА>` — бейне контейнерінің форматы. Мүмкін мәндер: `ami`, `ari`, `aki`, `bare` (әдепкі), `docker`, `ova`, `ovf`.
- `--file <ФАЙЛ>` — бейне жасау қажет бейне файлына немесе оның архивіне дейінгі жол.
- `--volume <ДИСК>` — бейне жасалатын дискінің атауы немесе идентификаторы.
- `--protected` — бейнені жоюдан қорғау.
- `--unprotected` — бейнені жоюдан қорғау.
- `--public` — бейнені жалпыға қолжетімді ету.
- `--private` — бейнені жеке ету (әдепкі бойынша).
- `--property <КЛЮЧ=ЗНАЧЕНИЕ>` — бейненің қосымша қасиеттері. Бірнеше қасиет орнату үшін бірнеше рет қолдануға болады.
- `--project <ПРОЕКТ>` — бейне қосылатын жобаның атауы немесе идентификаторы.
- `--project-domain <ДОМЕН_ПРОЕКТА>` — бейнені жоба доменіне атауы немесе идентификаторы арқылы бекіту. Флаг жобалардың атаулары арасында қақтығыстар болған жағдайда қолданылады.
- `<ОБРАЗ>` — диск бейнесінің атауы.

### {heading(Диск жасау)[id=cli_openstack_volume_create]}

```console
openstack volume create
      [--size <ДИСК_ӨЛШЕМІ>]
      [--type <ДИСК_ТҮРІ>]
      [--image <ОБРАЗ> | --snapshot <СНИМОК> | --source <ДИСК> | --source-replicated <РЕПЛИЦИРУЕМЫЙ_ДИСК>]
      [--description <СИПАТТАМАСЫ>]
      [--project <ЖОБА>]
      [--availability-zone <ҚОЛЖЕТІМДІЛІК_АЙМАҒЫ>]
      [--consistency-group <КОНСИСТЕНТТІЛІК_ТОБЫ>]
      [--property <КІЛТ=МӘН>]
      [--hint <КІЛТ=МӘН>]
      [--bootable | --non-bootable]
      [--read-only | --read-write]
      <АТАУЫ>
```

Мұнда:

- `--size <ДИСК_ӨЛШЕМІ>` — диск өлшемі ГБ есебінде.
- `--type <ДИСК_ТҮРІ>` — диск түрінің атауы немесе идентификаторы.
- `--image <ОБРАЗ>` — диск жасау үшін образдың атауы немесе идентификаторы.
- `--snapshot <СНИМОК>` — диск жасау үшін снимктің атауы немесе идентификаторы.
- `--source <ДИСК>` — көз ретінде пайдалану қажет диск (клондау).
- `--source-replicated <РЕПЛИЦИРУЕМЫЙ_ДИСК>` — клондау үшін репликацияланатын дискінің атауы немесе идентификаторы.
- `--description <СИПАТТАМАСЫ>` — дискінің сипаттамасы.
- `--project <ЖОБА>` — диск бекітілуі қажет жобаның атауы немесе идентификаторы.
- `--availability-zone <ҚОЛЖЕТІМДІЛІК_АЙМАҒЫ>` — диск жасалуы қажет қолжетімділік аймағының атауы немесе идентификаторы.
- `--consistency-group <КОНСИСТЕНТТІЛІК_ТОБЫ>` — диск үшін консистенттілік тобы.
- `--property <КІЛТ=МӘН>` — дискінің қосымша қасиеттері. Бірнеше қасиет орнату үшін бірнеше рет қолданылуы мүмкін.
- `--hint <КІЛТ=МӘН>` — планировщикке (scheduler) арналған қосымша параметрлер.
- `--bootable` — дискіні жүктемелі ретінде белгілеу үшін қолданылатын кілт. Жүктемелі дискілерден ВМ жасауға болады.
- `--non-bootable` — дискіні жүктемелі емес ретінде белгілеу үшін қолданылатын кілт (әдепкі бойынша қолданылады).
- `--read-only` — «тек оқу» режимін орнату үшін қолданылатын кілт.
- `--read-write` — «оқу-жазу» режимін орнату үшін қолданылатын кілт (әдепкі бойынша қолданылады).
- `<АТАУЫ>` — дискінің атауы.

## {heading(Желілерді басқару)[id=cli_network]}

### {heading(Желілер тізімін көру)[id=cli_openstack_network_list]}

```console
openstack network list
      [--external | --internal]
      [--long]
      [--name <АТАУЫ>]
      [--enable | --disable]
      [--project <ЖОБА>]
      [--project-domain <ЖОБА_ДОМЕНІ>]
      [--share | --no-share]
      [--status <КҮЙ>]
      [--provider-network-type <ЖЕЛІ_ТҮРІ>]
      [--provider-physical-network <ФИЗИКАЛЫҚ_ЖЕЛІ>]
      [--provider-segment <ЖЕЛІ_СЕГМЕНТІ>]
```

Мұнда:

* `--external` — тек сыртқы желілерді көрсету.
* `--internal` — тек ішкі желілерді көрсету.
* `--long` — қосымша қасиеттерді шығару.
* `--name <АТАУЫ>` — `<АТАУЫ>` атауы бар желіні көрсету.
* `--enable` — тек `enabled` күйіндегі желілерді көрсету.
* `--disable` — тек `enabled` күйіндегі желілерді көрсету.
* `--project <ЖОБА>` — көрсетілген жобадағы (атауы немесе идентификаторы бойынша) желілерді сүзгілеу.
* `--project-domain <ЖОБА_ДОМЕНІ>` — желілерді жоба домені бойынша атауы немесе идентификаторы арқылы сүзгілеу. Опция жобалардың атаулары арасында қақтығыс болған жағдайда қолданылады.
* `--share` — бірнеше жоба үшін ортақ желілерді көрсету.
* `--no-share` — тек бір жоба үшін ортақ желілерді көрсету.
* `--status <КҮЙ>` — белгілі бір күйлердегі желілерді көрсету. Мүмкін мәндері:

   * `ACTIVE` — белсенді.
   * `BUILD` — жасау процесінде.
   * `DOWN` — өшірулі.
   * `ERROR` — жұмыс қатесі.

* `--provider-network-type <ЖЕЛІ_ТҮРІ>` — белгілі бір түрдегі желілерді көрсету. Мүмкін мәндері: `flat`, `geneve`, `gre`, `local`, `vlan`, `vxlan`.
* `--provider-physical-network <ФИЗИКАЛЫҚ_ЖЕЛІ>` — `<ФИЗИКАЛЫҚ_ЖЕЛІ>` атауы бар физикалық желіні көрсету.
* `--provider-segment <ЖЕЛІ_СЕГМЕНТІ>` — VLAN желілері үшін VLAN идентификаторы немесе GENEVE/GRE/VXLAN желілері үшін Tunnel ID идентификаторы бойынша желілер тізімін көрсету.

```console
openstack network create
      [--share | --no-share]
      [--enable | --disable]
      [--project <ЖОБА>]
      [--project-domain <ЖОБА_ДОМЕНІ>]
      [--description <СИПАТТАМАСЫ>]
      [--availability-zone-hint <ҚОЛЖЕТІМДІЛІК_АЙМАҒЫ>]
      [--external | --internal]
      [--default | --no-default]
      [--qos-policy <QOS_ЕРЕЖЕСІ>]
      [--provider-network-type <ЖЕЛІ_ТҮРІ>]
      [--provider-physical-network <ФИЗИКАЛЫҚ_ЖЕЛІ>]
      <ЖЕЛІ>
```

Мұнда:

- `--share` — желіні жариялы (басқа жобаларда қолжетімді) етіп орнату.
- `--no-share` — желіні жеке (приватный) етіп орнату (әдепкі бойынша).
- `--enable` — желінің қолжетімділік белгісі (әдепкі бойынша).
- `--disable` — желінің қолжетімсіздік белгісі.
- `--project <ЖОБА>` — желі қосылатын жобаның атауы немесе идентификаторы.
- `--project-domain <ЖОБА_ДОМЕНІ>` — желіні жоба доменіне атауы немесе идентификаторы арқылы бекіту. Флаг жобалардың атаулары арасында қақтығыс болған жағдайда қолданылады.
- `--description <СИПАТТАМАСЫ>` — желінің сипаттамасы.
- `--availability-zone-hint <ҚОЛЖЕТІМДІЛІК_АЙМАҒЫ>` — желі үшін қолжетімділік аймағы (`Network Availability Zone` кеңейтімі қажет).
- `--external` — желіні сыртқы етіп орнату.
- `--internal` — желіні ішкі етіп орнату (әдепкі бойынша).
- `--default` — әдепкі сыртқы желі ретінде қолдану.
- `--no-default` — әдепкі сыртқы желі ретінде қолданбау (әдепкі бойынша).
- `--qos-policy <QOS_ЕРЕЖЕСІ>` — желі үшін QoS ережесінің атауы немесе идентификаторы.
- `--provider-network-type <ЖЕЛІ_ТҮРІ>` — виртуалды желі іске асырылатын физикалық механизм. Мүмкін мәндері: `flat`, `geneve`, `gre`, `local`, `vlan`, `vxlan`.
- `--provider-physical-network <ФИЗИКАЛЫҚ_ЖЕЛІ>` — физикалық желінің атауы (тек сыртқы желі үшін).
- `<ЖЕЛІ>` — желінің атауы.

Мұнда:

- `--network <ЖЕЛІ>` — порт жасалатын желінің атауы немесе идентификаторы.
- `--description <СИПАТТАМАСЫ>` — порт үшін сипаттама.
- `--device <ҚҰРЫЛҒЫ_ID>` — порттың құрылғы идентификаторы.
- `--device-owner <ПОРТ_ИЕСІ>` — порт иесінің атауы.
- `--vnic-type <VNIC_ТҮРІ>` — порт үшін VNIC түрі. Мүмкін мәндер: `direct`, `direct-physical`, `macvtap`, `normal` (әдепкі бойынша), `baremetal`.
- `--host <ТҮЙІН_ID>` — порт байланатын түйіннің идентификаторы.
- `--dns-name <DNS_АТЫ>` — порт үшін DNS-аты тағайындау.
- `--fixed-ip subnet=<ПОДСЕТЬ>,ip-address=<IP-МӘКЕЛЕМАҒЫ>` — порт үшін көрсетілген подсетьдегі (атауы немесе идентификаторы) IP-мәкелемағ.
- `--enable` — портты белсенді ету (әдепкі мән).
- `--disable` — портты белсенді емес ету.
- `--mac-address <MAC_МӘКЕЛЕМАҒЫ>` — порттың MAC-мәкелемағы.
- `--project <ЖОБА>` — портты жобаға атауы немесе идентификаторы бойынша бекіту.
- `--project-domain <ЖОБА_ДОМЕНІ>` — портты жоба доменіне атауы немесе идентификаторы бойынша тағайындау. Флаг жоба атаулары арасында қақтығыстар болған жағдайда қолданылады.
- `--security-group <ҚАУІПСІЗДІК_ТОБЫ>` — порт үшін қауіпсіздік тобы. `--no-security-group` опциясы портқа қауіпсіздік топтарын қоспайды (әдепкі бойынша).
- `--enable-port-security` — порт үшін қорғанысты қосу (әдепкі бойынша).
- `--disable-port-security` — порт үшін қорғанысты өшіру.
- `--allowed-address ip-address=<IP-МӘКЕЛЕМАҒЫ>[,mac-address=<MAC_МӘКЕЛЕМАҒЫ>]` — портқа байланысты рұқсат етілген адрес жұбы.
- `<ПОРТ>` — порттың атауы.

- `--remote-ip <IP-МӘКЕЛЕМАҒЫ>` — сүзгілеу қолданылатын қосылу адресінің блогы CIDR жазбасында. Әдепкі мән — `0.0.0.0/0`.
- `--remote-group <ҚАУІПСІЗДІК_ТОБЫ>` — қашықтағы қауіпсіздік тобының атауы немесе идентификаторы.
- `--description <СИПАТТАМАСЫ>` — ереженің сипаттамасы.
- `--dst-port <ПОРТ>` — тағайындау порты. Жеке порт немесе порттар диапазоны болуы мүмкін (`137:139`). TCP және UDP протоколдары үшін қажет. ICMP протоколы үшін еленбейді.
- `--icmp-type <ICMP_ТҮРІ>` — ICMP IP протоколы үшін ICMP түрі.
- `--icmp-code <ICMP_КОДЫ>` — ICMP IP протоколы үшін ICMP коды.
- `--protocol <ПРОТОКОЛ>` — IP протоколы. Мүмкін мәндер: `icmp`, `tcp`, `udp`. Әдепкі мәні `tcp`.
- `--ingress` — кіріс трафик үшін ережені қолдану (әдепкі бойынша қолданылады).
- `--egress` — шығыс трафик үшін ережені қолдану.
- `--ethertype <ETHERNET_КАДР_ТҮРІ>` — Ethernet-кадрдың түрі (екі байттық он алтылық сан).
- `--project <ЖОБА>` — ереже жасалатын жобаның атауы немесе идентификаторы.
- `--project-domain <ЖОБА_ДОМЕНІ>` — ережені жоба доменіне атауы немесе идентификаторы бойынша тағайындау. Флаг жоба атаулары арасында қақтығыстар болған жағдайда қолданылады.
- `<ЕРЕЖЕ>` — қауіпсіздік тобы ережесінің атауы.

#### {heading(Қауіпсіздік тобының ережелерін жою)[id=cli_sec_rule_delete]}

```console
openstack security group rule delete <ЕРЕЖЕ>
```
Мұнда `<ЕРЕЖЕ>` — қауіпсіздік тобы ережесінің идентификаторы.

## {heading(Жүктемені теңгерушілерді басқару)[id=cli_loadbalancer_listener_pool_manage]}

### {heading(Жүктемені теңгеруші)[id=cli_loadbalancer]}

#### {heading(Жүктемені теңгерушілердің тізімін көру)[id=cli_loadbalancer_list]}

```console
openstack loadbalancer list
      [--name <АТАУЫ>]
      [--enable | --disable]
      [--project <ЖОБА>]
      [--vip-network-id <VIP_ЖЕЛІ>]
      [--vip-subnet-id <VIP_ПОДСЕТЬ>]
      [--vip-qos-policy-id <VIP_QOS_САЯСАТЫ>]
      [--vip-port-id <VIP_ПОРТ>]
      [--provisioning-status {ACTIVE,DELETED,ERROR,PENDING_CREATE,PENDING_UPDATE,PENDING_DELETE}]
      [--operating-status {ONLINE,DRAINING,OFFLINE,DEGRADED,ERROR,NO_MONITOR}]
      [--provider <ПРОВАЙДЕР>]
      [--availability-zone <ҚОЛЖЕТІМДІЛІК_АЙМАҒЫ>]
```

Мұнда:

- `--name <АТАУЫ>` — жүктемені теңгерушінің атауы бойынша сүзгі.
- `--enable` — қосылған жүктемені теңгерушілерді көрсету.
- `--disable` — өшірілген жүктемені теңгерушілерді көрсету.
- `--project <ЖОБА>` — теңгерушілер көрсетілетін жоба.
- `--vip-network-id <VIP_ЖЕЛІ>` — VIP-желінің атауы немесе идентификаторы бойынша сүзгі.
- `--vip-subnet-id <VIP_ПОДСЕТЬ>` — подсетьдің атауы немесе идентификаторы бойынша сүзгі.
- `--vip-qos-policy-id <VIP_QOS_САЯСАТЫ>` — VIP QoS атауы немесе идентификаторы бойынша сүзгі.
- `--vip-port-id <VIP_ПОРТ>` — порттың атауы немесе идентификаторы бойынша сүзгі.
- `--provisioning-status` — теңгерушілерді белгілі бір дайындау статусында шығару. Мүмкін мәндер: `ACTIVE`, `DELETED`, `ERROR`, `PENDING_CREATE`, `PENDING_UPDATE`, `PENDING_DELETE`.
- `--operating-status` — теңгерушілерді белгілі бір жұмыс статусында шығару. Мүмкін мәндер: `ONLINE`, `DRAINING`, `OFFLINE`, `DEGRADED`, `ERROR`, `NO_MONITOR`.
- `--provider <ПРОВАЙДЕР>` — провайдер бойынша сүзгі.
- `--availability-zone <ҚОЛЖЕТІМДІЛІК_АЙМАҒЫ>` — қолжетімділік аймағы бойынша сүзгі.


Мұнда `<ТЕҢГЕРУШІ>` — жүктемені теңгерушінің атауы немесе идентификаторы.

```console
openstack loadbalancer create

      [--description <СИПАТТАМАСЫ>]

      [--vip-port-id <VIP_ПОРТ>]
      [--vip-subnet-id <VIP_ПОДСЕТЬ>]
      [--vip-network-id <VIP_ЖЕЛІ>]
      [--vip-qos-policy-id <VIP_QOS_САЯСАТЫ>]
      [--project <ЖОБА>]
      [--provider <ПРОВАЙДЕР>]
      [--availability-zone <ҚОЛЖЕТІМДІЛІК_АЙМАҒЫ>]
      [--enable | --disable]
```

Мұнда:

- `--name <АТАУЫ>` — жүктемені теңгерушінің атауы.
- `--description <СИПАТТАМАСЫ>` — теңгерушінің сипаттамасы.
- `--vip-address <VIP_МӘКЕЛЕМАҒЫ>` — теңгеруші үшін IP-мәкелемағ немесе оның идентификаторы.
- `--vip-port-id <VIP_ПОРТ>` — теңгеруші үшін порттың атауы немесе идентификаторы. `--vip-network-id` флагымен бірге қолданылмайды.
- `--vip-subnet-id <VIP_ПОДСЕТЬ>` — теңгеруші үшін подсетьдің атауы немесе идентификаторы.
- `--vip-network-id <VIP_ЖЕЛІ>` — теңгеруші үшін желінің атауы немесе идентификаторы.
- `--vip-qos-policy-id <VIP_QOS_САЯСАТЫ>` — теңгеруші үшін QoS ережесінің атауы немесе идентификаторы.
- `--project <ЖОБА>` — теңгеруші бекітілетін жоба.
- `--provider <ПРОВАЙДЕР>` — теңгерушінің провайдері.
- `--availability-zone <ҚОЛЖЕТІМДІЛІК_АЙМАҒЫ>` — теңгеруші үшін қолжетімділік аймағы.
- `--enable` — теңгерушіні қосу (әдепкі бойынша).
- `--disable` — теңгерушіні өшіру.

Мұнда:

- `--name <АТАУЫ>` — тепетеңділік ережесінің атауы.
- `--description <СИПАТТАМАСЫ>` — тепетеңділік ережесінің сипаттамасы.
- `--protocol <ПРОТОКОЛ>` — тепетеңділік протоколы. Мүмкін мәндер: `TCP`, `HTTP`, `HTTPS`.
- `--connection-limit <ШЕК>` — тепетеңділік ережесіне рұқсат етілген қосылымдардың ең көп саны.

- `--protocol-port <ПОРТ>` — тепетеңділік протоколының порты.
- `--timeout-client-data <КҮТУ_УАҚЫТЫ>` — фронтендің бос тұруының күту уақыты, миллисекундпен. Әдепкі мәні: `50000`.
- `--timeout-member-connect <КҮТУ_УАҚЫТЫ>` — серверге қосылу күту уақыты, миллисекундпен. Әдепкі мәні: `5000`.
- `--timeout-member-data <КҮТУ_УАҚЫТЫ>` — сервердің бос тұруының күту уақыты, миллисекундпен. Әдепкі мәні: `50000`.
- `--timeout-tcp-inspect <КҮТУ_УАҚЫТЫ>` — мазмұнды тексеру үшін қосымша TCP-пакеттерді күту, миллисекундпен. Әдепкі мәні: `0`.
- `--enable` — тепетеңділік ережесін қосу (әдепкі бойынша).
- `--disable` — тепетеңділік ережесін өшіру.
- `--allowed-cidr <РУҚСАТ ЕТІЛГЕН_CIDR>` — CIDR нотациясындағы рұқсат етілген IP-адрес немесе желі маскасы. Бірнеше мәнді бөлек `--allowed-cidr` кілтімен көрсету қажет. Мысал: `--allowed-cidr <РУҚСАТ ЕТІЛГЕН_CIDR_1> --allowed-cidr <РУҚСАТ ЕТІЛГЕН_CIDR_2>`.
- `<ТЕПЕТЕҢДІГІШ>` — жүктемені тепетеңдігіштің атауы немесе идентификаторы.

- `--description <СИПАТТАМАСЫ>` — серверлер пулының сипаттамасы.
- `--protocol <ПРОТОКОЛ>` — тағайындалу протоколы. Мүмкін мәндер: `TCP`, `HTTP`, `PROXY`.
- `--listener <ЕРЕЖЕ>` — серверлер пулына байланыстырылатын тепетеңділік ережесінің атауы немесе идентификаторы.

- `--session-persistence <ҚАСИЕТТЕР>` — өңдеуші үшін желінің үздіксіздік қасиеттері (**кілт=мән** форматында).

- `--enable` — серверлер пулын қосу (әдепкі бойынша).
- `--disable` — серверлер пулын өшіру.
- `--tls-container-ref <КОНТЕЙНЕРГЕ_СІЛТЕМЕ>` — TLS-контейнерге сілтеме.
- `--ca-tls-container-ref <КОНТЕЙНЕРГЕ_СІЛТЕМЕ>` — CA-сертификаты бар TLS-контейнерге сілтеме.
- `--crl-container-ref <КОНТЕЙНЕРГЕ_СІЛТЕМЕ>` — қайтарылған CA-сертификаттарының тізімі бар контейнерге сілтеме.
- `--enable-tls` — TLS-шифрлауды қосу.
- `--disable-tls` — TLS-шифрлауды өшіру.

```console
      --timeout <КҮТУ_УАҚЫТЫ>
      --max-retries <ТӘСІЛДЕР_САНЫ>
      [--url-path <URL>]
      --type <ТҮРІ>
```

- `--http-version <HTTP_НҰСҚАСЫ>` — қолданылатын HTTP нұсқасы.
- `--timeout <КҮТУ_УАҚЫТЫ>` — ең ұзақ күту уақыты, секундпен.
- `--max-retries <ТӘСІЛДЕР_САНЫ>` — қатысушының жұмыс статусы `ONLINE` болып өзгертуге дейінгі қайта қосылудың сәтті тәсілдерінің саны.
- `--url-path <URL>` — монитор қолжетімділікті тексеру сұраныстарын жіберетін URL-адрес.
- `--type <ТҮРІ>` — монитордың түрі. Міндетті параметр. Мүмкін мәндер: `PING`, `HTTP`, `HTTPS`, `TCP`.
- `--max-retries-down <ТӘСІЛДЕР_САНЫ>` — монитор `ERROR` күйіне өтетін қосылудың ең көп тәсілдер саны.
- `--enable` — мониторды қосу (әдепкі бойынша).
- `--disable` — мониторды өшіру.
- `<СЕРВЕРЛЕР_ПУЛЫ>` — мониторға арналған пулдың атауы немесе идентификаторы.

#### {heading(Серверлер пулын жою)[id=cli_loadbalancer_pool_delete]}

```console
openstack loadbalancer pool delete <СЕРВЕРЛЕР_ПУЛЫ>
```
Мұнда `<СЕРВЕРЛЕР_ПУЛЫ>` — жүктемені тепетеңдігіш серверлер пулының атауы немесе идентификаторы.

#### {heading(Серверлер пулында сервер жасау)[id=cli_openstack_loadbalancer_member_create]}

```console
openstack loadbalancer member create
      [--name <СЕРВЕР>]
      [--disable-backup | --enable-backup]
      [--weight <САЛМАҚ>]
      --address <IP-АДРЕС>
      [--subnet-id <ЖЕЛІШЕ>]
      --protocol-port <ПОРТ>
      [--monitor-port <ПОРТ>]
      [--monitor-address <IP-АДРЕС>]
      [--enable | --disable]
      <СЕРВЕРЛЕР_ПУЛЫ>
```

Мұнда:

- `--name <СЕРВЕР>` — сервердің атауы.
- `--disable-backup` — сервер үшін резервтік көшірмелеуді өшіру (әдепкі бойынша).
- `--enable-backup` — сервер үшін резервтік көшірмелеуді қосу.
- `--weight <САЛМАҚ>` — сервердің салмағы (толығырақ — {linkto(../../../networks/balancing/concepts/about#balancing-load-balancer-instance-weight)[text=%text]} бөлімінде).
- `--address <IP-АДРЕС>` — трафигі жүктемені тепетеңдігішпен қызмет көрсетілетін сервердің IP-адресі.
- `--subnet-id <ЖЕЛІШЕ>` — сервер қолжетімді желіше деректемесінің идентификаторы.
- `--protocol-port <ПОРТ>` — сервер тыңдайтын порт нөмірі.
- `--monitor-port <ПОРТ>` — серверді мониторингтеу үшін қолданылатын қосымша порт нөмірі (health monitoring).
- `--monitor-address <IP-АДРЕС>` — серверді мониторингтеу үшін қолданылатын қосымша IP-адрес.
- `--enable` — серверді қосу (әдепкі бойынша).
- `--disable` — серверді өшіру.
- `<СЕРВЕРЛЕР_ПУЛЫ>` — сервер жасалатын серверлер пулының атауы немесе идентификаторы.

#### {heading(Серверді серверлер пулынан жою)[id=cli_loadbalancer_server_delete]}

## {heading(Маршрутизаторларды басқару)[id=cli_openstack_router_manage]}

### {heading(Маршрутизаторлардың тізімін көру)[id=cli_router_list]}

```console
openstack router list
      [--name <АТАУЫ>]
      [--enable | --disable]
      [--long]
      [--project <ЖОБА>]
      [--project-domain <ЖОБА_ДОМЕНІ>]
```

Мұнда:

- `--name <АТАУЫ>` — маршрутизаторларды атауы бойынша сүзгілеу.
- `--enable` — белсенді маршрутизаторлардың тізімін шығару.
- `--disable` — белсенді емес маршрутизаторлардың тізімін шығару.
- `--long` — қосымша қасиеттерді шығару.
- `--project <ЖОБА>` — маршрутизаторларды жобаның атауы немесе идентификаторы бойынша сүзгілеу.
- `--project-domain <ЖОБА_ДОМЕНІ>` — маршрутизаторларды жоба домені бойынша атау немесе идентификатор арқылы сүзгілеу. Опция жобалардың атаулары арасында қақтығыстар болған жағдайда қолданылады.

### {heading(Маршрутизатор туралы ақпаратты көру)[id=cli_router_info]}

```console
openstack router show <МАРШРУТИЗАТОР>
```

Мұнда `<МАРШРУТИЗАТОР>` — маршрутизатордың атауы немесе идентификаторы.

### {heading(Маршрутизатор жасау)[id=cli_openstack_router_create]}

```console
openstack router create
    [--project <ЖОБА> [--project-domain <ЖОБА_ДОМЕНІ>]]
    [--enable | --disable]
    [--distributed]
    [--ha]
    [--description <СИПАТТАМАСЫ>]
    [--availability-zone-hint <ҚОЛЖЕТІМДІЛІК_АЙМАҒЫ>]
    <МАРШРУТИЗАТОР>
```

Мұнда:

- `--project <ЖОБА> [--project-domain <ЖОБА_ДОМЕНІ>]` — маршрутизатор тиесілі болатын жобаның атауы және қажет болған жағдайда домені.
- `--enable` — маршрутизаторды белсенді ету (әдепкі мәні).
- `--disable` — маршрутизаторды белсенді емес ету.
- `--distributed` — бөлінгендік белгісі. Маршрутизатор тек есептеу түйіндерінде жасалады.
- `--ha` — жоғары қолжетімділік белгісі (High availability). Маршрутизатор барлық түйіндерде жасалады.

  {note:warn}
  `--distributed` және `--ha` параметрлерін қолдану үшін Neutron тарапынан қолдау және тиісті баптаулар қажет.
  {/note}

- `--description <СИПАТТАМАСЫ>` — маршрутизаторға арналған сипаттама.
- `--availability-zone-hint <ҚОЛЖЕТІМДІЛІК_АЙМАҒЫ>` — `<ҚОЛЖЕТІМДІЛІК_АЙМАҒЫ>` қолжетімділік аймағы.
- `<МАРШРУТИЗАТОР>` — маршрутизатордың атауы.

### {heading(Маршрутизатор параметрлерін өзгерту)[id=cli_openstack_router_set]}

```console
openstack router set
      [--name <АТАУЫ>]
      [--description <СИПАТТАМАСЫ>]
      [--enable | --disable]
      [--route destination=<ЖЕЛІШЕ>,gateway=<IP-АДРЕС>]
      [--no-route]
      [--ha | --no-ha]
      [--external-gateway <ЖЕЛІ>]
      <МАРШРУТИЗАТОР>
```

Мұнда:

- `--name <АТАУЫ>` — маршрутизатордың жаңа атауы.
- `--route destination=<ЖЕЛІШЕ>,gateway=<IP-АДРЕС>` — статикалық маршрутты көрсету. Мұнда:

  - `<ЖЕЛІШЕ>` — CIDR нотациясындағы мақсатты желіше.
  - `<IP-АДРЕС>` — ВМ IP-адресі.

- `--no-route` — маршрутизатордың статикалық маршруттарын тазалау. Бар статикалық маршруттарды қайта жазу үшін екі флагты да қолданыңыз: `--route` және `--no-route`.
- `--external-gateway <ЖЕЛІ>` — сыртқы желі ({var(cloud)} сыртындағы желілерге қолжетімділігі бар). Әдетте `ext-net` желісі қолданылады.

Қалған параметрлердің сипаттамасы {linkto(#cli_openstack_router_create)[text=%text]} бөлімінде келтірілген.

### {heading(Маршрутизатор параметрлерін қалпына келтіру)[id=cli_router_reset]}

```console
openstack router unset
      [--route destination=<ЖЕЛІШЕ>,gateway=<IP-АДРЕС>]

      [--tag <ТЕГ> | --all-tag]
      <МАРШРУТИЗАТОР>
```

Мұнда:

- `--tag <ТЕГ>` — маршрутизатор үшін жойылуы қажет тегтің атауы.
- `--all-tag` — маршрутизатор үшін барлық тегтерді жою.

Қалған параметрлердің сипаттамасы {linkto(#cli_openstack_router_set)[text=%text]} бөлімінде келтірілген.

### {heading(Желішені маршрутизаторға қосу)[id=cli_router_subnet_add]}

## {heading(Floating IP-адрестерді басқару)[id=cli_openstack_floating_ip_manage]}

```console
openstack floating ip list
      [--network <ЖЕЛІ>]
      [--port <ПОРТ>]
      [--long]
      [--status <СТАТУС>]
      [--project <ЖОБА>]
      [--project-domain <ЖОБА_ДОМЕНІ>]

```

Мұнда:

- `--network <ЖЕЛІ>` — Floating IP-адрестерді желінің атауы немесе идентификаторы бойынша сүзгілеу.

- `--long` — қосымша қасиеттерді шығару.
- `--status <СТАТУС>` — IP-адрестерді статус бойынша сүзгілеу. Мүмкін мәндер: `ACTIVE`, `DOWN`.

- `--project-domain <ЖОБА_ДОМЕНІ>` — адресхановтарды жоба домені бойынша атау немесе идентификатор арқылы сүзгілеу. Опция жобалардың атаулары арасында қақтығыстар болған жағдайда қолданылады.
- `--router <МАРШРУТИЗАТОР>` — Floating IP-адрестерді маршрутизатордың атауы немесе идентификаторы бойынша сүзгілеу.

- `--fixed-ip-address <IP-АДРЕС>` — Floating IP-адреспен сәйкестендірілуі қажет порттың IP-адресі.

- `--project <ЖОБА>` — IP-адрес бекітілетін жобаның атауы немесе идентификаторы.
