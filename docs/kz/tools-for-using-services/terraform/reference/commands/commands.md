# {heading(Terraform негізгі командалары)[id=tools-terraform-commands]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

[Terraform командасы жолы](https://www.terraform.io/cli/commands) — бұл көптеген ішкі командаларды қабылдайтын `terraform` командасы.

Негізінен қолданылатын командалар:

- `terraform init` — Terraform жұмыс каталогын инициализациялайды.
- `terraform validate` — Terraform файлының синтаксисінің дұрыстығын растайды.
- `terraform plan` — `apply` командасын іске қосқанда не өзгеретінін көрсетеді. `plan` командасының өзі жоспарды сақтамайды: оны файлға сақтау үшін `-out=<ЖОСПАР_ФАЙЛЫ>` параметрін қолданыңыз, содан кейін сақталған жоспарды `terraform apply <ЖОСПАР_ФАЙЛЫ>` командасымен қолданыңыз. Нәтижелердің ниетке сай болатынына көз жеткізу үшін `apply` алдында әрқашан `plan` командасын орындау ұсынылады.
- `terraform apply` — инфрақұрылымды құрады немесе өзгертеді. Команда орындау жоспарын көрсетеді және «иә» немесе «жоқ» жауабын талап етеді (егер `--auto-approve` жалаушасы қолданылмаса, бұл жағдайда команда автоматты түрде орындалады).
- `terraform apply -refresh-only` — күй файлын нақты ресурстармен синхрондауды инфрақұрылымды өзгертпей орындайды. Ескірген `terraform refresh` командасы растауды сұрамай сол әрекетті орынайды және үйлесімділік үшін сақталған.
- `terraform fmt` — `.tf` конфигурация файлдарын канондық форматқа келтіреді.
- `terraform import <КОНФИГУРАЦИЯДАҒЫ_РЕСУРСТЫҢ_АДРЕСІ> <РЕСУРСТЫҢ_ID>` — инфрақұрылымның бар ресурсын Terraform конфигурациясындағы ресурсқа байланыстырады.
- `terraform output` — конфигурацияда `output` блоктарымен жарияланған шығыс айнымалыларының мәндерін шығарады.
- `terraform state list` — күй файлында сақталған ресурстардың тізімін шығарады.
- `terraform destroy` — Terraform басқаратын инфрақұрылымды жояды. Бұл күй файлында жасалған және сақталған барлық нәрсені кластерден қайтарымсыз жояды.

Командаларды қолданар алдында `.tf` конфигурация файлдары орналасқан жұмыс каталогына өтіңіз.

Автоматтандыру скрипттерінде командаларды қолданған жағдайларда, ыңғайлылық үшін, команданы қолданар алдында жұмыс каталогын ауыстыру үшін `-chdir=` опциясы қолданылады:

```console
terraform -chdir=terraform/configuration apply
```
