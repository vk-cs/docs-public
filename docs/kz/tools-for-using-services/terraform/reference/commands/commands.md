# {heading(Terraform-дың негізгі командалары)[id=tools-terraform-commands]}

{include(/kz/_includes/_translated_by_ai.md)}

[Terraform командалық жолы](https://www.terraform.io/cli/commands) — бұл көптеген ішкі командаларды қабылдайтын `terraform` командасы.

Негізгі қолданылатын командалар:

- `terraform init` — Terraform жұмыс каталогын инициализациялайды.
- `terraform validate` — Terraform файлы синтаксисінің дұрыстығын растайды.
- `terraform plan` — `apply` командасы іске қосылғанда не өзгеретінін көрсетеді. `plan` командасының өзі жоспарды сақтамайды: оны файлға сақтау үшін `-out=<ЖОСПАР_ФАЙЛЫ>` параметрін қолданыңыз, содан кейін сақталған жоспарды `terraform apply <ЖОСПАР_ФАЙЛЫ>` командасымен қолданыңыз. Нәтижелер ниетіңізге сәйкес келетініне көз жеткізу үшін әрқашан `apply` алдында `plan` командасын орындау ұсынылады.
- `terraform apply` — инфрақұрылымды құрады немесе өзгертеді. Команда орындау жоспарын көрсетеді және «иә» немесе «жоқ» деп жауап беруді сұрайды (`--auto-approve` жалауы қолданылмаса; бұл жалаумен команда автоматты түрде орындалады).
- `terraform apply -refresh-only` — инфрақұрылымды өзгертпей, күй файлын нақты ресурстармен синхрондастырады. Ескірген `terraform refresh` командасы растау сұрамай сол әрекетті орындайды және үйлесімділікті сақтау үшін қалдырылған.
- `terraform fmt` — `.tf` конфигурация файлдарын канондық пішімге келтіреді.
- `terraform import <КОНФИГУРАЦИЯДАҒЫ_РЕСУРСТЫҢ_АДРЕСІ> <РЕСУРСТЫҢ_ID>` — инфрақұрылымның бар ресурсын Terraform конфигурациясындағы ресурсқа байланыстырады.
- `terraform output` — конфигурациядағы `output` блоктарымен жарияланған шығыс айнымалылардың мәндерін шығарады.
- `terraform state list` — күй файлында сақталған ресурстардың тізімін шығарады.
- `terraform destroy` — Terraform басқаратын инфрақұрылымды жояды. Бұл кластерден күй файлында жасалған және сақталғанның бәрінің қайтарымсыз жойылуына әкеледі.

Командаларды қолданбас бұрын `.tf` конфигурация файлдары бар жұмыс директориясына ауысыңыз.

Командаларды автоматтандыру сценарийлерінде қолданған кезде, ыңғайлы болу үшін команданы қолданар алдында жұмыс директориясын ауыстыруға арналған `-chdir=` опциясы пайдаланылады:

```console
terraform -chdir=terraform/configuration apply
```
