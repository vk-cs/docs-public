[Marketplace](https://cloud.vk.ru/docs/ru/applications-and-services/marketplace) жүйесіне қосымшалар қосу мүмкіндігіне ие болу үшін:

1. Әзірге жасалмаған болса, {var(cloud)} жүйесінде қосымшаңызды Marketplace жүйесіне жүктейтін пайдаланушыны [тіркеліңіз](/kz/intro/onboarding/account).

   Тіркелген кезде барлық жаңа пайдаланушылар үшін жоба автоматты түрде жасалады. Сервистік пакеттерді тестілеу және оларды Marketplace жүйесіне жүктеу үшін осы жобаны пайдалана аласыз.

1. Мына ақпаратпен [marketplace@cloud.vk.com](mailto:marketplace@cloud.vk.com) мекенжайына хат жіберіңіз:

   - Компания атауы.
   - Қосымшаңыздың Terraform манифесттерін тестілеу жүргізілетін жобаның идентификаторы ([Project ID](/kz/tools-for-using-services/api/rest-api/endpoints#rest-api-endpoints-get-project-id)).

     Мән VK Cloud жеке кабинетіндегі жоба параметрлері бетіндегі **Terraform** қойындысында көрсетіледі.

   - Сервисті жарияламай тұрып тестілеу үшін Marketplace тестілік атаулар кеңістігіне кіру қажет болатын пайдаланушының электрондық поштасы.
   - Сервистік кілттің иесі болып тағайындалатын пайдаланушының электрондық поштасы.
   - Қосымшаның инстанстарын жасау кезіндегі қателер туралы хабарламалар келіп түсетін пайдаланушының электрондық поштасы.

   Жауап хатында сервистік кілт жіберіледі. Оның қолданылу мерзімі әдепкі бойынша — 1 жыл. Сервистік кілтте қосымша қолжетімді болатын Marketplace тестілік және ашық атаулар кеңістіктері бар.

   Сіздің жобаңыздың идентификаторы (Project ID) жеткізушілер тізіміне енгізіледі. VK Cloud жүйесіндегі жобаңыздың бонусдық шотына қосымшаңызды Marketplace жүйесінде тестілеу үшін бонусдық қаражат есептелінеді.
