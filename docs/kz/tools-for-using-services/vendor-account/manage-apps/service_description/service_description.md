# {heading(Дүкенге арналған сервис сипаттамасын толтыру)[id=service_description]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Сервис сипаттамасы мыналарды қамтиды:

* Белгішені.
* Қысқаша сипаттаманы.
* Толық сипаттаманы.

Сервис сипаттамасы оның конфигурациясында орнатылады.

## {heading(Белгіше)[id=service_description_icon]}

Сервис белгішесі сервис карточкасында көрсетіледі:

* Дүкен каталогында.
* Сервис бетіндегі **Сервис сипаттамасы** қойындысында.

Image-based қосымша үшін белгіше [сервислік пакеттің](/kz/tools-for-using-services/vendor-account/manage-apps/ibservice_add/ib_structure) құрамында жүктеледі.

SaaS-қосымша үшін кемінде 62 × 62 пиксель өлшеміндегі SVG форматындағы белгішені тіркемеге салып [marketplace@cloud.vk.com](mailto:marketplace@cloud.vk.com) мекенжайына хат жіберіңіз. Жауап хатта [JSON-файлда](/kz/tools-for-using-services/vendor-account/manage-apps/saas_add/saas_configure/saas_json) көрсетілетін белгішеге сілтеме жіберіледі.

## {heading(Сервисдің қысқаша сипаттамасы)[id=service_description_short]}

Сервисдің қысқаша сипаттамасы сервис карточкасында көрсетіледі:

* Дүкен каталогында.
* Сервис бетіндегі **Сервис сипаттамасы** қойындысында.

Мәтін сервис конфигурациясындағы `short_description` параметрінде көрсетіледі:

* Image-based қосымша үшін — сервислік пакеттегі `service.yaml` файлында.
* SaaS-қосымша үшін — JSON-файлда.

## {heading(Сервисдің толық сипаттамасы)[id=service_description_full]}

Сервисдің толық сипаттамасы сервис бетіндегі **Сервис сипаттамасы** қойындысында көрсетіледі.

Мәтін сервис конфигурациясында көрсетіледі:

* Image-based қосымша үшін — сервислік пакеттегі `full_description.md` файлында.
* SaaS-қосымша үшін — JSON-файлдағы `full_description` параметрінде.

Жалпы жағдайда сервисдің толық сипаттамасы мынадай бөлімдерді қамтуы тиіс:

* Сервис туралы ақпарат.
* Тарифтеу ережелері.
* Пайдалы сілтемелер.
* Техникалық қолдау.
* Лицензиялық келісім.

### {heading(Сервис туралы ақпарат)[id=service_description_info]}

Бөлімде мынадай ақпарат келтіріңіз:

* Сервисдің қысқаша шолуы.

   Сервисдің не екенін, қандай міндеттерді шешуге көмектесетінін (негізгі пайдалану сценарийлерін) сипаттаңыз.
* Жеткізуші кім:

   * Вендор.
   * Дистрибьютор.
   * VK.

   {note:info}

   Opensource-шешімдер үшін жеткізуші — VK.

   {/note}
* Жеткізуші туралы ақпарат (міндетті емес).

   {note:info}

   Opensource-шешімдер үшін жеткізуші туралы ақпарат көрсетілмейді.

   {/note}
* Сервис сипаттамалары. Кесте түрінде мынадай деректерді көрсетіңіз:

   * Сервис түрі:

      * Image-based.
      * SaaS.

   * Сервис нұсқасы (бар болса). Мысалы, Usergate 7.01.

      {note:info}

      Сервис нұсқасы оның конфигурациясында көрсетілген сервис ревизиясы емес.

      {/note}
   * Image-based қосымша үшін — ОС-тың нақты нұсқасы. Мысалы, Ubuntu 22.04.
   * Сервис категориясы. Категория мысалдары:

      * Аналитика.
      * Дерекқорлар.
      * Қауіпсіздік.
      * Әзірлеу құралдары.
      * VPN.

Image-based қосымша үшін бөлімде қосымша ақпарат көрсетіңіз:

* Сервисді орналастыру нұсқалары:

   * Бір ВМ.
   * Кластер.

* Бұлтты платформаның қандай инфрақұрылымы пайдаланылатыны. Мысалы, ВМ, виртуалды желілер, DNS.
* Желіге қойылатын талаптар:

   * ВМ-ның сыртқы желіге қолжетімділігі болуы тиіс.
   * Субжелі баптауларында жеке DNS өшірілген болуы тиіс.

Пайдаланушыда сервис туралы толық түсінік қалыптастыру үшін бөлімге сервис схемалары мен интерфейс скриншоттарын (міндетті емес) қосыңыз.

{caption(Сервис туралы ақпарат бар бөлімді толтыру мысалы, Markdown форматы)[align=left;position=above]}
```markdown
UserGate NGFW UTM (Unified Threat Management) класындағы шешімдердің барлық функцияларын қамтиды, интернет-қауіптердің барлық түрінен қорғауды және интернет-қолжетімділікті басқаруды қамтамасыз етеді. UserGate NGFW шабуылдардан қорғауды, трафикті басқаруды, интернет-пайдаланушыларды аутентификациялауды жүзеге асырады, сонымен қатар қызметкерлердің интернет-ресурстарға кіруінің қауіпсіздігін қамтамасыз етіп, оларды қауіпті және зиянды мазмұнды жүктеуден қорғайды.

Сервис жеткізушісі: UserGate компаниясы.

## Шешілетін міндеттер

### Желіаралық экран ретінде

* Физикалық шекарада сыртқы кеңістікті ішкі немесе корпоративтік желіден бөлу.
* Нақты қашықтан жұмыс істейтін пайдаланушылардың нақты ақпараттық жүйелерге қолжетімділігін және аутентификациясын ұйымдастыруға арналған VPN-шлюз.
* Site-to-Site VPN L2TP IPSec арқылы локальды инфрақұрылым-бұлт түріндегі гибридтік ортаны ұйымдастыру және филиалдарды орталықпен және {var(cloud)} бұлтымен біріктіру.
```

### {heading(Тарифтеу ережелері)[id=service_description_tariffication]}

Бөлімде мынадай ақпарат келтіріңіз:

* Тарифтеу түрі (көбірек білу үшін — {linkto(/kz/tools-for-using-services/vendor-account/manage-apps/concepts/about#xaas_billing)[text=%text]} бөлімінде).
* Егер сервистің бірнеше тарифтік жоспары болса, олармен сервис бетіндегі тарифтік жоспарлар матрицасында танысуға болатынын көрсетіңіз.
* Егер сервисте ақылы тарифтік опциялар болса, мұндай опциялар тарифтік жоспардың құнына қосымша тарифтелетінін көрсетіңіз.
* Егер сервисте келісімдік бағасы бар тарифтік жоспарлар болса, бұл туралы ақпарат көрсетіңіз.
* Image-based қосымша үшін бұлтты платформа инфрақұрылымының құны бөлек тарифтелетінін көрсетіңіз.

{note:err}

Егер image-based қосымша бұлтты платформаның көлемі мен құнын сервисді қосқан сәтте анықтау мүмкін болмайтын инфрақұрылымын пайдаланса (мысалы, жұмыс барысында жинақталатын ақпаратты сақтау — бекаптар), тарифтеу ережелерінің сипаттамасында мұны көрсетіңіз.

{/note}

{caption(Тарифтеу ережелері бар бөлімді толтыру мысалы, Markdown форматы)[align=left;position=above]}
```markdown

# Тарифтеу ережелері
Сервис Bring Your Own License моделі бойынша ұсынылады. Тарифтеу тек тұтынылатын {var(cloud)} инфрақұрылымы үшін жүзеге асырылады. Оның құнын тарифтік жоспарды баптау шеберіндегі **Детализация** блогында бағалауға болады. Қорытынды құн тарифтік жоспарды баптау шеберінің соңғы бетінде көрсетіледі.
```
{/caption}

```markdown
# Пайдалы сілтемелер
```

* Сервисдің техникалық қолдауын алу ережелері.
* Image-based қосымша үшін — бұлтты платформа инфрақұрылымы бойынша техникалық қолдау алу ережелері.
* Техникалық қолдау контактілері.
