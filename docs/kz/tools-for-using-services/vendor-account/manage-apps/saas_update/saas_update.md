# {heading(SaaS-қосымшасын жаңарту)[id=saas_update]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

SaaS-қосымшасының конфигурациясын жаңарту мыналарды қамтуы мүмкін:

* Тарифтік жоспарлар мен опциялардың параметрлерін өзгерту.
* Тарифтік жоспарлар мен опцияларды қосу.
* Тарифтік жоспарлар мен опцияларды жою.

Дүкендегі SaaS-қосымшасын жаңарту үшін:

1. Сервистің конфигурациясы бар файлды өңдеңіз.

   1. Сервистің ағымдағы жарияланған ревизиясын дүкеннің тесттік кеңістіктерінде қолжетімді етіп сақтау үшін JSON-файлға сервистің жаңа конфигурациясын сипаттайтын жаңа бөлімді қойыңыз:

      {caption(null)[align=left;position=above]}
      ```json
      {
        "services": [
          {
          <SERVICE_PARAMETERS>,
          "preview": {
              "parameters": [
              ]
            },
          "plans": [
            ]
          },
          {
          <SERVICE_PARAMETERS>,
          "preview": {
              "parameters": [
              ]
            },
          "plans": [
            ]
          }
        ]
      }
      ```
      {/caption}

      Егер сервистің ағымдағы ревизиясын дүкеннің тесттік кеңістігінде қолжетімді етіп сақтау қажет болмаса, бұл қадамды өткізіп жіберіңіз.
   1. Сервистің жаңа конфигурациясын сипаттаңыз (толығырақ — [SaaS-қосымшасының конфигурациясы](../saas_add/saas_configure) бөлімінде).
   1. Сервистің жаңа конфигурациясында сервистің жаңа ревизиясын көрсетіңіз.

      {note:warn}

      Көрсетілген сервис ревизиясы дүкенге бұрыннан жүктелген болса, сервис жаңартылмайды.

      {/note}
   1. Егер тарифтік жоспарлардың параметрлері өзгертілген болса, сервистің жаңа конфигурациясында жоспарлардың жаңа ревизияларын көрсетіңіз.

      {note:warn}

      Көрсетілген жоспар ревизиялары дүкенге бұрыннан жүктелген болса, тарифтік жоспарлар жаңартылмайды.

      {/note}

1. Егер тарифтік жоспарлар қосылған немесе жойылған болса, брокер директориясындағы `resources/plan_mapping.json` файлын өңдеңіз (толығырақ — {linkto(../saas_add/saas_broker_add_configuration#saas_broker_add_configuration)[text=%text]} бөлімінде).
1. Дүкен брокерден сервистің ағымдағы конфигурациясын мерзімді түрде сұрайды, сондықтан жаңа конфигурация дүкеннің тесттік кеңістігіне автоматты түрде түседі.

   {note:err}

   Дүкен сервистің ағымдағы конфигурациясын ала алуы үшін брокер тәулік бойы қолжетімді болуы керек.

   {/note}
1. Сервистің жаңа ревизиясын дүкеннің тесттік кеңістігінде тексеріңіз (толығырақ — {linkto(../saas_add/saas_upload/saas_upload_testmarketplace#saas_upload_testmarketplace)[text=%text]} бөлімінде).
1. Сервистің жаңа ревизиясын дүкеннің ашық кеңістігінде жариялаңыз (толығырақ — {linkto(../saas_add/saas_upload/saas_upload_publish#saas_upload_publish)[text=%text]} бөлімінде).

   Алдыңғы жарияланған ревизия, егер ол сервистің конфигурация файлында сақталған болса, дүкеннің тесттік кеңістігіне ауысады. Тесттік кеңістіктерде сервистің конфигурациясында сипатталған жарияланбаған барлық ревизиялар сақталады.

   Сервистің конфигурациясынан жойылған сервис ревизиялары дүкеннің тесттік те, ашық та кеңістіктерінде қолжетімді болмайды.

   Жаңа ревизияны жариялау сервистің бұрыннан бар инстанстарына (тенанттар/аккаунттар) әсер етпейді. Бұл сервис инстанстарының ревизиясы, ол сервистің конфигурациясынан жойылып, дүкенде қолжетімді болмаса да, өзгеріссіз қалады.
