# {heading(Сервистік пакеттің құрылымы)[id=ib_structure]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Сервистік пакет файлдарының құрылымы JSON-файл генераторының нұсқасымен анықталады. Генератор сервистік пакеттегі файлдарды image-based қолданбаны дүкенмен интеграциялау үшін брокер қажет ететін JSON-файлға түрлендіреді. Генератордың нұсқасы `version.yaml` файлында көрсетіледі.

## {heading(JSON-файл генераторы 0.0.1)[id=ib_structure_file]}

JSON-файл генераторы 0.0.1 үшін файлдық құрылымды жасау үшін:

1. `<SERVICE_NAME>` сервисінің директориясын жасаңыз.
1. Сервис директориясында `version.yaml` файлын жасаңыз. Файлдың ішінде `version` параметрінде генератордың `0.0.1` нұсқасын көрсетіңіз:

   ```yaml
   version: 0.0.1
   ```

1. Сервис директориясында келесі директориялар мен файлдарды жасаңыз:

   * `full_description.md` файлы — сервистің толық сипаттамасын қамтиды.
   * `service.yaml` файлы — сервис параметрлері мен оның тарифтік жоспарларын сипаттайды.
   * `images` директориясы — дүкендегі сервис иконкасының суреті бар файлды қамтиды.

      * `png` немесе `svg` кеңейтілімі бар файл, сервис иконкасы ретінде қолданылады (көбірек ақпарат — {linkto(../../service_description#service_description_icon)[text=%text]} бөлімінде). Файл атауы `service.yaml` файлын толтыру кезінде `icon` параметрінде қолданылады.

         Файл өлшемі 1 МБ-тан аспауы тиіс. Сурет өлшемі кемінде 62×62 пиксель болуы қажет.

   * `parameters` директориясы — сервистің барлық тарифтік жоспарларының опцияларын сипаттайтын файлдарды қамтиды:

      * `<OPTION_NAME>.yaml` файлдары — тарифтік жоспарлардың опцияларын сипаттайды. Әрбір жеке файл бір опцияға сәйкес келеді. Бұл опциялар нақтылы тарифтік жоспарды сипаттайтын файлды (нақтылы жоспар директориясындағы `plan.yaml` файлы) қалыптастыру кезінде қолданылады.

   * `plans` директориясы — сервистің барлық тарифтік жоспарларын қамтиды. Ішінде әрбір жоспар үшін жеке директориялар орналасқан:

      * Әрбір `<PLAN_NAME>` жоспары үшін жеке директориялар — нақтылы тарифтік жоспарды сипаттайтын файлдарды қамтиды. Бір директория бір жоспарға сәйкес келеді:

         * `plan.yaml` файлы — нақтылы тарифтік жоспардың параметрлерін сипаттайды.
         * `display.yaml` файлы — тарифтік жоспарды конфигурациялау шеберін сипаттайды. Тарифтік жоспарды конфигурациялау шебері сервисті қосу және тарифтік жоспарды жаңарту кезінде дүкенде көрсетіледі.
         * `deployment` директориясы — Terraform манифестін қамтиды.

            * `deploy.tf` файлы — қолданбалы платформада сервистің нақтылы тарифтік жоспарының инфрақұрылымы мен орналастыру процесін сипаттайтын манифест.
            * `settings.yaml` файлы (міндетті емес) — манифестті орындау параметрлері.

{note:warn}

Файлдар мен директориялардың атаулары үшін латын әріптерін және бөлгіш ретінде астынғы сызық белгілерін қолданыңыз. Атауларда бос орындарды қолдану ұсынылмайды.

{/note}

{cut(JSON-файл генераторы 0.0.1 үшін сервистік пакет файлдарының құрылымы)}

```text
image_based_service
├── images
│   └── icon.png
├── parameters
│   ├── api_requests_daily_limit.yaml
│   ├── checklists_per_product.yaml
│   ├── export_issues.yaml
│   ├── groups.yaml
│   ├── members.yaml
│   └── report_notifications.yaml
├── plans
│   ├── advanced
│   ├── basic
│   └── free
│       └── deployment
│           ├── deploy.tf
│           ├── settings.yaml
│       ├── display.yaml
│       └── plan.yaml
├── full_description.md
├── service.yaml
└── version.yaml
```

{/cut}

{note:info}

`deployment` директориясында орналастырылатын Terraform параметрлері бір `deploy.tf` файлының орнына бірнеше `.tf` манифесттерінде сипатталуы мүмкін.

{/note}

{caption(`.tf` манифесттері бар `deployment` директориясының мазмұны мысалы)[align=left;position=above]}
```text
image_based_service/plans/free/deployment
│
├── common.tf
├── compute.tf
├── network.tf
├── output.tf
├── secgroup.tf
└── variables.tf
```
{/caption}
