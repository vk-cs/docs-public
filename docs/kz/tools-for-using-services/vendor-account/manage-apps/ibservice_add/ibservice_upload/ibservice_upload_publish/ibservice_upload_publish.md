# {heading(Сервисті жариялау)[id=ibservice_upload_publish]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Сервис тұтынушыларға жарияланғаннан кейін ғана қолжетімді болады.

Image-based қосымшаны дүкенде жариялау үшін [marketplace@cloud.vk.com](mailto:marketplace@cloud.vk.com) мекенжайына хат жіберіңіз. Хатта сервистің ID-сін және оның ревизиясын көрсетіңіз.

Сервистік пакет модерациядан өткізіледі. Осыдан кейін сервис дүкенде жарияланады.

Жарияланатын сервис ревизиясы дүкеннің тесттік кеңістігінен сервистік кілтте көрсетілген ашық кеңістікке ауыстырылады. Сервис осы ашық кеңістікке қол жетімділігі бар барлық пайдаланушыларға қолжетімді болады.

{note:warn}

Ашық кеңістіктерде сервистің соңғы жарияланған ревизиясы ғана қолжетімді.

{/note}
