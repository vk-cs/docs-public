# {heading(Сервистің бейнесін жариялау)[id=ibservice_upload_publish_image]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Сервистің бейнесін бұлтты платформада жариялау үшін:

1. [marketplace@cloud.vk.com](mailto:marketplace@cloud.vk.com) мекенжайына хат жіберіңіз.

   Хатта сервистің бейнесінің ID-сын көрсетіңіз.

   Көрсетілген бейне жарияланады. Жауап хатта сервистің публичті бейнесінің ID-сы жіберіледі.

   {note:info}

   Сервистің публичті бейнесі бұлтты платформаның барлық пайдаланушыларына қолжетімді болады.

   {/note}
1. `plans/<PLAN_NAME>/deployment/deploy.tf` манифесттерінде сервистің бейнесінің ID-сын сервистің публичті бейнесінің ID-сына ауыстырыңыз.
1. `service.yaml` файлында сервистің жаңа ревизиясын көрсетіңіз.
1. Сервистің публичті бейнесінің ID-сы бар сервистік пакетті дүкенге жүктеу үшін {linkto(../ibservice_upload_package#ibservice_upload_package)[text=%text]} бөлімінде келтірілген Infra API сервисіне сұрау орындаңыз.
