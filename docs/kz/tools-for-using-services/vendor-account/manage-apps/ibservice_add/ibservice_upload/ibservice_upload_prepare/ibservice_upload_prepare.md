# {heading(Дайындық операциялар)[id=ibservice_upload_prepare]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Сервистік пакетті дүкенге жүктейтін пайдаланушының бұлтты платформада тіркелгісі (жеке кабинет) болуы тиіс. Тіркеу бойынша нұсқаулық [«{var(cloud)} платформасында тіркелу»](/kz/intro/onboarding/account) бөлімінде берілген.

Келесі ақпаратпен [marketplace@cloud.vk.com](mailto:marketplace@cloud.vk.com) мекенжайына хат жіберіңіз:

* Компанияның атауы.
* Terraform манифесттерін тестілеу жүргізілетін жобаның идентификаторы (OpenStack PID).

   Мән бұлтты платформаның жеке кабинетінде жобаның баптаулар бетінде Terraform қойындысында көрсетіледі.
* Сервисті жарияламай тұрып тестілеу үшін дүкеннің тестілік кеңістіктеріне (namespace) кіру қажет пайдаланушының email мекенжайы.
* Сервистік кілттің иесі болып тағайындалатын пайдаланушының email мекенжайы.
* Сервистің инстанстарын жасау кезіндегі қателер туралы хабарламалар келіп түсетін пайдаланушының email мекенжайы.

   Жауап хатпен сервистік кілт жіберіледі. Әдепкі бойынша қолданылу мерзімі — 1 жыл. Сервистік кілт сервис қолжетімді болатын дүкеннің тестілік және ашық кеңістіктерін (namespace) қамтиды.

{note:info}

OpenStack PID Terraform манифесттерін жергілікті түрде және орналастыру жүйесімен (deployment system) тестілеу үшін жеткізушілер тізімінде болуы тиіс.

{/note}
