# {heading(Ресурстар конфигурациясына арналған кіріс айнымалылары)[id=tf_manifest_variable]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Ресурстар конфигурациясына арналған кіріс айнымалыларын сипаттаңыз. Айнымалыларды шартты түрде {linkto(#tab_tf_variables)[text=%number кестеде]} келтірілген топтарға бөлуге болады.

{caption({counter(table)[id=numb_tab_tf_variables]} кесте — Terraform айнымалылары)[align=right;position=above;id=tab_tf_variables;number={const(numb_tab_tf_variables)}]}
[cols="2,5,2", options="header"]
|===
|Топ
|Сипаттамасы
|Мүмкін түрлері

|Арнайы
|
Брокерден алынған деректерді пайдалануға мүмкіндік беретін айнымалылар.

Келесі айнымалылар қолдау көрсетіледі:

* `instance_uuid` — сервисдің орналастыру идентификаторы. iVK CS провайдерінің ресурстарының көпшілігін сипаттауда қолданылады.
* `email` — сервисті қосқан пайдаланушының email атауы.

Мұндай айнымалыларды манифестте жариялағанда, олардың мәнін Terraform автоматты түрде алады
|string

|Сыртқы
|
Тарифтік жоспарды конфигурациялау шеберінде бапталатын тарифтік опциялардың мәндерін беруге мүмкіндік беретін айнымалылар.

Айнымалының атауы тарифтік опцияның YAML-файлының атауына сәйкес болуы тиіс.

Манифестте мұндай айнымалыны жариялаудан бөлек, ол мыналарда көрсетілуі тиіс:

* Өз YAML-файлында тарифтік опция ретінде сипатталған.
* Тарифтік жоспарда көрсетілген (`plans/<PLAN_NAME>/plan.yaml` файлы).
* Тарифтік жоспарды конфигурациялау шеберінде көрсетілген (`plans/<PLAN_NAME>/display.yaml` файлы).

Сыртқы айнымалы үшін әдепкі мәнді беруге болады. Ол сыртқы мәнді алу мүмкін болмағанда қолданылады
|number, string, boolean

|Жергілікті
|
Тек манифестте қолданылатын айнымалылар. Айнымалыны жариялағанда `default` аргументінде мәнді көрсетіңіз
|Terraform қолдайтын түрлер
|===
{/caption}

{note:warn}

Айнымалыны жариялағанда `type` параметрінде түрін көрсетіңіз.

{/note}

{caption(Арнайы айнымалыларды жариялау мысалы)[align=left;position=above]}
```hcl

# Сервисдің орналастыру идентификаторы
variable "instance_uuid" {
  type    = string
}

# Пайдаланушының email атауы
variable "email" {
  type    = string
}
```
{/caption}

{caption(Сыртқы және жергілікті айнымалыларды жариялау мысалы)[align=left;position=above]}
```hcl

# ВМ жасалатын виртуалды желінің атауы
variable "sub_network" {
  type    = string
  default = "test-net"
}

# ВМ үшін CPU саны
variable "flavor_vcpus" {
  type    = number
  default = 2
}
```
{/caption}

Кіріс айнымалыларын сипаттағанда `locals` блоктарын пайдалануға болады. Олардың көмегімен есептеулерді, соның ішінде басқа жарияланған айнымалылар негізіндегі есептеулерді қолдана отырып, айнымалыларды беруге болады.
