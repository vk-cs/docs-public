# {heading(Әрекеттер реті)[id=ibservice_add_steps]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Image-based қосымшаны дүкенге қосу үшін:

1. [Сервистің бейнесін жасап, оны дүкенге жүктеңіз](../ib_image_create).

   Ұсынылатын тәсіл — Packer көмегімен.

   {note:err}

   Сервисті дүкенде жарияламас бұрын бейнесі бұлтты платформада жарияланады (толығырақ — {linkto(../ibservice_upload/ibservice_upload_publish_image#ibservice_upload_publish_image)[text=%text]} бөлімінде). Бұлтты платформаның пайдаланушыларында сервистің инстанстары публичтік бейне негізінде орналастырылады. Бейненің деректері жалпыға қолжетімді болады.

   {/note}
1. Сервистік пакеттің файлдық құрылымын [жасаңыз](../ib_structure).
1. Сервистің конфигурациясын сипаттайтын файлдарды (тарифтік жоспарлар, опциялар) [дайындаңыз](../ibservice_configure).
1. Сервистің инфрақұрылымының конфигурациясын сипаттайтын файлдарды [дайындаңыз](../tf_manifest).
1. Сервисті дүкенге [жүктеп, жариялаңыз](../ibservice_upload).
