# {heading(Суретке негізделген қолданбаның конфигурациялық файлдарының тізімі)[id=ibservice_files]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Брокерге арналған сервис конфигурациясы `YAML` және `MD` форматындағы файлдар арқылы сипатталады. YAML-файлдар белгілі бір құрылымға және сәйкес конфигурациялық файлдарды сипаттайтын бөлімдерде келтірілген параметрлерге ие болуы тиіс.

Келесі конфигурациялық файлдарды дайындаңыз:

1. {linkto(../ibservice_param#ibservice_param)[text=%text]}.
1. {linkto(../ibservice_full_description#ibservice_full_description)[text=%text]}.
1. Тарифтік опциялар файлдары `parameters/<OPTION_NAME>.yaml` (көбірек білу үшін — {linkto(../ibopt_fill_in#IB_option_fill_in)[text=plans/<PLAN_NAME>/plan.yaml]} бөлімінде).
1. Тарифтік жоспарлар файлдары {linkto(../ibplan#ibplan)[text=%text]}.
1. Әр тарифтік жоспар үшін тарифтік жоспарды конфигурациялау шеберінің файлдары {linkto(../ib_display#ib_display)[text=plans/<PLAN_NAME>/display.yaml]}.
