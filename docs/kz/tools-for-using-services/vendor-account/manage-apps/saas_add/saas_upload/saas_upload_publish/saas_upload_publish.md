# {heading(Сервисті жариялау)[id=saas_upload_publish]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Сервис тұтынушыларға жарияланғаннан кейін ғана қолжетімді болады.

SaaS-қосымшаны дүкенде жариялау үшін [marketplace@cloud.vk.com](mailto:marketplace@cloud.vk.com) мекенжайына хат жіберіңіз. Хатта сервистің ID-сін және оның ревизиясын көрсетіңіз.

Сервистің конфигурациясы модерациядан өткізіледі. Осыдан кейін сервис дүкенде жарияланады.

Жарияланатын сервис ревизиясы дүкеннің тесттік кеңістігінен сервистің конфигурациясындағы `metadata` параметрінде көрсетілген ашық кеңістікке ауыстырылады. Сервис осы ашық кеңістікке қолжетімділігі бар барлық пайдаланушыларға қолжетімді болады.

{note:warn}

Ашық кеңістіктерде сервистің соңғы жарияланған ревизиясы ғана қолжетімді.

{/note}
