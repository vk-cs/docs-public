# {heading(Әрекеттер реті)[id=saas_add_steps]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

SaaS-қосымшаны дүкенге қосу үшін:

1. Сервис үшін [брокерді әзірлеңіз](../saas_broker).
1. Сервис конфигурациясын (тарифтік жоспарлар, опциялар) [сипаттаңыз](../saas_configure).
1. Сервис конфигурациясын брокерге [жүктеңіз](../saas_broker_add_configuration).
1. Сервисті дүкенге [жүктеп, жариялаңыз](../saas_upload).
