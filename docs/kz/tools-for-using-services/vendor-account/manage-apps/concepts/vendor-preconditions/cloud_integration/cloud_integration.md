# {heading(Бұлттық платформадағы қызметтің жұмыс істеуі)[id=cloud_integration]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Қызметтің бұлттық платформада қалай жұмыс істейтінін тексеру үшін дүкенде жарияламай тұрып, қызметті тексеріп көруге кеңес береміз. Ол үшін бұлттық платформаның жобасының бонусдық шотына есептелетін бонустар беріледі.

Тестілеу барысында қызмет инстансымен негізгі операциялар мен қызметтің пайдаланушы сценарийлері тексеріледі.

Бұлттық платформадағы қызметті тестілеу және қызметті дүкенде жариялау туралы толық ақпарат [Image-based қосымшасын дүкенге жүктеу](../../../ibservice_add/ibservice_upload) және [SaaS-қосымшасын дүкенге жүктеу](../../../saas_add/saas_upload) бөлімдерінде берілген.
