# {heading(SaaS-қосымшасының API-сына қойылатын талаптар)[id=saas]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

SaaS-қосымшаны дүкенге қосу мүмкін болуы үшін SaaS-қосымшасының API-сы келесі әрекеттерді орындауға мүмкіндік беруі керек:

* Сервистің инстансының өмірлік циклін басқару:

   * Жасау. Дүкен SaaS-қосымшасының барлық тарифтік жоспарлары мен опцияларын ала алуы керек.
   * Жаңарту (тарифтік жоспарды немесе опцияларды өзгерту).
   * Ақпарат алу (ағымдағы тарифтік жоспар мен опциялар).
   * Жою.

* Егер сервиспен жұмыс істеу үшін сервистік байланыстырулар қолданылса — олардың өмірлік циклін басқару:

   * Жасау.
   * Ақпарат алу.
   * Жою.

* Егер сервистің инстансымен операциялар асинхронды орындалса — келесі операциялардың мәртебесін алу:

   * Сервистің инстансымен:

      * Жасау.
      * Жаңарту.
      * Жою.

   * Сервистік байланыстырумен (егер сервиспен жұмыс істеу үшін сервистік байланыстырулар қолданылса):

      * Жасау.
      * Жою.

* Егер SaaS-қосымшасы үшін алдын ала төлемді тарификация түрі қолданылса және тегін тарифтік жоспар болмаса — келесі операцияларды орындау:

   * Сервистің инстансын тоқтата тұру. Бұл сервистің инстансы деактивацияланған жағдайда деректердің жойылуынан сақтайды.
   * Сервистің инстансының жұмысын қайта бастау.

* Егер SaaS-қосымшасы үшін кейін төлемді тарификация түрі қолданылса — келесі операцияларды орындау:

   * Есепті кезеңге (мысалы, айға) сервистің инстанстары бойынша оны тұтыну туралы ақпаратты беру.
   * Сервистің инстансын тоқтата тұру. Бұл сервистің инстансы деактивацияланған жағдайда деректердің жойылуынан сақтайды.
   * Сервистің инстансының жұмысын қайта бастау.

{note:warn}

Дүкен мен SaaS-қосымшасының арасындағы өзара әрекеттесу автоматтандырылған болуы керек. Қолмен орындалатын операцияларға жол берілмейді.

{/note}
