# {heading(Агент)[id=ib_image_agent]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Агент — бұл сервисті орналастыру барысында ВМ-ге орнатылатын бағдарламалық жасақтама. Негізгі функциялары:

* Скрипттерді орындайды.
* Скрипттердің орындалуын бақылайды.
* Скрипттердің орындалу нәтижелерін сервистің инстансын орналастыру кезінде пайдалануға мүмкіндік береді.
* Скрипттердің орындалу нәтижелерін пайдаланушыға жіберуге мүмкіндік береді.
* Сервистің инстансын мониторингті баптауға мүмкіндік береді.

{note:warn}

Кластерде орналастырылатын сервистің бейнесінде агент міндетті түрде болуы керек.

{/note}

Бір ВМ-ге орналастырылатын сервистің бейнелеінде агент болмауы мүмкін. Бұл жағдайда сервисте мынадай мүмкіндіктер болмайды:

* Скрипттердің орындалуын бақылау.
* Скрипттердің орындалу нәтижелерін пайдаланушыға жіберу.
* Мониторинг.

Мысалы, агент болмаса, сервистің инстансын алғашқы баптау үшін скриптпен жасалған бір реттік құпиясөзді жеткізу мүмкіндігі болмайды.
