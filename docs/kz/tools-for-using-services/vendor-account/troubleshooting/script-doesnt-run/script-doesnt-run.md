ВМ инстансында SSL-сертификаты жаңартылғаннан кейін `ivkcs_cert` ресурсының сипаттамасында көрсетілген скрипт орындалмайды.

Мәселенің туындауы мүмкін себептері:

- Жүйе скрипт таба алмайды.
- Скрипт орындалатын пайдаланушының мұға жеткілікті құқығы жоқ.

## Шешім

1. `ivkcs_cert` ресурсының `renewal_hook_path` аргументіндегі скриптке жеткізу жолы дұрыс көрсетілгенін тексеріңіз.
1. `ivkcs_cert` ресурсының сипаттамасында `cert_files_owner` аргументі берілген болса, онда көрсетілген пайдаланушының мыналары бар-жоғын тексеріңіз:

    - скрипт орналасқан қалтаға кіру мүмкіндігі,
    - скриптті орындау құқығы.

1. Тексеру нәтижесі теріс болса, қосымшаңыздың конфигурациясына қажетті [өзгерістерді енгізіңіз](/kz/tools-for-using-services/vendor-account/how-to-guides/ssl-cert-usage#adjust_vm_image).
1. Мәселені өз бетінше шешу мүмкін болмаса, [техникалық қолдау қызметіне жүгініңіз](/kz/contacts).
