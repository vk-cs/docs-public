# {heading(Image-based қосымшаны жаңарту)[id=ibservice_update]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Image-based қосымшаның конфигурациясын жаңарту мыналарды қамтуы мүмкін:

* Тарифтік жоспарлар мен опциялар параметрлерін өзгерту.
* Тарифтік жоспарлар мен опцияларды қосу.
* Тарифтік жоспарлар мен опцияларды өшіру.
* Terraform манифесттерінде сипатталған ресурстар параметрлерін өзгерту.
* Terraform манифесттеріне ресурстарды қосу.

{note:err}

Дүкеннің ағымдағы нұсқасы Terraform манифесттерінің конфигурациясынан ресурстарды өшіруді қолдамайды. Бұл функция келесі нұсқада іске асырылады.

Манифесттердегі барлық өзгерістер кері үйлесімділікті қолдауы қажет.

{/note}

Дүкенде image-based қосымшаны жаңарту үшін:

1. Сервистік пакет файлдарын өңдеңіз. Файлдар параметрлері [Image-based қосымшаны дүкенге қосу](/kz/tools-for-using-services/vendor-account/instructions/manage-ib-apps/ib-add) бөлімінде келтірілген.
1. `service.yaml` файлында `revision` параметрінде сервистің жаңа ревизиясын көрсетіңіз.

   {note:warn}

   Көрсетілген сервис ревизиясы дүкенге бұрыннан жүктелген болса, сервис жаңартылмайды.

   {/note}

1. Тарифтік опциялар файлдары (`parameters` директориясы) өзгертілген болса, онда кемінде бір өзгертілген опцияны қолданатын әрбір тарифтік жоспар үшін жаңа ревизияны көрсетіңіз.

   Тарифтік жоспарды сипаттайтын файлдар өзгертілген болса, онда `plans/<ИМЯ_ПЛАНА>/plan.yaml` файлында жаңа ревизияны көрсетіңіз.

   {note:warn}

   Көрсетілген жоспар ревизиялары дүкенге бұрыннан жүктелген болса, тарифтік жоспарлар мен опциялар жаңартылмайды.

   {/note}

1. Жаңартылған сервистік пакетті жүктеп, сервистің жаңа ревизиясын дүкеннің ашық атаулар кеңістігінде жариялаңыз (қосымша мәліметтер — [Image-based қосымшаны қосу](/kz/tools-for-using-services/vendor-account/instructions/manage-ib-apps/ib-add#upload_package) бөлімінде).

   Алдыңғы жарияланған ревизия дүкеннің тестілік атаулар кеңістігіне өтеді. Тестілік атаулар кеңістіктерінде сервистің барлық жарияланбаған ревизиялары сақталады.

   Жаңа ревизияны жариялау сервистің бұрыннан бар инстанстарына әсер етпейді. Осы сервис инстанстарының ревизиясы өзгермейді.
