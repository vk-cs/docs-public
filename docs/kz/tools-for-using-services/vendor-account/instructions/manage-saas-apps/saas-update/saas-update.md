SaaS-қосымшаны оның тарифтік жоспарларына өзгерістер енгізілген жағдайда жаңарту қажет:

* тарифтік жоспарлардың немесе опциялардың параметрлері өзгертілсе;
* тарифтік жоспарлар немесе опциялар қосылатын болса;
* тарифтік жоспарлар немесе опциялар жойылатын болса.

Мұндай өзгерістер болған жағдайда Marketplace-тегі SaaS-қосымшаның конфигурациясын жаңартыңыз:

1. `catalog_<ҚЫЗМЕТ_АТЫ>.json` JSON-файлын қызмет конфигурациясының сипаттамасымен өңдеңіз.

   1. Marketplace-тің тесттік атаулар кеңістігінде қызметтің ағымдағы жарияланған ревизиясына қолжетімділікті сақтау үшін JSON-файлға қызметтің жаңа конфигурациясын сипаттауға арналған қосымша бөлімді енгізіңіз.

      {cut(Қосымша бөлімнің құрылымы)}

      {include(/kz/_includes/_saas_add_update.md)[tags=service_config]}

      {/cut}

   1. JSON-файлда қызметтің жарияланған ревизияларының сипаттамалары бар барлық бөлімдер сақталғанына көз жеткізіңіз.

      {note:err}

      Мұндай бөлімдерді жою осы ревизиялардың жойылуына әкеледі. Жоюға тек қызметтің жарияланбаған ревизияларына ғана рұқсат етіледі: тесттік немесе жарияланымнан алынған.

      {/note}

   1. Қызметтің жаңа конфигурациясында [қызметтің жаңа ревизиясы](../../../reference/saas-apps-reference/saas-param) көрсетілгеніне көз жеткізіңіз. Көрсетілген қызмет ревизиясы Marketplace-ке бұрыннан жүктелген болса, қызмет жаңартылмайды.

   1. Егер ағымдағы тарифтік жоспарлардың параметрлерін өзгерткен болсаңыз, қызметтің жаңа конфигурациясында [жоспарлардың жаңа ревизиялары](../../../reference/saas-apps-reference/saas-plan) көрсетілгеніне көз жеткізіңіз. Көрсетілген жоспар ревизиялары Marketplace-ке бұрыннан жүктелген болса, тарифтік жоспарлар жаңартылмайды.

1. Егер тарифтік жоспарларды қосқан немесе жойған болсаңыз, брокер директориясындағы `resources/plan_mapping.json` файлын өңдеңіз.

   {cut(resources/plan_mapping.json файлының құрылымы)}

   ```json
   {
      "<ҚЫЗМЕТ_АТЫ>": {
         "<ЖОСПАР_ID>": <SAAS_ЖОСПАР_ID>,
         "<ЖОСПАР_ID>": <SAAS_ЖОСПАР_ID>
      }
   }
   ```

   Мұнда:

   * `<ҚЫЗМЕТ_АТЫ>` — қызметтің атауы.
   * `<ЖОСПАР_ID>` — `catalog_<ҚЫЗМЕТ_АТЫ>.json` файлында көрсетілген тарифтік жоспарлардың ID-сы.
   * `<SAAS_ЖОСПАР_ID>` (формат `string`) — `<ЖОСПАР_ID>` тарифтік жоспарларының ID-сына сәйкес келетін қызмет жағындағы тарифтік жоспарлардың ID-сы.

   `plan_mapping.json` файлының мазмұны мысалы:

   ```json
   {
     "VKT": {
       "0dc54b75-XXXX-89d5a47eef71": 1,
       "312b628e-XXXX-080ab4ca3acb": 2,
       "e2ae1588-XXXX-3f5081a799a9": 3,
       "b54e7247-XXXX-7a9dccc22e7b": 4
     }
   }
   ```

   {/cut}

   Брокер Marketplace-ке қызмет конфигурацияларының тізімін мерзімді түрде жіберіп отыратындықтан, жаңа конфигурация Marketplace-тің тесттік атаулар кеңістігіне автоматты түрде түседі.

   {note:err}

   Marketplace қызметтің ағымдағы конфигурациясын уақтылы ала алуы үшін брокер тәулік бойы қолжетімді болуы тиіс.

   {/note}

1. Қызметтің жаңа ревизиясын Marketplace-тің тесттік атаулар кеңістігінде тесттен өткізіңіз.

   {include(/kz/_includes/_saas_add_update.md)[tags=test_service]}

1. Қажет болса, қызметтің жаңа ревизиясының конфигурациясына өзгерістер енгізіңіз:

   1. Брокер орналасқан директорияның `resources` ішкі директориясына өтіңіз.
   1. `catalog_<ҚЫЗМЕТ_АТЫ>.json` және `plan_mapping.json` файлдарын өңдеңіз.
   1. Тесттеуді тағы бір рет қайталаңыз.

1. Егер тесттеу және отладка кезеңіне арналған құнның тесттік мәндерін жаңа ревизияда көрсеткен болсаңыз, `catalog_<ҚЫЗМЕТ_АТЫ>.json` файлын өңдеп, оған нақты мәндерді көрсетіңіз.

1. Қызметтің жаңа ревизиясын Marketplace-тің ашық атаулар кеңістігінде жариялаңыз. Ол үшін [marketplace@cloud.vk.com](mailto:marketplace@cloud.vk.com) мекенжайына хат жіберіңіз. Хатта қызметтің ID-сын және оның жаңа ревизиясын көрсетіңіз.

   Қызмет конфигурациясының модерациясы жүргізіледі. Осыдан кейін қызметтің жаңа ревизиясы Marketplace-тің тесттік атаулар кеңістігінен [қызмет конфигурациясының JSON-файлындағы](../../../reference/saas-apps-reference/saas-param) `metadata` параметрінде көрсетілген ашық кеңістікке ауысады. Қызметтің жаңа ревизиясы осы ашық атаулар кеңістігіне қолжетімділігі бар барлық пайдаланушыларға қолжетімді болады.

   {note:warn}

   Ашық атаулар кеңістіктерінде қызметтің соңғы жарияланған ревизиясы ғана қолжетімді.

   {/note}

   Алдыңғы жарияланған ревизия Marketplace-тің тесттік атаулар кеңістігіне ауысады. Тесттік атаулар кеңістіктерінде қызмет конфигурациясының JSON-файлында сипатталған барлық жарияланбаған ревизиялар сақталады.

   Қызмет конфигурациясынан жойылған қызмет ревизиялары Marketplace-тің тесттік те, ашық та атаулар кеңістіктерінде қолжетімді болмайды.

   Жаңа ревизияны жариялау қызметтің бұрыннан бар инстанстарына (тенанттар/аккаунттар) әсер етпейді. Осы қызмет инстанстарының ревизиясы ол қызмет конфигурациясынан жойылып, Marketplace-те енді қолжетімді болмаса да, өзгермейді.
