Сервис ресурстарының конфигурациясына арналған кіріс айнымалылары шартты түрде арнайы, сыртқы және жергілікті болып бөлінеді.

[cols="2,5,2", options="header"]
|===
|Топ
|Сипаттамасы
|Мүмкін түрлері

|Арнайы
|Брокерден алынған деректерді пайдалануға мүмкіндік беретін айнымалылар.

Мынадай айнымалылар қолдау көрсетіледі:

* `instance_uuid` — сервистің орналастыру идентификаторы. iVK CS провайдерінің көпшілік ресурстарын сипаттауда қолданылады.
* `email` — сервисті қосқан пайдаланушының email.

Мұндай айнымалыларды манифесте жариялағанда, олардың мәнін Terraform автоматты түрде алады
|`string`

|Сыртқы
|Тарифтік жоспарды конфигурациялау шеберінде бапталатын тарифтік опциялардың мәндерін орнатуға мүмкіндік беретін айнымалылар.

Айнымалының аты тарифтік опция YAML-файлының атына сәйкес болуы тиіс.

Манифесте жариялаудан бөлек, мұндай айнымалы:

* Өз YAML-файлында тарифтік опция ретінде сипатталған болуы тиіс.
* Тарифтік жоспарда көрсетілген болуы тиіс (`plans/<ЖОСПАР_АТЫ>/plan.yaml` файлы).
* Тарифтік жоспарды конфигурациялау шеберінде көрсетілген болуы тиіс (`plans/<ЖОСПАР_АТЫ>/display.yaml` файлы).

Сыртқы айнымалыға әдепкі мән орнатуға болады. Ол сыртқы мәнді алу мүмкін болмаған жағдайда қолданылады
|`number`, `string`, `boolean`

|Жергілікті
|Тек манифесте қолданылатын айнымалылар. Айнымалының мәні оны `default` аргументінде жариялағанда орнатылады
|Terraform қолдайтын кез келген түрлер
|===

{note:warn}

Айнымалының түрі оны `type` параметрінде жариялағанда көрсетілуі тиіс.

{/note}

Арнайы айнымалыларды жариялау мысалы:

```hcl

# Сервистің орналастыру идентификаторы
variable "instance_uuid" {
  type    = string
}

# Пайдаланушының email
variable "email" {
  type    = string
}
```

Сыртқы және жергілікті айнымалыларды жариялау мысалы:

```hcl

# ВМ жасалатын виртуалды желінің аты
variable "sub_network" {
  type    = string
  default = "test-net"
}

# ВМ үшін CPU саны
variable "flavor_vcpus" {
  type    = number
  default = 2
}
```

Кіріс айнымалыларын сипаттағанда `locals` блоктарын пайдалануға болады. Олар айнымалылардың мәндерін оларды жариялағанда, соның ішінде басқа жарияланған айнымалылардың мәндері арқылы есептеуге мүмкіндік береді.
