`settings.yaml` файлы Terraform манифестінің орындалу параметрлерін қамтиды, ол сіздің қосымшаңыздың орналастырылуын сипаттайды.

[cols="2,5,2,2", options="header"]
|===
|Аты
|Сипаттамасы
|Міндетті
|Әдепкі мән

|`preset`
|Пресет нұсқасы — Terraform манифесттеріне арналған провайдерлер жиыны. Мүмкін мәндер:

* `base_v2` — VK CS 0.5.5, iVK CS 1.0.1 бар тұрақты пресет.
* `base_v3` — VK CS 0.7.1, iVK CS 1.2.0 бар тұрақты пресет.
* `base_alpha` — қазіргі уақытта тестіленіп жатқан пресет.

Жаңа пресет нұсқалары пайда болғанда ескі нұсқалар қолдануға қолжетімді болып қалады
| ![](/kz/assets/no.svg "inline")
|Соңғы тұрақты пресет

|`retry`
|
Terraform манифестінің бірінші орындалуы қатеден аяқталған жағдайда инфрақұрылымды қайта орналастыруды орындау керек пе, соны анықтайды. Қатенің мүмкін себептері:

* Манифесттегі синтаксистік немесе логикалық қателер.
* Бұлтты платформаға қолжетімділік жоқ.
* [Мониторинг]() барысында `health check` алынбады.
* Скрипттердің орындалуы қатеден аяқталды.

Мүмкін мәндер:

* `yes` — инфрақұрылымды қайта орналастыру әрекеттерін қосу.
* `no` — инфрақұрылымды қайта орналастыру әрекеттерін өшіру

| ![](/kz/assets/no.svg "inline")
|`yes`
|===

`settings.yaml` файлының мысалы:

```yaml
preset: base_v3
retry: no
```
