Скрипттер сервисді орналастыру барысында әртүрлі операцияларды орындауға мүмкіндік береді, мысалы, кластерге біріктіру кезінде түйіндерді синхрондау.

Скрипттерді пайдаланудың екі тәсілі бар:

- [cloud-init пакеті](https://cloudinit.readthedocs.io/en/latest) арқылы;
- [Marketplace агенті](/kz/tools-for-using-services/vendor-account/manage-apps/concepts/vendor-preconditions/ib_image_agent) арқылы.

## {heading(Скрипттерді Cloud-init арқылы орындау)[id=tf_script_userdata]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

### Тәсілдің мүмкіндіктері

Cloud-init скрипттердің орындалу кезегін конфигурациялауға және олардың бір серверде іске қосылу сәтін анықтауға мүмкіндік береді. Мысалы, скрипт ӘРҚ (ОС) әр жүктелгенде немесе тек бір рет орындалуы мүмкін.

### Тәсілдің кемшіліктері

- Скриптті орындау кезіндегі қате инстансты орналастыруды тоқтатады. Бұл қажетті баптаулардың барлығы қолданылмай қалатынын білдіреді.
- Скрипттің іске қосылуы мен Terraform-ның басқа ресурстарының жұмысы арасында тәуелділікті анықтауға болмайды: скрипт әлі орындалып жатуы мүмкін, бірақ Marketplace-те инстансты орналастыру аяқталғаны белгіленіп қойылады.

### Terraform манифестінің қажетті компоненттері

- (Қалауыңызша) Скрипттердің мазмұнын [кіріс айнымалыларында](../tfmanifest_variable) сипаттау. Bash және Python тілдеріне қолдау көрсетіледі.
- Скрипттердің орындалу реті мен баптауларын [ivkcs_user_data](/kz/tools-for-using-services/vendor-account/manage-apps/ivkcs/ivkcs_resources/ivkcs_user_data#user_script) ресурсының `user_script` аргументінде сипаттау.
- Скрипттердің мазмұнын `ivkcs_user_data` ресурсында тікелей немесе айнымалыларды пайдалану арқылы сипаттау.

[VK CS Infra (iVK CS) провайдері бойынша анықтамалықта](/kz/tools-for-using-services/vendor-account/manage-apps/ivkcs/ivkcs_resources/ivkcs_user_data#user_script) Terraform манифестінің `ivkcs_user_data` ресурсында скрипттерді сипаттау мысалы келтірілген.

## {heading(Скрипттерді Marketplace агенті арқылы орындау)[id=tf_script_agentexec]}

### Тәсілдің мүмкіндіктері

Marketplace агенті скрипттің іске қосылуын Terraform-ның басқа ресурстарының жұмысына қатысты тәуелді етіп орнатуға, тайм-аут орнатуға, шығу кодтарын бақылауға және қателер кезінде қосымшаны орналастыруды тоқтатуға мүмкіндік береді.

Сервисді орналастыру барысында агент орындалған скрипттердің хешін конфигурацияларды басқару сервисіне жібереді. Бұл сервис инстансы бар ВМ-ның (қазіргі сәтте қандай скрипттер орындалғанын) ағымдағы күйін бағалауға және оны Terraform манифестінде сипатталған күйге келтіруге мүмкіндік береді.

Marketplace агенті конфигурацияларды басқару сервисіне скрипттердің статусын жібереді. Мүмкін статустар:

- `ok` — скрипт сәтті орындалды.
- `running` — скрипт орындалып жатыр.
- `failed` — скрипт қатенімен аяқталды. Қате себебін [агент логтарын қарап](../../../instructions/manage-ib-apps/ib-add#agent_log) анықтауға болады.

   `failed` статусын алғанда орналастыру жүйесі сервисді орналастыру процесін қайта іске қосады. Қайталау талпыныстары бір жарым сағатқа дейін созылуы мүмкін. Оларды [settings.yaml файлында](../tfmanifest_settings) өшіруге болады.

Скрипттердің орындалу нәтижелерін конфигурацияларды басқару сервисіне форматталған түрде жіберген және басқа скрипттерді орындау кезінде пайдалануға болады.

### Тәсілдің кемшіліктері

- Marketplace агентін орнату қажет.
- ӘРҚ (ОС) қайта жүктелгенде скрипттерді қайта іске қосу мүмкін емес.

### Terraform манифестінің қажетті компоненттері

- Инстанстың ВМ-ына Marketplace агентін орнатуды сипаттау. Толығырақ — [VK CS Infra (iVK CS) провайдері бойынша анықтамалықта](/kz/tools-for-using-services/vendor-account/manage-apps/ivkcs/ivkcs_resources/ivkcs_user_data).
- (Қалауыңызша) Скрипттердің мазмұнын [кіріс айнымалыларында](../tfmanifest_variable) сипаттау. Bash және Python тілдеріне қолдау көрсетіледі.
- Скрипттердің орындалу реті мен баптауларын [ivkcs_agent_exec](/kz/tools-for-using-services/vendor-account/manage-apps/ivkcs/ivkcs_resources/ivkcs_agent_exec) ресурсы немесе `locals` блогы арқылы сипаттау.

   Мысалы, `ivkcs_agent_exec` ресурсының көмегімен әрбір скрипт үшін орындалу тайм-аутын және оған `failed` статусы берілуіне дейінгі орындау талпыныстарының санын анықтауға болады.

- Скрипттердің мазмұнын `ivkcs_user_data` ресурсында тікелей немесе айнымалыларды пайдалану арқылы сипаттау.
- (Қалауыңызша) Скрипттердің орындалу нәтижелерін `ivkcs_agent_script_result` деректер көзінің көмегімен алу. Скрипттердің орындалу нәтижелерін [шығыс параметрлерінде](../tfmanifest_output) жіберуіне немесе Terraform манифестінің басқа ресурстарында пайдаланылуына болады.

[Terraform манифесті](../tf-manifest) бөлімінде `ivkcs_agent_exec` ресурсында скрипттерді қолданатын манифест мысалы келтірілген.

{note:info}

Ресурстар мен деректер көздері [VK CS Infra (iVK CS) провайдері бойынша анықтамалықта](/kz/tools-for-using-services/vendor-account/manage-apps/ivkcs) сипатталған.

{/note}
