`service.yaml` конфигурациялық файлы мына ақпаратты қамтиды:

- [Қосымшаның жалпы параметрлері](#app_parameters).
- [plans массиві](#ib-apps-param-service-plans) тарифтік жоспарлардың атауларымен. Бұл атаулар тек сервистік пакетті сипаттау үшін қолданылады және Marketplace интерфейсінде көрсетілмейді.
- [preview секциясы](#service_options_for_matrix) тарифтік опциялардың атауларымен. Бұл атаулар тек сервистік пакетті сипаттау үшін қолданылады және Marketplace интерфейсінде көрсетілмейді.
