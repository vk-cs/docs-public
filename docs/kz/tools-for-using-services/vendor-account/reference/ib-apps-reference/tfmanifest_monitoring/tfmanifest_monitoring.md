Мониторинг сервистің ВМ-дегі инстансының күйін бақылауға мүмкіндік береді, мысалы, орнату кезінде скрипттер орындалғаннан кейін сервистің жұмыс істеуін тексеру. Marketplace агенті белгіленген мерзімде `health check` алады (сервистің инстансының қолжетімділігі туралы деректер) және нәтижені конфигурацияларды басқару қызметіне жібереді. Егер сервис скрипттер орындалғаннан кейін іске қосылмаса, агент `health check` қабылдамайды және сервисті орнату қатесімен аяқталады.

`health check` алу уақытының шектеуі (тайм-аут) сервистің қолжетімділігін тексеру кезінде әдепкі бойынша 5 мин тең. Оны Terraform манифестінде баптауға болмайды. Қажет болған жағдайда тайм-аутты [marketplace@cloud.vk.com](mailto:marketplace@cloud.vk.com) мекенжайына хат жіберу арқылы өзгертуге болады.

Сервисті орнату кезінде мониторингті пайдалану үшін Terraform манифесті мына компоненттерден тұруы керек:

1. Инстанстың ВМ-сіне Marketplace агентін орнатуды сипаттау. Толығырақ — [VK CS Infra (iVK CS) провайдері бойынша анықтамалықта](/kz/tools-for-using-services/vendor-account/manage-apps/ivkcs/ivkcs_resources/ivkcs_user_data).
1. [ivkcs_agent_check](/kz/tools-for-using-services/vendor-account/manage-apps/ivkcs/ivkcs_resources/ivkcs_agent_check) ресурсы арқылы мониторинг тәсілдерін сипаттау.

   Мониторингті баптау мысалы:

   ```hcl
   resource "ivkcs_agent_check" "health" {
     hosts = ["HOST"]
     uuid  = var.instance_uuid
     # Сервисті порт бойынша мониторингтеу
     port_health {
       # IP-мекенжай
       host = "127.0.0.1"
       # Порт
       port    = 9092
       # Мониторингтің мерзімділігі
       period  = "1m"
     }
   }  
   ```

   Осы мысалда Marketplace агенті 1 минут мерзімділікпен `http://127.0.0.1:9092/` IP-мекенжайындағы сервистің қолжетімділігі туралы деректерді алады және оларды конфигурацияларды басқару қызметіне жібереді.
