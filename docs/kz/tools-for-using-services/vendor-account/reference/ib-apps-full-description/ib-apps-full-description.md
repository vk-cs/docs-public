Сервисдің толық сипаттамасы Marketplace-тегі сервис бетінің **Сервис сипаттамасы** қойындысында көрсетіледі.

Сипаттама мәтіні сервис конфигурациясында көрсетіледі:

* Image-based қосымша үшін — сервис paketінің `full_description.md` файлында.
* SaaS-қосымша үшін — JSON-файлдағы `full_description` параметрінде.

Жалпы жағдайда сервисдің толық сипаттамасында келесі бөлімдер болады:

* [Сервис туралы ақпарат](#service_description_info).
* Тарифттеу ережелері(#service_description_tariffication).
* [Пайдалы сілтемелер](#service_description_links).
* [Техникалық қолдау](#service_description_support).
* [Лицензиялық келісім](#service_description_license).
