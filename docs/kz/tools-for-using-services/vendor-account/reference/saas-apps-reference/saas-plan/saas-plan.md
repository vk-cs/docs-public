Кестеде келтірілген параметрлер [сервис конфигурациясының JSON-файлында](../../../instructions/manage-saas-apps/saas-add#service_config) `plans` бөлімінде көрсетіледі.

[cols="2,4,2,1,2", options="header"]
|===
|Аты
|Сипаттамасы
|Форматы
|Міндетті
|Әдепкі мәні

|`id`
|
UUID4 генераторы арқылы жасалған тарифтік жоспардың UUID4 идентификаторы (ID)
|string (UUID4)
| ![](/kz/assets/check.svg "inline")
| ![](/kz/assets/no.svg "inline")

|`revision`
|
Тарифтік жоспардың ревизиясы. Ревизия мен тарифтік жоспар ID-сыны тіркесімі оның сервис ішіндегі бірегейлігін анықтайды. Қалған параметрлер тарифтік жоспардың нақты ревизиясының сипаттамаларын баяндайды.

{note:err}

Тарифтік жоспардың ID және ревизия тіркесімі сервис аясында бірегей болуы тиіс. Егер осындай ID және ревизиясы бар жоспар сервисде болса, тарифтік жоспар жаңартылмайды

{/note}
|string, 255 таңбаға дейін
| ![](/kz/assets/check.svg "inline")
| ![](/kz/assets/no.svg "inline")

|`name`
|
Дүкен интерфейсінде көрсетілмейтін тарифтік жоспардың техникалық атауы. Бос орындардың орнына астынғы сызық белгісін қолдана отырып, латын әріптерімен көрсетілуі тиіс
|string, 255 таңбаға дейін
| ![](/kz/assets/check.svg "inline")
| ![](/kz/assets/no.svg "inline")

|`description`
|
Дүкен интерфейсінде көрсетілетін тарифтік жоспардың атауы
|string, 255 таңбаға дейін
| ![](/kz/assets/check.svg "inline")
| ![](/kz/assets/no.svg "inline")

|`free`
|
Тарифтік жоспардың тегін екенін немесе емес екенін анықтайды
|boolean
| ![](/kz/assets/check.svg "inline")
| ![](/kz/assets/no.svg "inline")

|`plan_updateable`
|
Пайдаланушының сервисді жоймай-ақ бір тарифтік жоспардан екіншісіне өтуі мүмкін екенін анықтайды.

Сервисдің аттас параметрінде берілген мәнді қайта анықтайды
|boolean
| ![](/kz/assets/no.svg "inline")
| ![](/kz/assets/no.svg "inline")

|`metadata`
|
Тарифтік жоспар қолжетімді болатын дүкеннің тесттік және ашық кеңістіктерін (namespace) анықтайды.

Тесттік кеңістіктер `test_ns` кілтінде көрсетіледі.

Ашық кеңістіктер `prod_ns` кілтінде көрсетіледі.

Егер кеңістіктер көрсетілмесе, аттас [сервис параметрінде](../saas-param) көрсетілген мәндер қолданылады
|map, кілттері — string
| ![](/kz/assets/no.svg "inline")
| ![](/kz/assets/no.svg "inline")
|===
