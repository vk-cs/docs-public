`billing` секциясы [сервистің JSON конфигурация файлында](../../../instructions/manage-saas-apps/saas-add#service_config) келесі ақпаратты қамтиды:

* Тарифтік жоспардың құны.
* Тарифтеу үшін есепті кезеңнің ұзақтығы.
* Marketplace ресурс пайдалану туралы есептерді брокерден қаншалықты жиі сұрайтыны.
* Пайдаланылмаған бонустармен жұмыс істеу тәртібі.
* `integer` типті тарифтік опцияларды өзгерту қадамы.
* Жоспардың тарифтік опцияларының құны. Келесі ақылы тарифтік опциялар типтері қолдау көрсетіледі:

  * Сандық (`integer`, `number`). Алдын ала төлемді және кейін төлемді тарифтеу қолдау көрсетіледі.
  * Логикалық (`boolean`). Алдын ала төлемді тарифтеу қолдау көрсетіледі.

Тарифтеу типтері туралы толығырақ — [Тарифтеу](/kz/tools-for-using-services/vendor-account/manage-apps/concepts/about#xaas_billing) бөлімінде.

{note:warn}

Тарифтік жоспарда алдын ала төлемді және кейін төлемді опцияларды бір уақытта пайдалануға болмайды. Кейін төлемді тарифтік опциялар тек тегін тарифтік жоспарда болуы мүмкін.

{/note}

Қолданылатын тарифтеу типі тарифтік опциялар [schemas секциясында](../schemas-section) қай жерде сипатталғанына байланысты:

* Егер опциялар `service_instance.create` және `service_instance.update` секцияларында сипатталса, алдын ала төлемді тарифтеу қолданылады.
* Егер опциялар `service_instance.resource_usages` секциясында сипатталса, кейін төлемді тарифтеу қолданылады.

`billing` секциясының құрылымы келесідей:

```json
"billing": {
            "cost": <ҚҰНЫ>,
            "billing_cycle_flat": <ЕСЕПТІК_КЕЗЕҢ>,
            "billing_cycle_step": <ТЕКСЕРУЖИІЛІГІ>,
            "refundable": <ҚАЙТарылуға_ЖАТАДЫ>,
            "options": {
              "<ОПЦИЯ_АТЫ>": {
                <БИЛЛИНГ_ОПЦИЯЛАРЫ>
                },
              ...
              }
            }
```

Мұнда:

* `<ҚҰНЫ>` — ақылы тарифтік опцияларды есептемегенде, есептік кезең үшін жоспардың құны. Marketplace орналастырылған елдің валютасында көрсетіледі. Егер жоспар тегін болса, `0` мәні көрсетіледі. Тек алдын ала төлемді тарифтеу қолдау көрсетіледі.

* (Қосымша) `<ЕСЕПТІК_КЕЗЕҢ>` — тарифтеу үшін есептік кезеңнің ұзақтығы. Тек алдын ала төлемді тарифтік жоспар үшін орнатуға болады.

  Келесі форматта көрсетіледі: `<АЙ_САНЫ> mons <КҮН_САНЫ> days`. Мысалы, `1 mons 15 days` немесе `30 days`. Айдағы `mons` күндер саны күнтізбе бойынша есептеледі, сондықтан `1 mons 0 days` және `0 mons 31 days` кезеңдері бір-біріне тең емес.

* (Қосымша) `<ТЕКСЕРУЖИІЛІГІ>` — Marketplace брокерде өңделмеген есептердің бар-жоғын тексеретін кезеңнің ұзақтығы. Толығырақ — [Тарифтеу](/kz/tools-for-using-services/vendor-account/manage-apps/concepts/about#xaas_billing) бөлімінде. Тек кейін төлемді тарифтік опциялары бар тарифтік жоспар үшін орнатуға болады.

  Келесі форматта көрсетіледі: `<АЙ_САНЫ> mons <КҮН_САНЫ> days`. Мысалы, `1 mons 15 days` немесе `30 days`. Айдағы `mons` күндер саны күнтізбе бойынша есептеледі, сондықтан `1 mons 0 days` және `0 mons 31 days` кезеңдері бір-біріне тең емес.

* (Қосымша) `<ҚАЙТарылуға_ЖАТАДЫ>` — пайдаланушы тарифтік жоспарды өзгертсе немесе сервис инстансын жойса, есептік кезеңнің қалған күндері үшін ақшаны жобаның бонус шотына қайтару керек пе. Тек алдын ала төлемді тарифтік жоспар үшін көрсетуге болады. Әдепкі мәні — `true`.

  Параметр пайдаланушы тарифтік жоспарды өзгерткенде (тарифтік опцияларды өңдегенде немесе жаңасына ауысқанда) сервис үшін ақы алу күніне әсер етеді:

  * `true` — күн өзгермейді.
  * `false` — күн тарифтік жоспар өзгертілген күнге жаңартылады.

* (Қосымша) `options` секциясы ақылы тарифтік опциялардың құнын сипаттайды.
  * `<ОПЦИЯ_АТЫ>` — сервистің JSON конфигурация файлындағы тарифтік опцияның атауы.
  * `<БИЛЛИНГ_ОПЦИЯЛАРЫ>` — тарифтік опцияның құны және `integer` типті опция үшін өзгерту қадамының параметрлері. Тарифтік опцияның өзі (типі, мән параметрлері) [schemas секциясында](../schemas-section) сипатталады.

### billing секциясын сипаттау мысалдары

{cut(Өзгерту қадамы бар integer типті тегін тарифтік опциясы бар billing секциясының мысалы)}

```json
"billing": {
  "cost": 2000,  // Тарифтік жоспардың құны
  "options": {
    "quantity": { // JSON файлындағы опция атауы
      "base": 25, // Опцияның стандартты мәні
      "cost": 0, // Опцияны өзгерту қадамының құны
      "unit": {
        "size": 100 // Опцияны өзгерту қадамы
      }
    }
  }
}
```

Төменде осы мысалдағы тарифтік жоспардың құны мен опцияның тарифтік жоспар конфигурациялау шеберінде қалай көрсетілетіні көрсетілген. Шеберде көрсетілетін опция атауы `schemas` секциясындағы `<ОПЦИЯ_АТЫ>.description` параметрімен анықталады. Бұл мысалда `quantity.description` мәні `Жүктелетін жинақтардың көлемі` болып табылады.

* Тарифтік жоспар параметрлерінде опция үшін стандартты мән таңдалған:

  ![](../assets/Option_int_with_user_step_prepayed4.png){params[width=90%]}

* Тарифтік жоспар параметрлерінде опция мәні стандартты мәнмен салыстырғанда 2 қадамға ұлғайтылған:

  ![](../assets/Option_int_with_user_step_free_SaaS1.png){params[width=90%]}

  Жоспардың құны өзгерген жоқ, себебі опция тегін.

{/cut}

{cut(Өзгерту қадамы бар integer типті алдын ала төлемді тарифтік опциясы бар billing секциясының мысалы)}

```json
"billing": {
  "cost": 2000, // Тарифтік жоспардың құны
  "options": {
    "quantity": { // JSON файлындағы опция атауы
      "base": 25, // Опцияның стандартты мәні
      "cost": 150, // Опцияны өзгерту қадамының құны

        "size": 100 // Опцияны өзгерту қадамы
      }
    }
  }
}
```

Шеберде көрсетілетін опция атауы `schemas` секциясындағы `<ОПЦИЯ_АТЫ>.description` параметрімен анықталады. Бұл мысалда `quantity.description` мәні `Жүктелетін жинақтардың көлемі` болып табылады.

{cut(Кейін төлемді сандық тарифтік опциясы бар billing секциясының мысалы)}

```json
"billing": {
  "cost": 0, // Тарифтік жоспардың құны
  "options": {
    "storage": { // JSON файлындағы опция атауы
      "cost": 7,
      "unit": {
      "size": 1,
      "measurement": "ГБ"
      }
    }
  }
}
```

Келтірілген мысалда тарифтік жоспар тегін, кейін төлемді `storage` тарифтік опциясының бірлігі 1 ГБ құрайды және оның құны 7 ақша бірлігі.

Тарифтік жоспар конфигурациялау шеберінің түрі суретте келтірілген. Шеберде көрсетілетін опция атауы `schemas` секциясындағы `<ОПЦИЯ_АТЫ>.description` параметрімен анықталады. Бұл мысалда `storage.description` мәні `Кибер Бэкап Облачный өнімдері үшін ДЦ Киберпротектте сақтау` болып табылады.
