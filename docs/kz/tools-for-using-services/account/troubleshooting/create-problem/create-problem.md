Жобаны құру кезінде қате аккаунтта тым көп жоба жасалған жағдайда пайда болуы мүмкін. [Негізгі квоталар](/kz/tools-for-using-services/account/concepts/quotasandlimits#quotasandlimits-general) шеңберінде бір пайдаланушы 5 жобадан аспайтын жоба құра алады.

### Шешу

1. [Өтіңіз](https://cloud.vk.ru/app/) VK Cloud жеке кабинетына.
1. Барлық жобалардың тізімін тексеріңіз.
1. Егер лимитке жетілген болса, жобаны [өшіріңіз](/kz/tools-for-using-services/account/instructions/project-settings/manage#project-delete).

Егер лимит асып кетпеген болса, қатенің скриншотымен [техникалық қолдау қызметіне хабарласыңыз](/kz/contacts).
