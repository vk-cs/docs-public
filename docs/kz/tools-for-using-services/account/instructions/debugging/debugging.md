# {heading(Оқиғалар журналымен жұмыс)[id=tools-account-debugging]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Сервисті пайдалану кезінде орын алған оқиғалар мен қателер туралы ақпарат {var(cloud)} логтарында сақталады. Бұл деректер орын алған инциденттерді талдау кезінде техникалық қолдау қызметі пайдаланады.

{note:info}
Іске қосылған виртуалды машинаның жұмысында істен шығулар болса, {linkto(../../../../computing/iaas/instructions/vm/vm-console#iaas-vm-console-logs)[text=ВМ хабарламаларының логтарын]} техникалық қолдау қызметіне ұсыныңыз.
{/note}

Логтарды жергілікті жүктеп алу үшін:

{tabs}

{tab(Жеке кабинет)}

1. {var(cloud)} [жеке кабинетіне өтіңіз](https://msk.cloud.vk.ru/app/).
1. Беттің жоғарғы жағындағы пайдаланушы атауын басыңыз.
1. Ашылмалы тізімнен **Қосымшаны тестілеу** (Отладка приложения) опциясын таңдаңыз.

   {note:info}

   Әр оқиға туралы толық ақпарат JSON пішімінде оны басқан кезде қолжетімді.

   {/note}

1. Көрсетілетін жазбаларды баптаңыз:

   - **Бэкенд түрі**: ашылмалы тізімнен сервис таңдаңыз. Қажетті сервис тізімде болмаса, **Белгісіз бэкенд** опциясын таңдаңыз.
   - **Тек 4хх және 5хх көрсету**: тек `4XX` немесе `5XX` түріндегі қателермен аяқталған оқиғаларды көрсету қажет болса, опцияны қосыңыз.

1. **log жүктеп алу** (Скачать log) түймесін басыңыз. `dpp-log-<дата>.json` түріндегі файл жүктеледі.

{/tab}

{/tabs}
