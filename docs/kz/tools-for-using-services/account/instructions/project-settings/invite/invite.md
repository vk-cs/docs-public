# {heading(Жобаға қатысушыны шақыру)[id=tools-account-project-invite]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Қатысушыны шақыруды және оған рұқсаттарды баптауды келесі {linkto(../../../../../access/iam/concepts/roles-reference#iam-roles-reference)[text=рөлдерді]} иеленетін пайдаланушылар жасай алады: иесі, суперәкімші және пайдаланушылар әкімшісі (IAM). Жоба қатысушыларын көру мүмкіндігі жобаның әкімшісіне және бақылаушыға да қолжетімді.
