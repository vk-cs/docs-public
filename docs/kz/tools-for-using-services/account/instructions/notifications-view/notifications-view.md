# {heading(Хабарландыруларды көру)[id=tools-account-notifications-view]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Жеке кабинеттің хабарландырулары платформаның маңызды техникалық жаңартулары туралы, мысалы, сервистердің жаңа мүмкіндіктері немесе бағдарламалық өнімдердің жаңа нұсқаларына қолдау көрсету туралы хабарлайды.

Хабарландырулар тізімін қысқа және толық нұсқаларда көру үшін:

1. Жеке кабинет бетінің жоғарғы жағындағы ![Хабарландырулар](assets/bell_icon.svg "inline") белгішесін басыңыз.

    Соңғы хабарландырулар тізімі бар терезе ашылады.

1. Толық тізімді көру үшін **Барлық хабарландырулар** түймесін басыңыз.

    Тізім жеке бетте ашылады.

Хабарландырулардың әртүрлі түрлері үшін тізімде әртүрлі әрекет түймелері қолжетімді, мысалы:

- **Толығырақ**: жаңарту туралы қосымша ақпаратты көру.
- **Іс-жүзінде көру**: функционалды қосуға болатын жеке кабинет бөлімін ашу.
- **Өтініш қалдыру**: құралға немесе сервиске қолжетімділік алу бойынша сұрау жасау.
