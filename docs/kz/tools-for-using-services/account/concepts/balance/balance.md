# {heading(Жоба балансы)[id=account-balance]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

{include(../../../../_includes/_balance.md)}

Бонустар болған жағдайда қаражат алдымен бонустық шоттан, содан кейін негізгі шоттан алынады.

Тарифтеу «pay as you go» қағидаты бойынша жүргізіледі: ақы тұтынылатын ресурстар үшін ғана алынады. Ақшалай қаражат жұмыс істеп тұрған виртуализация объектілерінен минут сайын алынады. Виртуализация объектілері тоқтатылған жағдайда, алу тек жалға алынған диск кеңістігі және бар резервтік көшірмелерді сақтау үшін жалғасады.

{note:warn}
Қорытынды құн **үтірден кейінгі екі таңбаға** дейін дөңгелектенеді.
{/note}
