# {heading(POST-ты рұқсат етілген әдістер тізіміне қосу кезіндегі қате)[id=cdn-post-method-add-error]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Рұқсат етілген HTTP-әдістер тізіміне POST қосу кезінде қате пайда болады. POST әдісі әдетте кэштелуге жатпайды және CDN-де кэштеуге арналған рұқсат етілген әдістер тізімдерінен жиі алынып тасталады.

### {heading(Шешім)[id=cdn-post-method-add-error-decision]}

Егер сіз дереккөзге проксилеуге арналған әдістер тізімін баптап жатсаңыз, POST әдісін кэштеу баптауларына қосу мүмкін болмайды.
