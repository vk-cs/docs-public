# {heading(Linux ОС бар Bare Metal серверіне қосылу)[id=bare-metal-connect-nix]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

SSH — Linux ОС бар серверге қосылудың ең кең таралған және қауіпсіз тәсілі. Аутентификацияның екі негізгі тәсілі бар:

- Құпиясөз арқылы: {var(cloud)} образдарында әдепкі бойынша қауіпсіздік мақсатында өшірілген.
- SSH кілті арқылы: қосылудың ең қауіпсіз тәсілі. {var(cloud)} образдарында әдепкі бойынша пайдаланылады.

## {heading(Дайындық қадамдары)[id=bare-metal-connect-server-preparatory-steps]}

1. {linkto(../../../../computing/bare-metal/instructions/os-setup#bare-metal-os-setup)[text=ОС орнату]} кезінде {var(cloud)} образдарынан жүктелетін `*.pem` жеке кілт файлы бар екеніне көз жеткізіңіз.
1. Bare Metal сервері іске қосылғанына және ОС жүктелу процесі аяқталғанына, мысалы, {linkto(../../../../computing/bare-metal/connect/console#bare-metal-console)[text=VNC-консоль]} арқылы көз жеткізіңіз.
1. Егер серверде желілік сүзгілеу құралдары (`ufw`, `nftables`, `iptables` және т.б.) пайдаланылса, SSH протоколы бойынша қолжетімділік үшін (`22` TCP порты) ереже қосыңыз.
1. Bare Metal серверінде SSH қызметі іске қосылғанына және жұмыс істеп тұрғанына көз жеткізіңіз. Қызметтің күйін келесі команда арқылы тексеруге болады:

   ```shell
   sudo service sshd status
   ```

{note:warn}

Егер виртуалды машинаға SSH арқылы қосылу мүмкін болмаса немесе қолжетімсіз болса, {linkto(../../../../computing/bare-metal/connect/console#bare-metal-console)[text=VNC-консольді]} пайдаланыңыз.

{/note}

## {heading(Bare Metal серверіне қосу)[id=bare-metal-connect-server]}

{tabs}

{tab(Linux/macOS)}

1. Терминалды ашып, кілт файлына қатынас құқықтарын конфигурациялаңыз:

   ```bash
   chmod 400 <КИЛТ_ФАЙЛЫ>
   ```

   Мұнда `<КИЛТ_ФАЙЛЫ>` — жеке кілті бар `*.pem` файлына дейінгі жол.

   `/path/to/file/` каталогында орналасқан `MyPrivateKey.pem` кілт файлының мысалы:

   ```bash
   chmod 400 /path/to/file/MyPrivateKey.pem
   ```

1. Серверге қосылыңыз:

   {tabs}

   {tab(Сыртқы IP-адрес арқылы)}

   Егер серверіңіз үшін сыртқы IP-адрес арқылы қосылу конфигурацияланған болса (мысалы, дамытылған роутер арқылы), команданы орындаңыз:

   ```bash
   ssh -i <КИЛТ_ФАЙЛЫ> \
          <ПАЙДАЛАНУШЫ_АТЫ>@<СЕРВЕРДІҢ_СЫРТҚЫ_IP-АДРЕСІ>
   ```

   Мұнда:

   - `<КИЛТ_ФАЙЛЫ>` — жеке кілті бар `*.pem` файлына дейінгі жол.
   - `<ПАЙДАЛАНУШЫ_АТЫ>` — әдепкі тіркелгі атауы, ол {linkto(../../../../computing/iaas/concepts/oper-system#iaas-oper-system-default-account)[text={var(cloud)} бейнелерінде қолданылады]}.
   - `<СЕРВЕРДІҢ_СЫРТҚЫ_IP-АДРЕСІ>` — серверге сырттан қосылу үшін конфигурацияланған IP-адрес.

   {include(../../../../_includes/_ssh-warning.md)[tags=new-host]}

   {/tab}

   {tab(Ішкі IP-адрес арқылы)}

   Егер Bare Metal серверіңізде сыртқы IP-адрес болмаса, оған аралық сервер арқылы қосылыңыз:

   1. Аралық сервер әлі конфигурацияланбаған болса, конфигурациялаңыз. Аралық сервер, мысалы, мынадай {linkto(../../../../computing/iaas/concepts/vm#iaas-concepts-vm)[text=виртуалды машина]} болуы мүмкін, ол:

      - Bare Metal серверімен бір желіде орналасады;
      - сыртқы IP-адресі бар.

      Егер мұндай талаптарға сәйкес ВМ болмаса:

      1. Bare Metal серверіңіздің қай желіге қосылғанын және оның ішкі IP-мекенжайын {linkto(../../../../computing/bare-metal/instructions/manage-server#bare-metal-server-get-info)[text=біліңіз]}.
      1. Келесі параметрлері бар жаңа ВМ {linkto(../../../../computing/iaas/instructions/vm/vm-create#iaas-vm-create)[text=жасаңыз]} немесе бұрыннан барын {linkto(../../../../computing/iaas/instructions/vm/vm-add-net#vm-add-net)[text=қосыңыз]}:

         - **Желі**: Bare Metal сервері қосылған сол желіні таңдаңыз.
         - **Сыртқы IP тағайындау**: бұл опцияны қосыңыз. ВМ-ге {linkto(../../../../networks/vnet/concepts/ips-and-inet#vnet-ips-and-inet-floating-ip)[text=Floating IP-адрес]} қосылады.

      1. Аралық серверге сыртқы IP-адрес арқылы қосылудың жұмыс істейтінін тексеріңіз.

   1. Bare Metal серверіне қосылыңыз.

      Алдымен аралық серверге оның сыртқы IP-адресі арқылы, содан кейін Bare Metal серверіне оның ішкі IP-адресі арқылы қосылу қажет. Мұны бір командамен жасауға болады:

      ```bash
      ssh -i <КИЛТ_ФАЙЛЫ> \
          -J <ПАЙДАЛАНУШЫ_АТЫ>@<АРАЛЫҚ_СЕРВЕРДІҢ_IP-АДРЕСІ> \
             <ПАЙДАЛАНУШЫ_АТЫ>@<СЕРВЕРДІҢ_ІШКІ_IP-АДРЕСІ>
      ```

      Мұнда:

      - `<КИЛТ_ФАЙЛЫ>` — жеке кілті бар `*.pem` файлына дейінгі жол.
      - `<ПАЙДАЛАНУШЫ_АТЫ>` — әдепкі тіркелгі атауы, ол {linkto(../../../../computing/iaas/concepts/oper-system#iaas-oper-system-default-account)[text={var(cloud)} бейнелерінде қолданылады]}. Аралық сервер үшін де, Bare Metal сервері үшін де оларда қолданылатын ОС бейнесіне сәйкес пайдаланушы атын енгізу қажет.
      - `<АРАЛЫҚ_СЕРВЕРДІҢ_IP-АДРЕСІ>` — аралық сервердің сыртқы IP-адресі.
      - `<СЕРВЕРДІҢ_ІШКІ_IP-АДРЕСІ>` — Bare Metal серверіңіздің ішкі IP-адресі.

      {include(../../../../_includes/_ssh-warning.md)[tags=new-host]}

1. Жеке кілт файлына қатынас құқықтарын конфигурациялаңыз:

   1. `.pem` жеке кілт файлының қасиеттерін ашыңыз.
   1. **Қауіпсіздік** қойындысына өтіп, **Қосымша** түймесін басыңыз. **Қосымша қауіпсіздік параметрлері** терезесі ашылады.
   1. **Мұраға алуға тыйым салу** түймесін басып, ашылған терезеде **Осы нысаннан мұраланған барлық рұқсаттарды жою** опциясын таңдаңыз.
   1. **Қосымша қауіпсіздік параметрлері** терезесінде **Қосу** түймесін басыңыз.
   1. Ашылған терезеде **Субъектіні таңдаңыз** опциясын басып, ВМ-ге қосылу үшін команданы жол (командалық жол) іске қосылатын Windows ОС пайдаланушысын көрсетіңіз.
   1. Ашылған параметрлер терезелерінде дәйекті түрде **ОК** басу арқылы өзгерістерді растаңыз.
