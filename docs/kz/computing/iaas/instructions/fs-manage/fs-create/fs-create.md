# {heading(Файлдық сақтауышты құру)[id=iaas-fs-create]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Cloud Servers платформасында файлдық сақтауыштарды жеке кабинет арқылы, OpenStack CLI{ifdef(public)} немесе API арқылы құруға болады. API көмегімен файлдық сақтауышты құру үшін {linkto(../../../../../tools-for-using-services/api/api-spec/iaas-api/manila-api#api-spec-manila)[text=файлдық сақтауыштарды басқарудың OpenAPI-сипаттамасын]} пайдаланыңыз{/ifdef}.

{tabs}

{tab(Жеке кабинет)}

1. {ifdef(public)}[Өтіңіз](https://msk.cloud.vk.ru/app/){/ifdef}{ifdef(private,private-pg,private-pdf,private-pg-pdf)}{linkto(../../../../../tools-for-using-services/account/instructions/lk-entry#tools-account-lk-entry)[text=Өтіңіз]}{/ifdef} {var(cloud)} жеке кабинетына.
1. Файлдық сақтауыш құру қажет {linkto(../../../../../tools-for-using-services/account/concepts/projects#tools-account-concepts-projects)[text=жобаны]} таңдаңыз.
1. **Бұлттық есептеулер** → **Файлдық сақтауыш** бөліміне өтіңіз.
1. **Сақтауыш құру** немесе **Құру** түймесін басыңыз.
1. Файлдық сақтауыштың параметрлерін орнатыңыз:

   - **Файлдық сақтауыш атауы**: тек латын әріптерінен, сандардан және `-`, `_` және `.` арнаулы таңбаларынан тұруы мүмкін.
   - **Сақтауыш өлшемі**: сақтауыштың өлшемі ГБ. {ifdef(public)}Квота шегінде, 10 ГБ-ден кем емес және 10000 ГБ-ден көп емес болуы тиіс.{/ifdef}
   - **Протокол**: Windows ОС-інен сақтауышқа кіру үшін CIFS протоколын, Linux-тан — NFS протоколын таңдаңыз.
   {ifdef(private,private-pg,private-pdf,private-pg-pdf)}
   - Қолжетімділік аймағы: ұсынылған файлдық сақтауыштың қолжетімділік аймақтарынан таңдаңыз.
   {/ifdef}
   - **Желі**: ұсынылғандардан таңдаңыз немесе жаңасын құрыңыз. Жаңа желі үшін сонымен қатар **Субжелі адресін** көрсетіңіз.
   - **Файлдық сақтауыш желісі**: ұсынылғандардан таңдаңыз немесе жаңасын құрыңыз.

1. **Келесі қадам** түймесін басыңыз.
1. (Қалауыңыз бойынша) Сақтауышқа кіру ережелерін қосыңыз:

   1. **Жаңа ереже қосу** түймесін басыңыз.
   1. Дереккөздің IP-адресін немесе субжелі адресін енгізіңіз.
   1. Кіру режимін таңдаңыз: `Оқу және жазу` немесе `Тек оқу`.
   1. **Ереже қосу** түймесін басыңыз.

   {note:info}
   Файлдық сақтауыш құрылғаннан кейін де кіру {linkto(../../../../../computing/iaas/instructions/fs-manage/fs-access-rules#iaas-fs-access-rules-adding)[text=ережелерін қосуға]} болады.
   {/note}

1. **Файлдық сервер қосу** түймесін басыңыз.

{ifdef(private,private-pg,private-pdf,private-pg-pdf)}
Файлдық сақтауыш 2-15 минут ішінде құрылады.

Сақтауышты құру кезінде беттің оң жақ төменгі бұрышында құру үдерісінің прогресс белгішесі көрсетіледі. Процентті және орындалу кезеңін (дайындау, құру, баптау) көру үшін белгішені және үдеріс атауын басыңыз.

Үдеріс аяқталғаннан кейін белгіше келесі статусалардың бірінде көрсетіледі:

- Барлық үдерістер аяқталды (жасыл белгіше) — сақтауыш құрылды және жұмысқа дайын.
- Барлық үдерістер аяқталды (сары белгіше) — сақтауыш құрылды, бірақ кезекті кезеңдерде қате орын алды. Қатенің сипаттамасы және оның пайда болу себебін анықтау үшін {var(cloud)} әкімшісіне жүгіне алатын коды келтірілген.
- Қате орын алды (қызыл белгіше) — сақтауыш құрылмады, қате орын алды. Қатенің сипаттамасы және оның пайда болу себебін анықтау үшін {var(cloud)} әкімшісіне жүгіне алатын коды келтірілген.

Сақтауышты құру үдерісі {var(cloud)}-тегі параллель әрекеттерді блоктамайды.
{/ifdef}

{/tab}

{tab(OpenStack CLI)}

1. OpenStack клиенті {linkto(../../../../../tools-for-using-services/cli/openstack-cli#openstack-install)[text=орнатылғанын]} тексеріңіз және жобада {linkto(../../../../../tools-for-using-services/cli/openstack-cli#openstack-authorize)[text=аутентификациядан өтіңіз]}.
1. Manila клиенті {linkto(../../../../../tools-for-using-services/cli/openstack-cli#openstack-install-package)[text=орнатылғанын]} тексеріңіз.
1. Бар файлдық сақтауыш желісін таңдаңыз немесе жаңасын құрыңыз.

   {tabs}

   {tab(Бар желіні таңдау)}

   1. Бар файлдық сақтауыш желілерінің тізімін мына команданы орындап алыңыз:

      ```console
      openstack share network list
      ```

      Қажетті желінің атауын немесе идентификаторын жазып алыңыз.

   1. (Қалауыңыз бойынша) Таңдалған желінің қасиеттерін мына команданы орындап көріңіз:

      ```console
      openstack share network show <ЖЕЛІ>
      ```

      Мұнда `<ЖЕЛІ>` — жобада бар файлдық сақтауыш желісінің атауы немесе идентификаторы.

   {/tab}

   {tab(Жаңа желі құру)}

   Команданы орындаңыз:

   ```console
   openstack share network create --neutron-net-id <ЖЕЛІ_ID> --neutron-subnet-id <СУБЖЕЛІ_ID> --name <ЖЕЛІ_АТАУЫ>
   ```

   Мұнда:

   - `<ЖЕЛІ_ID>` — жобада бар жеке желінің идентификаторы.
   - `<СУБЖЕЛІ_ID>` — оның субжелісінің идентификаторы.
   - `<ЖЕЛІ_АТАУЫ>` — құрылатын файлдық сақтауыш желісінің атауы.

   Құрылған желінің атауын немесе идентификаторын жазып алыңыз.

   {/tab}

   {/tabs}

1. Файлдық сақтауышты мына команданың көмегімен құрыңыз:

   ```console
   openstack share create --name <САҚТАУЫШ_АТАУЫ> --share-network <ЖЕЛІ> <ПРОТОКОЛ> <ӨЛШЕМ> 
   ```

   Мұнда:

   - `<САҚТАУЫШ_АТАУЫ>` — құрылатын файлдық сақтауыштың атауы.
   - `<ЖЕЛІ>` — алдыңғы қадамда таңдалған немесе құрылған желінің атауы немесе идентификаторы.
   - `<ПРОТОКОЛ>` — кіру протоколы. Windows ОС-інен сақтауышқа кіру үшін CIFS протоколын, Linux-тан — NFS протоколын көрсетіңіз.
   - `<ӨЛШЕМ>` — файлдық сақтауыштың қалаған өлшемі ГБ. {ifdef(public)}Квота шегінде, 10 ГБ-ден кем емес және 10000 ГБ-ден көп емес болуы тиіс.{/ifdef}

{/tab}
