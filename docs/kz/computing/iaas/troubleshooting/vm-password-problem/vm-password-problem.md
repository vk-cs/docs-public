# {heading(ВМ-да құпиясөзді өзгерту мүмкін болмай жатыр)[id=iaas-vm-password-problem]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Жеке кабинетте ВМ әкімшісінің құпиясөзін өзгерту кезінде **ВМ әкімшісінің құпиясөзін орнату мүмкін болмады. Кейінірек қайталап көріңіз немесе қолдау қызметіне хабарласыңыз.** қатесі пайда болады.

Бұл ВМ-ге құпиясөз орнатуға арналған QEMU guest agent қолжетімсіздігімен байланысты болуы мүмкін.

### {heading(Шешімі)[id=iaas-vm-password-problem-decision]}

1. Виртуалды машина консоліне қосылып, авторизациядан өтіңіз.
1. Келесі команданы орындап, QEMU қонақ агентін жаңартыңыз:

   ```console
   sudo sh -c "apt install -y qemu-guest-agent;systemctl enable qemu-guest-agent;systemctl start qemu-guest-agent"
   ```

1. ВМ қайта іске қосып, әкімші құпиясөзін тағы бір рет өзгертіп көріңіз. Егер қате сақталса, [техникалық қолдау қызметіне хабарласыңыз](/kz/contacts).
