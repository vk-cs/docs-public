# {heading(ВМ образын жою кезіндегі 403 қатесі)[id=iaas-error-image-deleting]}

{include(/kz/_includes/_translated_by_ai.md)}

Образды жою әрекетінде `403 Forbidden` қатесі пайда болады.

Мүмкін себептер:

- Образ қолданылуда. Осы образдан жасалған дискілер немесе виртуалды машиналар оған тәуелді.
- Образ ортақ (`shared`) және басқа жобадағы мүлік. Оны тек иелік ететін жоба жоя алады.

### {heading(Шешім)[id=iaas-error-image-deleting-solution]}

1. Образды оны жасаған жобада жойып жатқаныңызға көз жеткізіңіз.

   1. Жобаның образдар тізімін қараңыз:

      ```console
      openstack image list
      ```

   1. Образ туралы егжей-тегжейлі ақпаратты қараңыз:

      ```console
      openstack image show <ID_ОБРАЗА>
      ```

      Егер шығыстағы `visibility` өрісінің мәні `shared` болса, образ басқа жобадағы мүлік және оны сіздің жобадан жоюға болмайды. Образды иелік ететін жобада жойыңыз немесе оны жобадан ажыратыңыз (команда образ иесі болып табылатын жобада орындалады):

      ```console
      openstack image remove project <ID_ОБРАЗА> <ID_ЖОБА>
      ```

1. Осы образ негізінде жасалған ресурстар бар-жоғын тексеріңіз:

   1. Образдан жасалған дискілерді табыңыз. Бастапқы образ `volume_image_metadata` өрісінде көрсетілген:

      ```console
      openstack volume list
      openstack volume show <ID_ДИСКІ>
      ```

   1. Образдан жасалған виртуалды машиналарды табыңыз:

      ```console
      openstack server list --long
      openstack server show <ID_ВМ>
      ```

   1. Егер тәуелді дискілер немесе ВМ-лер табылса, алдымен оларды жойыңыз немесе олардың жойылуын күтіп, содан кейін қайталап көріңіз:

      ```console
      openstack image delete <ID_ОБРАЗА>
      ```

1. Егер образ қолданылмаса, жобаның мүлкі болса және қате сақталса, [техникалық қолдау қызметіне хабарласыңыз](/kz/contacts) және образ ID-сін көрсетіңіз.
