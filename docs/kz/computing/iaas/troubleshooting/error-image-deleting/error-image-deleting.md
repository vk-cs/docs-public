# {heading(Образті өшіру кезіндегі 403 қатесі)[id=iaas-error-image-deleting]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Образті өшіруге тырысқанда `403 Forbidden` қатесі пайда болады.

Мүмкін себептер:

- Образ қолданылуда. Одан осы образден жасалған дисктер немесе виртуалды машиналар тәуелді.
- Образ ортақ (`shared`) және басқа жобаныкы. Оны тек ие болушы жоба өшіре алады.

### {heading(Шешу)[id=iaas-error-image-deleting-solution]}

1. Образті ол жасалған жобада өшіріп жатқаныңызға көз жеткізіңіз.

   1. Жобаның образдер тізімін қараңыз:

      ```console
      openstack image list
      ```

   1. Образ туралы толық ақпаратты қараңыз:

      ```console
      openstack image show <ОБРАЗ_ID>
      ```

      Егер нәтижедегі `visibility` өрісінің мәні `shared` болса, образ басқа жобаныкы және оны сіздің жобаңыздан өшіру мүмкін емес. Образті ие болушы жобада өшіріңіз немесе оны сіздің жобаңыздан ажыратыңыз (команда образ иесі болып табылатын жобада орындалады):

      ```console
      openstack image remove project <ОБРАЗ_ID> <ЖОБА_ID>
      ```

1. Осы образ негізінде жасалған ресурстардың бар-жоғын тексеріңіз:

   1. Образден жасалған дисктерді табыңыз. Бастапқы образ `volume_image_metadata` өрісінде көрсетілген:

      ```console
      openstack volume list
      openstack volume show <ДИСК_ID>
      ```

   1. Образден жасалған виртуалды машиналарды табыңыз:

      ```console
      openstack server list --long
      openstack server show <ВМ_ID>
      ```

   1. Егер тәуелді дисктер немесе ВМ табылса, алдымен оларды өшіріңіз немесе олардың өшірілуін күтіңіз, содан кейін әрекетті қайталаңыз:

      ```console
      openstack image delete <ОБРАЗ_ID>
      ```

1. Егер образ қолданылмайтын болса және сіздің жобаңызға тиесілі болса, бірақ қате сақталса, [техникалық қолдауға](/kz/contacts) жүгініп, образ ID-сын көрсетіңіз.
