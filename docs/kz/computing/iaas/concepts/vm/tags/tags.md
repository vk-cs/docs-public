# {heading(Тегтер)[id=iaas-tags]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Тег — {var(cloud)} ішіндегі виртуалды машиналаларды жіктеуге мүмкіндік беретін жол. Тегтер ВМ-ді топтастыруға мүмкіндік береді, мысалы орта бойынша, команда бойынша немесе мақсаты бойынша, және {linkto(../../../../../computing/iaas/instructions/vm/vm-filter#iaas-vm-filter)[text=сүзгілеу]} кезінде керектілерін тезірек табуға болады.

Сіз виртуалды машинаға тегті {linkto(../../../../../computing/iaas/instructions/vm/vm-manage#iaas-vm-manage-tags)[text=тағайындай]} аласыз, оның атауы мен түсін көрсете отырып. OpenStack CLI-да тег `<АТАУ>^<ТҮС>` пішімінде болады, мысалы `env:prod^positive`. Түс келесі мәндердің бірімен беріледі:

- `validation` — күлгін;
- `negative` — қызыл;
- `positive` — жасыл;
- `neutral` — сұр;
- `info` — көк;
- `light` — ақ;
- `warning` — қызғылт сары.

Тегтерге шектеулер қолданылады:

- тег бос бола алмайды;
- бір тегтің ең көп ұзындығы — 60 таңба, түс белгілеуін қоса алғанда;
- `/` және `,` таңбаларына тыйым салынады;
- бір ВМ-де 50-ден аспайтын тег болуы мүмкін;
- тегтер регистрге сезімтал: мысалы, `Prod` және `prod` — әртүрлі тегтер.
