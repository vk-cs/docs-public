# {heading(Қолданба бэкендіне қосу)[id=captcha-connect-backend]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

1. Сервисіңіздің бэкендінен капча-сессияны құруға арналған VK Капча API-сіне сұрау жіберіңіз. Ол үшін {linkto(../../../../tools-for-using-services/api/api-spec/captcha-api#api-spec-captcha)[text=GET /captchaNotRobot.createSession]} әдісін пайдаланыңыз.

   Әдіс жауапта қолданбаңыздың фронтендінде виджетті іске қосуға арналған сілтемені қайтарады (`link` параметрі).

1. Капча виджетін іске қосуға арналған алынған сілтемені сервисіңіздің фронтендіне жіберіңіз.

1. Сервисіңіздің фронтендінен капчаны сәтті өткендігінің `success_token` токенін алыңыз.

1. Сервисіңіздің бэкендінен капчаны сәтті өткендігінің `success_token` токенін валидациялауға арналған VK Капча API-сіне сұрау жіберіңіз. Ол үшін {linkto(../../../../tools-for-using-services/api/api-spec/captcha-api#api-spec-captcha)[text=GET /captchaNotRobot.validate]} әдісін пайдаланыңыз.

   Әдіс жауапта капчаны өткендігінің статусын қайтарады (`status` параметрі).

1. Токен валидті болса, пайдаланушы әрекетін өңдеңіз.
