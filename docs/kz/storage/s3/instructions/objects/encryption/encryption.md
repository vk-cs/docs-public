# {heading(Объекттерді шифрлау)[id=s3-instructions-encryption]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

{var(s3)} қызметінде объекттерді екі режимде шифрлау мүмкіндігі бар:

- Сервер жағындағы шифрлау (Server-side encryption, SSE), кілттерді басқару мүмкіндігінсіз (SSE-E).
- Клиент басқаратын кілттермен шифрлау (SSE-C).

{note:warn}
Шифрлау параметрлеріне қарамастан, өлшемі 21 байттан аз объекттер шифрланбаған күйде сақталады.
{/note}

## {heading(Сервер жағындағы шифрлау)[id=s3-instructions-encryption-server]}

SSE-E Envelope Encryption схемасы бойынша орындалады. Әр объект шифрлау кілттерін басқару қызметі (Key Management Service, KMS) арқылы бірегей кілтпен шифрланады. {var(s3)} қызметінде KMS ретінде Hashicorp Vault қолданылады. Қосымша қорғаныс ретінде SSE кілтті үнемі ауыстыратын түбір кілт көмегімен шифрлайды. Деректерді шифрлау үшін 256 биттік Advanced Encryption Standard (AES-256) қолданылады.

Объекттер бакетке сақтауға дейін шифрланады және одан жүктіп алу кезінде шифры ашылады. Сервер жағындағы шифрлау екі типті шифрлауды қамтиды:

- Бакеттің әдепкі шифрлауы. Объектіні жүктеу және жүктіп алу тақырыптарын көрсетпей орындалады. Шифрлау барлық жаңа объектілерге қолданылады, ал бұрын жүктелген объекттер өзгеріссіз қалады. Бакеттің шифрлауын өшіру кезінде тиісінше: барлық жаңа объекттер шифрланбай жүктеледі.
- Шифрланбаған бакетке жүктелетін объектіні шифрлау. Объектіні жүктеу кезінде `x-amz-server-side-encryption` тақырыбын көрсетіңіз: AES-256. Объектіні жүктіп алу кезінде бұл тақырып көрсетілмейді.

Бакеттің әдепкі шифрлауын орнату үшін команда орындаңыз:

```console
aws s3api put-bucket-encryption \
   --bucket <БАКЕТ_АТЫ> \
   --endpoint-url=<ҚЫЗМЕТ_URL_МЕНҚАЙРАТЫ> \
   --server-side-encryption-configuration '{
      "Rules": [
         {
         "ApplyServerSideEncryptionByDefault": {
  	        "SSEAlgorithm": "AES256"}}]}'
```

Бакеттің шифрлауын жою үшін команда орындаңыз:

```console
aws s3api delete-bucket-encryption \
   --bucket <БАКЕТ_АТЫ> \
   --endpoint-url=<ҚЫЗМЕТ_URL_МЕНҚАЙРАТЫ>
```

Бакеттің шифрлау конфигурациясын алу үшін команда орындаңыз:

```console
aws s3api get-bucket-encryption \
   --bucket <БАКЕТ_АТЫ> \
   --endpoint-url=<ҚЫЗМЕТ_URL_МЕНҚАЙРАТЫ>
```

Шығу мысалы:

```console
{
   "ServerSideEncryptionConfiguration": {
      "Rules": [
         {
            "ApplyServerSideEncryptionByDefault": {
               "SSEAlgorithm": "AES256"
            }
         }
      ]
   }
}
```

## {heading(Пайдаланушы басқаратын кілттермен шифрлау)[id=s3-instructions-encryption-key]}

SSE-C шифрлауы пайдаланушы ұсынған кілтпен орындалады. Кілт объектіні шифрлау және шифрын ашу үшін ғана қолданылады. Сұраудан кейін кілт жойылады және объектінің метадеректерінде сақталмайды. Шифрлау кілті API арқылы сұрау кезінде көрсетіледі.

Пайдаланушы кілттерімен шифрлауды қолдану үшін:

1. AES-256 алгоритмімен шифрлау кілтін генерациялаңыз. Ол үшін MD5 хешін есептеңіз.
1. Объектіні жүктеп, кілт пен хешті Base64 түрінде кодтап, тақырыптарда беріңіз:

   - `x-amz-server-side-encryption-customer-key`.
   - `x-amz-server-side-encryption-customer-key-MD5`.
   - `x-amz-server-side-encryption-customer-algorithm: AES256`.
