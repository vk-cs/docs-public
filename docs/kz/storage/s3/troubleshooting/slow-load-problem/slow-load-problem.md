# {heading(Үлкен файлдарды AWS CLI арқылы баяу жүктеу)[id=s3-slow-load-problem]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

100 МБ-тан үлкен файлдарды AWS CLI арқылы жүктеу интернет-каналдың өткізу қабілеттілігінен едәуір төмен жылдамдықпен жүреді.

Файлдарды бір TCP-қосылу арқылы беру кезінде мәселе желінің жоғары кешігуі (latency) себебінен туындауы мүмкін. Интернет-каналдың өткізу қабілеттілігін толық пайдалану үшін файлды бір уақытта бірнеше ағынмен жүктеңіз. Ол үшін {linkto(../../concepts/features#s3-concepts-features-object-uploading)[text=құрамдас жүктеуді]} пайдаланып, сіздің жағдайыңызға ең қолайлы бір уақытта жүктелетін файл бөліктерінің саны мен олардың өлшемін таңдаңыз:

- Әр бөліктің өлшемін арттыру API-сұраныстарының жалпы санын және қызметтік трафикті азайтады, бұл жалпы трафик көлемін қысқартады.
- Параллель жүктелетін бөліктер санын арттыру файлды жүктеудің жалпы уақытын қысқартады. Алайда бұл тәсіл сіздің процессорыңыздың қуатымен және интернет-каналдың өткізу қабілеттілігімен шектеледі.

### {heading(Шешім)[id=s3-slow-load-problem-resolve]}

1. Бакетке объекттерді AWS CLI арқылы жүктеу үшін `aws s3api put-object` емес, `aws s3 cp` командасы қолданылатынына көз жеткізіңіз. `aws s3 cp` командасы өлшемі `multipart_threshold` параметрінің мәнінен асатын (әдепкі бойынша 8 МБ) объекттер үшін құрамдас жүктеуді автоматты түрде қолданады.

1. Құрамдас жүктеу параметрлерін оңтайландырыңыз:

   ```console
   aws configure set default.s3.<ИМЯ_ПАРАМЕТРА> <ЗНАЧЕНИЕ>
   ```

   Мұнда:

   - `<ИМЯ_ПАРАМЕТРА>` — құрамдас жүктеу параметрінің атауы:

     - `multipart_threshold`: құрамдас жүктеу үшін қажетті файлдың ең аз өлшемі (әдепкі бойынша 8 МБ).
     - `multipart_chunksize`: құрамдас жүктеу кезіндегі файл бөліктерінің өлшемі (әдепкі бойынша 8 МБ).
     - `max_concurrent_requests`: параллель жүктелетін файл бөліктерінің саны (әдепкі бойынша 10).

   - `<ЗНАЧЕНИЕ>` — құрамдас жүктеу параметрінің жаңа мәні.

   {cut(Командалар мысалдары)}

   ```console
   aws configure set default.s3.multipart_chunksize 16MB
   ```

   ```console
   aws configure set default.s3.max_concurrent_requests 20
   ```

   {/cut}

   {note:warn}
   Объект бөліктерінің ең көп саны — 10000. `multipart_chunksize` параметрінің мәнін таңдағанда ең үлкен файл үшін бөліктердің жалпы саны осы шектен аспайтынына көз жеткізіңіз.
   {/note}
