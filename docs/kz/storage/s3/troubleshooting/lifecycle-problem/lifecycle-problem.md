# {heading(Өмірлік цикл ережелері қолданылмайды)[id=s3-lifecycle-problem]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Нысандарды автоматты түрде жоюға арналған {linkto(../../concepts/lifecycle#s3-concepts-lifecycle)[text=өмірлік цикл]} ережелері бапталған, бірақ белгіленген мерзім біткеннен кейін нысандар жойылмайды.

Бұл мәселе ережелерде көрсетілген нысан кілтінде қате болған жағдайда орын алуы мүмкін.

### {heading(Шешу)[id=s3-lifecycle-problem-resolve]}

1. Ережеде көрсетілген {linkto(../../concepts/about#s3-concepts-about-object-key)[text=нысан кілті]} бакеттегі нысан кілтіне дәл (регистрді ескере отырып) сәйкес келетінін тексеріңіз.
1. Нысан кілті дұрыс көрсетілген болса, ереже қолданылғанша 24–48 сағат күтіңіз. Мұндай кешігу — қызметтің қалыпты жұмысы, қате емес.
1. Мәселе сақталса, [техникалық қолдау көрсету қызметіне](/kz/contacts) хабарласыңыз.
