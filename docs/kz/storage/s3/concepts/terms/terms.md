|===
|Жиыртылған атау
|Толық атауы

|ACL
|Access Control List — объектке кім немесе не қол жеткізе алатынын және субъектіге қандай операцияларды орындауға рұқсат етілгеніне немесе тыйым салынғанына анықтама беретін қолжетімділікті басқару тізімі

|API
|Application Programming Interface — қосымшаның бағдарламалық интерфейсі. Бір компьютер бағдарламасының басқа бағдарламамен өзара әрекеттесу тәсілдерінің (сыныптардың, процедуралардың, функциялардың, құрылымдардың немесе константалардың жиынтығы) сипаттамасы

|AWS
|Amazon Web Services — Amazon Simple Storage Service (Amazon S3) объектілерін сақтау сервисін ұсынатын бұлттық объектілік жад

|AWS CLI
|AWS командалық жол интерфейсі. {var(s3)} сервистерін басқару үшін қолданылады

|JavaScript
|Мультипарадигмалы бағдарламалау тілі. Объектіге бағытталған, императивтік және функционалдық стильдерді қолдайды

|JSON
|JavaScript Object Notation — JavaScript негізінде жасалған деректер алмасудың мәтіндік пішімі

|HashiCorp Vault
|Құпиясөздер сияқты әртүрлі құпияларды қауіпсіз сақтауды және оларға қолжетімділікті қамтамасыз ететін құрал

|IAM
|Веб-интерфейс (Web UI) арқылы әкімшілік жүргізу құралы.

|KMS
|Key Management Service — шифрлау кілттерін орталықтандырылған басқару қызметі. {var(s3)} үшін KMS ретінде Hashicorp Vault қолданылады

|S3
|Simple Storage Service. Объектілерді сақтау сервисі

|SSE
|Server-side encryption, сервер жағындағы шифрлау. {var(s3)} әрбір объектісі KMS (SSE-E) көмегімен немесе пайдаланушы ұсынған кілтпен (SSE-C) бірегей кілтпен шифрланады

|URL
|Uniform Resource Locator, ресурстың бірыңғай көрсеткіші — электрондық ресурстардың бірыңғай адресдер жүйесі немесе ресурс орналасқан жердің бірыңғай анықтағышы. Интернеттегі объектілерге сілтемелерді жазудың стандарты ретінде қолданылады

|ОС
|Операциялық жүйе

|pub/sub
|Басушы-жазушы (publisher-subscriber) хабарламалардың жұмыс моделі

|push-модель
|Конфигурацияларда берілген шарттар орындалған кезде хабарламаларды бірден жіберу моделі

|SNS
|Simple Notification Service, көрсетілген URL-адрестерге (HTTP-сұраулар арқылы) хабарламаларды автоматты жіберу механизмі

|EventBridge
|Хабарламаларды жіберу сервисі
