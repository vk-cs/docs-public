# {heading(Объекттердің өмірлік циклі)[id=s3-concepts-lifecycle]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

{var(s3)} бакеттегі объекттердің өмірлік циклін (lifecycle) конфигурациялауға мүмкіндік береді. Өмірлік цикл — бакеттен объекттердің немесе олардың {linkto(../versioning#s3-concepts-versioning)[text=нұсқаларының]} белгіленген ережелер бойынша автоматтандырылған жойылуы.

Ережелер бір бакет деңгейінде белгіленеді. Бакеттер тобына немесе жобаға арналған өмірлік циклді конфигурациялау мүмкін емес.

Жеке кабинетте{ifdef(s3,s3-pdf)} IAM Only{/ifdef} өмірлік цикл ережелерін {linkto(../../instructions/manage-lifecycle#s3-instructions-manage-lifecycle)[text=басқару]} тек жекелей жүргізіледі. Бірнеше ережені бірден қосу, жою және өзгерту мыналар арқылы мүмкін:

- {linkto(../../connect/s3-cli#s3-connect-cli)[text=AWS CLI]} арқылы өмірлік циклдің {linkto(#s3-concepts-lifecycle-config)[text=JSON-конфигурациясы]} көмегімен.  
- {linkto(../../api/lifecycle#s3-api-lifecycle)[text=API]} арқылы XML-конфигурациясы көмегімен.

Өмірлік цикл ережелерін жасау ерекшеліктері:

- Конфигурацияда кемінде бір ереже болуы тиіс.
- Ереженің атауы (`ID` параметрі) — тек сандардан, латын әріптерінен және `_`, `.`, `-` таңбаларынан тұратын бірегей идентификатор.
- Әрбір өмірлік цикл ережесі мыналарды қамтиды:

  - Ережеге ілігетін объекттерді таңдауға арналған фильтр (`Filter` параметрі). Бір немесе екі түрлі фильтрацияны қамтуы мүмкін:

    - Объект {linkto(../about#s3-concepts-about-object-key)[text=кілтінің]} префиксі бойынша (`Prefix` параметрі). Префикс мысалдары: `image`, `image/`, `image/photo`.

      Бір ережеде тек бір префикс болуы мүмкін. Объекттерді бірнеше префикс бойынша фильтрлеу үшін әрбір префикске жеке ереже жасау қажет.

    - Объект {linkto(../features#s3-concepts-features-tagging)[text=тегтері]} бойынша (`Tag` немесе `Tags` параметрі).

  - Объекттің өмір сүру уақыты (`Expiration` параметрі). Объект қанша күннен кейін жойылатынын анықтайды.

- Сақтау шығындарын азайту үшін `AbortIncompleteMultipartUpload` параметрі арқылы аяқталмаған құрама жүктеулерді үзуді ұсынылады. Бұл параметр құрама жүктеу инициализациясынан кейін қанша күн өткен соң аяқталмаған жүктеу үзіліп, жүктелген бөліктер жойылатынын анықтайды.

- Ереже қосылғаннан кейін ол бакеттегі сәйкес объекттерге немесе объект нұсқаларына автоматты түрде қолданылады.

    Одан әрі объекттер фондық режимде жойылады: алдымен өмір сүру уақыты өткеннен кейін қолжетімсіз болады, содан кейін келесі 24 сағат ішінде кезек бойынша жойылады.

Шектеулер:

- Әрбір бакет үшін 50 ережеден аспайтын мөлшерде ереже белгілеуге болады.
- API арқылы ережелерді жасағанда ережелері бар XML-файлының өлшемі 512 КБ-тан аспауы тиіс.

Өмірлік цикл ережелері фондық режимде асинхронды жұмыс істейді және {var(s3)} қызметінің өнімділігіне әсер етпейді.

## {heading(Өмірлік цикл ережелерінің конфигурациясы)[id=s3-concepts-lifecycle-config]}

- `ID` — ереженің бірегей идентификаторы.
- `Status` — ереженің статусы. Мүмкін мәндері: `Enabled` — ереже қолданылады, `Disabled` — ереже қолданылмайды.

JSON-конфигурациясы үшін барлық ережелер `Rules[i]` элементтерінен тұратын `Rules` массиві (array) түрінде `object` форматында беріледі.

{note:warn}

{linkto(../../instructions/manage-lifecycle#s3-instructions-manage-lifecycle)[text=Орнату]} конфигурациясының үлгілерін қолданар алдында қажет:

- `Days`, `ExpiredObjectDeleteMarker` элементтерінен тұратын `Expiration` блогінде тек біреуін қалдырып, қалғанын өшіру;
- барлық `// <ТЕКСТ_КОММЕНТАРИЯ>` комментарийлерін өшіру;
- өрістерді қажетті мәндермен толтыру;
- версионирленген жоқ бакет болса, `NoncurrentVersionExpiration` конфигурация элементін өшіру.

Әйтпесе, AWS CLI командасын орындау қатеге ұшырауы мүмкін.

{/note}

{cut(Префикс пен бірнеше тегі бар конфигурация үлгісі JSON форматында)}

```json
{
  "Rules": [
    {
      "ID": "Object expiration rule",
      "Status": "Enabled",
      "Expiration": {
        "Days": 1,                                       // ExpiredObjectDeleteMarker орнына көрсетіледі
        "ExpiredObjectDeleteMarker": true                // Days орнына көрсетіледі (тек версионирленген бакеттер үшін)
      },
      "ID": "string",
      "Status": "Enabled",
      "Filter": {
        "And": {
          "Prefix": "string",
          "Tags": [
            { "Key": "tagKey1", "Value": "tagValue1" },
            { "Key": "tagKey2", "Value": "tagValue2" },
            { "Key": "tagKey3", "Value": "tagValue3" }
          ]
        }
      },
      "NoncurrentVersionExpiration": {                   // Тек версионирленген бакеттер үшін
        "NoncurrentDays": 30,
        "NewerNoncurrentVersions": 50
      },
      "AbortIncompleteMultipartUpload": {                // Аяқталмаған құрамдас жүктеулерді үзу
        "DaysAfterInitiation": 7
      }
    }
  ]
}
```

|`Expiration`
|Объектінің өмір сүру мерзімі. Объектінің ағымдағы нұсқасына, {linkto(../versioning#s3-concepts-versioning-status)[text=версионирлеу статусына]} және {linkto(../versioning#s3-concepts-versioning-delete-marker)[text=өшіру маркерінің]} болуына байланысты бұл мерзім біткеннен кейін объектіге әрекеттердің бірі қолданылады.

Версионирлеуі өшірілген бакет үшін объект қайтарылмайтын түрде өшіріледі.

Версионирлеуі қосылған бакет үшін.

- Ағымдағы нұсқа өшіру маркері емес — өшіру маркері жасалады және ағымдағы нұсқаға айналады.
- Ағымдағы нұсқа өшіру маркері — ештеңе болмайды. Алайда басқа нұсқалар жоқ болып, `Days` орнына `ExpiredObjectDeleteMarker` қолданылса, өшіру маркері өшіріледі.

Версионирлеуі тоқтатылған бакет үшін.

- `null` — жалғыз нұсқа: `null` нұсқасы өшіріледі.
- Нұсқалар бірнеше және ағымдағы — `null`: `null` нұсқасы өшіріледі. `null` нұсқасы өшірілгеннен кейін объектінің басқа нұсқалары қалса, `null` нұсқасы бар өшіру маркері жасалады.
- Нұсқалар бірнеше және ағымдағы `null` емес: тек `null` нұсқасы бар өшіру маркері жасалады.
- Ағымдағы нұсқа өшіру маркері — ештеңе болмайды. Алайда басқа нұсқалар жоқ болып, `Days` орнына `ExpiredObjectDeleteMarker` қолданылса, өшіру маркері өшіріледі.

`Days` немесе `ExpiredObjectDeleteMarker` конфигурация элементтері арқылы беріледі.

Форматы: `object`.

Толық жолы: `Rules[i]` → `Expiration`

|`Days`
|Бакетке жүктелгеннен кейінгі күндер саны.

`Rules[i]` → `Expiration` → `ExpiredObjectDeleteMarker` конфигурация элементімен үйлеспейді.

Форматы: `integer`.

Толық жолы: `Rules[i]` → `Expiration` → `Days`

|`ExpiredObjectDeleteMarker`

(тек версионирленген бакеттер үшін)
|Объектінің басқа нұсқалары қалмағанда, бакеттен объектінің өшіру маркерін өшіру қажет пе екенін анықтайтын опция.

Форматы: `boolean`, `true` мәнінде.

Толық жолы: `Rules[i]` → `Expiration` → `ExpiredObjectDeleteMarker`

|`ID`
|Ереженің бірегей идентификаторы.

Форматы: `string`.

Толық жолы: `Rules[i]` → `ID`

|`Status`
|Ереженің статусы.

Форматы: `string`.

Мүмкін мәндері:

- `Enabled` — ереже қолданылады;
- `Disabled` — ереже қолданылмайды.

Толық жолы: `Rules[i]` → `Status`

|`Filter`
|Ереже қолданылатын объектілер бойынша фильтр.

Форматы: `object`.

Толық жолы: `Rules[i]` → `Filter`

|`And`
|Бір ережеде префикс бойынша да, бірнеше тег бойынша да сүзгілеу қолданылған кезде қолданылатын конфигурация элементі.

Форматы: `object`.

Толық жолы: `Rules[i]` → `Filter` → `And`

|`Prefix`
|{linkto(../about#s3-concepts-about-object-key)[text=Объект кілтінің]} префиксі

Форматы: `string`.

Толық жолы: `Rules[i]` → `Filter` → `And` → `Prefix`

|`Tags`
|Массив (array) түріндегі объектінің {linkto(../features#s3-concepts-features-tagging)[text=тегтері]}. `Tags[i]` массивінің әрбір элементі `object` форматында болады және `Key` және `Value` кілт/мән жұптарын қамтиды.

Форматы: `array`.

Толық жолы: `Rules[i]` → `Filter` → `And` → `Tags`

|`Key`
|{linkto(../features#s3-concepts-features-tagging)[text=Тегтің]} кілті.

Форматы: `string`.

Толық жолы: `Rules[i]` → `Filter` → `And` → `Tags[i]` → `Key`

|`Value`
|{linkto(../features#s3-concepts-features-tagging)[text=Тегтің]} мәні.

Форматы: `string`.

Толық жолы: `Rules[i]` → `Filter` → `And` → `Tags[i]` → `Value`

|`NoncurrentVersionExpiration`

(тек версионирленген бакеттер үшін)
|Объектінің өткенге айналған нұсқаларын өшіру шарттары.

Форматы: `object`.

Толық жолы: `Rules[i]` → `NoncurrentVersionExpiration`

|`NoncurrentDays`

(тек версионирленген бакеттер үшін)
|Объектінің өткенге айналған нұсқасы сақталатын күндер саны, содан кейін бұл нұсқа өшіріледі.

`NewerNoncurrentVersions`-пен бірге қолданылса, өткенге айналған нұсқаны өшіру екі лимитке де жеткенде ғана орындалады.

Форматы: `integer`.

Толық жолы: `Rules[i]` → `NoncurrentVersionExpiration` → `NoncurrentDays`

|`NewerNoncurrentVersions`

(тек версионирленген бакеттер үшін)
|Сақталатын объектінің өткенге айналған нұсқаларының саны. Көрсетілген лимитке жеткенде, объектінің ескі нұсқалары автоматты түрде өшіріледі.

`NoncurrentDays`-пен бірге қолданылса, өткенге айналған нұсқаны өшіру екі лимитке де жеткенде ғана орындалады.

Форматы: `integer`, бірақ 100-ден аспайды.

Толық жолы: `Rules[i]` → `NoncurrentVersionExpiration` → `NewerNoncurrentVersions`

|`AbortIncompleteMultipartUpload`
|Аяқталмаған құрамдас жүктеулерді үзу шарттары.

- Құрамдас жүктеу инициализацияланғаннан кейінгі `DaysAfterInitiation`-де көрсетілген күндер саны ішінде аяқталмаса, {var(s3)} құрамдас жүктеуді үзіп, оған байланысты жүктелген барлық бөліктерді өшіреді.
- Құрамдас жүктеу көрсетілген күндер саны ішінде аяқталса, бұл ереже бойынша ешқандай әрекет орындалмайды.

Ереже барлық аяқталмаған жүктеулерге, оның ішінде бұрыннан бар жүктеулерге де қолданылады. `AbortIncompleteMultipartUpload` объектілерді өшірмейді, тек жүктелетін объектінің аяқталмаған бөліктерін өшіреді.

Форматы: `object`.

Толық жолы: `Rules[i]` → `AbortIncompleteMultipartUpload`

|`DaysAfterInitiation`
|Құрамдас жүктеу инициализацияланғаннан кейінгі күндер саны, ол өткеннен кейін аяқталмаған жүктеу үзіледі.

Форматы: `integer`.

Толық жолы: `Rules[i]` → `AbortIncompleteMultipartUpload` → `DaysAfterInitiation`

|`Expiration`
|Объектінің өмір сүру мерзімі. Объектінің ағымдағы нұсқасына, {linkto(../versioning#s3-concepts-versioning-status)[text=версионирлеу статусына]} және {linkto(../versioning#s3-concepts-versioning-delete-marker)[text=өшіру маркерінің]} болуына байланысты бұл мерзім біткеннен кейін объектіге әрекеттердің бірі қолданылады.

Версионирлеуі өшірілген бакет үшін объект қайтарылмайтын түрде өшіріледі.

Версионирлеуі қосылған бакет үшін.

- Ағымдағы нұсқа өшіру маркері емес — өшіру маркері жасалады және ағымдағы нұсқаға айналады.
- Ағымдағы нұсқа өшіру маркері — ештеңе болмайды. Алайда басқа нұсқалар жоқ болып, `Days` орнына `ExpiredObjectDeleteMarker` қолданылса, өшіру маркері өшіріледі.

Версионирлеуі тоқтатылған бакет үшін.

- `null` — жалғыз нұсқа: `null` нұсқасы өшіріледі.
- Нұсқалар бірнеше және ағымдағы — `null`: `null` нұсқасы өшіріледі. `null` нұсқасы өшірілгеннен кейін объектінің басқа нұсқалары қалса, `null` нұсқасы бар өшіру маркері жасалады.
