# {heading(Домендер аралық сұраулар (CORS))[id=s3-concepts-cors]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

CORS (Cross-Origin Resource Sharing) — домендер аралық сұрауларды өңдеу ережелерін белгілеуге мүмкіндік беретін механизм. Әдепкі бойынша браузерлер бір доменде орналасқан веб-қосымша басқа доменде орналасқан дереккөз үшін API шақырған жағдайда қолжетімділікті блоктайды. Бұл ресурстарға рұқсатсыз қолжетімділікті болдырмау үшін жасалады. {var(s3)} сервисінде CORS қолдауының арқасында сіз бұл шектеуді айналып өтіп, басқа домендерде орналасқан клиенттік веб-қосымшалар үшін бакеттеріңізге қолжетімділікті таңдамалы түрде рұқсат ете аласыз.

Бакет үшін CORS механизмін қосуға екі тәсіл бар:

- Жеке кабинетте әрбір CORS ережесін бөлек {linkto(../../../instructions/access-management/cors#s3-instructions-cors-add)[text=белгілеу]}.
- API көмегімен барлық CORS ережелерінің XML-конфигурациясын бір мезгілде {linkto(../../../api/cors#api-spec-s3-cors-request-body)[text=жүктеу]}.

{note:warn}
Екінші тәсілді қолданған кезде бар CORS конфигурациясы қайта жазылады. Бұл дегеніміз, бұрын жеке кабинетте қосылған ережелер жоғалатынын білдіреді.
{/note}

Әрбір бакет үшін мына параметрлер көрсетілетін өз CORS ережелері бапталады:

- `AllowedOrigins` — бакетке сұраулар жасауға рұқсат етілген домендер.
- `AllowedMethods` — сұрауларда рұқсат етілген HTTP-әдістер.
- (Міндетті емес) `MaxAgeSeconds` — пайдаланушы браузерінің {linkto(#s3-concepts-cors-request)[text=алдын ала сұрауының]} нәтижелерін кеште сақтай алатын уақыты, секундпен.
- (Міндетті емес) `AllowedHeaders` — сұрауларда рұқсат етілген тақырыптар.
- (Міндетті емес) `ExposeHeaders` — сұрауға жауапта пайдаланушыға қолжетімді болатын тақырыптар.

## {heading(CORS-сұрауларының ерекшеліктері)[id=s3-concepts-cors-request]}

CORS-сұрауы — `Origin` тақырыбын қамтитын HTTP-сұрау. Бұл тақырыпта сұрау инициаторының домені көрсетіледі. Егер CORS-сұрауы деректерді өзгертуге әкелуі мүмкін болса, ол қауіпсіз емес деп қаралып, екі кезеңде орындалады:

- Сұралатын ресурс үшін CORS шектеулерін тексеретін алдын ала сұрау (preflight request).
- Ресурсты алуға бағытталған негізгі сұрау.

Алдын ала сұрау `OPTIONS` әдісін қолданады және негізгі сұраудың параметрлерін қамтиды: тақырыптар, HTTP-әдіс және домен (`Origin`).

{var(s3)} браузерден алдын ала сұрауды алғанда, ол сұралатын бакет үшін CORS конфигурациясын талдап, сұрауды қабылдауы немесе қабылдамауы мүмкін. Сұраудың қабылдануы үшін мына шарттар орындалуы тиіс:

- `Origin` тақырыбында көрсетілген домен бакеттің CORS конфигурациясындағы `AllowedOrigins` тізіміне кіруі тиіс.
- Сұрауда көрсетілген HTTP әдісі бакеттің CORS конфигурациясындағы `AllowedMethods` тізіміне кіруі тиіс.
- Сұрауда көрсетілген тақырыптар бакеттің CORS конфигурациясындағы `AllowedHeaders` тізіміндегі тақырыптарға сәйкес келуі тиіс.

Егер алдын ала сұрау қабылданбаса, браузер негізгі сұрауды жіберуін блоктайды.

Егер алдын ала сұрау қабылданса, {var(s3)} бакеттің CORS конфигурациясы туралы ақпаратты қайтарады. Браузер бұл ақпаратты CORS конфигурациясындағы `MaxAgeSeconds` параметрінде көрсетілген кезең ішінде кеште сақтай алады.

Алдын ала сұрауға жауаптарды кештеу {var(s3)} жұмыс істеу өнімділігін айтарлықтай жақсартады, өйткені қажетті сұраулар санын азайтады. Соның өзіне бірдей бакетке қайталанған сұрау кезінде бакеттің CORS конфигурациясы туралы деректер браузер кешінде болса, алдын ала сұрау қажет болмайды.
