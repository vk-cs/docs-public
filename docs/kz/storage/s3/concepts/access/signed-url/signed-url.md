# {heading(Қол қойылған URL арқылы кіру)[id=s3-concepts-signed-url]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Әдепкі бойынша жобадағы барлық объектілер мен бакеттер жекеменшік болып табылады. Алайда сіз басқа пайдаланушыларға бакеттен объектілерді жүктеп алуға немесе оған жүктеп салуға рұқсат беруге болады, алдын ала қол қойылған URL-мекенжай жасау арқылы. Онда көрсетіледі:

- Публикалық қол жеткізу кілті. Мысалы, {var(s3)} аккаунтына байланыстырылған {linkto(../../access/account-and-keys#s3-concepts-account-and-keys-access-keys)[text=публикалық қол жеткізу кілті]} немесе {linkto(../../access/account-and-keys#s3-concepts-account-and-keys-bucket-access-keys)[text=бакеттің қол жеткізу кілті]}.
- Бакет атауы.
- Объект кілті.
- URL-мекенжайдың жарамдылық мерзімі.
- Құпия қол жеткізу кілтімен шифрланған қолтаңба.

{note:info}
Әдепкі бойынша алдын ала қол қойылған URL-мекенжай онда көрсетілген объектіні жүктеп алуға мүмкіндік береді. Сондай-ақ объектілерді бакетке жүктеп салуға арналған URL-мекенжайлар жасауға болады. Толығырақ — [Amazon AWS ресми құжаттамасында](https://docs.amazonaws.cn/en_us/AmazonS3/latest/userguide/PresignedUrlUploadObject.html).
{/note}

Қол қойылған URL-мекенжайы бар кез келген адам онда көрсетілген объектіге кіруге қол жеткізеді. Мұның үшін авторизация қажет емес. Қол қойылған URL-мекенжайды бірнеше рет пайдалануға болады, бірақ тек онда көрсетілген жарамдылық мерзімі ішінде.

Қол қойылған URL-мекенжайдың мүмкіндіктері оны қол қойған адамның құқықтарымен шектеледі. Мысалы, егер осы URL-мекенжай қол қойылған кілті бар {var(s3)} аккаунты жойылса, URL-мекенжай жұмысын тоқтатады.

{cut(Қол қойылған URL-ді жалпы түрі)}

```console
https://hb.ru-msk.vkcloud-storage.ru/<БАКЕТ_АТАУЫ>/<ОБЪЕКТ_КІЛТІ>?
     X-Amz-Algorithm=<АЛГОРИТМ>
    &X-Amz-Expires=<ЖАРАМДЫЛЫҚ_УАҚЫТЫ>
    &X-Amz-SignedHeaders=<ТАҚЫРЫПША_ТІЗІМІ>
    &X-Amz-Date=<КҮН_ЖӘНЕ_УАҚЫТ>
    &X-Amz-Credential=<ҚОЛ_ЖЕТКІЗУ_КІЛТІ>/<YYYYMMDD>/ru-msk/s3/aws4_request
    &X-Amz-Signature=<ҚОЛТАҢБА>
```

Мұнда:

- `<ОБЪЕКТ_КІЛТІ>` — қол жеткізу берілген объектінің кілті.
- `<БАКЕТ_АТАУЫ>` — объект орналасқан бакеттің атауы.
- `<АЛГОРИТМ>` — қолтаңба нұсқасы және оны есептеу алгоритмі, мысалы `AWS4-HMAC-SHA256`.
- `<ЖАРАМДЫЛЫҚ_УАҚЫТЫ>` — URL-мекенжайдың жарамдылық уақыты секундпен. `X-Amz-Date` тақырыпшасында көрсетілген сәттен бастап есептеледі. Максимальді мәні — 604800 секунд (7 тәулік).
- `<ТАҚЫРЫПША_ТІЗІМІ>` — сұраныстың қол қойылатын тақырыпшаларының тізімі. Тақырыпшалар `;` таңбасымен бөлінеді. `Host` тақырыпшасы және сұраныста қолданылатын барлық `X-Amz-*` тақырыпшалары міндетті түрде қол қойылуы керек.
- `<КҮН_ЖӘНЕ_УАҚЫТ>` — URL-мекенжайдың жарамдылық мерзімі бітетін күн мен уақыт ISO8601 форматында, мысалы `20180719T000000Z`. Күн `X-Amz-Credential` тақырыпшасындағы күнмен мәні бойынша сәйкес болуы керек.
- `<ҚОЛ_ЖЕТКІЗУ_КІЛТІ>` — Access Key ID, қол жеткізу кілтінің идентификаторы.
- `<YYYYMMDD>` — `X-Amz-Credential` тақырыпшасына қоюға арналған `YYYYMMDD` форматындағы күн. `X-Amz-Date` тақырыпшасында орнатылған күнмен мәні бойынша сәйкес болуы керек.  
- `<ҚОЛТАҢБА>` — сұраныстың қолтаңбасы. Сұраныс құпия қол жеткізу кілтімен қол қойылады.

{/cut}
