# {heading(Кіруге басқару (ACL))[id=s3-concepts-acl]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

{var(s3)} сервисіндегі ACL (Access Control List, қолжетімділікті басқару тізімі) қойманың қандай есептік жазбаларына немесе топтарына бакетке немесе объектіге қолжетімділік берілетінін анықтайды. Әр бакетте немесе объектіде өз ACL-і бар, ол 100 элементке дейін қамтуы мүмкін. Әр элементте {linkto(#s3-concepts-acl-permittees)[text=құқық алушы]} және оған берілетін {linkto(#s3-concepts-acl-permissions)[text=рұқсат түрі]} көрсетіледі. Бакетке немесе объектіге сұрау түскен кезде {var(s3)} тиісті ACL-дерде сұрауды жіберушіде қажетті құқықтардың бар-жоғын тексереді.

{var(s3)} сервисі {linkto(#s3-concepts-acl-pre-set)[text=стандартты ACL]} жиынтығын — алдын ала дайындалған құқық алушылар тізімін және оларға тағайындалған рұқсаттарды қолдайды. Бакет жасағанда {var(s3)} әдепкі бойынша `private` стандартты ACL қолданылады. Бұл ACL бакет иесіне оған толық басқару құқығын береді және қалған пайдаланушыларға кіруге тыйым салады.

Объектінің ACL тағайындалуы мүмкін:

- Жеке кабинет арқылы бакетке жаңа объект жүктегенде сіз оған {linkto(#s3-concepts-acl-pre-set)[text=стандартты ACL]}-нің бірін таңдайсыз.
- API көмегімен жүктегенде объектінің ACL-ін сұраудың денесінде немесе тақырыптарында көрсетуге болады.

ACL көрсетілмесе, жаңа бакетке немесе объектіге максималды шектеулі кіруге бар `private` стандартты ACL тағайындалады: бакет жасағанда кіруге тек бакет иесі алады, объект қосқанда кіруге тек объект иесі алады.

Кейіннен бакет немесе объект үшін ACL өзгертуге болады. Бакеттің және оның ішіндегі объектінің ACL-і әртүрлі болуы мүмкін.

ACL параметрлері {linkto(../../../instructions/access-management/acl#s3-instructions-acl)[text=берілуі]} мына форматтағы {linkto(../../../api/acl#api-spec-s3-acl-request-body)[text=конфигурация]} арқылы берілуі мүмкін:

- XML, API арқылы сұрау жібергенде;
- JSON, AWS CLI қолданылғанда.

## {heading(Құқық алушылар)[id=s3-concepts-acl-permittees]}

Бакеттерге және объектілерге кіру құқықтары келесі құқық алушылар категорияларына берілуі мүмкін:

- {ifdef(public)}{var(cloud)}{/ifdef}{ifdef(s3,s3-pdf)}IAM Only{/ifdef} жобасы.
- Алдын ала анықталған метатоптар:

    - `AuthenticatedUsers` — кез келген {ifdef(public)}{var(cloud)}{/ifdef}{ifdef(s3,s3-pdf)}IAM Only{/ifdef} жобасындағы {var(s3)}-нің барлық тіркелгілері.
    - `AllUsers` — кез келген анонимді пайдаланушы, соның ішінде {var(s3)}{ifdef(public)} және {var(cloud)}{/ifdef} пайдаланушысы емес те.

{note:warn}
Метатоптарды тек қажет болған жағдайда ғана қолданыңыз.

Бакетке және ондағы объектілерге анықталмаған адамдар шеңберіне кіруге рұқсат ашқанда, сіз осы ресурстармен жасалатын операцияларды{ifdef(public)}, ақылы операцияларды да қоса, бақылай алмайсыз. Бакетпен жасалатын операциялардың ақысы оның иесіне тиесілі{/ifdef}.
{/note}

## {heading(Стандартты ACL)[id=s3-concepts-acl-pre-set]}

{var(s3)} алдын ала баптастырылған кіруге басқару тізімдерін — стандартты ACL-ді ұсынады. Бұл тізімдерді бакетке, объектіге немесе олардың ағымдағы ACL-іне кіруге арналған API-сұрауларда қолдануға болады.

Стандартты ACL сұрауда `x-amz-acl` HTTP-тақырыбы арқылы көрсетіледі. Тек бір стандартты ACL көрсетуге болады. {var(s3)} стандартты ACL бар сұрауды алғанда, ол алдын ала баптастырылған рұқсаттарды сәйкес бакеттің немесе объектінің ACL-іне қосады{ifdef(s3-pdf)}({linkto(#tab_acl)[text=%number кесте]}){/ifdef}.
