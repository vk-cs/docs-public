## {heading(Мүмкіндіктердің қысқаша сипаттамасы)[id=s3-index-description-of-features]}

{var(s3)} — бұл S3 протоколымен үйлесімді, қауіпсіз, сенімді және масштабталатын нысандық деректер қоймасын ұйымдастыруға арналған, тапсырыс берушінің өз деректер орталығында (әрі қарай — ДО) ұсынылатын аппараттық қуаттарға орнатылатын сервис (on-premises).

{var(s3)} әртүрлі типті нысандарды бөлек-бөлек сақтау мәселесін шешеді, сонымен қатар бір мезгілдегі өтініштер санына қарамастан кез келген типті нысандарды тарату жылдамдығының тұрақты болуы міндетін орындайды.
