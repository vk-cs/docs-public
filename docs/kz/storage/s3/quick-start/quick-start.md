# {heading(Жылдам бастау)[id=s3-quick-start]}

{include(/kz/_includes/_translated_by_ai_kz.md)}

Жылдам бастау қызметпен жұмысты бастауға және оның мүмкіндіктерімен танысуға көмектеседі.

Жылдам бастаудың барлық қадамдарын өткеннен кейін нысандарды бакетке жүктей аласыз және жүктелген нысандарға сілтеме арқылы қолжетімділік беруді үйренесіз.

{note:warn}
Бакетке жүктелген нысандар [тарифтеленеді](../tariffication). Жылдам бастаудан өткеннен кейін олар сізге қажет болмаса, {linkto(#delete_unused)[text=бұл нысандар мен бакетті өшіріңіз]}.
{/note}
